# スマホへの通知の設計

作成日: 2026-11-09
対象: [notify-phone.ps1](../../../.claude/scripts/notify-phone.ps1)・[settings.json](../../../.claude/settings.json) の Stop フック
経緯: [スマホへの通知の経緯](スマホへの通知の経緯.md)

Claude の返答が終わるたびに、スマホの ntfy アプリへ通知を送る仕組みです。

- **返答が終わるたびに送る。** PC の画面を見ているときも送る。
- **文面は返答の1行目**（最初の「。」まで）。だから Claude は、作業を終えたときの返答の1行目に「何が終わったか」を1文で書く。
- **トピック名はリポジトリに入れない**（公開リポジトリのため）。

---

## 1. 流れ

`.claude/settings.json` の Stop フック → `notify-phone.ps1` → ntfy.sh → スマホの ntfy アプリ。

| 項目 | 中身 |
|---|---|
| 文面 | その回の返答の1行目（最初の「。」まで） |
| 題名 | `フォルダー名（PC名）`。`Action-try` など別のフォルダーで動いている Claude と見分けるため |
| 送る時 | 返答が全部終わったとき。作業の途中では送らない |

Claude の PushNotification ツールは使いません。PC の画面を見ているときは送られないためです。

## 2. トピック名の置き場所

- 各PCの `%APPDATA%\claude-notify\ntfy-topic.txt` と、個人用 OneDrive の `01_ClaudeSessions/ntfy-topic.txt` に置く。
- 新しいPCでは、最初の通知のときに OneDrive から自動で取ってくる。
- ntfy.sh はトピック名を知っていれば誰でも読めるので、返答の1行目にパスワードや個人情報を書かない。

## 3. 使い方

- **トピック名を確かめる**: `powershell -ExecutionPolicy Bypass -File .claude\scripts\notify-phone.ps1 -Mode topic`
- **動作を確かめる**: ユーザーのトピックへは送らず、`-Topic` で使い捨てのトピックへ送り、`https://ntfy.sh/<トピック>/json?poll=1` で届いたかを見る。

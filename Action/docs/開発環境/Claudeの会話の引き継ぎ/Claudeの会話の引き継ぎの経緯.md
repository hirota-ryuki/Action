## 2026-11-05 会話ファイルを個人用 OneDrive へバックアップする

- 会話ファイルを rclone で個人用 OneDrive へコピーする仕組みを足した。会社用の OneDrive には置かないため、個人用 OneDrive のアプリにはサインインせず、rclone だけで送る。
- 保存先のフォルダ名を `01_ClaudeSessions` にした。

**用語:**

| 用語 | 何のことか |
|---|---|
| 個人用 OneDrive | 個人の Microsoft アカウントのクラウドの保存場所。会社用（学校法人河原学園）のものとは別 |

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 関数 | `rclone` | 会話ファイルを個人用 OneDrive へコピーするため | クラウドの保存場所とフォルダーの間で、ファイルをコピーするコマンド。ブラウザーで1回許可すると、アプリにサインインせずに送れる | 外部ツール（rclone。[claude-sessions.ps1](../../../../.claude/scripts/claude-sessions.ps1) の `-Mode setup` で `winget` から入れる） |

## 2026-11-15 アーカイブした会話を全PCで消せるようにする

- アーカイブした会話が、このPCで 86 件・約 515MB たまっていた。コピーは「新しい方で上書き」だけなので、1台で消しても次の pull で個人用 OneDrive から戻り、OneDrive から消してもほかのPCの push で送り戻される。
- そこで、アーカイブの記録と同じ作りで「消した記録」（PCごとのファイル）を個人用 OneDrive で共有し、pull・push・restore のたびに記録にある会話を消して、送受信の対象から外すようにした。
- 決めたこと: 消すのはアーカイブした会話の全部（日数で絞らない）。消すのは `delete-archived-sessions.cmd` を手で実行したときだけ。このPCに控えは残さず、OneDrive のごみ箱（約30日）だけで戻せるようにする。
- 確かめたこと:
  - 使い捨てのフォルダーで、rclone の `--exclude-from` と `delete --include-from` に `/<ID>.jsonl`・`/<ID>/**` を渡すと、その会話のファイルとフォルダーだけが外れる・消えることを見た。
  - `-DryRun` で、86 件・515.1MB が選ばれ、いま使っている会話は入らないことを見た。
  - 存在しない ID を1件だけ入れた試しの記録を置き、pull でその会話のファイルだけが消え、ほかの 94 件はそのままで、pull・push が終了コード 0 で終わることを見た。

**用語:**

| 用語 | 何のことか |
|---|---|
| pull・push | ここでは、個人用 OneDrive から取ってくること（pull）と、送ること（push）。Git の pull・push とは別 |
| 終了コード | プログラムが終わるときに返す数。0 は成功、0 以外は失敗 |
| `.jsonl` | 1行が1つの JSON のファイル。Claude の会話ファイル（`<会話のID>.jsonl`）の形式 |

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 引数 | `--exclude-from` | 消した会話を、送受信の対象から外すため | 外すファイルの名前の一覧を、ファイルで渡す。`rclone copy` に付ける | 外部ツール（rclone）のオプション |
| 引数 | `--include-from` | 消す会話だけを選ぶため | 対象にするファイルの名前の一覧を、ファイルで渡す。`rclone delete` に付ける | 外部ツール（rclone）のオプション |
| 引数 | `-DryRun` | 消す前に、何が消えるかを確かめるため | 付けると、消す会話を見せるだけで消さない | [claude-sessions.ps1](../../../../.claude/scripts/claude-sessions.ps1) の `param`（`[switch]`） |
| 値 | `/<ID>.jsonl`・`/<ID>/**` | 1つの会話のファイルとフォルダーだけを選ぶため | `<ID>.jsonl` と、同じ名前のフォルダーの中身すべて（`**`）に合うパターン | 外部ツール（rclone）のフィルターの書き方 |

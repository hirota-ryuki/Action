# スマホへの通知の経緯

設計: [スマホへの通知の設計](スマホへの通知の設計.md)

何をして、なぜ今の形になったかの記録です。日付ごとに書き足します。

---

## 2026-11-06 返答が終わるたびに ntfy でスマホへ通知する

- Claude の PushNotification ツールは PC の画面を見ているときに送られないので、Stop フックから ntfy.sh へ送る形にした。
- 通知の文面を、返答の1行目（何が終わったか）にした。
- 作業の途中で通知を送らない決まりにし、題名にフォルダー名を入れて、別のフォルダーで動いている Claude と見分けられるようにした。

**用語:**

| 用語 | 何のことか |
|---|---|
| ntfy（ntfy.sh） | 通知を送る無料の公開サービス（`https://ntfy.sh`）。決まった URL へ文字を送ると、その名前（トピック）を購読しているスマホのアプリに通知が出る |
| Stop フック | Claude が返答を終えたときに、設定したコマンドを自動で動かす仕組み。`.claude/settings.json` に書く |

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 値 | `PushNotification` | （使わない）Claude が自分で通知を送るため | Claude Code に入っている、通知を送るツール。PC の画面を見ているときは送られないので使わない | Claude Code のツール |

## 2026-11-09 説明を CLAUDE.md からこのページに移す

- CLAUDE.md を短くするため、仕組みの説明をこのページに移した。CLAUDE.md には、Claude がふるまいとして守ること（返答の1行目の書き方、途中で通知を送らない、確かめるときは使い捨てのトピック、PushNotification ツールを使わない）だけを残した。仕組みそのものは変えていない。

**用語:**

| 用語 | 何のことか |
|---|---|
| トピック | ntfy で、送り先と受け取り先をそろえる名前。トピック名を知っていれば、誰でも送れて、誰でも読める |

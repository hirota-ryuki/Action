# スマホへの通知の設計

作成日: 2026-11-09
対象: [notify-phone.ps1](../../../../.claude/scripts/notify-phone.ps1)・[settings.json](../../../../.claude/settings.json) の Stop フック
経緯: [スマホへの通知の経緯](スマホへの通知の経緯.md)

Claude の返答が終わるたびに、スマホの ntfy アプリへ通知を送る仕組みです。

- **返答が終わるたびに送る。** PC の画面を見ているときも送る。
- **文面は返答の1行目**（最初の「。」まで）。だから Claude は、作業を終えたときの返答の1行目に「何が終わったか」を1文で書く。
- **トピック名はリポジトリに入れない**（公開リポジトリのため）。

**用語:**（フックと `%APPDATA%` は[用語集](../../用語集.md#開発環境)にあります）

| 用語 | 何のことか |
|---|---|
| ntfy（ntfy.sh） | 通知を送る無料の公開サービス（`https://ntfy.sh`）。ユーザー登録なしで、決まった URL へ文字を送ると、その名前を購読しているスマホのアプリに通知が出る |
| トピック | ntfy で、送り先と受け取り先をそろえる名前。トピック名を知っていれば、誰でも送れて、誰でも読める |

---

## 1. 流れ

`.claude/settings.json` の Stop [フック](../../用語集.md#開発環境) → `notify-phone.ps1` → ntfy.sh → スマホの ntfy アプリ。

| 項目 | 中身 |
|---|---|
| 文面 | その回の返答の1行目（最初の「。」まで）。次の決まりで整える |
| 題名 | `フォルダー名（PC名）`。`Action-try` など別のフォルダーで動いている Claude と見分けるため |
| 送る時 | 返答が全部終わったとき。作業の途中では送らない |

`settings.json` の `Stop` には、会話の送信（[Claudeの会話の引き継ぎの設計](../Claudeの会話の引き継ぎ/Claudeの会話の引き継ぎの設計.md)）と並べて、通知のスクリプトを書いてあります。

```json
"Stop": [{ "hooks": [
  { "type": "command", "command": "powershell.exe -NoProfile -ExecutionPolicy Bypass -File \"$CLAUDE_PROJECT_DIR/.claude/scripts/claude-sessions.ps1\" -Mode push", "timeout": 120, "async": true },
  { "type": "command", "command": "powershell.exe -NoProfile -ExecutionPolicy Bypass -File \"$CLAUDE_PROJECT_DIR/.claude/scripts/notify-phone.ps1\"", "timeout": 30, "async": true }
] }]
```

文面を決める `Get-Headline` の決まりは次のとおりです。

- 空の行と、```（コードの囲み）の行は飛ばし、最初の文字がある行を使う。
- 行の頭の `#`・`-`・`1.` や、`**`・`` ` ``・リンクの記号は外す。
- 「。」がある（行の最後でない）ときは、最初の「。」まで。「。」が無い行は、行全体を使う。
- 120字を超えたら、119字で切って「…」を付ける。
- 返答が取れなかったときは「Claude の返答が終わりました」にする。

Claude の PushNotification ツールは使いません。PC の画面を見ているときは送られないためです。

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 値 | `Stop` | 返答が終わったときに通知を送るため | フックの種類の1つ。Claude が返答を終えたときに動く | Claude Code の設定（[settings.json](../../../../.claude/settings.json) の `hooks`） |
| 値 | `PushNotification` | （使わない）Claude が自分で通知を送るため | Claude Code に入っている、通知を送るツール。PC の画面を見ているときは送られないので使わない | Claude Code のツール |

## 2. トピック名の置き場所

- 各PCの `%APPDATA%\claude-notify\ntfy-topic.txt` と、個人用 OneDrive の `01_ClaudeSessions/ntfy-topic.txt` に置く。
- 新しいPCでは、最初の通知のときに OneDrive から自動で取ってくる。
- ntfy.sh はトピック名を知っていれば誰でも読めるので、返答の1行目にパスワードや個人情報を書かない。

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 値 | `ntfy-topic.txt` | トピック名を、PCと個人用 OneDrive に覚えておくため | トピック名だけを書いたテキストのファイル | 開発環境の [notify-phone.ps1](../../../../.claude/scripts/notify-phone.ps1) が作る |

## 3. 使い方

- **トピック名を確かめる**: `powershell -ExecutionPolicy Bypass -File .claude\scripts\notify-phone.ps1 -Mode topic`
- **動作を確かめる**: ユーザーのトピックへは送らず、`-Topic` で使い捨てのトピックへ送り、`https://ntfy.sh/<トピック>/json?poll=1` で届いたかを見る。

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 引数 | `-Mode` | 通知を送る動きと、トピック名を見る動きを切り替えるため | `notify`（通知を送る）か `topic`（トピック名を表示する）。省略すると `notify` | 開発環境の [notify-phone.ps1](../../../../.claude/scripts/notify-phone.ps1) の `param` |
| 引数 | `-Topic` | 送り先のトピックを一時的に変えるため | 付けると、保存してあるトピック名の代わりに、その名前へ送る。動作確認に使う | 開発環境の [notify-phone.ps1](../../../../.claude/scripts/notify-phone.ps1) の `param` |
| 引数 | `-ExecutionPolicy Bypass` | スクリプトを動かせるようにするため | PowerShell のスクリプトの実行を制限する設定を、今回だけ無視する | Windows の PowerShell（`powershell.exe`）のオプション |
| 引数 | `-File` | 動かすスクリプトを指すため | 指した `.ps1` のファイルを動かす | Windows の PowerShell（`powershell.exe`）のオプション |
| 値 | `json?poll=1` | 届いた通知を、あとから読むため | ntfy の URL の末尾に付けると、そのトピックに届いた通知を JSON で返し、待たずに終わる | 外部サービス（ntfy.sh） |

# Claudeの会話の引き継ぎの経緯

設計: [Claudeの会話の引き継ぎの設計](Claudeの会話の引き継ぎの設計.md)

何をして、なぜ今の形になったかの記録です。日付ごとに書き足します。

---

## 2026-11-05 会話ファイルを個人用 OneDrive へバックアップする

- 会話ファイルを rclone で個人用 OneDrive へコピーする仕組みを足した。会社用の OneDrive には置かないため、個人用 OneDrive のアプリにはサインインせず、rclone だけで送る。
- 保存先のフォルダ名を `01_ClaudeSessions` にした。

## 2026-11-06 別のPCで使っていた会話をタブで開き直す

- フォルダーを開いたときに、いちばん最近 Claude を使ったPCの記録から、会話をタブで開き直すようにした。

## 2026-11-07 アーカイブの状態をほかのPCに引き継ぐ（#55）

- アーカイブの状態は VSCode の保存領域にあり、VSCode が開いている間は拡張に上書きされるため、VSCode を閉じているときだけ書き込むようにした。

## 2026-11-09 説明を CLAUDE.md からこのページに移す

- CLAUDE.md を短くするため、仕組みの説明をこのページに移した。CLAUDE.md には、Claude がふるまいとして守ること（会社用の OneDrive に置かない、設定がまだのPCでは `setup-sessions.cmd` を頼む、同じ会話を2台で同時に進めない）だけを残した。仕組みそのものは変えていない。

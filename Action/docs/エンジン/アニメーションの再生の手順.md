# アニメーションの再生の手順

作成日: 2026-11-08
設計: [アニメーションの再生の設計](アニメーションの再生の設計.md)
経緯: [アニメーションの再生の経緯](アニメーションの再生の経緯.md)

エンジンのアニメーションの再生に、キーフレームの間の補間と、クリップの切り替えをなめらかにする曲線を足すまでの手順です。上から順にやると、[アニメーションの再生の設計](アニメーションの再生の設計.md) の形になります。

**出来上がるもの:** 30fps のキーフレームのクリップを 60fps 以上で描いても、ポーズがカクカク切り替わらず、なめらかに動きます。ループのつなぎ目でもつまずきません。クリップを切り替えるときの補間は、始めと終わりがゆっくりになります。

**前提:**

- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 始める前は、エンジンにもとからある形になっている。もとの形では、今の時間より後でいちばん近いキーフレームのポーズをそのまま使う（間を補間しない）。クリップの切り替えの補間は、まっすぐ（線形）に進む。
- ほかの手順書を先に済ませる必要はない。
- 作業を始める前に、main からブランチを切る。

この手順書では、アニメーションの1枚を「コマ」、ゲームの1回の更新を「フレーム」と書きます。エンジンの用語の「キーフレーム」はそのまま使います。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | ボーンの行列を補間する関数 | ビルドが通る |
| 2 | 1つ前のキーフレームとの間を補間する | 動きがなめらかになる |
| 3 | ループで越えた時間を次の周回へ持ち越す | ループのつなぎ目でつまずかない |
| 4 | クリップの切り替えの補間を、始めと終わりがゆっくりな曲線にする | 切り替えがカクッとしない |

## 手順1: ボーンの行列を補間する関数を作る

キーフレームのポーズは、ボーンごとの行列（平行移動・拡大・回転が混ざったもの）で入っています。行列の要素をそのまま混ぜると形がくずれるので、平行移動・拡大・回転に分けて、それぞれ補間してから組み立て直します。回転はクォータニオンにして `Slerp` します。

## 手順2: 1つ前のキーフレームとの間を補間する

今のキーフレーム（今の時間より後でいちばん近いもの）と、1つ前のキーフレームの間を、今の時間の割合 t で補間します。

## 手順4: クリップの切り替えの補間を、始めと終わりがゆっくりな曲線にする

クリップを切り替えるときの補間の割合が、まっすぐ（線形）に増えると、補間の始まりと終わりで動きの速さが急に変わり、カクッと見えます。smoothstep（`t * t * (3 - 2t)`）にして、始めと終わりをゆっくりにします。

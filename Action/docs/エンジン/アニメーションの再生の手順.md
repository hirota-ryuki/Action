# アニメーションの再生の手順

設計: [アニメーションの再生の設計](アニメーションの再生の設計.md)
経緯: [アニメーションの再生の経緯](アニメーションの再生の経緯.md)

エンジンのアニメーションの再生に、キーフレームの間を曲線で補間する処理と、クリップの切り替えをなめらかにする曲線を足すまでの手順です。上から順にやると、[アニメーションの再生の設計](アニメーションの再生の設計.md) の形になります。

**出来上がるもの:** 30fps のキーフレームのクリップを 240fps などで描いても、手足の動きがキーフレームのところで折れず、なめらかに動きます。ループのつなぎ目でもつまずきません。クリップを切り替えるときの補間は、始めと終わりがゆっくりになります。

**前提:**

- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 始める前は、エンジンにもとからある形になっている。もとの形では、今の時間より後でいちばん近いキーフレームのポーズをそのまま使う（間を補間しない）。クリップの切り替えの補間は、まっすぐ（線形）に進む。
- ほかの手順書を先に済ませる必要はない。

この手順書では、アニメーションの1枚を「コマ」、ゲームの1回の更新を「フレーム」と書きます。エンジンの用語の「キーフレーム」はそのまま使います。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | ボーンの行列を平行移動・拡大・回転に分ける関数と、曲線の式 | ビルドが通る |
| 2 | 4つのキーフレームの行列から、間の行列を曲線で作る関数 | ビルドが通る |
| 3 | 今のキーフレームと1つ前のキーフレームの間を、曲線で補間する | 動きがなめらかになる |
| 4 | ループで越えた時間を次の周回へ持ち越す | ループのつなぎ目でつまずかない |
| 5 | クリップの切り替えの補間を、始めと終わりがゆっくりな曲線にする | 切り替えがカクッとしない |

**読み方:**

- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- 消すところは、消す行を枠で示します（番号は消す前の番号）。書き換えるところは、「前」と「後」の枠を並べています。
- 小手順の見出しは、足すコードのコメントか関数の名前です。何のためのコードかは、コードのコメントに書いてあります。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

## 手順1: ボーンの行列を分ける関数と、曲線の式を作る

キーフレームのポーズは、ボーンごとの行列（平行移動・拡大・回転が混ざったもの）で入っています。行列の要素をそのまま混ぜると形がくずれるので、平行移動・拡大・回転に分けてから補間します。あわせて、補間に使う曲線の式（エルミート曲線と Catmull-Rom）を作ります。

- `Hermite()`: 始めの値 p1・終わりの値 p2 と、それぞれの点での傾き v1・v2 から、間の値を求める。
- `CatmullRom()`: 傾きを前後の点から作る。p1 での傾きは p0 → p2 の向き、p2 での傾きは p1 → p3 の向き。キーフレームの間隔が違っても傾きが合うように、間の時間（span）で割り合いを決める。

		float Hermite(float p1, float p2, float v1, float v2, float t)

## 手順2: 4つのキーフレームの行列から、間の行列を曲線で作る

補間したい2つのキーフレーム（k1・k2）に、その前（k0）と後（k3）を足した4つの行列から、k1 と k2 の間の行列を作ります。平行移動・拡大・回転のそれぞれを、手順1の `CatmullRom()` で曲線にします。

- 回転はクォータニオンです。q と -q は同じ回転なので、隣どうしの向き（内積の符号）をそろえてから、4つの成分をそれぞれ曲線にし、最後に正規化します。

## 手順3: 今のキーフレームと1つ前のキーフレームの間を、曲線で補間する

今のキーフレーム（今の時間より後でいちばん近いもの）と1つ前のキーフレームの間を、今の時間の割合 t で補間します。直線で補間すると、キーフレームごとに手足の動きの向きと速さが急に変わり、FPS が高いとカクカクして見えるので、前後のキーフレームも使う手順2の曲線にします。

- 前後のキーフレームの取り方:
  - ふつうは、1つ前の前（i0）と、今の次（i3）。
  - クリップの端で前や次がないときは、端のキーフレームそのものを使う。
  - ループのクリップで、最後のキーフレームが最初と同じポーズなら、反対側から取る（先頭の前は最後から2つ目、最後の次は2つ目）。ループのつなぎ目でも、動きが折れずにつながる。
- 最初のキーフレーム（1つ前がない）のときと、間隔が 0 のときは、もとのとおりキーフレームのポーズをそのまま使う。

## 手順5: クリップの切り替えの補間を、始めと終わりがゆっくりな曲線にする

# アニメーションの再生の設計

経緯: [アニメーションの再生の経緯](アニメーションの再生の経緯.md)
手順: [アニメーションの再生の手順](アニメーションの再生の手順.md)（キーフレームの間を曲線で補間し、切り替えの曲線を足す）

アニメーションクリップ（`.tka`）のキーフレームから、毎フレームのボーンの姿勢を決める仕組みです。

- キーフレームの間は、前後のキーフレームも通る曲線（Catmull-Rom）で補間する。直線にしない。
- クリップ同士の切り替えは、混ぜる割合を smoothstep で変える。
- ループのクリップは、最後のキーフレームを越えた分の時間を次の周回へ持ち越す。

**用語:**

| 用語 | 何のことか |
|---|---|
| キーフレーム | アニメーションの中で、ボーンの位置・向き・大きさが記録されている時刻。クリップは 30fps なので、1/30 秒ごとにある |
| 姿勢 | ボーンの位置・向き・大きさ |
| ポーズ | 全部のボーンの姿勢をまとめたもの。ある時刻の、体の形 |
| ローカル行列 | 親のボーンから見た、ボーンの姿勢を表す行列（[上半身の層の設計](../アニメーションの上半身の層/アニメーションの上半身の層の設計.md)の「親から見た行列」と同じもの） |
| ルートの空間 | いちばん根元のボーン（ルート）を基準にした座標。ボーンごとに、親のローカル行列を順にかけて求める |
| Catmull-Rom | 4つの点（k0〜k3）のうち、真ん中の2つ（k1・k2）の間を、前後の点も使ってなめらかにつなぐ曲線 |
| エルミート曲線 | 2つの点の位置と、その点での傾きを決めて引く曲線。Catmull-Rom は、傾きを前後の点から作ったもの |
| クロスフェード | 前のクリップの動きから新しいクリップの動きへ、混ぜる割合を少しずつ変えて切り替えること |

[smoothstep](../../用語集.md#動きを近づける) は用語集にあります。

## 1. 全体像

| クラス | 役割 |
|---|---|
| `Animation`（[Animation.h](../../../k2EngineLow/graphics/Animation.h)） | クリップの切り替えと、クリップ同士の補間（`Play` の `interpolateTime`）。再生中のクリップごとに `AnimationPlayController` を持つ |
| `AnimationPlayController`（[AnimationPlayController.cpp](../../../k2EngineLow/graphics/AnimationPlayController.cpp)） | 1つのクリップの再生。時間を進め、今のキーフレームからボーンのローカル行列を作る |

1フレームの流れ（`AnimationPlayController::Update`）:

1. `m_time` に経過時間を足す。
2. `ProgressKeyframeNo`: 今の時間より後で一番近いキーフレームの番号（`m_currentKeyFrameNo`）まで進める。最後まで行ったら、ループなら先頭へ戻り、そうでなければ最後で止まる。
3. `SamplingBoneMatrixFromAnimationClip`: 1つ前のキーフレームと今のキーフレームの間を、前後のキーフレームも通る曲線で補間して、ボーンの行列を作る。
4. 親から順にルートの空間の行列にする。

## 2. キーフレームの間の補間

1つ前のキーフレーム（k1）と今のキーフレーム（k2）の間を、さらに1つ前（k0）と1つ後（k3）も通る曲線（Catmull-Rom）で補間します。直線で補間すると、手足がキーフレームを結んだ折れ線の上を動き、キーフレームのところで動きの向きと速さが急に変わります。240fps などで描くと、それが1秒に約30回見えてカクカクします。

時間の軸（k1 と k2 の間が補間する区間。t は、その区間のどこにいるか）:

```
時間 ──────────────────────────────────────────────▶
      k0          k1       今の時間        k2          k3
      ●───────────●──────────┼────────────●───────────●
      │←  span01 →│←──────  span12  ────→│←  span23 →│
                   │←  今の時間−k1 の時間 →│
                   t = （今の時間 − k1 の時間）÷ span12   （0 のとき k1、1 のとき k2）
```

- 割合 t は上の式。0〜1 に収める。
- 行列を、平行移動・拡大・回転に分けて補間します（`DecomposeBoneMatrix`。クリップ同士の補間の `Animation::UpdateGlobalPose` と同じ分け方）。
  - 平行移動・拡大: x・y・z を、それぞれ Catmull-Rom の曲線にする。
  - 回転: クォータニオンを、隣どうしの向き（内積の符号）をそろえてから、4つの成分をそれぞれ曲線にし、正規化する。クォータニオンは q と −q が同じ回転を表すので、符号がばらばらだと、同じ回転なのに曲線が反対側へ大回りしてしまうため、符号をそろえる。
- 曲線は、k1・k2 の位置と傾きから引くエルミート曲線（`Hermite`）。
  - 傾きは `CatmullRom` が作る。k1 での傾きは「k0 から k2 へ向かう変化」、k2 での傾きは「k1 から k3 へ向かう変化」。
  - キーフレームの間隔が違っても傾きが合うように、変化に「k1 から k2 の時間（span12）が、傾きを測る区間の時間に占める割合」を掛ける。k1 なら `span12 ÷ (span01 + span12)`。間隔が等しければ 1/2。
- k0・k3 がクリップの外になるときは、端のキーフレームそのものを使う（先頭の k0 は k1 自身、最後の k3 は k2 自身）。
- ループのクリップで、最後のキーフレームが最初と同じポーズ（`IsSameBoneMatrix`）なら、反対側から取る。キーフレームの番号が 0〜N−1 のとき:

| 取りたいもの | 取る番号 |
|---|---|
| 先頭（0 番）の前の k0 | N−2 番（最後の N−1 番は 0 番と同じなので、その1つ前） |
| 最後（N−1 番）の次の k3 | 1 番（0 番は N−1 番と同じなので、その次） |

- 最初のキーフレーム（前がない）と、時間の間隔が 0 のときは、補間せずにそのまま使います。
- ループのクリップは、最後のキーフレームを越えた分の時間を次の周回へ持ち越します。越えた分を捨てると、つなぎ目で少し止まって見えるためです。

| ジャンル | 名前 | 何をするか | どこから来たもの |
|---|---|---|---|
| 関数 | `Hermite()` | 位置と傾きから、エルミート曲線の値を求める | [AnimationPlayController.cpp](../../../k2EngineLow/graphics/AnimationPlayController.cpp) の無名名前空間 |
| 関数 | `CatmullRom()` | 前後の点と時間の間隔から傾きを作り、`Hermite` を呼ぶ | 同じ AnimationPlayController.cpp の無名名前空間 |
| 関数 | `IsSameBoneMatrix()` | 2つの行列がほぼ同じかを返す | 同じ AnimationPlayController.cpp の無名名前空間 |

## 3. クリップ同士の補間の進み方

`Play` / `PlayFromTime` に補間時間を渡すと、前のクリップのポーズから新しいクリップのポーズへ、その時間をかけて移ります（クロスフェード）。前のクリップも補間の間は時間が進み続けます（ループしないクリップは、最後まで行くと最後のポーズで止まる）。

混ぜる割合は `AnimationPlayController::GetInterpolateRate()`（[AnimationPlayController.h](../../../k2EngineLow/graphics/AnimationPlayController.h)）が返します。経過時間 ÷ 補間時間を smoothstep（`t² × (3 − 2t)`）に通した値です。時間に比例する（線形の）割合だと、補間の始まりと終わりで動きの速さが急に変わり、カクッと見えるためです。どのキャラクターの、どのクリップの切り替えにも効きます。

## 4. 決めたこと

| 候補 | 選ばなかった理由 |
|---|---|
| クリップのキーフレームを増やす（60fps・120fps で書き出す） | クリップごとに作り直しが必要で、ファイルも大きくなる。UE もキーフレームの間は直線で補間するので、曲線で間を埋める処理を別に書く必要がある。エンジンで曲線にすれば、今のクリップのままどの fps でもなめらかになる |
| キーフレームの間を直線で補間する（前の形） | キーフレームのところで手足の動きの向きと速さが急に変わり、240fps ではカクカクして見えた |
| クリップ同士の補間の割合を線形のままにする | 補間の始まりと終わりで動きの速さが急に変わる。smoothstep なら、補間時間を変えずになめらかになる |

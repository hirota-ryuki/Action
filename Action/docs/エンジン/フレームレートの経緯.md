# フレームレートの経緯

設計: [フレームレートの設計](フレームレートの設計.md)

何をして、なぜ今の形になったかの記録です。日付ごとに書き足します。

---

## 2026-11-06 FPS の上限をなくした（ブランチ `feature/unlimited-fps`）

以前は `USE_FPS_LIMITTER` が有効で、VSync 待ち＋60FPS 上限だった。どこまで FPS が出るかを試すために無効にした。

## 2026-11-08 FPS が上がって速くなった所を、経過時間で進めるようにした

GPU の選び方を直して FPS が約30から約480に上がると（[GPUの選び方の経緯](GPUの選び方の経緯.md)）、「デルタタイムが採用されていない箇所が何箇所かあり、弊害が出ている」とのことだった。1フレームにつき決まった量で進めていた所を探して直した。

| 所 | 前 | 今 |
|---|---|---|
| エフェクト（`EffectEngine::Update`） | 受け取った経過時間を使わず、毎フレーム1フレーム（1/60秒）進めていた。30fps では半分の速さ、480fps では8倍の速さ | 経過時間 × 60 フレーム進める |
| 炎を重ねて再生する間隔（`FireEffect`） | ゲームのフレーム数で数えていた | 経過時間をエフェクトのフレームに直して数える |
| 物理（`GameObjectManager`） | 毎フレーム 1/60秒進めていた | 実際の経過時間を渡す |
| カメラの右スティック（`GameCamera`） | 1フレームに 2° | 120°/秒（60fps のときの 2°/フレームと同じ） |

明るさに目が慣れる速さ（`CalcSceneLuminance`）は、毎フレーム経過時間を入れ直していたので直していない。3D サウンドのドップラー効果は、速さの単位が cm/秒になって音速とそろわず、急に強くかかるおそれがあり、ゲームでも音を使っていないので直していない。

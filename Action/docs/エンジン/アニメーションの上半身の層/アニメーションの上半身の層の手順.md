# アニメーションの上半身の層の手順

設計: [アニメーションの上半身の層の設計](アニメーションの上半身の層の設計.md)
経緯: [アニメーションの上半身の層の経緯](アニメーションの上半身の層の経緯.md)

作成日: 2026-11-19
対象: `k2EngineLow` の `Animation`・`k2Engine` の `ModelRender`（#193 の上半身の層）

エンジンのアニメーションに「層」を足して、下のアニメーション（歩きなど）の上に、別のアニメーションを骨ごとの重みで重ねられるようにするまでの手順です。上から順にやると、[アニメーションの上半身の層の設計](アニメーションの上半身の層の設計.md) の形になります。

**出来上がるもの:** `ModelRender` に `InitAnimationLayer()` で「どの骨から先に、どれだけ重ねるか」を渡すと、`PlayLayerAnimationFromTime()` で流したクリップが、その骨から先にだけ重なります。重ねる強さは `SetLayerWeight()`（0〜1）、再生の速さは `SetLayerAnimationSpeed()`（0 で止まる）で変えられます。下のアニメーションで腰が上下しても、重ねた胸や腕は腰に付いていきます。

**前提:**

- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 始める前は、エンジンにもとからある形になっている。もとの `Animation` は、流したクリップの姿勢を、全部の骨にそのまま書き込む。
- 先に [アニメーションの再生の手順](../アニメーションの再生/アニメーションの再生の手順.md) を済ませておく（`Animation.cpp` の行番号は、それを済ませた形で数えている）。
- この手順で足すものは、ゲームからはまだ呼ばない。呼ぶのは [三人称の溜め撃ちの手順](../../ゲーム/プレイヤー/三人称の溜め撃ち/三人称の溜め撃ちの手順.md)。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | `Animation` に、層の骨ごとの重み・全体の重みを持たせる | ビルドが通る |
| 2 | ボーンの行列を組む・分ける・親から見た形にする関数 | ビルドが通る |
| 3 | 骨を親から順に並べる `SetLayerBoneWeights()` | ビルドが通る |
| 4 | 下の姿勢に重ねて書き込む `ApplyAsLayer()` | ビルドが通る |
| 5 | 層のときは、スケルトンへそのまま書かずに `ApplyAsLayer()` で重ねる | ビルドが通り、ゲームの動きは変わらない |
| 6 | `ModelRender` から層を作って流せるようにする | ビルドが通り、ゲームの動きは変わらない |

**読み方:**

- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- 書き換えるところは、「前」と「後」の枠を並べています。
- コードの下に、3つを置きます。
  - 「行・何をしているか」の表: 1行ずつの動き。
  - 「なぜ」「効果」: その小手順でそう書く理由と、書くと何ができるようになるか。
  - 「初めて出てくる名前」の表: このページで初めて出てくる変数・引数・関数・型・C++ の書き方を、コードに出てくる順に並べます。2回目からは載せないので、わからない名前はページ内検索（`Ctrl+F`）で最初に出てきた所を探してください。

この手順書では、骨の行列について次の言葉を使います。

| 言葉 | 何のことか |
|---|---|

## 手順1: Animation に、層の重みを持たせる

1つの `Animation` を「層」として使えるようにします。層かどうかは、骨ごとの重みを持っているかで決めます。重みは骨の番号ごとに 0〜1 で持ち、全体の重みを掛けて使います。

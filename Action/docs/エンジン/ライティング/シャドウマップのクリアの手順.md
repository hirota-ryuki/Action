# シャドウマップのクリアの手順

作成日: 2026-11-09
設計: [シャドウマップのクリアの設計](シャドウマップのクリアの設計.md)
経緯: [シャドウマップのクリアの経緯](シャドウマップのクリアの経緯.md)

シャドウマップのクリアの値を 1.0 から、いちばん奥を表す `exp(40)` に変えるまでの手順です。上から順にやると、[シャドウマップのクリアの設計](シャドウマップのクリアの設計.md) の形になります。

**出来上がるもの:** 影を落とす物がない所に、太陽の光が当たります。地面が影を落とさないステージでも、画面全体が影にならず、キャラクターや木の影だけが地面に落ちます。

**前提:**

- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 始める前は、エンジンにもとからある形（`ShadowMapRender::Init()` で `{ 1.0f, 1.0f, 1.0f, 1.0f }` でクリア）になっている。
- 作業を始める前に、main からブランチを切る。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 指数シャドウマップの指数の定数 | ビルドが通る。見た目は変わらない |
| 2 | クリアの値を `exp(40)` にする | 影を落とす物がない所に光が当たる |

## 手順1: 指数シャドウマップの指数を定数にする

クリアの値を出すのに、シェーダーと同じ指数 40 が要るので、先に名前を付けて置いておきます。まだどこからも使わないので、見た目は変わりません。

**この手順で触るファイル:**

| ファイル | 何をするか |
|---|---|
| [ShadowMapRender.cpp](../../../k2Engine/graphics/preRender/ShadowMapRender.cpp) | 追加（無名の namespace と定数1つ） |

[ShadowMapRender.cpp](../../../k2Engine/graphics/preRender/ShadowMapRender.cpp) の `namespace nsK2Engine {` の行の下、`void ShadowMapRender::Init(bool isSoftShadow)` の上に**追加**します。

```diff
 namespace nsK2Engine {
+    namespace {
+        // 指数シャドウマップの指数。DrawShadowMap.fx と Shadowing.h の INFINITY と同じ値にする。
+        constexpr float SHADOW_MAP_EXPONENT = 40.0f;
+    }
+
     void ShadowMapRender::Init(bool isSoftShadow)
     {
```

**確かめ方:** ビルドが通る。起動すると、見た目は前と変わらない。

## 手順2: クリアの値をいちばん奥の値にする

1.0 でクリアすると、指数シャドウマップでは `exp(40 × 0)` と同じで「ライトのすぐ前に遮る物がある」ことになり、影を落とす物がない所が全部影になります。クリアの値を、いちばん奥（深度 1.0）の `exp(40)` にします。ソフトシャドウでは g に2乗を使うので、g は `exp(40)` の2乗にします。

**この手順で触るファイル:**

| ファイル | 何をするか |
|---|---|
| [ShadowMapRender.cpp](../../../k2Engine/graphics/preRender/ShadowMapRender.cpp) | 書き換え（`Init()` の最初のクリアの値） |

[ShadowMapRender.cpp](../../../k2Engine/graphics/preRender/ShadowMapRender.cpp) の `ShadowMapRender::Init()` の最初の、空行と `clearColor` の行を**書き換え**ます。

```diff
     void ShadowMapRender::Init(bool isSoftShadow)
     {
- 
-        float clearColor[4] = { 1.0f, 1.0f, 1.0f, 1.0f };
+        // 影を落とす物が描かれなかった所は、いちばん奥（深度 1.0）の値 exp(40) にしておき、光が当たるようにする。
+        // 1.0 でクリアすると exp(40 × 0) と同じになり、「ライトのすぐ前に遮る物がある」として全部影になる。
+        // ソフトシャドウでは g に2乗を入れる（DrawShadowMap.fx と同じ）。exp(80) でも float に収まる。
+        const float farValue = expf(SHADOW_MAP_EXPONENT);
+        float clearColor[4] = { farValue, farValue * farValue, 0.0f, 1.0f };
 
         DXGI_FORMAT colorFormat;
```

消す1行目は、もとからある空白1つだけの行です。

**確かめ方:** ビルドが通る。起動すると、地面に太陽の光が当たり、プレイヤー・敵・木の影が地面に落ちる。岩や服が空を映した鏡のようにテカらない。

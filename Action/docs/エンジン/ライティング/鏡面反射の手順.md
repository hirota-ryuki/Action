# 鏡面反射の手順

作成日: 2026-11-09
設計: [鏡面反射の設計](鏡面反射の設計.md)
経緯: [鏡面反射の経緯](鏡面反射の経緯.md)

PBR の鏡面反射（スペキュラ）を、強すぎるもとの式から、GGX 分布と Smith の遮蔽の式に置き換えるまでの手順です。上から順にやると、[鏡面反射の設計](鏡面反射の設計.md) の形になります。

**出来上がるもの:** 草や地面を斜めから見ても、白く光らなくなります。ステージにもキャラクターにも、ハイライトはほとんど出なくなります（どちらも滑らかさが低いため）。

**前提:**

- 始める前は、エンジンにもとからある `CookTorranceSpecular()`（ベックマン分布・反射率 0.5 固定）になっている。
- 作業を始める前に、main からブランチを切る。
- シェーダーはゲームの起動のときにコンパイルされるので、C++ のビルドは要らない。手順ごとの「確かめ方」は、ゲームを起動するか、Windows SDK の `fxc.exe` でコンパイルする（下のコマンド）。

```
cd Action\Game\Assets\shader
"C:\Program Files (x86)\Windows Kits\10\bin\10.0.26100.0\x64\fxc.exe" /nologo /T ps_5_0 /E PSMainSoftShadow /Fo %TEMP%\t.cso DeferredLighting.fx
"C:\Program Files (x86)\Windows Kits\10\bin\10.0.26100.0\x64\fxc.exe" /nologo /T ps_5_0 /E PSMainSoftShadow /Fo %TEMP%\t.cso model.fx
```

`DeferredLighting.fx` の 94 行目の警告（`col_1` が初期化されていないかもしれない）は、もとからあるものです。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 鏡面反射の調整値（反射率・粗さの下限・明るさの上限） | コンパイルが通る。見た目は変わらない |
| 2 | `CookTorranceSpecular()` の中身を GGX と Smith の遮蔽の式にする | 草や地面が白く光らなくなる |

新しく作るファイル・消すファイル・コメントアウトする行はありません。

**もとからあって、変えないもの:**

- 同じファイルの `SpcFresnel()`（Schlick 近似のフレネル）は、手順2の新しい式でもそのまま呼びます。
- `Beckmann()` は使わなくなりますが、消しません。
- `CookTorranceSpecular()` を呼ぶ `CalcLighting()` は変えません。ライトの色を掛け、金属度でスペキュラカラーを付け、最後に滑らかさで拡散反射と混ぜる、のはもとのままです。

```hlsl
    float3 spec = CookTorranceSpecular(
        -ligDir, toEye, normal, smooth)
        * ligColor;
    ...
    spec *= lerp(float3(1.0f, 1.0f, 1.0f), specColor, metaric);
    ...
    return max( float3( 0.0f, 0.0f, 0.0f ), diffuse * (1.0f - smooth) + spec * smooth );
```

## 手順1: 鏡面反射の調整値を足す

新しい式で使う3つの数値を、先に名前を付けて置いておきます。まだどこからも使わないので、見た目は変わりません。

**この手順で触るファイル:**

| ファイル | 何をするか |
|---|---|
| [PBRLighting.h](../../../Game/Assets/shader/PBRLighting.h) | 追加（定数3つ） |

[PBRLighting.h](../../../Game/Assets/shader/PBRLighting.h) の、`SpcFresnel()` の閉じかっこと空行の下、`CookTorranceSpecular()` の説明コメント（`/// <summary>`）の上に**追加**します。

```diff
 float SpcFresnel(float f0, float u)
 {
     // from Schlick
     return f0 + (1-f0) * pow(1-u, 5);
 }
 
+// 鏡面反射の調整値。
+static const float SPECULAR_F0 = 0.04f;             // 正面から見たときの反射率。金属でない物（草・土・岩・肌・布）はおよそ4%。
+static const float SPECULAR_MIN_ROUGHNESS = 0.3f;   // 粗さの下限。0に近いとハイライトが点になり、明るさが跳ね上がる。
+static const float SPECULAR_MAX = 1.0f;             // 鏡面反射の上限（ライトの色に掛ける前の値）。ライトの色より明るく照り返さない。
+
 /// <summary>
 /// クックトランスモデルの鏡面反射を計算
 /// </summary>
```

HLSL では、ファイルの外に置く定数は `static const` にします（`static` を付けないと、定数バッファの値として扱われ、ここで書いた値が入りません）。

**確かめ方:** 上の `fxc.exe` のコマンドで、`DeferredLighting.fx` と `model.fx` のコンパイルが通る。ゲームを起動すると、見た目は前と変わらない（草や地面を斜めから見ると、まだ白く光る）。

## 手順2: 鏡面反射を GGX と Smith の遮蔽の式にする

もとの式は、反射率 0.5 固定・視線が面すれすれのときの N·V での割り算・粗さの `min`（下限のつもりが上限になっていた）が重なって、照り返しが強すぎます。`CookTorranceSpecular()` の説明コメントと中身を、手順1の調整値を使う新しい式に置き換えます。関数の名前と引数は変えないので、呼んでいる `CalcLighting()` はそのままです。

**この手順で触るファイル:**

| ファイル | 何をするか |
|---|---|
| [PBRLighting.h](../../../Game/Assets/shader/PBRLighting.h) | 書き換え（`CookTorranceSpecular()` の説明コメントと中身） |

[PBRLighting.h](../../../Game/Assets/shader/PBRLighting.h) の、手順1で足した `SPECULAR_MAX` の行と空行の下にある、説明コメントから関数の閉じかっこまでを**書き換え**ます。

```diff
 static const float SPECULAR_MAX = 1.0f;             // 鏡面反射の上限（ライトの色に掛ける前の値）。ライトの色より明るく照り返さない。
 
 /// <summary>
-/// クックトランスモデルの鏡面反射を計算
+/// クックトランスモデルの鏡面反射を計算（GGX 分布と Smith の遮蔽）
 /// </summary>
+/// <remark>
+/// 戻り値は N·L を掛けたあとの値。光が当たっていない面（N·L が 0 以下）では 0 を返す。
+/// 視線が面すれすれ（N·V が 0 に近い）でも、Smith の遮蔽の分母に k が残るので割り算で無限には大きくならない。
+/// それでも逆光の面すれすれでは大きくなるので、SPECULAR_MAX で止める。
+/// </remark>
 /// <param name="L">光源に向かうベクトル</param>
 /// <param name="V">視点に向かうベクトル</param>
 /// <param name="N">法線ベクトル</param>
 /// <param name="smooth">滑らかさ</param>
 float CookTorranceSpecular(float3 L, float3 V, float3 N, float smooth)
 {
-    // マイクロファセットが小さくなりすぎると、鏡面反射が強くなりすぎることがあるので、
-    // 下限を0.5にした。
-    float microfacet = min( 0.5f, 1.0f - smooth );
-
-    // 金属度を垂直入射の時のフレネル反射率として扱う
-    // 金属度が高いほどフレネル反射は大きくなる
-    float f0 = 0.5;
+    float NdotL = dot(N, L);
+    if (NdotL <= 0.0f) {
+        return 0.0f;
+    }
+    float NdotV = max(dot(N, V), 0.001f);
 
     // ライトに向かうベクトルと視線に向かうベクトルのハーフベクトルを求める
     float3 H = normalize(L + V);
+    float NdotH = saturate(dot(N, H));
+    float VdotH = saturate(dot(V, H));
 
-    // 各種ベクトルがどれくらい似ているかを内積を利用して求める
-    float NdotH = max( saturate(dot(N, H)), 0.001f );
-    float VdotH = max( saturate(dot(V, H)), 0.001f );
-    float NdotL = max( saturate(dot(N, L)), 0.001f );
-    float NdotV = max( saturate(dot(N, V)), 0.001f );
-
-    // D項をベックマン分布を用いて計算する
-    float D = Beckmann(microfacet, NdotH);
+    // 粗さ。見た目の粗さに合わせるため2乗したものを使う。
+    float roughness = max(1.0f - smooth, SPECULAR_MIN_ROUGHNESS);
+    float a = roughness * roughness;
+    float a2 = a * a;
 
-    // F項をSchlick近似を用いて計算する
-    float F = SpcFresnel(f0, VdotH);
+    // D項：GGX 分布
+    float d = NdotH * NdotH * (a2 - 1.0f) + 1.0f;
+    float D = a2 / (PI * d * d);
 
-    // G項を求める
-    float G = min(1.0f, min(2*NdotH*NdotV/VdotH, 2*NdotH*NdotL/VdotH));
+    // F項：Schlick 近似
+    float F = SpcFresnel(SPECULAR_F0, VdotH);
 
-    // m項を求める
-    float m = PI * NdotV * NdotH;
+    // G項を 4·N·L·N·V で割ったもの（Smith の遮蔽、Schlick-GGX 近似）
+    float k = a * 0.5f;
+    float visL = NdotL * (1.0f - k) + k;
+    float visV = NdotV * (1.0f - k) + k;
+    float vis = 0.25f / (visL * visV);
 
-    // ここまで求めた、値を利用して、クックトランスモデルの鏡面反射を求める
-    return max(F * D * G / m, 0.0);
+    // 逆光で面すれすれに見るときは、滑らかな物ほど数十倍まで明るくなるので、上限で止める。
+    return min(D * F * vis * NdotL, SPECULAR_MAX);
 }
```

要所は次の3つです。くわしくは [鏡面反射の設計](鏡面反射の設計.md) の「2. 実装方法」を見てください。

- **N·L が 0 以下なら、すぐ 0 を返す。** 最後に N·L を掛けるので、光が斜めに当たるほど暗くなる。
- **G 項を 4·N·L·N·V で割った形（`vis`）でまとめて出す。** 分母に `k` が残るので、N·V が 0 に近くても、もとの式のように割り算で跳ね上がらない。
- **最後に `SPECULAR_MAX` で止める。** 滑らかな物を逆光で面すれすれに見たときに、ライトの色を超えて白く飛ばないようにする。

**確かめ方:** 上の `fxc.exe` のコマンドで、`DeferredLighting.fx` と `model.fx` のコンパイルが通る。ゲームを起動して、カメラを低くして草や地面を斜めに見ても、白く光らない。

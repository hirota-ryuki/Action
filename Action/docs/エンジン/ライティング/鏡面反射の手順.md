# 鏡面反射の手順

設計: [鏡面反射の設計](鏡面反射の設計.md)
経緯: [鏡面反射の経緯](鏡面反射の経緯.md)

PBR の鏡面反射（スペキュラ）を、強すぎるもとの式から、GGX 分布と Smith の遮蔽の式に置き換えるまでの手順です。上から順にやると、[鏡面反射の設計](鏡面反射の設計.md) の形になります。

**出来上がるもの:** 草や地面を斜めから見ても、白く光らなくなります。ステージにもキャラクターにも、ハイライトはほとんど出なくなります（どちらも滑らかさが低いため）。

**前提:**

- 始める前は、エンジンにもとからある `CookTorranceSpecular()`（ベックマン分布・反射率 0.5 固定）になっている。
- シェーダーはゲームの起動のときにコンパイルされるので、C++ のビルドは要らない。手順ごとの「確かめ方」は、ゲームを起動するか、Windows SDK の `fxc.exe` でコンパイルする（下のコマンド）。

```
cd Action\Game\Assets\shader
"C:\Program Files (x86)\Windows Kits\10\bin\10.0.26100.0\x64\fxc.exe" /nologo /T ps_5_0 /E PSMainSoftShadow /Fo %TEMP%\t.cso DeferredLighting.fx
"C:\Program Files (x86)\Windows Kits\10\bin\10.0.26100.0\x64\fxc.exe" /nologo /T ps_5_0 /E PSMainSoftShadow /Fo %TEMP%\t.cso model.fx
```

`DeferredLighting.fx` の 94 行目の警告（`col_1` が初期化されていないかもしれない）は、もとからあるものです。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 鏡面反射の調整値（反射率・粗さの下限・明るさの上限） | コンパイルが通る。見た目は変わらない |
| 2 | `CookTorranceSpecular()` の中身を GGX と Smith の遮蔽の式にする | 草や地面が白く光らなくなる |

**読み方:**

- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- 消すところは、消す行を枠で示します（番号は消す前の番号）。書き換えるところは、「前」と「後」の枠を並べています。
- 小手順の見出しは、足すコードのコメントか関数の名前です。何のためのコードかは、コードのコメントに書いてあります。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

**もとからあって、変えないもの:**

- 同じファイルの `SpcFresnel()`（Schlick 近似のフレネル）は、手順2の新しい式でもそのまま呼びます。
- `Beckmann()` は使わなくなりますが、消しません。
- `CookTorranceSpecular()` を呼ぶ `CalcLighting()` は変えません。ライトの色を掛け、金属度でスペキュラカラーを付け、最後に滑らかさで拡散反射と混ぜる、のはもとのままです。

```hlsl
    float3 spec = CookTorranceSpecular(
        -ligDir, toEye, normal, smooth)
        * ligColor;
    ...
    spec *= lerp(float3(1.0f, 1.0f, 1.0f), specColor, metaric);
    ...
    return max( float3( 0.0f, 0.0f, 0.0f ), diffuse * (1.0f - smooth) + spec * smooth );
```

## 手順1: 鏡面反射の調整値を足す

```cpp
// 鏡面反射の調整値。
static const float SPECULAR_F0 = 0.04f;             // 正面から見たときの反射率。金属でない物（草・土・岩・肌・布）はおよそ4%。
static const float SPECULAR_MIN_ROUGHNESS = 0.3f;   // 粗さの下限。0に近いとハイライトが点になり、明るさが跳ね上がる。
static const float SPECULAR_MAX = 1.0f;             // 鏡面反射の上限（ライトの色に掛ける前の値）。ライトの色より明るく照り返さない。
```

</td></tr></table>

**ポイント:**

- **N·L が 0 以下なら、すぐ 0 を返す。** 最後に N·L を掛けるので、光が斜めに当たるほど暗くなる。
- **G 項を 4·N·L·N·V で割った形（`vis`）でまとめて出す。** 分母に `k` が残るので、N·V が 0 に近くても、もとの式のように割り算で跳ね上がらない。
- **最後に `SPECULAR_MAX` で止める。** 滑らかな物を逆光で面すれすれに見たときに、ライトの色を超えて白く飛ばないようにする。

**確かめ方:** 上の `fxc.exe` のコマンドで、`DeferredLighting.fx` と `model.fx` のコンパイルが通る。ゲームを起動して、カメラを低くして草や地面を斜めに見ても、白く光らない。

# シャドウマップのクリアの設計

作成日: 2026-11-09
対象: [ShadowMapRender.cpp](../../../k2Engine/graphics/preRender/ShadowMapRender.cpp) の `ShadowMapRender::Init()`
経緯: [シャドウマップのクリアの経緯](シャドウマップのクリアの経緯.md)
手順: [シャドウマップのクリアの手順](シャドウマップのクリアの手順.md)（どのファイルに何を足し、何を書き換えたか）

ディレクションライトの影を作るシャドウマップを、毎フレーム描く前に何の値で埋めておくか（クリアの値）のページです。

- **クリアの値は、いちばん奥（深度 1.0）を表す `exp(40)` にする。** 影を落とす物が描かれなかった所は、光が当たる。
- **指数の 40 は、シェーダーの `INFINITY` と同じ値にする。** C++ 側は `SHADOW_MAP_EXPONENT` という定数で持つ。

---

## 1. 全体像

エンジンの影は、指数シャドウマップ（ESM）です。深度そのものではなく、`exp(40 × 深度)` をシャドウマップに書き、照らすときに比べます。

```
シャドウマップを描く（DrawShadowMap.fx）
  影を落とす物のピクセル = exp(40 × ライトから見た深度)          （ソフトシャドウでは g に2乗）
  何も描かれないピクセル = クリアの値                             ← このページ

照らす（Shadowing.h の CalcShadowRate()）
  pos = exp(40 × (このピクセルのライトから見た深度 − 0.001))
  ハードシャドウ: pos ≥ シャドウマップの値 なら影
  ソフトシャドウ: チェビシェフの不等式で、影になる割合を出す
```

ライトから見た深度は 0.0（ライトのすぐ前）〜 1.0（いちばん奥）なので、シャドウマップの値は `exp(0) = 1` 〜 `exp(40) ≒ 2.35 × 10^17` の範囲になります。

## 2. 実装方法

```cpp
namespace {
    // 指数シャドウマップの指数。DrawShadowMap.fx と Shadowing.h の INFINITY と同じ値にする。
    constexpr float SHADOW_MAP_EXPONENT = 40.0f;
}

void ShadowMapRender::Init(bool isSoftShadow)
{
    const float farValue = expf(SHADOW_MAP_EXPONENT);
    float clearColor[4] = { farValue, farValue * farValue, 0.0f, 1.0f };
    ...
```

- **r にいちばん奥の値 `exp(40)` を入れる。** 照らすときの `pos` は、深度が 0.98 未満のピクセルしか比べないので、必ず `exp(40)` より小さくなり、影にならない。
- **g には2乗 `exp(80)` を入れる。** ソフトシャドウでは `DrawShadowMap.fx` が g に2乗を書き、チェビシェフの不等式で分散に使うため、同じ形にそろえる。`exp(80) ≒ 5.5 × 10^34` は float の上限（約 3.4 × 10^38）に収まる。ハードシャドウ（R32_FLOAT）では g は使われない。
- クリアの値は `RenderTarget::Create()` に渡すと、`RenderContext::ClearRenderTargetView()` で毎フレームこの値で埋められる（もとからある仕組み）。

## 3. 調整用の数値

| 名前 | 値 | 何を決めるか |
|---|---|---|
| `SHADOW_MAP_EXPONENT` | 40.0 | 指数シャドウマップの指数。**`DrawShadowMap.fx` と `Shadowing.h` の `INFINITY` を変えたら、ここも同じ値にする** |

## 4. 決めたこと

- 以前はクリアの値が 1.0 でした。`exp(40 × 0) = 1` と同じなので、「ライトのすぐ前に遮る物がある」という意味になり、影を落とす物が描かれなかった所は全部影になっていました。前のステージ（`kariAsiba`）は地面が影を落としていて、シャドウマップが地面で埋まっていたので目立ちませんでした。くわしくは経緯を見てください。
- シェーダー側で「クリアされたままの所は光が当たる」と判定する方法もありますが、クリアの値を正しくすれば、シェーダーは今のままで正しく動くので、こちらにしました。

## 5. 既知の課題

- 指数の 40 が、C++（`SHADOW_MAP_EXPONENT`）と2つのシェーダー（`INFINITY`）の3か所にあります。どれかを変えるときは、3か所とも合わせます。
- シャドウマップの範囲（カスケードの区切り、`CascadeShadowMapMatrix.cpp` のライトの高さ 50m 決め打ち）は、このページでは扱いません。

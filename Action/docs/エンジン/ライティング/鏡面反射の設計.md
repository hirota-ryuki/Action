# 鏡面反射の設計

作成日: 2026-11-08
対象: ディファードライティングとフォワード描画（`model.fx`）の鏡面反射（[PBRLighting.h](../../../Game/Assets/shader/PBRLighting.h) の `CookTorranceSpecular()`）
経緯: [鏡面反射の経緯](鏡面反射の経緯.md)
手順: [鏡面反射の手順](鏡面反射の手順.md)（どのファイルに何を足し、何を書き換えたか）

PBR のライティングで、光が面に当たって照り返すハイライト（鏡面反射・スペキュラ）の計算のページです。ステージもキャラクターも、ディレクションライト・ポイントライト・スポットライトのどれも、この1つの関数で計算します。

- **GGX 分布と Smith の遮蔽を使う、ふつうのクックトランスモデルにする。** 視線が面すれすれでも明るさが跳ね上がらない。
- **正面から見たときの反射率は 4%（金属でない物の値）に固定する。** 金属らしさは、今までどおり `CalcLighting()` で色を付けて出す。
- **粗さには下限（0.3）、明るさには上限（ライトの色まで）を付ける。** 滑らかな物でも、ハイライトが点になったり、逆光で白く飛んだりしないようにする。

---

## 1. 全体像

```
CalcLighting()（PBRLighting.h）
  ├ 拡散反射 = アルベド × フレネルを考えた拡散反射率 × ライトの色 × N·L / π
  ├ 鏡面反射 = CookTorranceSpecular(L, V, N, 滑らかさ) × ライトの色      ← このページ
  │             × lerp(白, スペキュラカラー, 金属度)
  └ 結果 = 拡散反射 × (1 − 滑らかさ) ＋ 鏡面反射 × 滑らかさ
```

滑らかさと金属度は、G-Buffer の「メタリック・影・スムース」の絵（r が金属度、a が滑らかさ）から読みます。スペキュラマップのないモデル（ステージの地形・草木・岩など）は、エンジンの `specMap_None.DDS` が使われ、金属度 0・滑らかさ約 0.36 になります。

## 2. 実装方法

`CookTorranceSpecular()` は、N·L を掛けたあとの値を返します。光の当たっていない面（N·L が 0 以下）では 0 を返します。

```hlsl
float roughness = max(1.0f - smooth, SPECULAR_MIN_ROUGHNESS);
float a = roughness * roughness;      // 見た目の粗さに合わせて2乗する
float a2 = a * a;

float d = NdotH * NdotH * (a2 - 1.0f) + 1.0f;
float D = a2 / (PI * d * d);          // D項: GGX 分布

float F = SpcFresnel(SPECULAR_F0, VdotH);   // F項: Schlick 近似

float k = a * 0.5f;                   // G項 ÷ (4·N·L·N·V): Smith の遮蔽（Schlick-GGX）
float vis = 0.25f / ((NdotL * (1 - k) + k) * (NdotV * (1 - k) + k));

return min(D * F * vis * NdotL, SPECULAR_MAX);  // 上限で止める
```

- **G項を 4·N·L·N·V で割った形（vis）でまとめて計算する。** 式どおり G を出してから N·V で割ると、N·V が 0 に近いところで割り算が大きくなる。まとめた形なら分母に k が残るので、視線が面すれすれでも有限の値になる。
- **最後に N·L を掛ける。** 拡散反射と同じく、光が斜めに当たるほど暗くなる。
- **上限（`SPECULAR_MAX`）で止める。** k が残っても、滑らかな物を逆光で面すれすれに見ると、ライトの色の数十倍になる（滑らかさ 0.8 で、視線が面から 10° のとき約 25 倍）。ブルームで白く光るので、ライトの色を超えないようにする。

## 3. 調整用の数値

| 名前 | 値 | 何を決めるか | 上げると | 下げると |
|---|---|---|---|---|
| `SPECULAR_F0` | 0.04 | 正面から見たときの反射率 | 全体がテカる | 照り返しが弱くなる。斜めから見たときの照り返し（フレネル）は残る |
| `SPECULAR_MIN_ROUGHNESS` | 0.3 | 粗さの下限 | ハイライトが広く・弱くなる | ハイライトが小さく・強くなり、ブルームで光りやすい |
| `SPECULAR_MAX` | 1.0 | 鏡面反射の上限（ライトの色に掛ける前） | 逆光のふちが白く光りやすくなる | ハイライトの芯が平らになる |

どれも [PBRLighting.h](../../../Game/Assets/shader/PBRLighting.h) の `CookTorranceSpecular()` のすぐ上にあります。シェーダーは起動のときにコンパイルされるので、値を変えたらゲームを起動し直せば反映されます。

ハイライトの強さは、このほかに `Game.cpp` の `MAIN_LIGHT_COLOR`（ライトの色、今は 2.0）と、各モデルのスペキュラマップの a（滑らかさ）でも変わります。

## 4. 決めたこと

- 以前の式は、ベックマン分布で、反射率 0.5 固定、粗さの上限 0.5（コメントでは「下限」のつもりだった）、分母が π·N·V·N·H でした。草や地面を斜めから見ると白く光り、すれすれではライトの色の十数倍まで明るくなっていました。くわしくは経緯を見てください。
- `Beckmann()` は使わなくなりましたが、ほかから呼ばれる場合に備えて残しています。
- 拡散反射と鏡面反射を滑らかさで混ぜる部分（`CalcLighting()` の最後の行）は変えていません。

## 5. 既知の課題

- キャラクターのトゥーンのハイライトは、この関数ではなく、[アニメ調ライティングの設計](アニメ調ライティングの設計.md) の「ハイライト」で別に作る予定です。
- ステージの草木の照り返しは、ほとんど見えなくなります。もっと照り返しがほしい物は、スペキュラマップで滑らかさを上げます。

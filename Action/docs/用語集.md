いくつものページで使う用語を、ここに1回だけ書きます。各ページの「用語」の表には載せず、初めて出てくる所でこのページへリンクします（例: `[臨界減衰](../../../用語集.md#動きを近づける)`）。

## 左右と向き

| 用語 | 何のことか |
|---|---|
| 画面の右・画面の左 | ゲームの画面で見たときの左右。一人称では、カメラから見た左右 |
| 骨の L・骨の R | ボーンの名前に付く側（`J_Bip_L_*`・`J_Bip_R_*`）。モデル自身から見た左右なので、こちらを向いたモデルでは画面の左右と逆になる。このゲームの一人称では、骨の L の腕が画面の右に映る |
| `J_Bip_*`・`J_Sec_*` | VRoid のモデルのボーンの名前の頭。`J_Bip_` は体の骨で、そのあとに中央（C）・左（L）・右（R）と部位（`Spine`・`UpperArm` など）が付く。`J_Sec_` は髪やスカートなどの揺れる骨 |
| ワールド座標 | ゲームの世界全体で共通の座標。Y が上。キャラクター自身の向きや、画面の向きを基準にした座標とは別のもの |
| ピッチ・ヨー・ロール | 回転の3つの向き。ピッチは前後に傾ける（うなずく向き）、ヨーは左右を向く（首を振る向き）、ロールは横に傾ける（首をかしげる向き） |

ページで左右を書くときは、どちらの左右かがわかるように「画面の右」「骨の R」と書きます。ただの「右」「左」は、キャラクター自身から見た左右（骨の L・R と同じ）にします。

## 動きを近づける

| 用語 | 何のことか |
|---|---|
| ばね | 離れているほど強く、元の位置（目標）へ引き戻す力。揺れ物では本当の力として、移動の向きでは「目標へ引き戻す動き」のたとえとして使う |
| 減衰 | 動きを止める向きにかかる力。強いほど揺り返さずに止まる。強さは `dampingRatio`（減衰比）で表し、1 のとき臨界減衰になる |
| 臨界減衰 | 減衰比が 1 のばね。行き過ぎも揺り返しもなく、いちばん速く目標に落ち着く。式は「加速 = −ω²·（目標との差）− 2·ω·（速さ）」（ω はばねの速さ） |
| `SmoothRate`（目標へ寄せる割合） | 毎フレーム「残りの差 × 割合」だけ目標へ近づけるときの割合。`1 − exp(−経過秒数 ÷ 時間)` にすると、FPS が変わっても同じ時間で同じだけ近づく。「時間」秒で残りの差の約 63% が縮まり、その3倍の秒数でほぼ（95%）追いつく |
| 時定数 | `SmoothRate` の「時間」のこと。この秒数で、残りの差の約 63% が縮まる |
| smoothstep | 0 から 1 へ、始めと終わりをゆっくり、真ん中を速く変える式（`t × t × (3 − 2t)`）。急に動き出さずに目標へ寄せられる |
| ease-out | 最初が速く、だんだん遅くなる動き方 |

## キャラクター

| 用語 | 何のことか |
|---|---|
| ステート・遷移 | ステートは、キャラクターが今どの動き（立つ・走る・攻撃する など）をしているかの1つ。遷移は、ステートが別のステートに切り替わること（[ステートマシンの設計](ゲーム/キャラクター/ステートマシン/ステートマシンの設計.md)） |
| BodyLink（体の連動） | 走る・歩く・跳ぶときに、脚の動きに合わせて骨盤・背骨・肩・腕・首を、アニメーションの上から毎フレーム少し回し足して、体全体がつながって動いて見えるようにする部品（[体の連動の設計](ゲーム/キャラクター/体の連動/体の連動の設計.md)） |
| `Action1`・`Action2` | 入力のボタンの名前。プレイヤーでは `Action1` が左クリック（氷魔法・3段攻撃）、`Action2` が右クリック（炎魔法）。敵では AI が押す（[入力の設計](ゲーム/キャラクター/入力/入力の設計.md)） |
| カプセル | 円柱の両端を半球にした形の当たり判定。キャラクターの移動（`CharacterController`）の判定に使う |
| レイ | 始点から終点まで線を引き、最初に何に当たるかを調べること |
| 陣営 | キャラクターが味方か敵かを表す分け方。敵対する陣営どうしだけ、攻撃が当たる・AI が狙う（[陣営と当たり判定の設計](ゲーム/キャラクター/陣営と当たり判定/陣営と当たり判定の設計.md)） |

## アニメーション制作

| 用語 | 何のことか |
|---|---|
| tka | k2Engine のアニメーションのファイル。`AnimationClip::Load` で読む |
| 層（アニメーションの層） | 決めた骨の範囲だけ、下のアニメーションの姿勢の上に、骨ごとの重みで重ねるアニメーション（[アニメーションの上半身の層の設計](エンジン/アニメーションの上半身の層/アニメーションの上半身の層の設計.md)） |
| T ポーズ・A ポーズ | 腕を真横に伸ばして立つ基準の姿勢が T ポーズ、腕を斜め下に下ろした姿勢が A ポーズ。リターゲットでは、元と先のポーズをそろえる |
| In Place | その場で足踏みする形のモーション。体が前へ進まず、進む分はゲームのプログラムで体を動かして足す |
| Y Bot | Mixamo の標準のキャラクター。T ポーズで、Mixamo のモーションの元の骨格 |
| IK Rig | UE の資産の1つ。骨格の骨を、腕・脚・背骨などの「チェーン」にまとめて名前を付け、リターゲットで元と先の骨を対応させる |
| ロトスコープ | 動画を見ながら、その動きをなぞってアニメーションを作る方法。このゲームでは、動画から読み取った関節の角度に合わせてポーズを作る（[動画からアニメーションを作る設計](ゲーム/アニメーション制作/動画からアニメーションを作る/動画からアニメーションを作る設計.md)） |
| 動画のコマ・クリップのコマ | 動画のコマは、元の動画の何コマ目か（「動画の 34コマ目」）。クリップのコマは、ゲームで使うクリップの先頭を 0 として数えた何コマ目か（「StopL の 3コマ目」）。どちらも 30fps |
| UE をコマンドラインで動かす | UE のエディターの画面を開かずに、`UnrealEditor-Cmd.exe` に Python のスクリプトを渡して動かすこと。書き方は[リターゲットの設計](ゲーム/アニメーション制作/リターゲット/リターゲットの設計.md)の「使い方」にあり、ほかのページはそこを見る |

## 描画

| 用語 | 何のことか |
|---|---|
| ディレクションライト | 太陽のように、どこでも同じ向きで届く光 |
| N·L | 面の法線 N と、光に向かう向き L の内積。1 に近いほど光が正面から当たる |
| G-Buffer | 色・法線・メタリックなどを、画面と同じ大きさの画像に分けて描いておいたもの |
| ディファードライティング | 先に描いておいた G-Buffer を読んで、画面全体にまとめて光の計算をする処理（`DeferredLighting.fx`） |
| フォワード描画 | モデルを描くときに、その場で光の計算までする描き方。半透明のものなど、G-Buffer に描けないものに使う |
| トゥーン | 光の当たり方を数段に分け、アニメのようにくっきりした陰影で見せる描き方 |
| GPU インスタンシング | 同じモデルを、1回の描画命令で何個も描く方法。1個ずつ違うのは、位置などを表すワールド行列だけ |
| BSP | Binary Space Partitioning（二分空間分割）。空間を平面で2つに分けることを繰り返して木にし、点を速く探せるようにする方法（[法線スムージングとBSPの設計](エンジン/法線スムージングとBSP/法線スムージングとBSPの設計.md)） |
| DDS | GPU がそのまま読める形で保存した画像のファイル |
| アルベド | 光を当てる前の、物そのものの色（テクスチャの色） |
| 環境光 | 特定の向きからではなく、まわり全体からくる弱い光 |
| ブルーム | 明るい所のまわりをにじませて、光って見せる効果 |
| 幾何学データ | モデルごとの、ワールド座標でモデルを囲む箱（AABB。軸に平行な直方体）。影の範囲を決めるのに使う。コードの名前は `GemometryData`（Geometry の綴り違い） |

## カメラと画面

| 用語 | 何のことか |
|---|---|
| 注視点 | カメラが見ている所 |
| 画角 | カメラに映る広さの角度（このゲームでは縦の角度）。狭いほど望遠になり、遠近のゆがみが小さい |
| Near（Near の面） | カメラに映る最も手前の距離。これより近いものは映らない。この面が壁に入ると、壁が欠けて向こう側が見える |
| HUD | ゲームの画面の上に重ねて出す情報（体力のゲージ・FPS など） |
| フェード | 透明度を少しずつ変えて、表示を出したり消したりすること |

## 開発環境

| 用語 | 何のことか |
|---|---|
| フック | Claude の決まったとき（会話の始まり・返答の終わり など）に、設定したコマンドを自動で動かす仕組み。`.claude/settings.json` に書く |
| タスク（VSCode） | VSCode から決まったコマンドを動かす設定。`.vscode/tasks.json` に書く。`runOn: folderOpen` にすると、フォルダーを開いたときに動く |
| `%APPDATA%` | Windows の、ユーザーごとのアプリの設定を置くフォルダー（`C:\Users\名前\AppData\Roaming`） |

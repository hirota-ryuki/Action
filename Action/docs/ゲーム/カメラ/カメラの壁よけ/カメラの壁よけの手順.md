# カメラの壁よけの手順

作成日: 2026-11-17
対象: [CameraCollision.h](../../../../Game/Source/Objects/CameraCollision.h)・[CameraCollision.cpp](../../../../Game/Source/Objects/CameraCollision.cpp) と、それを使う [GameCamera.h](../../../../Game/Source/Objects/GameCamera.h)・[GameCamera.cpp](../../../../Game/Source/Objects/GameCamera.cpp) の三人称
設計: [カメラの壁よけの設計](カメラの壁よけの設計.md)
経緯: [カメラの壁よけの経緯](カメラの壁よけの経緯.md)

三人称のカメラが、壁・柱・床の中に入らないようにするまでの手順です。

**出来上がるもの:** 寄りでも俯瞰でも、柱や壁を背にすると、カメラが柱や壁の手前で止まり、プレイヤーが映ります。壁から離れると、約 1秒でなめらかに元の距離へ戻ります。カメラを下から見上げる向きに回すと、床の手前で止まります。カメラが頭の中心から 60cm より近くまで寄ると、プレイヤーの体が消え、70cm より離れると映ります。

**前提:**

- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 三人称の寄りと俯瞰がある `GameCamera` が入っていること（[カメラのモードの手順](../カメラのモード/カメラのモードの手順.md)）。この手順は、その `GameCamera`（main の #182 の時点）から始めます。
- ステージに当たり判定（`PhysicsStaticObject`）があること（[ボス戦の広間の設計](../../ステージ/ボス戦の広間/ボス戦の広間の設計.md)）。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 球をすべらせて、カメラを壁の手前に寄せる `CameraCollision` を作る | ビルドが通る（ゲームの動きはまだ変わらない） |
| 2 | `GameCamera` の三人称に組み込む | 柱や壁を背にすると、カメラが手前で止まる |
| 3 | カメラが頭のすぐ近くまで寄ったら、体を隠す | 壁ぎわの角でカメラが寄ると、体が消える |

**読み方:**

- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- コードの下に、3つを置きます。
  - 「行・何をしているか」の表: 1行ずつの動き。
  - 「なぜ」「効果」: その小手順でそう書く理由と、書くと何ができるようになるか。
  - 「初めて出てくる名前」の表: このページで初めて出てくる名前を、コードに出てくる順に並べます。2回目からは載せないので、わからない名前はページ内検索（`Ctrl+F`）で最初に出てきた所を探してください。
- [前提知識](../../../前提知識.md) で「よく知っている」にあるもの（`Vector3`・`Length()`・`g_camera3D`・`PhysicsStaticObject`・`CharacterController`、`constexpr`・`override`・`nullptr` など）は、表に載せません。
- この手順では、もとからあるコードを消したり書き換えたりしません。足すだけです。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

```cpp
}

void CameraCollision::Reset()
{
	m_isReset = true;
}

Vector3 CameraCollision::Solve(const Vector3& start, const Vector3& position, float deltaTime)
{
	const Vector3 toCamera = position - start;
	const float length = toCamera.Length();
	if (length <= FLT_EPSILON) {
		m_distance = 0.0f;
		return position;
	}

	// 頭の中心からカメラを置きたい位置へ、球をすべらせる。
	btTransform from;
	btTransform to;
	from.setIdentity();
	to.setIdentity();
	from.setOrigin(btVector3(start.x, start.y, start.z));
	to.setOrigin(btVector3(position.x, position.y, position.z));
	SweepCallback callback;
	PhysicsWorld::GetInstance()->ConvexSweepTest(&m_sphere, from, to, callback);
	// どこまで進めたかの割合。当たらなければ 1（置きたい位置まで行ける）。
	const float hitRate = callback.hasHit() ? callback.m_closestHitFraction : 1.0f;

	if (m_isReset || hitRate < m_rate) {
		// 壁の中が映らないように、寄せるのはすぐに。
		m_rate = hitRate;
		m_isReset = false;
	}
	else {
		// 戻るのはゆっくり。経過時間を使い、FPS によらず同じ速さにする。
		m_rate += (hitRate - m_rate) * (1.0f - expf(-deltaTime / RETURN_SECONDS));
	}

	// 当たった点ではなく、頭の中心とカメラを結ぶ線の上に置く（柱の角で横へずれないように）。
	m_distance = length * m_rate;
	return start + toCamera * m_rate;
}
```

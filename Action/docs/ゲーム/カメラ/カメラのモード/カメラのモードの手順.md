# カメラのモードの手順

作成日: 2026-11-16
対象: [GameCamera.h](../../../../Game/Source/Objects/GameCamera.h)・[GameCamera.cpp](../../../../Game/Source/Objects/GameCamera.cpp) の三人称の寄り・俯瞰と、その切り替え
設計: [カメラのモードの設計](カメラのモードの設計.md)
経緯: [カメラのモードの経緯](カメラのモードの経緯.md)

1つしかなかった三人称のカメラを、近くから見る「寄り」（原神くらい）と、今までの「俯瞰」の2つに分け、B キーで切り替えられるようにするまでの手順です。

**出来上がるもの:** ゲームを始めると、寄りのカメラでプレイヤーの後ろから見ます。B キーを押すと俯瞰に、もう一度押すと寄りに、0.25秒かけてなめらかに移ります。V キー（パッドは B ボタン）で一人称に入り、もう一度 V を押すと、入る前の三人称（寄りか俯瞰）に戻ります。一人称のときに B キーを押すと、俯瞰に移ります。

**前提:**

- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- V キーで三人称と一人称を切り替える `GameCamera` が入っていること（[一人称の腕の設計](../../プレイヤー/一人称の腕/一人称の腕の設計.md)・[一人称の揺れの手順](../../プレイヤー/一人称の揺れ/一人称の揺れの手順.md)）。この手順は、その `GameCamera`（main の #170 の時点）から始めます。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 三人称の置き方を、寄りと俯瞰の2つにする（最初は寄り） | まだビルドしない（手順2で通る） |
| 2 | 一人称から V で、入る前の三人称に戻す | 起動すると寄りで映る。V で一人称に入って戻れる |
| 3 | B キーで俯瞰と寄りを切り替える | B で俯瞰と寄りが入れ替わる |
| 4 | 寄りと俯瞰の間を、なめらかに移す | 切り替えるとき、カメラが 0.25秒かけて動く |

**読み方:**

- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- 書き換えるところは、「前」と「後」の枠を並べています（番号は、それぞれ変える前と変えた後の番号）。
- コードの下に、3つを置きます。
  - 「行・何をしているか」の表: 1行ずつの動き。
  - 「なぜ」「効果」: その小手順でそう書く理由と、書くと何ができるようになるか。
  - 「初めて出てくる名前」の表: このページで初めて出てくる名前を、コードに出てくる順に並べます。2回目からは載せないので、わからない名前はページ内検索（`Ctrl+F`）で最初に出てきた所を探してください。
- [前提知識](../../../前提知識.md) で「よく知っている」にあるもの（`Vector3`・`g_camera3D` の `SetPosition`・`SetTarget`・`SetViewAngle`・`GetForward`、`constexpr`・`enum class` など）は、表に載せません。

## 手順1: 三人称の置き方を、寄りと俯瞰の2つにする

三人称のカメラの距離・注視点の高さ・見下ろす角度・画角を、モードごとに持てるようにします。最初のモードは寄りにします。

この手順の途中では、まだもとの `ThirdPerson` を使う所（`ToggleCameraMode`）が残るので、ビルドは手順2が終わってから通ります。

ビルドが通ります。起動して B を押すと、カメラが 0.25秒かけて上へ動きながら画角が広がり、俯瞰になります。もう一度押すと、なめらかに寄りに戻ります。一人称から V で戻るときは、一瞬で切り替わります。

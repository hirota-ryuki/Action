# 走りとダッシュのモーションの設計

作成日: 2026-11-07（[動画からアニメーションを作る設計](動画からアニメーションを作る設計.md) から分けた）
対象: `Run.fbx`・`DashL.fbx`・`DashR.fbx`、[dash_roto.json](../../../tools/UnrealScripts/dash_roto.json)
経緯: [動画からアニメーションを作る経緯](動画からアニメーションを作る経緯.md)

原神の動画から作った走り（Run）とダッシュ（DashL / DashR）の、範囲と調整の数値です。作り方の手順は [動画からアニメーションを作る設計](動画からアニメーションを作る設計.md) にあります。

- **前傾は腰で折らず、体全体を倒す。** 後ろ足から頭まで一本の線に近づける。
- **走りは足を頭の下の方へ踏み込み、着いてから腰を沈めて受け止める。**
- **振り戻す脚は、かかとをお尻へたたんで短い振り子にする。**

---

## 1. 使う範囲

| クリップ | 動画の範囲 | 区間 |
|---|---|---|
| Run | 34.25〜34.72秒（15コマ、最後は最初と同じ） | 右足が前に着く f02、左足 f09 |
| DashL / DashR | 33.41〜33.94秒（17コマ） | しゃがむ f00〜f04、蹴って低く滑る f04〜f11、着地 f11〜f16 |

DashR は DashL の左右（`map`）を入れ替えただけ。ダッシュのあとの走りは、左で蹴ったら f05、右なら f12 から始める（ダッシュの最後と同じ足の形）。

---

## 2. 調整用の数値（`dash_roto.json`）

| 内容 | 値 |
|---|---|
| 胴体の回し方の配分（腰・Spine・Chest・UpperChest） | 0.4・0.2・0.2・0.2（`torso_split`） |
| データより前へ倒す角度（胴体と首） | 走り 10°、ダッシュ 8°（`lean_deg`） |
| 脚も前へ倒す角度 | 走り 0°、ダッシュ 5°（`leg_lean_deg`） |
| 頭だけを起こす角度 | 30°（`head_pitch_deg`。首の線は変えず、顔の向きだけ） |
| 走りで踏み込んで腰を沈める | 最大 6cm。右足 f02〜f04、左足 f09〜f11 で沈む。足首の位置は変えない（`crouch`） |
| 走りで足首を前へずらす | 着く直前から最大 16cm 前へ出し、着いてから戻す。着いた瞬間の足首は腰の 22〜28cm 前（`shift_feet`） |
| 振り戻す脚の膝の曲がりの下限（走りだけ） | 125°。太ももが腰の下を通るとき（-95°〜-35°）だけ（`tuck_knee_deg`） |

### 腕

| クリップ | 作り方 |
|---|---|
| Run | 読み取りの値を使わず、反対側の太ももの角度から作る。太もも -131°（後ろ）〜 -15°（前）を 0〜1 にして、上腕 = -190° + 145°×割合、肘の曲がり = 45° + 40°×割合 |
| ダッシュの着地 | 最後の6コマで、読み取りの値から走りの腕へ 0.2〜1 の割合で寄せる（走りの始めと合わせる） |
| ダッシュ（33.61・33.64秒の後ろの腕） | 読み取りでは上を通って回っていたので、下を通るように手で直した |

---

## 3. 決めたこと

| 決めたこと | 理由 |
|---|---|
| ダッシュには、かかとをたたむのを入れない | 動画のとおり膝を深く曲げている。入れると着地で腰が 47cm まで沈んだ |
| たたむのは、太ももが腰の下を通るところからだけ | まだ後ろにあるうちにたたむと、かかとが 85cm まで跳ね上がった |
| 走りの腕は脚から作る | 読み取った腕をならすと、振りが打ち消し合ってほとんど振れなかった |

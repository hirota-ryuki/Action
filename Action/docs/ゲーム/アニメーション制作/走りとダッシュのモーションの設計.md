# 走りとダッシュのモーションの設計

作成日: 2026-11-07（[動画からアニメーションを作る設計](動画からアニメーションを作る設計.md) から分けた）
対象: `Run.fbx`・`Dash.fbx`、[dash_roto.json](../../../tools/UnrealScripts/dash_roto.json)
経緯: [動画からアニメーションを作る経緯](動画からアニメーションを作る経緯.md)

原神の動画から作った走り（Run）とダッシュ（Dash）の、範囲と調整の数値です。作り方の手順は [動画からアニメーションを作る設計](動画からアニメーションを作る設計.md) にあります。

- **前傾は原神のデータのまま。** 胴体・脚を、データより前へ倒し足さない（倒し足すと、原神より 8〜10° 前かがみになった）。
- **走りは足を頭の下の方へ踏み込む。腰の上下は原神のデータのまま（約7cm）で、沈め足さない。**
- **振り戻す脚は、かかとをお尻へたたんで短い振り子にする。**

---

## 1. 使う範囲

コマは 30fps で、クリップの先頭を 0コマ目と数える（以下同じ）。

| クリップ | 動画の範囲 | 区間 |
|---|---|---|
| Run | 34.25〜34.72秒（15コマ、最後は最初と同じ） | 右足が前に着くのが Run の 2コマ目、左足が 9コマ目 |
| Dash | 33.41〜33.94秒（17コマ） | しゃがむ 0〜4コマ目、蹴って低く滑る 4〜11コマ目、着地 11〜16コマ目 |

Dash は左足で蹴り、右足で着地する。原神と同じく、蹴る足はいつも同じ（右足で蹴るクリップは作らない）。ダッシュのあとの走りは Run の 5コマ目から始める（ダッシュの最後と同じ足の形）。

## 2. 調整用の数値（`dash_roto.json`）

| 内容 | 値 |
|---|---|
| 胴体の回し方の配分（腰・Spine・Chest・UpperChest） | 0.4・0.2・0.2・0.2（`torso_split`） |
| データより前へ倒す角度（胴体と首） | 走り・ダッシュとも 0°（`lean_deg`） |
| 脚も前へ倒す角度 | 走り・ダッシュとも 0°（`leg_lean_deg`） |
| 頭だけを起こす角度 | 30°（`head_pitch_deg`。首の線は変えず、顔の向きだけ） |
| 走りで踏み込んで腰を沈める | 0cm（`crouch` の `lower_cm`）。沈める割合 `weights` は残してあり、`lower_cm` を上げると Run の右足が着く 2〜4コマ目、左足が着く 9〜11コマ目で沈む。足首の位置は変えない |
| 走りで足首を前へずらす | 着く直前から最大 16cm 前へ出し、着いてから戻す。着いた瞬間の足首は腰の 22〜28cm 前（`shift_feet`） |
| 振り戻す脚の膝の曲がりの下限（走りだけ） | 125°。太ももが一番後ろから一番前まで振られていく間で、腰の下を通るとき（-95°〜-35°）だけ（`tuck_knee_deg`）。一番前まで出て戻り始めた脚（着地しようとしている脚）はたたまない |

### 腕

| クリップ | 作り方 |
|---|---|
| Run | 読み取りの値を使わず、反対側の太ももの角度から作る。太もも -131°（後ろ）〜 -15°（前）を 0〜1 にして、上腕 = -190° + 145°×割合、肘の曲がり = 45° + 40°×割合 |
| Run の脇の締め | ロトスコープの前に、元のクリップの上腕を体の側へ回す（`out_deg`、左 -8°・右 -25°）。肩から見た肘の外への距離は、左 3.7cm・右 5.2cm（締める前は 6.7cm・11.4cm）で、どのコマも同じ |
| Run の肘から先 | 前腕を体の外へ開く（`splay_deg`、左 25°・右 42°）。肩から見た手の外への距離は、左 10.3cm・右 11.2cm で、肘より 6cm ほど外。肩から肘はほぼ下へ、肘から手は外へ開く（原神の走りと同じ形） |
| ダッシュの低く滑るところ | 原神と同じく、腕を止める（`arm_hold`）。Dash の 5〜13コマ目は、前の腕（左）を上腕 -66°・前腕 6°（拳を胸の前へ出す。読み取りの平均）、後ろの腕（右）を上腕 -200°・前腕 -180°（後ろへまっすぐ伸ばし、拳が頭の高さ）で止める。3 → 5コマ目で読み取りの値から寄せ、13 → 16コマ目で読み取りの値へ戻す（smoothstep） |
| ダッシュの着地 | 最後の6コマで、読み取りの値から走りの腕へ 0.2〜1 の割合で寄せる（走りの始めと合わせる）。最後のコマは `arm_hold` の影響を受けないので、走りへのつながりは変わらない |

角度は前 0°・真上 90°・真下 -90°（後ろは -180°）で、前腕も地面に対する向き。

## 3. 決めたこと

| 決めたこと | 理由 |
|---|---|
| ダッシュには、かかとをたたむのを入れない | 動画のとおり膝を深く曲げている。入れると着地で腰が 47cm まで沈んだ |
| たたむのは、太ももが腰の下を通るところからだけ | まだ後ろにあるうちにたたむと、かかとが 85cm まで跳ね上がった |
| 着地しようとしている脚はたたまない | 右脚は着地の直前に太ももが -53° まで戻るので、角度だけで決めるとたたまれ、着地のコマで膝が 133° → 23° と一気に伸びて、すねがばたついて見えた |
| 走りの腕は脚から作る | 読み取った腕をならすと、振りが打ち消し合ってほとんど振れなかった |
| 走りの脇の締めは左右で角度を変える | 元のクリップは右腕の方が大きく開いている。同じ角度で回すと、右の肘を左と同じくらいまで寄せる前に左手が体の内へ入った。右を -40° まで回すと、右手が体の前を横切った |
| 前腕は `out_deg` でなく `splay_deg` で開く | `out_deg` は前後の軸まわりに回すので、元のクリップで前を向いている左の前腕はねじれるだけで、手が外へ出なかった |
| ダッシュの低く滑るところは腕を止める | 後ろの腕は体に隠れて読み取りが乱れ、1コマで 66° 跳ね、肘が 45° → 139° → 49° と曲げ伸ばしして、ばたついて見えた。原神ではこの間、腕はほとんど動かない |

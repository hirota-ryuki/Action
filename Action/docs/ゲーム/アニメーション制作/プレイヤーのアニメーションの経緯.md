# プレイヤーのアニメーションの経緯

設計: [プレイヤーのアニメーションの設計](プレイヤーのアニメーションの設計.md)、[リターゲットの設計](リターゲットの設計.md)、[姿勢補正スクリプトの設計](姿勢補正スクリプトの設計.md)

何をして、なぜ今の形になったかの記録です。日付ごとに書き足します（2026-11-07 に設計から移した。文章は移す前のまま）。コマは 30fps で、クリップの先頭を 0コマ目と数えます。

## Idle の肘を下げた（2026-11-08）

「Idle モーションの肘を下に下げて」とのことでした。測ると、元の Idle の上腕がすでに真下から横へ約19°開いていて、そこへ 11° 足したため約29°になり、肘が浮いていました（肩から 19cm 下・横へ 11cm）。
上腕を開くのをやめ、代わりに前腕を横へ 20° 開きました。肘は肩から 21cm 下・横へ 7cm に下がり、手の横の位置は 16〜19cm から 15〜18cm で、ほぼそのままです。

## Idle の腕をもう少し前へ戻した（2026-11-08）

「もう少し前」とのことで、後ろへ回す角度を上腕 8° → 6°、前腕 16° → 14° にしました。肩から見た手は 3〜5cm 前になりました。

## Idle の腕を少しだけ前へ戻した（2026-11-08）

「腕もう少しだけ前にして」とのことで、後ろへ回す角度を上腕 10° → 8°、前腕 18° → 16° にしました。肩から見た手は、3cm 後ろ〜2cm 前から 1〜3cm 前になりました。

## Idle の腕をもう少し開き、横揺れを半分にした（2026-11-08）

「もう少し外側に開いて」「横揺れを半分くらいの動きに抑えて」とのことでした。腕の開きは 8° → 11° にしました。
UE で測ると、Idle の横揺れは主に腰の横移動（-5.4〜+10.8cm）で、背骨の傾き（±4°くらい）が付き、足は動いていませんでした。`adjust_bone_rotation.py` に `motion_scale` を足し、全部のボーンの回転と位置を、全コマの平均のポーズを中心に 0.5倍にしました。腰の横移動は 8.2cm、頭は 11.4cm になり、足は 0.3cm 以内でその場に残りました。
はじめ `J_Bip_` のボーンだけを縮めたら、腰の横移動は親の `Root` に入っていたので縮まらず、脚の回転だけが半分になって足が横へ約 5cm 滑りました。そのため Root も含めた全部のボーンを縮めています。

## Idle の腕の横への開きを半分にした（2026-11-08）

16° 開いたものを見て「ちょっと開きすぎ。元と比べて半分の角度にしてみて」とのことで、上腕の開きを 8° にしました。前後はそのまま（後ろへ 10°・18°）です。肩から見た手は、横へ 13〜17cm になりました。

## Idle の腕を、もっと後ろ・もっと横へ出した（2026-11-08）

「腕の前後が最初のバージョンに戻っている」とのことでしたが、確かめてもらったときの作業ツリーが main から切った `WalkArms` だったため、Idle が直す前のままだっただけでした。
あわせて「もっと後ろ、もっと外側（横）に」とのことで、上腕を 6° → 10°、前腕を 15° → 18° 後ろへ、上腕の開きを 10° → 16° にしました。肩から見た手は、前後が 3cm 後ろ〜2cm 前（肩の真下あたり）、横が 19〜23cm になりました。

## Idle の腕を外へ開いた（2026-11-08）

体の横へ下ろしたあと、「袖が被っているのでもう少し外側に腕を広げて。少し被るくらいなら全然大丈夫」とのことでした。`pitch_deg` は左右の軸まわりにしか回せないので、前後の軸まわりに回して外へ開く `out_deg` を `adjust_bone_rotation.py` に足し、上腕を 10° 開きました。肩から見た手は、外へ約 9cm から 15〜18cm になりました。`idle_arms.json` は元の Idle から作り直す設定なので、Idle.fbx を main のものに戻してから流しました。

## Idle の腕を、体の横へ下ろした（2026-11-08）

「アイドルモーションの際、腕が前にあるので横にして」とのことでした。UE で肩から見た手の位置を測ると、Idle（Mixamo の Breathing Idle）は手が肩より 10〜15cm 前にあり、前腕が約30°前へ出て、手が太ももの前に来ていました（Walk は平均で肩のほぼ真下）。
`adjust_bone_rotation.py` で、上腕を 6°・前腕を 15° 後ろへ回しました（`idle_arms.json`）。手は肩の 1〜6cm 前、肘は肩のほぼ真下になり、横から見て腕が体の横に下りた形になります。左右への開きと、呼吸の揺れは元のままです。
はじめ `pitch_deg` に負の値を入れたら、手がかえって 20cm 前へ出ました。「正 = 前に倒す」はボーンの上の端が前へ出る向きなので、下を向いた腕では正の値で手が後ろへ動きます。

## Walk の腕を前へ出した（2026-11-08）

「歩きモーションのとき腕をもう少し前に出して」とのことでした。UE で肩から見た手の前後を測ると、Walk（Mixamo の Female Walk）は 14.7cm 後ろ〜3.4cm 前で、後ろへ振る方が大きくなっていました。
振り幅は変えずに、振る中心を前へずらしました。上腕を 8°・前腕を 6° 前へ回し（`walk_arms.json`）、手は 6.9cm 後ろ〜11.0cm 前になりました。

## ダッシュと走りは、原神の動画から作り直した（2026-11-06）

「原神の動きを再現して」とのことで、ダッシュ（DashL / DashR）と走り（Run）を、原神の動画から関節の角度を読み取って作り直しました（[動画からアニメーションを作る設計](動画からアニメーションを作る設計.md)）。ダッシュはしゃがみ・一蹴り・着地の3本をやめて、切り替えなしの通しの1本にしました。`DashCrouchL/R`・`DashLandL/R` と、`dash_lean.json`・`run_pelvis.json` は消しました。

## 歩く速さを 300 から 170 に下げた（2026-11-06）

Female Walk を等速で再生すると、足が地面を送る速さは約130でした。300 のままだと約2.3倍で再生することになり、早送りのように見えます。
そこで、原神の歩きに近い落ち着いた速さ（170、約1.3倍で再生）にしました。走る速さは以前と同じ 480 です。

## 起動直後に T ポーズになるエンジンの不具合を直した（2026-11-06）

`Animation::PlayCommon`（[Animation.h](../../../k2EngineLow/graphics/Animation.h)）は「同じクリップがもう再生中なら何もしない」を確かめるのに、最後に再生したコントローラーを見ます。
まだ何も再生していないときは、その番号が -1 になって配列の外を読んでいました。そこのゴミが偶然 0 番のクリップ（Idle）と一致すると、最初の再生が無視され、別のクリップ（Walk など）に切り替わるまで T ポーズのままになります。
何も再生していないときは確かめずに、補間なしで再生するようにしました。`IsPlaying()` も同じ理由で、何も再生していなければ `false` を返します。

## Walk の上半身を前へ 20° 起こした（2026-11-06）

リターゲットは、元のモーションの「基準のポーズからの動き」を、SK_Player の基準のポーズに足します。そのため、背骨の曲がり方は VRM の T ポーズのものが残ります。
SK_Player は胸から首にかけて後ろへ傾いた形（UpperChest→Neck が後ろへ約16°）です。Walk では歩くあいだずっと上半身がのけぞって見えていました（頭が腰より 4.7cm 後ろ）。
そこで、背骨の3本で合わせて前へ 20° 傾け、首で 8° 戻しました。頭は腰より 4.6cm 前になりました。歩くときは少し前に傾いている方が自然なので、まっすぐ（10°）より強めにしています。
また、元の Walk は顎が上がっていました（頭が平均 15° 上向き）。頭は戻しすぎず前へ 6° にして、平均 3° 下向き（0.5〜7.8°）＝顎を引いた形にしています。
Idle も同じ形（頭が腰より 2.8cm 後ろ）ですが、反りが小さく目立たないので直していません。

| 候補 | 選ばなかった理由 |
|---|---|
| リターゲッターのリターゲットポーズ（ターゲット側）を直して、リターゲットし直す | 元のモーションと UE のプロジェクトがある PC でしかできない。効果は同じ |
| ゲーム側（エンジン）でボーンに角度を足す | ゲームに置く FBX は SK_Player の骨格そのまま、という決まりから外れる |
| `.tka` を直接書き換える | FBX の方が新しいと、起動時に `.tka` が作り直されて消える |

> 以下の「ゲームの録画を原神の動画と並べて」から「Dash は Run を前へ倒して作った」までは、それより前のやり方（Run の骨の角度を足して形を作る）での記録で、新しいものが上にある。今のクリップには使っていない。

## 走りの上半身を、ダッシュより少し起きた前傾にした（2026-11-06）

「走っているときは、ダッシュの上体よりちょっと上に上がっている状態に」とのことでした。ダッシュの飛び出すポーズは前傾 約52° なので、走りを約43°（全コマの平均 41°、元は 31°）にしました。

- `run_pelvis.json` で、腰を 6°（-15° → -9°）、背骨を Spine 3°・Chest 2°・UpperChest 1° 前へ倒し、首・頭を 5° ずつ戻して前を見るようにしました。太ももは腰を倒した分だけ戻し（15° → 9°）、脚の向きは変えていません。
- 前に背骨だけで 47° まで倒したときは、骨盤が起きたままで「へっぴり腰」に見えたので、今回は腰と背骨で半分ずつ倒しています（骨盤 74° → 68°）。
- ダッシュのクリップは、同じだけ `dash_lean.json` で差し引いて、形を変えていません。

## 飛び出すポーズを低くし、顔を斜め下へ向けた（2026-11-06）

2枚目の参考画像（原神の、地面すれすれを前へ出る1コマ）を見せてもらい、「もっと姿勢を低く」「顔は斜め下を見て」とのことでした。画像の上半身の倒れ具合（地面から約38°）は今と同じで、違うのは腰の低さ（画像では脚の長さの半分ほど）、前の足のすねを後ろへほぼ水平にたたんでいること、後ろ足を低く伸ばしていることでした。

- `pose_to` の目標: 後ろ足 太もも -150°・すね -158°、前の足 太もも -20°・すね -170°（膝 150°）。腕は前のまま。`ground_toe_cm` は 5cm。腰は 85cm → 54cm（しゃがみ込みの底とほぼ同じ高さ）で、後ろ足 5cm・前の足 18cm 浮きます。
- 首 -12° → -2°、頭 -12° → 6° にして、顔を斜め下へ向けました。
- しゃがみ込みからのつなぎ: `ramp_end` を一蹴り（DashL / DashR）の 2コマ目にし、`blend_from`（1・0.5・0.15）に `bend_knees` を足しました。蹴る足が地面にめり込むコマで腰を上げる代わりに、膝を曲げて足を地面の上に保ちます。前は腰が 54 → 76 → 54cm と一度上がってから下がっていましたが、今は 54 → 64 → 54cm です。
- 着地（DashLandL / DashLandR）も `blend_from`（1・0.75・0.5・0.3・0.15・0.05、`bend_knees`）で一蹴りの最後のポーズから始めます。腰は 54cm から 85cm（走りの高さ）へだんだん上がり、前の足は膝を 80〜95° 曲げて接地します。前は着地の最初が 85cm で、低いポーズから 0.05秒で腰が跳ね上がっていました。

## 飛び出すポーズを、参考画像に合わせて起こし、前の膝を前へ出した（2026-11-06）

参考画像（原神の動画の、走り出して宙を前へ出る1コマ）を見せてもらい、「もっとこんな感じで前に出る感じ」とのことでした。画像では上半身は約48°の前傾、前の足は膝を前へ出してすねがほぼ真下、後ろ足は膝を伸ばして斜め後ろ下へ、後ろの腕はほぼ水平に後ろへ伸ばし、前の腕は肘を曲げて拳を前上へ出しています。

- 一蹴りの体の倒し方を腰 10°・背骨 5・5・4°・首 -12°・頭 -12° にしました（前は腰 20°・背骨 8・8・6°・首 -20°・頭 -22°）。上半身の前傾は約68° → 約52° です。
- `pose_to` の目標: 後ろ足 太もも -143°・すね -147°（膝 4°）、前の足 太もも -35°・すね -105°（膝 70°）、前の腕 上腕 -55°・前腕 30°、後ろの腕 上腕 175°・前腕 178°。
- 高さは `ground_toe_cm` を 15cm にしました。前の足が 15cm、後ろ足が 27cm 浮き、腰は 87cm です。
- そのあと「前に出ている足をもっと上に」とのことで、前の足を 太もも -35° → -10°・すね -105° → -100°（膝 70° → 90°）にしました。後ろ足の方が低くなって腰が下がるので、`ground_toe_cm` を 25cm にして腰の高さ（85cm）を保っています。後ろ足が 25cm、前の足が 27cm 浮きます。
- その前に試した「走りを前のめり（47°）」「へっぴり腰を直して膝を前へ」は、「2個前まで戻して」とのことで取り消しました。

## 一蹴りを、原神の動画に合わせて「低く滑るポーズ」にした（2026-11-06）

原神のサンプル動画（個人用 OneDrive の `02_Action参考資料/原神/`、33秒あたり）を1コマずつ見ると、ダッシュは「しゃがむ（約0.1秒）→ 同じポーズのまま低く滑る（約0.2秒）→ 上半身を起こしながら着地して走りへ（約0.1秒）」でした。滑るところは足を回さず、頭から後ろ足までほぼ一直線で、頭は起こして前を見ています。前の版（下の「まっすぐ走り出す1歩目」）は前傾を 45° に起こしたので、低く滑る感じがありませんでした。

- DashL は Run の 14〜16コマ目の3コマに、Run の 16コマ目を7コマくり返して足した10コマ（0.3秒）です（`frames.hold`）。`pose_to` は DashL の 3コマ目で目標に着き（`ramp_end`）、あとはそのポーズで止まります。DashR は Run の 5〜7コマ目です。
- 一蹴りだけ、体の倒し方をクリップごとに上書きします（腰 20°・背骨 8・8・6°・首 -20°・頭 -22°）。上半身は地面から約22°（真上から約68°）で、首と頭を起こして前を見ます。しゃがみ込みは全体の設定（45°）のままです。
- 滑るポーズ: 後ろ足は太もも -145°・すね -152° で斜め後ろへ低く伸ばし、前の足は太もも -65°・すね -160°（膝 95°）で膝を前へ出してすねを後ろへたたみます。前の腕は肘を曲げて拳を前へ（上腕 -30°・前腕 10°）、後ろの腕はまっすぐ後ろ上へ（上腕 165°・前腕 170°）。
- 高さは `ground_toe_cm` を 12cm にして決めています。前の足のつま先が 12cm、後ろ足が 19cm、腰が 75cm です。
- しゃがみ込みからは `blend_from`（1・0.5・0.15）で2コマのうちに伸び上がります。

## Run とダッシュの骨盤を起こした（2026-11-06）

「走っているときとダッシュのとき、お尻が上がっているところがある」とのことで、骨盤（腰 → 背骨の付け根の線）の向きを測りました（`log_frames` の `pelvis`。真上 = 90°）。

| | 直す前 | 今 |
|---|---|---|
| Walk（比べるため。直していない） | 78〜80° | — |
| Run | 58〜60° | 73〜75° |
| ダッシュ（一蹴り・しゃがみ込み） | 26〜28° | 49〜51° |
| 着地 | — | 65〜67° |

Run は歩きより骨盤が 20° 前へ倒れていて、ダッシュはさらに腰から 32° 倒していたので、体の前傾を骨盤だけで作っていました。そのため、前の太ももを上げたときに腰で大きく折れ、お尻が上を向いていました。

- **Run**（`run_pelvis.json`）: 腰（Hips）を 15° 起こし、そのぶん背骨（Spine）と両方の太ももを 15° 前へ回します。上半身と脚の向きは元のまま、骨盤だけが起きます。`ThirdPersonRunPlayer_Run.fbx` から `Run.fbx` を書き出し、ゲームの Run・Jump は `Run.fbx` を使います。
- **ダッシュ**（`dash_lean.json`）: 元を `Run.fbx` にし、腰の前傾を 32° → 24° にして、太ももを 8°、背骨（Spine・Chest・UpperChest）を 8・8・6° にしました（前は太もも 0°、背骨 5・5・4°）。着地は腰 14° → 8°、太もも 6°、背骨 5・5・4° です。上半身の前傾は全コマの平均で 72° → 69°、脚の形（`pose_to`・`crouch` の目標）は同じです。
- 作り直す順番: `run_pelvis.json` → `dash_lean.json`。

## Dash は Run を前へ倒して作った（2026-11-06）

ダッシュは以前、Run の1コマで止めた仮の状態でした。体全体をぐっと前へ出し、地面を一蹴りして飛び出す動きにするため、Run から `DashL.fbx`・`DashR.fbx` を作りました。

- **脚ごと全身を倒す**: 腰（Hips）を前へ 32° 回し、太ももは戻しません。後ろの足から頭まで、体が一直線に近いまま前へ倒れます（短距離走の加速の形）。
- **背骨は少しだけ**: Spine・Chest・UpperChest で合わせて 14°。腰と合わせて、上半身（腰→首）の前傾は全コマの平均で 73° です（90° が地面と平行）。
- **首と頭で前を見る**: 首 22°・頭 20° 戻して、地面ではなく進む先を見るようにしました。
- **足を地面に合わせる**: `keep_feet_on_ground` で、つま先の一番低い高さを元（0.66cm）にそろえています。着地は腰の真下になります。
- **蹴って宙へ飛び出す1歩にする**: 参考画像（原神のキャラクターが宙を飛ぶように走る1コマ）の形に合わせました。頭から後ろ足までほぼ一直線で地面とほぼ平行、後ろ足は水平近くまで伸ばし、前足は膝を前へ、片腕は拳を前へ突き出し、もう片腕は後ろへ引いた形です。
  - 倒したあとのコマごとの足の位置を測ると、左足は Run の 15〜16コマ目で接地して 17コマ目でつま先が離れ、右足は Run の 5〜7コマ目で接地して 8コマ目で離れます。
  - DashL（左足で蹴る）は Run の 14〜17コマ目・0〜5コマ目の10コマ（0.3秒）です。着地して蹴り（DashL の 3コマ目まで）、蹴った左足が後ろへ伸びていく Run の 5コマ目で終わります。Run の 5コマ目は、Run の中で参考画像にいちばん近いコマでした。DashR は半周期ずらした Run の 5〜14コマ目です。
  - DashL / DashR の 1コマ目から最後のコマへ、`pose_to` で腕・脚を目標の向きへゆっくり寄せます。蹴った足が離れる 3コマ目からは、腰を 8cm 下げます。最後のコマでは、体は地面すれすれを低く飛び、前の足は膝を前・上へ引き上げて、足の一番低いところが地面から 15〜17cm です（どのコマでもつま先は地面より上）。
  - 経緯: 最初は DashL / DashR の 3コマ目から寄せて腰を 15cm 持ち上げ、1.5倍で流していました（足は 27〜29cm 浮く）。「姿勢を低く」「バタバタして見える」とのことで、腰を下げ、寄せ始めを早め、等速にしました。そのあと「前の足の着地が早すぎる」とのことで、前の太ももを -50° から -25° に上げました（前の足は地面から 4〜6cm → 15〜17cm）。
  - 連打したときは、飛び出したポーズから次の蹴りの着地へ 0.05秒の補間で移ります（着地して、また蹴る）。
- **蹴る前にしゃがみ込む**（`DashCrouchL` / `DashCrouchR`）: 参考画像（片膝を深く曲げて低く構え、片腕を前へ垂らし、もう片腕を後ろへ引いた形）に合わせ、地面から出すときは一度しゃがんでから蹴ります。
  - DashCrouchL は Run の 10〜14コマ目の5コマに、Run の 14コマ目を4コマくり返して足した9コマ（0.27秒）です。Run の 14コマ目は DashL の最初のコマと同じで、蹴る左足が前へ下りてくるところです。DashCrouchR は Run の 1〜5コマ目です。
  - `pose_to` で最後のコマを次の形にします（角度は前 = 0、真下 = -90）。

    | | 太もも | すね | 足 | 膝の曲がり |
    |---|---|---|---|---|
    | 前の足（蹴る足） | -15° | -100° | -12°（ほぼ平ら） | 85° |
    | 後ろの足 | -115° | -160° | -50°（つま先立ち） | 45° |

    腕は、前の足と反対の腕を前へ垂らし（上腕 -85°・前腕 -45°）、同じ側の腕を後ろへ引きます（上腕 165°・前腕 -165°）。
  - DashCrouchL / DashCrouchR の 4コマ目で `pose_to` の形に着きます（`ramp_end`）。腰は `ground_toe_cm`（0.5cm）で、両足とも地面に着く高さまで下げます。腰の高さは 88cm から 58cm になります。
  - そのあとの4コマは踏ん張るところで、`crouch`（`crouch_after_pose`）で足を動かさずに腰をさらに 6cm 落とします（52cm、前の膝は 96°）。
  - DashL / DashR は `blend_from` で、しゃがみ込みの最後のポーズから始まります（混ぜる割合 1・0.7・0.4・0.15）。蹴る足のつま先が地面にめり込むコマ（最大 9cm）は腰を上げたので、腰は 52 → 65 → 81cm と2コマで一気に伸び上がり、蹴る足は DashL / DashR の 3コマ目まで地面に着いたままです。
  - ゲームでは、しゃがみ込みへ 0.05秒の補間で入り、2.5倍で約0.1秒流したあと、一蹴りへ 0.03秒で移ります。一蹴りがしゃがんだポーズから始まるので、補間は短くてよいです。連打で続けて蹴るときは、しゃがんだところを飛ばして DashL / DashR の 2コマ目から流します。
  - 経緯: 最初はしゃがむ 0.13秒のあと、ふつうの一蹴りへ 0.1秒の補間でつないでいました。「もっと滑らかに」「しゃがんで踏ん張って力を溜めてから一気に飛び出す感じ」とのことで、踏ん張る間と `blend_from` を足しました。そのあと「溜めはいるが、もっと一瞬で」とのことで、0.27秒（等速）から約0.1秒（2.5倍）にしました（2026-11-06）。
- **足の振りを少し大きく**: 太ももの振り幅を 1.15倍にしました。1.3倍だと、脚ごと倒した分と合わさって、振り上げたかかとが腰より高く（115cm）上がりすぎました（1.15倍で 109cm）。

# 走りとダッシュのモーションの設計

作成日: 2026-11-07（[動画からアニメーションを作る設計](../動画からアニメーションを作る/動画からアニメーションを作る設計.md) から分けた）
対象: `Run.fbx`・`Dash.fbx`、[dash_roto.json](../../../../tools/UnrealScripts/dash_roto.json)
経緯: [動画からアニメーションを作る経緯](../動画からアニメーションを作る/動画からアニメーションを作る経緯.md)の「2026-11-06 角度を足して直すやり方をやめ、動画から作り直した」から「2026-11-09 原神のまっすぐ走る動画に合わせて、肩から手までを一直線に外へ開いた」まで（走り・ダッシュの調整の項）

原神の動画から作った走り（Run）とダッシュ（Dash）の、範囲と調整の数値です。作り方の手順は [動画からアニメーションを作る設計](../動画からアニメーションを作る/動画からアニメーションを作る設計.md) にあります。

- 全体像: 動画から [ロトスコープ](../../../用語集.md#アニメーション制作)で読み取った脚・胴体・腕の角度を、UE で SK_Player のボーンに写してクリップにする。
- このページは、そこへゲーム用に足した調整（前傾・腰の沈み・足の踏み込み・腕の開き）を `dash_roto.json` の数値で決めたもの。

角度は前 0°・真上 90°・真下 -90°（後ろは -180°）。前腕も地面に対する向き。

- **前傾は原神のデータのまま。** 動画から読み取った角度に、さらに前へ倒す角度を足さない（足すと、原神より 8〜10° 前かがみになった）。
- **走りは足を頭の下の方へ踏み込む。腰の上下は原神のデータのまま（約7cm）で、さらに沈めない。**
- **振り戻す脚は、かかとをお尻へたたんで短い振り子にする。**

| 用語 | 何のことか |
|---|---|
| 腰・Spine・Chest・UpperChest | 胴体のボーン。腰（Hips）から上へ、背骨（Spine）・胸（Chest）・上胸（UpperChest）と並ぶ。`J_Bip_C_Spine` のように、`SK_Player` のボーンの名前になっている（[`J_Bip_*`](../../../用語集.md#左右と向き)） |
| 上腕・前腕 | 肩から肘までのボーンが上腕（`UpperArm`）、肘から手までが前腕（`LowerArm`） |

smoothstep は[用語集](../../../用語集.md#動きを近づける)にある。

## 1. 使う範囲

コマは 30fps で、クリップの先頭を 0コマ目と数える（以下同じ）。

| クリップ | 動画の範囲 | 区間 |
|---|---|---|
| Run | 34.25〜34.72秒（15コマ、最後は最初と同じ） | 右足が前に着くのが Run の 2コマ目、左足が 9コマ目 |
| Dash | 33.41〜33.94秒（17コマ） | しゃがむ 0〜4コマ目、蹴って低く滑る 4〜11コマ目、着地 11〜16コマ目 |

Dash は左足で蹴り、右足で着地する。原神と同じく、蹴る足はいつも同じ（右足で蹴るクリップは作らない）。ダッシュのあとの走りは Run の 5コマ目から始める（ダッシュの最後と同じ足の形）。

## 2. 調整用の数値（`dash_roto.json`）

[dash_roto.json](../../../../tools/UnrealScripts/dash_roto.json) のキー（Run・Dash の `rotoscope` と `clips` に書く）の名前。

| キー | 何をするか | どこから来たか |
|---|---|---|
| `torso_split` | 胴体の回転を、腰・Spine・Chest・UpperChest に分ける割合 | `adjust_bone_rotation.py` の `rotoscope` |
| `lean_deg` | 胴体と首を、データよりさらに前へ倒す角度（正が前） | 同上 |
| `leg_lean_deg` | 脚（太もも・すね・足）をさらに前へ倒す角度 | 同上 |
| `head_pitch_deg` | 頭だけに足す角度（負が顔を起こす）。首の線は変えず、顔の向きだけ | 同上 |
| `crouch`（`lower_cm`・`weights`） | 足首を動かさずに腰を落とす。`weights` はコマごとの割合 | `adjust_bone_rotation.py` のクリップの設定 |
| `shift_feet` | 足首を前へずらす（着く直前から前へ出し、着いてから戻す） | 同上 |
| `tuck_knee_deg` | 振り戻す脚の膝の曲がりの下限（かかとをお尻へたたむ） | 同上 |
| `arm_hold` | 腕を決まったポーズで止める。`a`・`b` が腕、`frames` が [寄せ始め・止め始め・止め終わり・戻し終わり] | 同上 |
| `out_deg`・`splay_deg` | 元のクリップの上腕を外へ回す・前腕を外へ倒す（[姿勢補正スクリプトの設計](../姿勢補正スクリプト/姿勢補正スクリプトの設計.md)） | 同上 |


| 内容 | 値 |
|---|---|
| 胴体の回し方の配分（腰・Spine・Chest・UpperChest） | 0.4・0.2・0.2・0.2（`torso_split`） |
| データより前へ倒す角度（胴体と首） | 走り・ダッシュとも 0°（`lean_deg`） |
| 脚も前へ倒す角度 | 走り・ダッシュとも 0°（`leg_lean_deg`） |
| 頭だけを起こす角度 | 30°（`head_pitch_deg`。首の線は変えず、顔の向きだけ） |
| 走りで踏み込んで腰を沈める | 0cm（`crouch` の `lower_cm`）。沈める割合 `weights` は残してあり、`lower_cm` を上げると Run の右足が着く 2〜4コマ目、左足が着く 9〜11コマ目で沈む。足首の位置は変えない |
| 走りで足首を前へずらす | 着く直前から最大 16cm 前へ出し、着いてから戻す。着いた瞬間の足首は腰の 22〜28cm 前（`shift_feet`） |
| 振り戻す脚の膝の曲がりの下限（走りだけ） | 125°。太ももが一番後ろから一番前まで振られていく間で、腰の下を通るとき（-95°〜-35°）だけ（`tuck_knee_deg`）。一番前まで出て戻り始めた脚（着地しようとしている脚）はたたまない |

### 腕

| クリップ | 作り方 |
|---|---|
| Run | 読み取りの値を使わず、反対側の太ももの角度から作る。太もも -131°（後ろ）〜 -15°（前）を 0〜1 にして、上腕 = -190° + 145°×割合、肘の曲がり = 45° + 40°×割合 |
| Run の腕の開き | 原神と同じく、肩 → 肘 → 手が一直線に少しずつ外へ開くようにする。ロトスコープの前に、元のクリップの上腕を回し（`out_deg`、左 -2°・右 -20°）、前腕を外へ開く（`splay_deg`、左 23°・右 36°）。肩から見た外への距離は、肘が左 5.9cm・右 6.6cm、手が左 11.7cm・右 12.1cm（手は肘の約2倍）で、どのコマも同じ |
| ダッシュの低く滑るところ | 原神と同じく、腕を止める（`arm_hold`）。Dash の 5〜13コマ目は、前の腕（左）を上腕 -66°・前腕 6°（拳を胸の前へ出す。読み取りの平均）、後ろの腕（右）を上腕 -200°・前腕 -180°（後ろへまっすぐ伸ばし、拳が頭の高さ）で止める。3 → 5コマ目で読み取りの値から寄せ、13 → 16コマ目で読み取りの値へ戻す（[smoothstep](../../../用語集.md#動きを近づける)） |
| ダッシュの着地 | 最後の6コマで、読み取りの値から走りの腕へ 0.2〜1 の割合で寄せる（走りの始めと合わせる）。最後のコマは `arm_hold` の影響を受けないので、走りへのつながりは変わらない |

## 3. 決めたこと

| 決めたこと | 理由 |
|---|---|
| ダッシュには、かかとをたたむのを入れない | 動画のとおり膝を深く曲げている。入れると着地で腰が 47cm まで沈んだ |
| たたむのは、太ももが腰の下を通るところからだけ | まだ後ろにあるうちにたたむと、かかとが 85cm まで跳ね上がった |
| 着地しようとしている脚はたたまない | 右脚は着地の直前に太ももが -53° まで戻るので、角度だけで決めるとたたまれ、着地のコマで膝が 133° → 23° と一気に伸びて、すねがばたついて見えた |
| 走りの腕は脚から作る | 読み取った腕をならすと、振りが打ち消し合ってほとんど振れなかった |
| 走りの腕の開きは左右で角度を変える | 元のクリップは右腕の方が大きく開き、前腕の向きも左右で違う。同じ角度では、肘と手の位置が左右でそろわない |
| 肘を寄せて前腕だけを開くのでなく、肩から手までを一直線に開く | 肘を寄せて前腕だけを開くと、肘から先が横へ折れて見えた。原神の動画では、手の外への距離は肘の約2倍で、腕全体が「ハ」の字に開いている |
| 前腕は `out_deg` でなく `splay_deg` で開く | `out_deg` は前後の軸まわりに回すので、元のクリップで前を向いている左の前腕はねじれるだけで、手が外へ出なかった |
| ダッシュの低く滑るところは腕を止める | 後ろの腕は体に隠れて読み取りが乱れ、1コマで 66° 跳ね、肘が 45° → 139° → 49° と曲げ伸ばしして、ばたついて見えた。原神ではこの間、腕はほとんど動かない |

# 止まるモーションの設計

作成日: 2026-11-07（[走りから止まる設計](../../プレイヤー/走りから止まる/走りから止まる設計.md) から分けた）
対象: `Game/Assets/modelData/player/Animation/StopL.fbx`・`StopR.fbx`
経緯: [走りから止まる経緯](../../プレイヤー/走りから止まる/走りから止まる経緯.md)

走りから止まるモーション StopL / StopR の作り方です。手順の全体は [動画からアニメーションを作る設計](../動画からアニメーションを作る/動画からアニメーションを作る設計.md) にあります。

- **原神の動画から作った通しの1本。** 前の足を突っ張って滑る → 起き上がって立つ。
- **StopL / StopR は脚・腕の左右を入れ替えただけ。**

---

## 1. 元にしたもの

| 項目 | 内容 |
|---|---|
| 動画 | 個人用 OneDrive の `02_Action参考資料/原神/`、29.78〜30.89秒（34コマ） |
| 向き | キャラクターが画面の左へ走っているので、`pose_to_angles.py` に `flip` を付けて左右を反転して読む |
| 角度 | [genshin_stop_pose.json](../../../../tools/UnrealScripts/genshin_stop_pose.json)（手で直したあと、ならしたもの。使うのは動画の 6コマ目から 34コマ分） |
| 設定 | [stop_roto.json](../../../../tools/UnrealScripts/stop_roto.json)（`start: 6, count: 34`） |

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| コマンド | [pose_to_angles.py](../../../../tools/Rotoscope/pose_to_angles.py) | 動画から読み取った結果を、モーションに使える角度にするため | 横から見た角度（前 0°・真上 90°・真下 -90°）に直す | このゲームの `Action/tools/Rotoscope/` のスクリプト（Python） |
| 引数 | `flip` | キャラクターが画面の左へ走る動画を、右へ走る向きで読むため | 付けると、左右を反転して読む | `pose_to_angles.py` の3つ目の引数 |
| 値 | `start`・`count` | 動画から読み取った結果の、使う範囲を決めるため | `start` は最初のコマ、`count` は使うコマの数。`start: 6, count: 34` なら 6コマ目から 34コマ分 | `stop_roto.json` の `rotoscope` の設定（JSON のキー） |

UE での設定は走りと同じ（胴体と首はデータのまま前へ倒し足さない、顔を 30° 起こす、一番低いつま先を 0.5cm に合わせる）。走りの最初のコマとつながるようにするため。

ただし頭と首は、Idle へなめらかにつながるよう次のように決めている。

| 部分 | 決め方 | 設定 |
|---|---|---|
| 顔の向き（水平から、+ が上） | 頭に角度を足すのでなく、顔の向きそのものを決める。3コマ目まで -16°（走りから入ったところと同じ）、4〜26コマ目で Idle と同じ -4° へ smoothstep、そのあとは -4° のまま。上へ戻る向きには動かない | `face_deg: [-16, -4]`、`face_frames: [4, 26]` |
| 首（首 → 頭の線） | 起き上がるところ（14〜30コマ目）で、データより最大 25° 起こす。最後が約84°になり、Idle（約84°）とそろう | `neck_add_deg: 25`、`neck_add_frames: [14, 30]` |

**用語:**

| 用語 | 何のことか |
|---|---|
| smoothstep | 0 から 1 へ、始めと終わりをゆっくり、真ん中を速く変える式（`u × u × (3 − 2u)`）。急に動き出さずに、目標へ寄せられる |

顔の向きと首は、UE で測り直して4回くり返して合わせる（最後の差は 0.5° 以下）。

**スカートは、太ももや腰の回りに一部だけついていく**（`skirt_follow`）。SK_Player のスカートは、前と後ろのボーン（`J_Sec_L/R_SkirtFront0`・`SkirtBack0`）が太ももの子、横のボーン（`SkirtSide0`）が腰の子で、モーションでは動かない。踏ん張るところ（3〜13コマ目）では原神のデータどおり両方の太ももがほぼ水平（-2〜-15°）まで上がるので、そのままだと前の布が水平に突き出て正面から中が見え、後ろの布も前へ持ち上がってめくれる。

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 値 | `skirt_follow` | スカートを、太ももや腰の動きに一部だけついていかせるため | 布の種類ごとの、ついていく割合 k を `follow` に書く（`Front`・`Back`・`Side`） | `adjust_bone_rotation.py` の設定（JSON のキー） |
| 値 | `J_Sec_L/R_SkirtFront0`・`SkirtBack0`・`SkirtSide0` | スカートの前・後ろ・横の布の根元を指すため | `SK_Player` のスカートのボーンの名前。左右（L・R）がある | ゲームの `SK_Player`（[姿勢補正スクリプトの設計](../姿勢補正スクリプト/姿勢補正スクリプトの設計.md) の「ボーン」） |

**用語:**

| 用語 | 何のことか |
|---|---|
| 子 | 親のボーンが動くと、それにつられて動くボーン（太ももの子は、太ももについて動く） |

親が基準のポーズから左右の軸まわりに回った角度を d とし、スカートの根元を (1 − k) × d だけ戻す。布は3枚（`_01`〜`_03`）とも同じにする。

| 布 | ついていく割合 k | 踏ん張るところの向き（前 0°・真下 -90°）。直す前 → 直したあと |
|---|---|---|
| 前（太ももの子） | 0.5 | -4〜+5° → -39〜-41°。太ももが布を少し突き抜けるが、布が下に垂れて正面からの視線をさえぎる |
| 後ろ（太ももの子） | 0.25 | -28〜-32° → -93〜-94°（ほぼ真下） |
| 横（腰の子） | 0.5 | -102〜-108° → -101〜-104° |

脚は原神のデータの角度のまま（太ももの上限 `thigh_max_deg` は使っていない）。走り（Run）から入るところで前の布が約 20° 下がるが、0.2秒の補間でつながる。

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 値 | `thigh_max_deg` | 太ももが上がりすぎないようにするため | 太ももを、この角度より上へ上げない（前 0°・真下 -90°）。ここでは設定していない | `adjust_bone_rotation.py` の `rotoscope` の設定（JSON のキー） |

**後ろへ来る腕の肘は、前後のコマとならす**（`arm_smooth: {"a": 4}`、肘は 5° より伸ばさない）。読み取りでは、肘が 8コマ目で 109° 曲がってから 11コマ目で 10° まで伸び、前腕が3コマで約100°後ろへ振られていた。そのあと 16〜18コマ目は肘が逆へ反っていた。肘の曲がりだけを幅 4コマのガウスでならし、前腕は 5〜15コマ目（約0.33秒）かけて、1コマ最大約9°で後ろへ振るようになった。上腕はならさない（始めと終わりの角度を変えず、走り・Idle とのつながりを保つ）。

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 値 | `arm_smooth` | 読み取りで肘が急に曲げ伸ばしされるのを抑えるため | 腕ごとに、肘の曲がりをならす幅（コマ数）を書く。`"a"` は腕（読み取りの結果の `a`・`b` が腕） | `adjust_bone_rotation.py` の `rotoscope` の設定（JSON のキー） |

**用語:**

| 用語 | 何のことか |
|---|---|
| ガウス | 前後のコマの値を、近いものほど重くして平均する方法（ガウス関数の形の重み）。急な跳ねがなだらかになる |

起き上がるところ（StopL / StopR の 14〜30コマ目。30fps、先頭を 0コマ目と数える）の脚は、読み取りの揺れを消すため、14コマ目の角度から 30コマ目の角度へ smoothstep でまっすぐ移している。

## 2. 作り直す

```bash
T=$(cd Action/tools/UnrealScripts && pwd -W)
MSYS_NO_PATHCONV=1 "<UE_5.8>/Engine/Binaries/Win64/UnrealEditor-Cmd.exe" "<空の>.uproject" -run=pythonscript \
  "-script=$T/adjust_bone_rotation.py $T/stop_roto.json" -unattended -nop4 -nosplash -NullRHI
```

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 変数 | `T` | スクリプトと設定の置き場を、何度も書かずに済ませるため | `adjust_bone_rotation.py` と JSON が入っているフォルダ（`Action/tools/UnrealScripts`）の、Windows 形式のパス | シェルの変数（このコマンドの1行目で決める） |
| C++ の書き方 | `$(cd ... && pwd -W)` | フォルダへ移ったうえで、その場所のパスを `T` に入れるため | `pwd -W` は、現在のフォルダを `C:/...` の形（Windows のパス）で出す。`$(...)` は、中のコマンドの出力をその場に入れる | 外部ライブラリ（Git Bash のシェルの書き方） |
| 環境変数 | `MSYS_NO_PATHCONV` | Git Bash がコマンドの引数を Windows のパスに勝手に書き換えるのを止めるため | `1` にすると、`-script=...` などの引数がそのまま UE に渡る | 外部ライブラリ（Git Bash の MSYS2） |
| コマンド | `UnrealEditor-Cmd.exe` | 画面を出さずに UE を動かすため | UE のコマンドライン版の実行ファイル | 外部ライブラリ（Unreal Engine） |
| 引数 | `-run=pythonscript` | UE に Python のスクリプトを実行させるため | 続く `-script=` のスクリプトを Python として実行する | 外部ライブラリ（Unreal Engine のコマンドライン） |
| 引数 | `-script=` | 実行するスクリプトと、その引数を渡すため | `adjust_bone_rotation.py` のあとに、設定の JSON のパスを続ける | 外部ライブラリ（Unreal Engine のコマンドライン） |
| 引数 | `-unattended` | 途中で確認の窓が出て止まらないようにするため | ダイアログを出さずに最後まで動かす | 外部ライブラリ（Unreal Engine のコマンドライン） |
| 引数 | `-nop4` | ソース管理（Perforce）につなごうとして止まらないようにするため | Perforce を使わない | 外部ライブラリ（Unreal Engine のコマンドライン） |
| 引数 | `-nosplash` | 起動の画面を出さないため | スプラッシュ画面を出さない | 外部ライブラリ（Unreal Engine のコマンドライン） |
| 引数 | `-NullRHI` | 画面に描かずに動かすため | 描画をしない（GPU を使わない）モードで起動する | 外部ライブラリ（Unreal Engine のコマンドライン） |

そのあとゲームを1回起動して `.tka` を作り直し、`.fbx` と `.tka` をコミットする。

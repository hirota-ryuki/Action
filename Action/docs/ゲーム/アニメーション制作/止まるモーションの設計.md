# 止まるモーションの設計

作成日: 2026-11-07（[走りから止まる設計](../プレイヤー/走りから止まる設計.md) から分けた）
対象: `Game/Assets/modelData/player/Animation/StopL.fbx`・`StopR.fbx`
経緯: [走りから止まる経緯](../プレイヤー/走りから止まる経緯.md)

走りから止まるモーション StopL / StopR の作り方です。手順の全体は [動画からアニメーションを作る設計](動画からアニメーションを作る設計.md) にあります。

- **原神の動画から作った通しの1本。** 前の足を突っ張って滑る → 起き上がって立つ。
- **StopL / StopR は脚・腕の左右を入れ替えただけ。**

---

## 1. 元にしたもの

| 項目 | 内容 |
|---|---|
| 動画 | 個人用 OneDrive の `02_Action参考資料/原神/`、29.78〜30.89秒（34コマ） |
| 向き | キャラクターが画面の左へ走っているので、`pose_to_angles.py` に `flip` を付けて左右を反転して読む |
| 角度 | [genshin_stop_pose.json](../../../tools/UnrealScripts/genshin_stop_pose.json)（手で直したあと、ならしたもの。使うのは 6コマ目から 34コマ） |
| 設定 | [stop_roto.json](../../../tools/UnrealScripts/stop_roto.json)（`start: 6, count: 34`） |

UE での設定は走りと同じ（胴体と首を 10° 前へ、顔を 30° 起こす、一番低いつま先を 0.5cm に合わせる）。走りの最初のコマとつながるようにするため。

起き上がるところ（f14〜f30）の脚は、読み取りの揺れを消すため、f14 の角度から f30 の角度へ smoothstep でまっすぐ移している。

---

## 2. 作り直す

```bash
T=$(cd Action/tools/UnrealScripts && pwd -W)
MSYS_NO_PATHCONV=1 "<UE_5.8>/Engine/Binaries/Win64/UnrealEditor-Cmd.exe" "<空の>.uproject" -run=pythonscript \
  "-script=$T/adjust_bone_rotation.py $T/stop_roto.json" -unattended -nop4 -nosplash -NullRHI
```

そのあとゲームを1回起動して `.tka` を作り直し、`.fbx` と `.tka` をコミットする。

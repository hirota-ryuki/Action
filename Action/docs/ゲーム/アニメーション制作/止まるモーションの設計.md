# 止まるモーションの設計

作成日: 2026-11-07（[走りから止まる設計](../プレイヤー/走りから止まる設計.md) から分けた）
対象: `Game/Assets/modelData/player/Animation/StopL.fbx`・`StopR.fbx`
経緯: [走りから止まる経緯](../プレイヤー/走りから止まる経緯.md)

走りから止まるモーション StopL / StopR の作り方です。手順の全体は [動画からアニメーションを作る設計](動画からアニメーションを作る設計.md) にあります。

- **原神の動画から作った通しの1本。** 前の足を突っ張って滑る → 起き上がって立つ。
- **StopL / StopR は脚・腕の左右を入れ替えただけ。**

---

## 1. 元にしたもの

| 項目 | 内容 |
|---|---|
| 動画 | 個人用 OneDrive の `02_Action参考資料/原神/`、29.78〜30.89秒（34コマ） |
| 向き | キャラクターが画面の左へ走っているので、`pose_to_angles.py` に `flip` を付けて左右を反転して読む |
| 角度 | [genshin_stop_pose.json](../../../tools/UnrealScripts/genshin_stop_pose.json)（手で直したあと、ならしたもの。使うのは動画の 6コマ目から 34コマ分） |
| 設定 | [stop_roto.json](../../../tools/UnrealScripts/stop_roto.json)（`start: 6, count: 34`） |

UE での設定は走りと同じ（胴体と首はデータのまま前へ倒し足さない、顔を 30° 起こす、一番低いつま先を 0.5cm に合わせる）。走りの最初のコマとつながるようにするため。

ただし頭と首は、Idle へなめらかにつながるよう次のように決めている。

| 部分 | 決め方 | 設定 |
|---|---|---|
| 顔の向き（水平から、+ が上） | 頭に角度を足すのでなく、顔の向きそのものを決める。3コマ目まで -16°（走りから入ったところと同じ）、4〜26コマ目で Idle と同じ -4° へ smoothstep、そのあとは -4° のまま。上へ戻る向きには動かない | `face_deg: [-16, -4]`、`face_frames: [4, 26]` |
| 首（首 → 頭の線） | 起き上がるところ（14〜30コマ目）で、データより最大 25° 起こす。最後が約84°になり、Idle（約84°）とそろう | `neck_add_deg: 25`、`neck_add_frames: [14, 30]` |

顔の向きと首は、UE で測り直して4回くり返して合わせる（最後の差は 0.5° 以下）。

**太ももは水平から 45° 下より上へ上げない**（`thigh_max_deg: -45`、`thigh_soft_deg: 10`）。原神のデータでは踏ん張るところ（3〜13コマ目）で両方の太ももがほぼ水平（-2〜-15°）まで上がり、腰が 48cm まで沈む。前が開いた長いドレスなら問題ないが、SK_Player はひざ丈のふんわりしたスカートなので、太ももがスカートの前を持ち上げて中が見えてしまう。スカートのボーンは横（`J_Sec_L/R_SkirtSide`）にしかなくモーションでも動かないので、前と後ろの布は腰と太ももについて動き、太ももを上げた分だけめくれる。脚が少しスカートに食い込むのはかまわないので、見えないことを優先する。

| 3〜13コマ目（踏ん張るところ） | データのまま | 上限を付けたあと |
|---|---|---|
| 太もも（両脚） | -2〜-15° | -45°（-55° から上限へなだらかに寄せる） |
| 前の脚の膝の曲がり | 46〜73° | 7〜35°（脚を伸ばして突っ張る形） |
| 腰の高さ | 48〜61cm | 71〜78cm |

すねの角度はデータのままにして、膝の曲がりを減らす。腰は、つま先を地面に合わせる高さの決め方で自然に上がる。走りから入る 0〜1コマ目と、起き上がる 23コマ目からあとはほとんど変わらない。

起き上がるところ（StopL / StopR の 14〜30コマ目。30fps、先頭を 0コマ目と数える）の脚は、読み取りの揺れを消すため、14コマ目の角度から 30コマ目の角度へ smoothstep でまっすぐ移している。

## 2. 作り直す

```bash
T=$(cd Action/tools/UnrealScripts && pwd -W)
MSYS_NO_PATHCONV=1 "<UE_5.8>/Engine/Binaries/Win64/UnrealEditor-Cmd.exe" "<空の>.uproject" -run=pythonscript \
  "-script=$T/adjust_bone_rotation.py $T/stop_roto.json" -unattended -nop4 -nosplash -NullRHI
```

そのあとゲームを1回起動して `.tka` を作り直し、`.fbx` と `.tka` をコミットする。

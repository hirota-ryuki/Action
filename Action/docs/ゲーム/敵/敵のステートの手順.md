# 敵のステートの手順

作成日: 2026-11-08
設計: [敵のステートの設計](敵のステートの設計.md)
経緯: [ステートマシンの経緯](../キャラクター/ステートマシンの経緯.md)
確かめた記録: [ゲームの手順書の経緯](../土台/ゲームの手順書の経緯.md)

Enemy の動き方（立ち止まる・進む・凍結）を、ステートで切り替えるまでの手順です。

**出来上がるもの:** Enemy が、入力（AI）の移動があれば Run、なければ Idle のアニメーションで動きます。凍結すると、その場で止まって落ちるだけになります。

**前提:**

- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [ステートマシンの手順](../キャラクター/ステートマシンの手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../README.md#ゲームを作る順番)）。
- アニメーションのクリップ（`Assets/animData/idle.tka`・`run.tka`）は、リポジトリにもとからある（変えない）。
- 作業を始める前に、main からブランチを切る。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | クリップの番号・ステートの種類・数値・触ってよいもの | ビルドが通る |
| 2 | 地面のステート（Idle・Move）と凍結のステート | ビルドが通る |
| 3 | ステートマシンを作り、Enemy に持たせる | Enemy が Idle で立つ |

```cpp
#pragma once

#include "State.h"

class CharacterMover;
class CharacterModel;
class StatusEffects;

// 敵のアニメーションクリップ。CharacterModelDesc::clips の添字になる。
enum EnEnemyAnimClip
{
	enEnemyAnimClip_Idle,
	enEnemyAnimClip_Run,
	enEnemyAnimClip_Num,
};

// 敵のステートの種類。
enum class EnemyStateId
{
	Idle,    // 立ち止まっている
	Move,    // 入力どおりに進んでいる
	Frozen,  // 凍結などで行動できない
	Num,
};

// ステートの調整用の数値。歩く速さなどは CharacterMoveSettings にある。
struct EnemyStateSettings
{
	float moveThreshold = 0.1f;     // 移動入力の長さがこれより小さければ立ち止まっているとみなす。
	float animBlendSeconds = 0.2f;  // アニメーションを切り替えるときの補間時間。
};

// ステートが触ってよいもの。ステートは Enemy クラスを直接は知らない。
struct EnemyStateContext
{
	CharacterMover* mover = nullptr;
	CharacterModel* model = nullptr;
	const StatusEffects* statusEffects = nullptr;
	EnemyStateSettings settings;
	// ひとつ前のステート。StateMachine が入れる。
	EnemyStateId previousId = EnemyStateId::Idle;
};

// 敵のステートの基底クラス。中身は共通の State（Character/StateMachine/State.h）にある。
using EnemyState = State<EnemyStateId, EnemyStateContext>;
```

共通の `StateMachine` の決まりどおり、ステートの種類は `Frozen` と `Num` を持ち、触ってよいもの（`EnemyStateContext`）は `statusEffects` と `previousId` を持ちます。

```cpp
#pragma once

#include "EnemyState.h"

// 地面で動くステート（Idle・Move）の共通部分。
// 動き方はどちらも入力どおり（CharacterMover::Update）で、違いはアニメーションだけ。
//   移動の入力がある → Move、ない → Idle
class EnemyGroundState : public EnemyState
{
public:
	// 入力で行き先を決める。Frozen が解けたあとの行き先にも使う。
	static EnemyStateId SelectByInput(const EnemyStateContext& context, const CharacterInput& input);

	void Enter(EnemyStateContext& context, const CharacterInput& input) override;
	EnemyStateId CheckTransition(const EnemyStateContext& context, const CharacterInput& input) const override;
	void Update(EnemyStateContext& context, const CharacterInput& input, float deltaTime) override;

protected:
	virtual int GetAnimClip() const = 0;
};
```

```cpp
#include "stdafx.h"
#include "EnemyGroundState.h"
#include "CharacterInput.h"
#include "CharacterMover.h"
#include "CharacterModel.h"

EnemyStateId EnemyGroundState::SelectByInput(const EnemyStateContext& context, const CharacterInput& input)
{
	if (input.moveDirection.Length() < context.settings.moveThreshold) {
		return EnemyStateId::Idle;
	}
	return EnemyStateId::Move;
}

void EnemyGroundState::Enter(EnemyStateContext& context, const CharacterInput& input)
{
	context.model->PlayAnimation(GetAnimClip(), context.settings.animBlendSeconds);
}

EnemyStateId EnemyGroundState::CheckTransition(const EnemyStateContext& context, const CharacterInput& input) const
{
	return SelectByInput(context, input);
}

void EnemyGroundState::Update(EnemyStateContext& context, const CharacterInput& input, float deltaTime)
{
	context.mover->Update(input, deltaTime);
}
```

```cpp
#pragma once

#include "EnemyState.h"

// 凍結などで行動できない。入力を無視し、重力で落ちるだけ。
// 行動できなくなったら、どのステートからでも StateMachine がここへ移す。
// アニメーションの停止と色の変化は StatusEffects が行うので、ここでは触らない。
//   行動できるようになった → 入力に合わせて Idle / Move
class EnemyFrozenState : public EnemyState
{
public:
	EnemyStateId GetId() const override
	{
		return EnemyStateId::Frozen;
	}
	const char* GetName() const override
	{
		return "Frozen";
	}

	EnemyStateId CheckTransition(const EnemyStateContext& context, const CharacterInput& input) const override;
	void Update(EnemyStateContext& context, const CharacterInput& input, float deltaTime) override;
};
```

```cpp
#include "CharacterMover.h"

EnemyStateId EnemyFrozenState::CheckTransition(const EnemyStateContext& context, const CharacterInput& input) const
{
	// 行動できない間は StateMachine がここを呼ばないので、呼ばれたら解けている。
	return EnemyGroundState::SelectByInput(context, input);

	context.mover->Update(CharacterInput(), deltaTime);
}
```

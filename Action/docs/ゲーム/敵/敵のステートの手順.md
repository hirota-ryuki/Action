# 敵のステートの手順

設計: [敵のステートの設計](敵のステートの設計.md)
経緯: [ステートマシンの経緯](../キャラクター/ステートマシンの経緯.md)

Enemy の体の動かし方（立ち止まる・進む・凍結）を、ステートで切り替えるようにするまでの手順です。ステートの基底クラスとステートマシンは [ステートマシンの手順](../キャラクター/ステートマシンの手順.md) で作ったものを使います。

**出来上がるもの:** Enemy が、入力（AI）の移動があれば Run、なければ Idle のアニメーションで動きます。凍結すると、その場で止まって落ちるだけになります。

**前提:**

- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [ステートマシンの手順](../キャラクター/ステートマシンの手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../README.md#ゲームを作る順番)）。
- アニメーションのクリップ（`Assets/animData/idle.tka`・`run.tka`）は、リポジトリにもとからある。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | クリップの番号・ステートの種類・数値・触ってよいもの | ビルドが通る |
| 2 | 地面のステート（Idle・Move）と凍結のステート | ビルドが通る |
| 3 | ステートマシンを作り、Enemy に持たせる | Enemy が Idle で立つ |

**読み方:**

- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- 書き換えるところは、「前」と「後」の枠を並べています。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

class EnemyStateMachine : public StateMachine<EnemyStateId, EnemyStateContext>
{
public:
	EnemyStateMachine();

	// mover・model・statusEffects は初期化済みのものを渡す。Idle から始める。
	void Init(const EnemyStateContext& context)
	{
		StateMachine::Init(context, EnemyStateId::Idle);
	}
};

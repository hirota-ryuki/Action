# ゲームの土台の設計

作成日: 2026-11-08
対象: [main.cpp](../../../Game/Source/App/main.cpp)、[system.cpp](../../../Game/Source/System/system.cpp)、[Game.cpp](../../../Game/Source/Core/Game.cpp)、[Stage.cpp](../../../Game/Source/Objects/Stage.cpp)
手順: [ゲームの土台の手順](ゲームの土台の手順.md)

ゲームが起動してから、キャラクターなどを置く前までの「土台」のページです。どこで何が作られ、どの順で更新されるかを知りたいときに読んでください。キャラクターの作りは [キャラクターの構成](../キャラクター/キャラクターの構成.md) から読んでください。

- **`Game` がゲームの中のものを全部作り、全部消す。** `main.cpp` は `Game` を1つ作るだけ。
- **更新の順番は `NewGO` の優先度で決める。** ステージ（0）→ キャラクター（1）→ カメラ（2）→ UI（3）。
- **起動の手続き（ウィンドウ・エンジン・ゲームループ）はテンプレートのまま使う。**

---

## 1. 全体の流れ

```
wWinMain（main.cpp）
 ├ InitGame()（system.cpp）… ウィンドウとエンジン（K2Engine）を作る
 ├ NewGO<Game>(0, "game")
 └ while (DispatchWindowMessage())
      K2Engine::Execute()   … 全部の IGameObject を優先度の順に Start / Update / Render

Game::Start()
 ├ 描画の設定（レイトレーシングを使わない、影の分け方）・太陽の光
 ├ 仮のカメラの位置（GameCamera が動き出すまで）
 ├ Stage（優先度 0）
 ├ Player・Enemy（1）、GameCamera（2）、FireEffect（1）、UIManager（3）
 └ SkyCube（0）… 空の画像を環境光（IBL）にも使う
```

| ファイル | 受け持つこと |
|---|---|
| [main.cpp](../../../Game/Source/App/main.cpp) | `wWinMain`。初期化 → `Game` を作る → ゲームループ → 終了。Debug ビルドでは、終わるときに D3D12 のリソースの消し忘れを出力する |
| [system.cpp](../../../Game/Source/System/system.cpp) | ウィンドウを作る（`InitGame()`）、メッセージを処理する（`MsgProc()`・`DispatchWindowMessage()`）。`g_hWnd` を持つ |
| [stdafx.h](../../../Game/Source/App/stdafx.h) | プリコンパイル済みヘッダー。エンジンの `k2EnginePreCompile.h` を読み、`nsK2EngineLow`・`nsK2Engine` を using する |
| [Game.h](../../../Game/Source/Core/Game.h) / [Game.cpp](../../../Game/Source/Core/Game.cpp) | ゲームの中のものを作って持ち、デストラクターで全部消す |
| [Stage.h](../../../Game/Source/Objects/Stage.h) / [Stage.cpp](../../../Game/Source/Objects/Stage.cpp) | ステージのモデルと、同じ形の物理の当たり（乗れる床） |

## 3. 実装方法

### 光と空

```cpp
g_renderingEngine->DisableRaytracing();                         // レイトレーシングは使わない
g_renderingEngine->SetCascadeNearAreaRates(0.01f, 0.1f, 0.5f);  // 影は近くを細かく、遠くを粗く
g_renderingEngine->SetDirectionLight(0, mainLightDirection, MAIN_LIGHT_COLOR);
...
m_skyCube->SetType(nsK2Engine::enSkyCubeType_SunriseToon);
g_renderingEngine->SetAmbientByIBLTexture(m_skyCube->GetTextureFilePath(), IBL_LUMINANCE);
```

光の色は HDR（1.0 より大きい値）で、太陽の強さを出します。環境光（IBL）は空の画像を使い回し、強すぎると影がつぶれるので弱め（0.16）にします。

### ステージの当たり

`Stage::Start()` でモデルを読み、そのメッシュをそのまま物理の当たりにします（`PhysicsStaticObject::CreateFromModel()`）。モデルを置いた行列を渡すので、位置・回転・大きさを変えても当たりが合います。ステージ自体は影を落としません。

## 4. 調整用の数値（`Game.cpp`）

| 名前 | 値 | 意味 |
|---|---|---|
| `SKY_LUMINANCE` | 1.6 | 空そのものの明るさ |
| `IBL_LUMINANCE` | 0.16 | 空からの環境光の強さ |
| `MAIN_LIGHT_DIRECTION` | (1, -1, -1) | 太陽の向き（`Start()` で正規化） |
| `MAIN_LIGHT_COLOR` | (2, 2, 2) | 太陽の色（HDR） |
| 仮のカメラ | 位置 (0, 180, -600)、注視点 (0, 80, 0)、Far 40000 | `GameCamera` が動き出すまで |

---

## 5. 決めたこと

| 決めたこと | 理由 |
|---|---|
| ゲームの中のものは `Game` が作って消す | 作る場所と消す場所が1か所になり、消し忘れが見つけやすい |
| `main.cpp`・`system.cpp` はテンプレートのまま | エンジンの起動の手続きで、ゲームによって変える必要がない |

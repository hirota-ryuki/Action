# ゲームの土台の経緯

設計: [ゲームの土台の設計](ゲームの土台の設計.md)

起動から Game・ステージまでの土台について、何をしたかの記録です。日付ごとに書き足します。このページは 2026-11-15 に、コミットの記録から書き起こしました。手順書をどう確かめたかは [ゲームの手順書の経緯](ゲームの手順書の経緯.md) にあります。

---

## 2026-06-29〜06-30 プロジェクトを足した（#3・#4）

k2Engine のテンプレートからゲームのプロジェクトを足し、コメントを足してカメラを直した。

## 2026-11-05 魔法・焚き火・キャラクターの部品を足した（#17〜#21）

氷魔法・焚き火の炎のエフェクト・キャラクターの入力の部品・炎魔法を足したときに、`Game.cpp` も書き足した。焚き火（`FireEffect`）は Game が作り、後片付けで消すようにした（#18）。

## 2026-11-08 UI を足した（#68）

`UIManager` を優先度3で作り、キャラクターが動いたあとの値を画面に出すようにした（[UIの構成の設計](../UI/UIの構成の設計.md)）。

## 2026-11-14 ボス戦の広間を足した（#122）

`BossStage` を足し、`Game.cpp` の `USE_BOSS_STAGE` で草原の `Stage` と切り替えるようにした（広間を使う）。広間では、月の光・夜空・露出の中間の明るさ（0.05）に変える（[ボス戦の広間の設計](../ステージ/ボス戦の広間の設計.md)）。

## 2026-11-14 魔法を Game が消すようにした（#132・#135）

魔法を撃つたびに1つ作る形にしたので、キャラクターが撃った魔法（今は `SkillBase` を継承したスキル）と炎魔法発射後の燃える床を、Game の後片付けで名前から探して消すようにした。

## 2026-11-15 草原のステージを消した（#145）

`USE_BOSS_STAGE` の切り替え、草原の `Stage`、焚き火の `FireEffect` と、草原用の光・プレイヤーと敵の最初の位置を消した。Game はいつもボス戦の広間を作る。[ゲームの土台の手順](ゲームの土台の手順.md) は、まだ仮の足場と `Stage` を置く形のまま（README の注意事項）。

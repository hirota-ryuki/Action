# ゲームの土台の設計

作成日: 2026-11-08
対象: [main.cpp](../../../../Game/Source/App/main.cpp)、[system.cpp](../../../../Game/Source/System/system.cpp)、[Game.cpp](../../../../Game/Source/Core/Game.cpp)、[BossStage.cpp](../../../../Game/Source/Objects/BossStage.cpp)
経緯: [ゲームの土台の経緯](ゲームの土台の経緯.md)
手順: [ゲームの土台の手順](ゲームの土台の手順.md)

ゲームの起動から、キャラクターなどを置く前までの「土台」のページです（キャラクターの作りは [キャラクターの構成](../../キャラクター/キャラクターの構成/キャラクターの構成.md)）。

- **`Game` がゲームの中のものを全部作り、全部消す。** `main.cpp` は `Game` を1つ作るだけ。
- **更新の順番は `NewGO` の優先度で決める。** ステージ（0）→ キャラクター（1）→ カメラ（2）→ UI（3）。
- **起動の手続き（ウィンドウ・エンジン・ゲームループ）はテンプレートのまま使う。**

| 用語 | 何のことか |
|---|---|
| `wWinMain` | Windows のアプリで、最初に呼ばれる関数（`main.cpp`）。ここからゲームが始まる |
| `g_hWnd` | ゲームのウィンドウを指す番号（ウィンドウハンドル `HWND`）を入れたグローバル変数（`system.cpp`）。ウィンドウを使う処理（エンジンの初期化など）に渡す |
| D3D12 | Direct3D 12。Windows でグラフィックスを描く API。エンジンが使っている |
| プリコンパイル済みヘッダー | 何度も読み込む重いヘッダーを、先に1回だけコンパイルしておいて、ビルドを速くする仕組み（`stdafx.h`） |
| カスケード（影の分け方） | 影の絵（シャドウマップ）を、カメラからの近さで何枚かに分けること。近くは細かく、遠くは粗くして、影の見た目と軽さを両立する |
| IBL | Image Based Lighting。1枚の空の画像から、周りの環境光を作る方法。ここでは夜の空の画像を使う |
| 逆光 | 光が、見ている向きの奥から来ること。玉座が暗い影になり、まわりが明るく縁取られる |
| 露出 | 画面全体の明るさを、見やすくそろえること。写真のカメラの露出と同じで、暗い画面は明るく、明るい画面は暗くなる |
| 中間の明るさ | 露出を決める、画面の平均的な明るさの目安（ふつうは 0.18）。小さくすると、暗い画面を明るく持ち上げない |
| HDR | High Dynamic Range。1.0 を超える明るさも扱える色。月の光の青 `1.35` のように、1 より大きい値を使える |

## 1. 全体の流れ

```
wWinMain（main.cpp）
 ├ InitGame()（system.cpp）… ウィンドウとエンジン（K2Engine）を作る
 ├ NewGO<Game>(0, "game")
 └ while (DispatchWindowMessage())
      K2Engine::Execute()   … 全部の IGameObject を優先度の順に Start / Update / Render

Game::Start()
 ├ 描画の設定（影の分け方）・月の光
 ├ 仮のカメラの位置（GameCamera が動き出すまで）
 ├ BossStage（優先度 0）… ボス戦の広間
 ├ Player・Enemy（1）、GameCamera（2）、UIManager（3）
 └ SkyCube（0）… 空の画像を環境光（IBL）にも使う
```

| ファイル | 受け持つこと |
|---|---|
| [main.cpp](../../../../Game/Source/App/main.cpp) | `wWinMain`。初期化 → `Game` を作る → ゲームループ → 終了。Debug ビルドでは、終わるときに、消し忘れた D3D12 のリソースを Visual Studio の出力ウィンドウに表示する |
| [system.cpp](../../../../Game/Source/System/system.cpp) | ウィンドウを作る（`InitGame()`）、メッセージを処理する（`MsgProc()`・`DispatchWindowMessage()`）。`g_hWnd` を持つ |
| [stdafx.h](../../../../Game/Source/App/stdafx.h) | プリコンパイル済みヘッダー。エンジンの `k2EnginePreCompile.h` を読み、`nsK2EngineLow`・`nsK2Engine` を using する |
| [Game.h](../../../../Game/Source/Core/Game.h) / [Game.cpp](../../../../Game/Source/Core/Game.cpp) | ゲームの中のものを作って持ち、デストラクターで全部消す |
| [BossStage.h](../../../../Game/Source/Objects/BossStage.h) / [BossStage.cpp](../../../../Game/Source/Objects/BossStage.cpp) | ボス戦の広間のモデル・当たり・ろうそくなどの光。プレイヤーと黒騎士を置く場所も持つ（[ボス戦の広間の設計](../../ステージ/ボス戦の広間/ボス戦の広間の設計.md)） |

## 2. Game が持つもの

優先度の小さい順に、毎フレーム Update が呼ばれます。

```
優先度 0（ステージ・空）→ 1（キャラクター）→ 2（カメラ）→ 3（UI）
```

| メンバー | 優先度 | 作る手順書 |
|---|---|---|
| `m_bossStage` | 0 | [ゲームの土台の手順](ゲームの土台の手順.md) |
| `m_skyCube` | 0 | [ゲームの土台の手順](ゲームの土台の手順.md) |
| `m_player`・`m_enemy` | 1 | [キャラクターの構成の手順](../../キャラクター/キャラクターの構成/キャラクターの構成の手順.md) |
| `m_gameCamera` | 2 | [プレイヤーの構成の手順](../../プレイヤー/プレイヤーの構成/プレイヤーの構成の手順.md) |
| `m_uiManager` | 3 | [UIの構成の手順](../../UI/UIの構成/UIの構成の手順.md) |

`Game` が持たないもの（キャラクターが使ったスキル `SkillBase`（魔法など）、炎魔法発射後の燃える床 `BurningGround`）は、`NewGO` の名前で探して、`Game` のデストラクターで消します。UI はキャラクターの値を読むので、キャラクターより先に消します。

## 3. 実装方法

### 光と空

```cpp
g_renderingEngine->SetCascadeNearAreaRates(0.01f, 0.1f, 0.5f);  // 影は近くを細かく、遠くを粗く
g_renderingEngine->SetDirectionLight(0, mainLightDirection, BOSS_MOON_COLOR);
g_renderingEngine->SetSceneMiddleGray(BOSS_SCENE_MIDDLE_GRAY);           // 暗い広間を明るく持ち上げない
...
m_skyCube->SetType(nsK2Engine::enSkyCubeType_NightToon);
g_renderingEngine->SetAmbientByIBLTexture(m_skyCube->GetTextureFilePath(), BOSS_IBL_LUMINANCE);
```

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 変数 | `g_renderingEngine` | 描画の設定を、どこからでも変えるため | 描画エンジン（`RenderingEngine`）を指すグローバルなポインター | k2Engine（エンジン）の [k2Engine.h](../../../../k2Engine/k2Engine.h) |
| 関数 | `SetCascadeNearAreaRates()` | 影の分け方を決めるため | カメラから、近い・中くらい・遠い範囲それぞれの割合（0〜1）を渡す。近くの割合を小さくすると、近くの影が細かくなる | k2Engine（エンジン）の [RenderingEngine.h](../../../../k2Engine/graphics/RenderingEngine.h) |
| 関数 | `SetDirectionLight()` | 月の光（向きのある光）を決めるため | ライトの番号・向き・色を渡す | k2Engine（エンジン）の [RenderingEngine.h](../../../../k2Engine/graphics/RenderingEngine.h) |
| 変数 | `mainLightDirection` | 月の光の向きを、正規化して渡すため | `BOSS_MOON_DIRECTION` を正規化した向き。これより前の行で作っている | ゲームの [Game.cpp](../../../../Game/Source/Core/Game.cpp) の `Game::Start()` の中 |
| 関数 | `SetSceneMiddleGray()` | 暗い広間を、明るく持ち上げないため | 露出の目安になる「中間の明るさ」を決める。小さくすると、画面全体が暗いままになる | k2Engine（エンジン）の [RenderingEngine.h](../../../../k2Engine/graphics/RenderingEngine.h) |
| メンバー変数 | `m_skyCube` | 空の画像を持つため | 空を描く `SkyCube`（`NewGO` で作る） | ゲームの [Game.h](../../../../Game/Source/Core/Game.h) の `Game` クラス |
| 関数 | `SetType()` | 空の絵の種類を選ぶため | 空の種類（`EnSkyCubeType`）を決める | k2Engine（エンジン）の [SkyCube.h](../../../../k2Engine/nature/SkyCube.h) |
| 値 | `enSkyCubeType_NightToon` | 夜空（トゥーン調）を選ぶため | `EnSkyCubeType` の値。夜の空の画像 | k2Engine（エンジン）の [SkyCube.h](../../../../k2Engine/nature/SkyCube.h)（`nsK2Engine`） |
| 関数 | `GetTextureFilePath()` | 空の画像のパスを、環境光にも渡すため | 空の画像のファイルのパス（`const wchar_t*`）を返す | k2Engine（エンジン）の [SkyCube.h](../../../../k2Engine/nature/SkyCube.h) |
| 関数 | `SetAmbientByIBLTexture()` | 空の画像から、環境光を作るため | 画像のパスと、明るさを渡す。画像はキューブマップ（箱の6面に貼る形）である必要がある | k2Engine（エンジン）の [RenderingEngine.h](../../../../k2Engine/graphics/RenderingEngine.h) |

月の光は青白くし、玉座の後ろの窓の方の上から入れます（玉座を逆光にする）。

露出は画面の平均の明るさに合わせて自動で変わります。そこで中間の明るさ（ふつうは 0.18）を下げて、暗い広間が昼のように明るくならないようにします。

環境光（IBL）は夜の空の画像を使い回し、弱め（0.08）にします。

### ステージの当たり

`BossStage::Start()` で、見た目のモデルとは別の、当たり判定用の単純な形（`BossHallCollision.fbx`）を読み、そのメッシュを物理の当たりにします（`PhysicsStaticObject::CreateFromModel()`）。モデルを置いた行列を渡すので、位置・回転・大きさを変えても当たりが合います。見た目のモデルは、柱・壁が影を落とし、天井と炎（`BossHallNoShadow.fbx`）は影を落としません（天井が落とすと、月の光が広間に入らなくなるため）。モデルはどれも [make_boss_stage.py](../../../../tools/BossStage/make_boss_stage.py) が書き出します。

## 4. 調整用の数値（`Game.cpp`）

| 名前 | 値 | 意味 |
|---|---|---|
| `BOSS_SKY_LUMINANCE` | 0.6 | 空そのものの明るさ |
| `BOSS_IBL_LUMINANCE` | 0.08 | 空からの環境光の強さ |
| `BOSS_MOON_DIRECTION` | (0.35, -1, -0.45) | 月の光の向き（`Start()` で正規化） |
| `BOSS_MOON_COLOR` | (0.55, 0.7, 1.35) | 月の光の色（HDR） |
| `BOSS_SCENE_MIDDLE_GRAY` | 0.05 | 露出を決める中間の明るさ（ふつうは 0.18） |
| 仮のカメラ | 位置 (0, 180, -600)、注視点 (0, 80, 0)、Far 40000 | `GameCamera` が動き出すまで |

## 5. 決めたこと

| 決めたこと | 理由 |
|---|---|
| ゲームの中のものは `Game` が作って消す | 作る場所と消す場所が1か所になり、消し忘れが見つけやすい |
| `main.cpp`・`system.cpp` はテンプレートのまま | エンジンの起動の手続きで、ゲームによって変える必要がない |

# ゲームの土台の手順

設計: [ゲームの土台の設計](ゲームの土台の設計.md)

k2Engine のテンプレートの空の `Game` に、光・スカイキューブ・カメラ・ステージを置くまでの手順です。ゲームの手順書は、ここから [README の「ゲームを作る順番」](../../README.md#ゲームを作る順番) の順に進めます。

**出来上がるもの:** 起動すると、空と光のある中に、乗れるステージ（仮の足場）が見えます。まだキャラクターはいません。

**前提:**

- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 始める前は、テンプレートのままの形になっている。`Game.h`・`Game.cpp` には、中身が空の `Game`（`Start()`・`Update()`・`Render()` だけ）がある。
- ステージのモデル（`Assets/modelData/stage/kariAsiba.tkm`）とスカイキューブの画像は、リポジトリにもとからある。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 描画の設定・光・スカイキューブ | 空が見える |
| 2 | 仮のカメラの位置 | 決めた位置から見える |
| 3 | ステージ | 足場が見える |

**読み方:**

- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

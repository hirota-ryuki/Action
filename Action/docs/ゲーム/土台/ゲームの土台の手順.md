# ゲームの土台の手順

作成日: 2026-11-08
設計: [ゲームの土台の設計](ゲームの土台の設計.md)
確かめた記録: [ゲームの手順書の経緯](ゲームの手順書の経緯.md)

k2Engine のテンプレートの空の `Game` に、光・スカイキューブ・カメラ・ステージを置くまでの手順です。ゲームの手順書は、ここから [README の「ゲームを作る順番」](../../README.md#ゲームを作る順番) の順に進めます。

**出来上がるもの:** 起動すると、空と光のある中に、乗れるステージ（仮の足場）が見えます。まだキャラクターはいません。

**前提:**

- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 始める前は、テンプレートのままの形になっている。`main.cpp`（ウィンドウを作ってゲームループを回す）・`system.cpp`・`stdafx.h` と、中身が空の `Game`（`Start()`・`Update()`・`Render()` だけ）がある。これらは、もとからある（この手順では `Game` 以外は変えない）。
- ステージのモデル（`Assets/modelData/stage/kariAsiba.tkm`）とスカイキューブの画像は、リポジトリにもとからある（変えない）。
- 作業を始める前に、main からブランチを切る。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 描画の設定・光・スカイキューブ | 空が見える |
| 2 | 仮のカメラの位置 | 決めた位置から見える |
| 3 | ステージ | 足場が見える |

## 手順1: 描画の設定・光・スカイキューブを置く

`Game::Start()` で、描画の設定（レイトレーシングを使わない、影の分け方）と、太陽の光（ディレクションライト）を決めます。空はエンジンの `SkyCube` で出し、その画像を環境光（IBL）にも使います。

**この手順で触るファイル:**

| ファイル | 何をするか |
|---|---|
| [Game.cpp](../../../Game/Source/Core/Game.cpp) | 追加（明るさ・光の定数、`Start()` で描画の設定・光・スカイキューブ、デストラクターで消す） |
| [Game.h](../../../Game/Source/Core/Game.h) | 追加（スカイキューブの前方宣言と、メンバー `m_skyCube`） |

```diff
 bool Game::Start()
 {
+	// レイトレーシングは現状未使用のため無効化。
+	g_renderingEngine->DisableRaytracing();
+	// カスケードシャドウの各分割領域の近距離比率を設定。近くを細かく、遠くを粗くする。
+	g_renderingEngine->SetCascadeNearAreaRates(0.01f, 0.1f, 0.5f);
+
+	Vector3 mainLightDirection = MAIN_LIGHT_DIRECTION;
+	mainLightDirection.Normalize();
+	g_renderingEngine->SetDirectionLight(0, mainLightDirection, MAIN_LIGHT_COLOR);
+
+	// SkyCubeのテクスチャをIBLの環境マップとしても使い回す。
+	m_skyCube = NewGO<nsK2Engine::SkyCube>(0, "skyCube");
+	m_skyCube->SetType(nsK2Engine::enSkyCubeType_SunriseToon);
+	m_skyCube->SetLuminance(SKY_LUMINANCE);
+	g_renderingEngine->SetAmbientByIBLTexture(m_skyCube->GetTextureFilePath(), IBL_LUMINANCE);
 
 	return true;
```

- **光の色は 1.0 より大きくしてよい（HDR）。** 2.0 で太陽の強さを出します。
- **環境光は弱めにする（0.16）。** 強すぎると影がつぶれます。

**確かめ方:** ゲームを起動すると、朝焼けの空が見える。

### 3-2. Stage.h・Stage.cpp を書く

<!-- new: ../../../Game/Source/Objects/Stage.h -->

```cpp
#pragma once

// ステージの地形を管理するクラス。
// モデルから物理コリジョンを生成し、キャラクターが乗れる静的な床を提供する。
class Stage : public IGameObject
{
public:
	Stage();
	~Stage();
	bool Start();
	void Update();
	void Render(RenderContext& rc);

	void SetPosition(const Vector3& position)
	{
		m_position = position;
	}

	void SetScale(const Vector3& scale)
	{
		m_scale = scale;
	}

	void SetRotation(const Quaternion& rotation)
	{
		m_rotation = rotation;
	}

private:
	Vector3 m_position = Vector3::Zero;
	Vector3 m_scale = Vector3::One;
	Quaternion m_rotation = Quaternion::Identity;
	ModelRender m_modelRender;
	PhysicsStaticObject m_physicsStaticObject;
};
```

<!-- new: ../../../Game/Source/Objects/Stage.cpp -->

```cpp
#include "stdafx.h"
#include "Stage.h"

namespace
{
	const char* STAGE_MODEL_PATH = "Assets/modelData/stage/kariAsiba.tkm";
}

Stage::Stage()
{

}

Stage::~Stage()
{

}

bool Stage::Start()
{
	m_modelRender.Init(STAGE_MODEL_PATH);
	m_modelRender.SetShadowCasterFlag(false);  // ステージ自体は影を落とさない。
	m_modelRender.SetTRS(m_position, m_rotation, m_scale);
	m_modelRender.Update();

	// モデルのメッシュ形状をそのまま物理コリジョンとして使用する。
	m_physicsStaticObject.CreateFromModel(m_modelRender.GetModel(), m_modelRender.GetModel().GetWorldMatrix());
	m_physicsStaticObject.SetFriction(1.0f);

	return true;
}

void Stage::Update()
{
	m_modelRender.Update();
}

void Stage::Render(RenderContext& rc)
{
	m_modelRender.Draw(rc);
}
```

- **ステージは影を落とさない。** 影はキャラクターだけにします。
- **当たりはモデルのメッシュをそのまま使う（`CreateFromModel()`）。** モデルを置いた行列（`GetWorldMatrix()`）を渡すので、位置・回転・大きさを変えても当たりが合います。

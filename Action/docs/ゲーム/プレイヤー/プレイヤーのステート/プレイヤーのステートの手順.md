# プレイヤーのステートの手順

設計: [プレイヤーのステートの設計](プレイヤーのステートの設計.md)
経緯: [プレイヤーのステートの経緯](プレイヤーのステートの経緯.md)

Player の体の動かし方（立ち止まる・歩く・走る・空中・凍結）を、ステートで切り替えるようにするまでの手順です。

**出来上がるもの:** 入力に合わせて Idle・Walk・Run・Air のアニメーションに切り替わり、歩く・走る・跳ぶ速さが変わります。凍結すると、その場で止まって落ちるだけになります。

**前提:**

- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [プレイヤーの構成の手順](../プレイヤーの構成/プレイヤーの構成の手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../../README.md#ゲームを作る順番)）。ステートマシンの仕組みは [ステートマシンの手順](../../キャラクター/ステートマシン/ステートマシンの手順.md) で作ったものを使う。
- アニメーションのクリップ（`Assets/modelData/player/Animation/Idle.fbx`・`Walk.fbx`・`Run.fbx`）は、リポジトリにもとからある。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | アニメーションを切り替える部品 `PlayerAnimator` | ビルドが通る |
| 2 | ステートの種類・数値・触ってよいもの（`PlayerState.h`）と、クリップの読み込み | 立って Idle が流れる |
| 3 | 地面のステート（Idle・Walk・Run） | ビルドが通る |
| 4 | 空中のステート（Air） | ビルドが通る |
| 5 | 凍結のステート（Frozen） | ビルドが通る |
| 6 | ステートマシンを作り、Player に持たせる | 歩く・走る・跳ぶ |

**読み方:**

- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- 書き換えるところは、「前」と「後」の枠を並べています。
- コードの下に、3つを置きます。
  - 「行・何をしているか」の表: 1行ずつの動き。
  - 「なぜ」「効果」: その小手順でそう書く理由と、書くと何ができるようになるか。
  - 「初めて出てくる名前」の表: このページで初めて出てくる変数・引数・関数・型・マクロ・C++ の書き方を、コードに出てくる順に並べます。2回目からは載せないので、わからない名前はページ内検索（`Ctrl+F`）で最初に出てきた所を探してください。「どこから来たもの」で、このゲームで作ったもの・エンジン（k2Engine）の機能・C++ の標準ライブラリ・C++ の書き方のどれかがわかります。
- [前提知識](../../../前提知識.md) で「よく知っている」にあるもの（クラス・継承・ポインター・テンプレート・`std::unique_ptr`・`K2_ASSERT`・`nullptr` など）は、表に載せません。「まあまあ」「怪しい」「微妙」にあるもの（`std::make_unique`・`std::move` など）は載せます。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

# プレイヤーの調整値の手順

作成日: 2026-11-08
設計: [プレイヤーの調整値の設計](プレイヤーの調整値の設計.md)
経緯: [JSON読み込みの経緯](../システム/JSON読み込みの経緯.md)

プレイヤーの調整値（移動・ダッシュ・止まる・モデル・アニメーション・剣など）を、コードから `Assets/data/player.json` に移すまでの手順です。上から順にやると、[プレイヤーの調整値の設計](プレイヤーの調整値の設計.md) の形になります。

**出来上がるもの:** `player.json` の数値やパスを書き換えて起動し直すだけで、プレイヤーの動き・モデル・アニメーション・剣が変わります。ビルドはいりません。JSON にキーがないときは今までと同じ値で動き、出力ウィンドウに `[PlayerConfig] …` と出ます。

**前提:**

- [JSON読み込みの手順](../システム/JSON読み込みの手順.md) が済んでいる（`#include "System/JsonFile.h"` で `JsonFile::Load()` が使える）。
- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 作業を始める前に、main からブランチを切る。
- Player 側（[Player.cpp](../../../Game/Source/Player/Player.cpp)）は**もとからある（変えない）**。`PlayerConfig::MakeCharacterConfig()`・`MakeStateSettings()`・`MakeSwordDesc()` を呼んで構造体を受け取るところはそのままで、関数の中身だけを JSON から読む形に変える。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | パスを `const char*` から `std::string` で持つようにする | ビルドが通り、動きが変わらない |
| 2 | `player.json` を作る | ファイルがある |
| 3 | `PlayerConfig.cpp` に JSON を読む土台（1回だけ読む・1つずつ読む）を足す | ビルドが通る |
| 4 | 移動の数値を JSON から読む | 歩く・走る・ジャンプが変わらない |
| 5 | ステート（ダッシュ・止まる）の数値を JSON から読む | ダッシュ・止まるが変わらない |
| 6 | モデルとアニメーションを JSON から読む | 見た目とアニメーションが変わらない |
| 7 | 魔法を撃つ位置を JSON から読む | 魔法が同じところから出る |
| 8 | 当たり判定と HP を JSON から読む | 弾の当たり方が変わらない |
| 9 | 剣を JSON から読む | 剣が右手に同じように付く |

## 手順2: player.json を作る

プレイヤーの数値とパスを書く JSON を作ります。値は今の [PlayerConfig.cpp](../../../Game/Source/Player/PlayerConfig.cpp) のものをそのまま写し、数値の意味のコメントも JSON の方へ移します（読むときにコメントを許しているので書ける）。

- アニメーションに合わせた長さは、秒ではなくコマ数で書きます（`4.0f / 30.0f` → `"crouchFrames": 4`）。秒にするのは手順3で作る関数です。
- ほかの値から計算しているもの（ダッシュの速さ、走る速さの倍率）は、計算の元の値を書きます（`390.0f / (7.0f / 30.0f)` → `"distance": 390.0` と `"kickFrames": 7`）。

**この手順で触るファイル:**

| ファイル | 何をするか |
|---|---|
| [player.json](../../../Game/Assets/data/player.json) | 新しく作る |

`Action/Game/Assets/data/` フォルダーを作り（なければ）、`player.json` を作ります。保存は UTF-8（BOM なし）。

## 手順3: PlayerConfig.cpp に JSON を読む土台を足す

手順4からの「段ごとに読む」で共通に使う関数を、先に足します。

- `player.json` は最初に呼ばれたときに1回だけ読み、取っておく（`GetJson()`）。
- 1つずつ読む `Read()` は、キーがないとき・型が違うときに既定値を返し、出力ウィンドウに出す。書き間違いに気づけるようにするため。

**この手順で触るファイル:**

| ファイル | 何をするか |
|---|---|
| [PlayerConfig.cpp](../../../Game/Source/Player/PlayerConfig.cpp) | 追加（`#include`、ファイルの説明、無名の namespace の先頭に読む関数） |

[PlayerConfig.cpp](../../../Game/Source/Player/PlayerConfig.cpp) の頭の `#include "PlayerConfig.h"` の下と、無名の namespace の先頭（`SWORD_OFFSET` の上）に**追加**します。`SWORD_OFFSET` などの定数は、手順8・9で消すまでそのまま置いておきます。

<!-- edit: ../../../Game/Source/Player/PlayerConfig.cpp -->

```diff
 #include "PlayerConfig.h"
+#include "System/JsonFile.h"
+
+// プレイヤーの調整値を Assets/data/player.json から読んで、各部品の設定の構造体に詰める。
+// 数値の意味・決めた理由のコメントは player.json の方に書いてある。
+// ここに書いてある値は、JSON にキーがないときの既定値（player.json を作ったときと同じ値）。
+// JSON のキー名や入れ子の形を知っているのは、このファイルだけにする（Player は JSON を知らない）。
 
 namespace
 {
+	using Json = JsonFile::Json;
+
+	constexpr const char* JSON_PATH = "player.json";
+	// アニメーションのコマ数を秒にするときの値。クリップはどれも 30fps で作っている。
+	constexpr float ANIM_FPS = 30.0f;
+
+	// player.json は最初に呼ばれたときに1回だけ読み、あとは取っておいたものを使う。
+	const Json& GetJson()
+	{
+		static const Json json = JsonFile::Load(JSON_PATH);
+		return json;
+	}
+
+	void Log(const std::string& message)
+	{
+		const std::string line = "[PlayerConfig] " + message + "\n";
+		OutputDebugStringA(line.c_str());
+	}
+
+	// 入れ子の1段（"move" など）を取り出す。ないときは空の {} を返すので、中のキーはどれも既定値になる。
+	Json GetSection(const char* name)
+	{
+		const Json& json = GetJson();
+		auto it = json.find(name);
+		if (it == json.end() || !it->is_object()) {
+			Log(std::string(JSON_PATH) + " に \"" + name + "\" がないので、既定値を使います。");
+			return Json::object();
+		}
+		return *it;
+	}
+
+	// section の key を読む。ないとき・型が違うときは defaultValue を返し、出力ウィンドウに出す（書き間違いに気づくため）。
+	template <class T>
+	T Read(const Json& section, const char* sectionName, const char* key, T defaultValue)
+	{
+		auto it = section.find(key);
+		if (it == section.end()) {
+			Log(std::string(JSON_PATH) + " に " + sectionName + "." + key + " がないので、既定値を使います。");
+			return defaultValue;
+		}
+		// 数値のところに文字列が書いてあるなど、型が違うときも既定値にする（落とさない）。
+		try {
+			return it->get<T>();
+		}
+		catch (const nlohmann::json::exception&) {
+			Log(std::string(JSON_PATH) + " の " + sectionName + "." + key + " の型が違うので、既定値を使います。");
+			return defaultValue;
+		}
+	}
+
+	// コマ数で書いてある値を読み、秒にして返す。
+	float ReadFramesAsSeconds(const Json& section, const char* sectionName, const char* key, float defaultFrames)
+	{
+		return Read(section, sectionName, key, defaultFrames) / ANIM_FPS;
+	}
+
+	// [x, y, z] の形の値を Vector3 で読む。
+	Vector3 ReadVector3(const Json& section, const char* sectionName, const char* key, const Vector3& defaultValue)
+	{
+		const std::vector<float> values = Read(section, sectionName, key, std::vector<float>{});
+		if (values.size() != 3) {
+			if (!values.empty()) {
+				Log(std::string(JSON_PATH) + " の " + sectionName + "." + key + " は [x, y, z] の3つで書いてください。既定値を使います。");

+	config.hitRadius = Read(hit, "hit", "radius", 45.0f);
+	config.hitCenterHeight = Read(hit, "hit", "centerHeight", 70.0f);
+
+	config.maxHp = Read(GetJson(), "(先頭)", "maxHp", 100.0f);
 	return config;
```

- `maxHp` は段に入れず、JSON のいちばん外に書いています。そのため `GetJson()` をそのまま `Read()` に渡します。

**確かめ方:** ビルドが通る。起動して、敵の弾がプレイヤーに前と同じように当たり、HP のゲージが前と同じに出る。

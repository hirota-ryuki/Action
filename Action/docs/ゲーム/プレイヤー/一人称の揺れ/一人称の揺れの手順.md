# 一人称の揺れの手順

作成日: 2026-11-16
対象: 一人称カメラの歩き・走りの揺れと着地の沈み（`FirstPersonBob`）
設計: [一人称の揺れの設計](一人称の揺れの設計.md)
経緯: [一人称の揺れの経緯](一人称の揺れの経緯.md)

一人称のカメラで歩く・走るときに、視点を上下・左右に揺らし、一人称の腕を足の運びに合わせて振り、ジャンプから着地したときに沈ませるまでの手順です。

**出来上がるもの:** 一人称で歩くと視点が足の運びに合わせて揺れ、腕が8の字に揺れて左右交互に前後へ振れます。左Shift を押したまま走ると、大きく速く揺れ、足が着くたびに少し下を向きます。氷を突き出している腕と、炎を溜める・放つ両腕は揺れません。着地すると、視点と腕がぐっと沈んで戻ります。

**前提:**

- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 一人称の腕（`FirstPersonArms`）と、V キーで一人称に切り替える `GameCamera` が入っていること（[一人称の腕の設計](../一人称の腕/一人称の腕の設計.md)。手順書はまだありません）。
- 歩き・走りの速さは `player.json` の `walkSpeed`（170）・`runSpeed`（960）。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | `Character` に「地面に着いているか」 | ビルドが通る |
| 2 | `FirstPersonBob` を作り、進んだ距離で歩み（位相）を進める | ビルドが通る |
| 3 | 位相からカメラの揺れ（上下・左右・傾き・首振り）を計算する | ビルドが通る |
| 4 | `GameCamera` でカメラを揺らす | 一人称で歩く・走ると視点が揺れる |
| 5 | 腕を揺らす（撃つ形の腕は揺らさない） | 腕が8の字に揺れ、交互に前後へ振れる |
| 6 | 着地の沈み | 着地すると視点と腕が沈んで戻る |

**読み方:**

- 新しいファイルは、空のクラスから始めて少しずつ足します。

- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- 書き換えるところは、「前」と「後」の枠を並べています（番号は、それぞれ変える前と変えた後の番号）。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

# 一人称の揺れの手順

作成日: 2026-11-16
対象: 一人称カメラの歩き・走りの揺れ、腕の振り、着地の沈み（`FirstPersonBob`）
設計: [一人称の揺れの設計](一人称の揺れの設計.md)
経緯: [一人称の揺れの経緯](一人称の揺れの経緯.md)

一人称のカメラで歩く・走るときに視点をわずかに揺らし、一人称の腕を歩きのように左右交互に振り、ジャンプから着地したときに沈ませるまでの手順です。

**出来上がるもの:** 一人称で歩くと、視点がわずかに揺れ、腕が左右交互に軽く前後へ振れます（両手はずっと画面に映ります）。左Shift を押したまま走ると、揺れと振りが大きく速くなり、足が着くたびにわずかに下を向きます。氷を突き出している腕と、炎を溜める・放つ両腕は揺れません。着地すると、視点と腕がぐっと沈んで戻ります。

**前提:**

- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 一人称の腕（`FirstPersonArms`）と、V キーで一人称に切り替える `GameCamera` が入っていること（[一人称の腕の設計](../一人称の腕/一人称の腕の設計.md)。手順書はまだありません）。
- 歩き・走りの速さは `player.json` の `walkSpeed`（170）・`runSpeed`（960）。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | `Character` に「地面に着いているか」 | ビルドが通る |
| 2 | `FirstPersonBob` を作り、進んだ距離で歩み（位相）を進める | ビルドが通る |
| 3 | 位相からカメラの揺れ（上下・左右・傾き・首振り）を計算する | ビルドが通る |

	constexpr float WALK_STEP_LENGTH = 90.0f;

	constexpr float MOVE_WEIGHT_SPEED = 8.0f;
	constexpr float RUN_WEIGHT_SPEED = 6.0f;
	// これより速く動いたら、ワープ（落ちて戻ったときなど）とみなし、揺れには数えない（cm/秒）。

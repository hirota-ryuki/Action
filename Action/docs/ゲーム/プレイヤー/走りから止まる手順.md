# 走りから止まる手順

設計: [走りから止まる設計](走りから止まる設計.md)
経緯: [走りから止まる経緯](走りから止まる経緯.md)

走っていて移動キーを離したとき、すぐには止まらず、前の足を突っ張って滑ってから立つようにするまでの手順です。

**出来上がるもの:** 走っていて移動キーを離すと、前の足を突っ張って低く滑り、起き上がって立ちます。どちらの足で踏ん張るかは、離した瞬間の走りの足に合わせます。ダッシュのあと移動の入力がないときも、同じように滑って止まります。

**前提:**

- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [ダッシュの手順](ダッシュの手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../README.md#ゲームを作る順番)）。
- 止まるクリップ `Assets/modelData/player/Animation/StopL.fbx`・`StopR.fbx` は、リポジトリにもとからある。作り方は [止まるモーションの設計](../アニメーション制作/止まるモーションの設計.md)。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 止まる数値・ステートの種類・クリップ | ビルドが通る |
| 2 | 走りのアニメーションの位置を覚える | ビルドが通る |
| 3 | 止まるステート `PlayerStopState` | ビルドが通る |
| 4 | 走り・歩き・ダッシュから Stop へ入る | 走って離すと滑って止まる |

**読み方:**

- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- 書き換えるところは、「前」と「後」の枠を並べています。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

# 走りから止まる手順

作成日: 2026-11-08
設計: [走りから止まる設計](走りから止まる設計.md)
経緯: [走りから止まる経緯](走りから止まる経緯.md)
確かめた記録: [ゲームの手順書の経緯](../土台/ゲームの手順書の経緯.md)

走っていて移動の入力を離したとき、すぐに止まらず、勢いで滑りながら踏ん張って止まる動き（Stop）を足すまでの手順です。上から順にやると、[走りから止まる設計](走りから止まる設計.md) の形になります。

**出来上がるもの:** 走っていて移動キーを離すと、前の足を突っ張って低く滑り、起き上がって立ちます。どちらの足で踏ん張るかは、離した瞬間の走りの足に合わせます。ダッシュのあと移動の入力がないときも、同じように滑って止まります。

**前提:**

- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [ダッシュの手順](ダッシュの手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../README.md#ゲームを作る順番)）。
- 止まるクリップ `Assets/modelData/player/Animation/StopL.fbx`・`StopR.fbx` は、リポジトリにもとからある（変えない）。作り方は [止まるモーションの設計](../アニメーション制作/止まるモーションの設計.md)。
- 作業を始める前に、main からブランチを切る。

この手順書では、アニメーションの1枚を「コマ」と書きます。コマは 30fps で、クリップの先頭を 0コマ目と数えます。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 止まる数値・ステートの種類・クリップ | ビルドが通る |
| 2 | 走りのアニメーションの位置を覚える | ビルドが通る |
| 3 | 止まるステート `PlayerStopState` | ビルドが通る |
| 4 | 走り・歩き・ダッシュから Stop へ入る | 走って離すと滑って止まる |

```cpp
#pragma once

#include "PlayerState.h"

// 走っていて移動の入力を離した。すぐには止まらず、走っていた勢いで前へ滑りながら踏ん張って止まる。
// アニメーションは、原神の動画（29.78〜30.89秒）から関節の角度を読み取って作った
// 「前の足を突っ張り、腰を落として滑る → 起き上がって立つ」の通しの1本（StopL / StopR、L・R は前へ突っ張る足）。
// どちらの足で踏ん張るかは、止まった瞬間の走りの位置で、前に着こうとしている足に合わせる。
// 進む速さは、入った瞬間の走る速さから stopSlideSeconds かけてまっすぐ遅くなり、0になる。向きは変えない。
//   ダッシュボタン・ジャンプボタン・足場がない → Dash / Air（いつでも割り込める）
//   移動の入力がある → Walk / Run（止まるのをやめて、また動き出す）
//   stopSeconds たった → Idle
class PlayerStopState : public PlayerState
{
public:
	PlayerStateId GetId() const override
	{
		return PlayerStateId::Stop;
	}
	const char* GetName() const override
	{
		return "Stop";
	}

	void Enter(PlayerStateContext& context, const CharacterInput& input) override;
	PlayerStateId CheckTransition(const PlayerStateContext& context, const CharacterInput& input) const override;
	void Update(PlayerStateContext& context, const CharacterInput& input, float deltaTime) override;
	void Exit(PlayerStateContext& context) override;

private:
	Vector3 m_direction = Vector3::AxisZ;  // 滑る方向（水平・正規化済み）。
	float m_startSpeed = 0.0f;             // 滑り始めの速さ。
	float m_elapsed = 0.0f;                // 入ってからの時間。
};
```

<!-- new: ../../../Game/Source/Player/State/PlayerStopState.cpp -->

```cpp
#include "stdafx.h"
#include "PlayerStopState.h"
#include "PlayerGroundState.h"
#include "CharacterInput.h"
#include "CharacterMover.h"

namespace
{
	// 1周期 length のループの中で、a と b がどれだけ離れているか（近い方の向きで測る）。
	float LoopDistance(float a, float b, float length)
	{
		float d = fmodf(fabsf(a - b), length);
		return min(d, length - d);
	}
}

void PlayerStopState::Enter(PlayerStateContext& context, const CharacterInput& input)
{
	const PlayerStateSettings& s = context.settings;
	const CharacterMoveSettings& move = context.mover->GetSettings();
	m_elapsed = 0.0f;
	m_startSpeed = move.walkSpeed * move.runSpeedMultiplier;
	m_direction = context.mover->GetForward();
	m_direction.y = 0.0f;
	if (m_direction.LengthSq() > FLT_EPSILON) {
		m_direction.Normalize();
	}
	else {
		m_startSpeed = 0.0f;
	}

	// 走りの中で、今いちばん近い「足が前に着くところ」の足で踏ん張る。
	bool isLeft = true;
	if (s.runAnimSeconds > 0.0f) {
		const float time = context.animator->GetRunTime();
		isLeft = LoopDistance(time, s.stopLRunTime, s.runAnimSeconds) <= LoopDistance(time, s.stopRRunTime, s.runAnimSeconds);
	}
	context.animator->SetNextBlend(s.stopBlendSeconds);
	context.animator->Play(isLeft ? enPlayerAnimClip_StopL : enPlayerAnimClip_StopR);
}

PlayerStateId PlayerStopState::CheckTransition(const PlayerStateContext& context, const CharacterInput& input) const
{
	if (input.dash.isTrigger && context.settings.dashDistance > 0.0f && context.mover->IsOnGround()) {
		return PlayerStateId::Dash;
	}
	if (input.jump.isTrigger && context.mover->GetSettings().jumpSpeed > 0.0f && context.mover->IsOnGround()) {
		return PlayerStateId::Air;
	}
	const PlayerStateId next = PlayerGroundState::SelectByInput(context, input);
	if (next != PlayerStateId::Idle) {
		return next;
	}
	return m_elapsed < context.settings.stopSeconds ? PlayerStateId::Stop : PlayerStateId::Idle;
}

void PlayerStopState::Update(PlayerStateContext& context, const CharacterInput& input, float deltaTime)
{
	// 滑る速さは、時間の割合に合わせてまっすぐ下げる（フレームの真ん中の時間で測る）。
	const float slide = context.settings.stopSlideSeconds;
	float speed = 0.0f;
	if (slide > 0.0f && m_elapsed < slide) {
		const float mid = min(m_elapsed + deltaTime * 0.5f, slide);
		speed = m_startSpeed * (1.0f - mid / slide);
	}
	m_elapsed += deltaTime;
	context.mover->Move(m_direction * speed, deltaTime);
}

void PlayerStopState::Exit(PlayerStateContext& context)
{
	// 起き上がったポーズから、次の動きへゆっくりつなぐ。
	context.animator->SetNextBlend(context.settings.stopExitBlendSeconds);
}
```

- **踏ん張る足は、走りの中で「今いちばん近い、足が前に着くところ」の足。** 走りは 15コマで1周期、右足は 2コマ目、左足は 9コマ目に前へ着きます。1周期の中で近い方の向きに測ります（`LoopDistance()`）。
- **滑る速さは、走る速さから `stopSlideSeconds` かけてまっすぐ 0 にする。** フレームの真ん中の時間で測るので、FPS によらず同じ距離を滑ります。
- **ダッシュ・ジャンプ・移動の入力で、いつでも割り込める。**

**確かめ方:** ソリューションのビルドが通る。

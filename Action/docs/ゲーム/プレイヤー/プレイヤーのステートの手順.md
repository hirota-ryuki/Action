# プレイヤーのステートの手順

作成日: 2026-11-08
設計: [プレイヤーのステートの設計](プレイヤーのステートの設計.md)
経緯: [プレイヤーのステートの経緯](プレイヤーのステートの経緯.md)
確かめた記録: [ゲームの手順書の経緯](../土台/ゲームの手順書の経緯.md)

Player の動き方（立ち止まる・歩く・走る・空中・凍結）を、ステートで切り替えるまでの手順です。アニメーションの切り替えを受け持つ `PlayerAnimator` も、ここで作ります。ダッシュは [ダッシュの手順](ダッシュの手順.md)、走りから止まる動きは [走りから止まる手順](走りから止まる手順.md) で足します。

**出来上がるもの:** 入力に合わせて Idle・Walk・Run・Air のアニメーションに切り替わり、歩く・走る・跳ぶ速さが変わります。凍結すると、その場で止まって落ちるだけになります。

**前提:**

- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [プレイヤーの構成の手順](プレイヤーの構成の手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../README.md#ゲームを作る順番)）。ステートマシンの仕組みは [ステートマシンの手順](../キャラクター/ステートマシンの手順.md) で作ったものを使う。
- アニメーションのクリップ（`Assets/modelData/player/Animation/Idle.fbx`・`Walk.fbx`・`Run.fbx`）は、リポジトリにもとからある（変えない）。
- 作業を始める前に、main からブランチを切る。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | アニメーションを切り替える部品 `PlayerAnimator` | ビルドが通る |
| 2 | ステートの種類・数値・触ってよいもの（`PlayerState.h`）と、クリップの読み込み | 立って Idle が流れる |
| 3 | 地面のステート（Idle・Walk・Run） | ビルドが通る |
| 4 | 空中のステート（Air） | ビルドが通る |
| 5 | 凍結のステート（Frozen） | ビルドが通る |

```cpp
#pragma once

// プレイヤーのアニメーションクリップの番号。
enum EnPlayerAnimClip
{
	enPlayerAnimClip_Idle,
	enPlayerAnimClip_Walk,
	enPlayerAnimClip_Run,
	enPlayerAnimClip_Jump,
	enPlayerAnimClip_Num,
};

// プレイヤーのアニメーションの切り替えを受け持つ部品。
// ステート同士の受け渡し（次の切り替えだけに使う補間時間、クリップごとの始める位置）をここに持つ。
// ステートは ModelRender を直接触らず、これを通してアニメーションを流す。
class PlayerAnimator
{
public:
	PlayerAnimator();

	// modelRender は初期化済みのもの。defaultBlendSeconds はふだんの補間時間。
	void Init(ModelRender* modelRender, float defaultBlendSeconds);

	// クリップを切り替えて、speed 倍の速さで流す。
	// 予約（SetNextBlend・SetNextStartTime）があれば使い、使ったら全部消す。
	void Play(int clip, float speed = 1.0f);
	// 補間時間と始める位置を指定して切り替える。予約は使わず、消さない。
	void PlayFrom(int clip, float blendSeconds, float startTime, float speed);

	// 次の Play だけで使う補間時間。前のステートが Exit で入れておく。
	void SetNextBlend(float seconds)
	{
		m_nextBlendSeconds = seconds;
	}
	// 次の Play で、そのクリップを始める位置（秒）。
	void SetNextStartTime(int clip, float time);
	// 予約した始める位置。なければ0より小さい値。
	float GetNextStartTime(int clip) const;

private:
	void ClearNext();

	ModelRender* m_modelRender = nullptr;
	float m_defaultBlendSeconds = 0.2f;
	float m_nextBlendSeconds = -1.0f;            // 0より小さければ、ふだんの補間時間を使う。
	float m_nextStartTimes[enPlayerAnimClip_Num]; // 0より小さければ最初から。
};
```

<!-- new: ../../../Game/Source/Player/PlayerAnimator.cpp -->

```cpp
#include "stdafx.h"
#include "PlayerAnimator.h"

PlayerAnimator::PlayerAnimator()
{
	ClearNext();
}

void PlayerAnimator::Init(ModelRender* modelRender, float defaultBlendSeconds)
{
	m_modelRender = modelRender;
	m_defaultBlendSeconds = defaultBlendSeconds;
	ClearNext();
}

void PlayerAnimator::Play(int clip, float speed)
{
	const float blend = m_nextBlendSeconds >= 0.0f ? m_nextBlendSeconds : m_defaultBlendSeconds;
	const float startTime = GetNextStartTime(clip);
	ClearNext();
	if (m_modelRender == nullptr) {
		return;
	}
	if (startTime >= 0.0f) {
		m_modelRender->PlayAnimationFromTime(clip, blend, startTime);
	}
	else {
		m_modelRender->PlayAnimation(clip, blend);
	}
	m_modelRender->SetAnimationSpeed(speed);
}

void PlayerAnimator::PlayFrom(int clip, float blendSeconds, float startTime, float speed)
{
	if (m_modelRender == nullptr) {
		return;
	}
	m_modelRender->PlayAnimationFromTime(clip, blendSeconds, startTime);
	m_modelRender->SetAnimationSpeed(speed);
}

void PlayerAnimator::SetNextStartTime(int clip, float time)
{
	if (clip >= 0 && clip < enPlayerAnimClip_Num) {
		m_nextStartTimes[clip] = time;
	}
}

float PlayerAnimator::GetNextStartTime(int clip) const
{
	if (clip >= 0 && clip < enPlayerAnimClip_Num) {
		return m_nextStartTimes[clip];
	}
	return -1.0f;
}

void PlayerAnimator::ClearNext()
{
	m_nextBlendSeconds = -1.0f;
	for (float& time : m_nextStartTimes) {
		time = -1.0f;
	}
}
```

```cpp
#pragma once

#include "PlayerAnimator.h"
#include "State.h"

class CharacterMover;
class StatusEffects;
struct CharacterInput;

// プレイヤーのステートの種類。
enum class PlayerStateId
{
	Idle,    // 立ち止まっている
	Walk,    // 歩いている
	Run,     // 走っている
	Air,     // 空中にいる（跳んだ・足場から落ちた）
	Frozen,  // 凍結などで行動できない
	Num,
};

// ステートの調整用の数値。歩く・走る・跳ぶ速さは CharacterMoveSettings にある。
struct PlayerStateSettings
{
	float moveThreshold = 0.1f;       // 移動入力の長さがこれより小さければ立ち止まっているとみなす。
	float animBlendSeconds = 0.2f;    // アニメーションを切り替えるときの補間時間。
	float walkAnimMoveSpeed = 0.0f;   // 歩くアニメーションを等速で再生したとき、足が地面を送る速さ。0なら等速で再生する。
};

// ステートが触ってよいもの。ステートは Player クラスを直接は知らない。
struct PlayerStateContext
{
	CharacterMover* mover = nullptr;
	PlayerAnimator* animator = nullptr;
	const StatusEffects* statusEffects = nullptr;
	PlayerStateSettings settings;
	// ひとつ前のステート。Enter の中で、どこから来たかを見るのに使う。StateMachine が入れる。
	PlayerStateId previousId = PlayerStateId::Idle;
};

// プレイヤーのステートの基底クラス。中身は共通の State（Character/StateMachine/State.h）にある。
using PlayerState = State<PlayerStateId, PlayerStateContext>;
```

- **`Frozen` と `Num` を必ず持つ。** 共通の `StateMachine` が、行動できないときに `Frozen` へ移し、`Num` でステートの数を知るためです。
- **ステートは Player を知らない。** 触ってよいもの（移動・アニメーション・状態異常）だけを `PlayerStateContext` で渡します。

[PlayerConfig.h](../../../Game/Source/Player/PlayerConfig.h) に `PlayerState.h` の `#include` と、ステートの数値を返す関数を**追加**します。`PlayerState.h` が `PlayerAnimator.h` を読むので、`PlayerConfig.cpp` からクリップの番号（`EnPlayerAnimClip`）も使えるようになります。

		return PlayerStateId::Air;
	}
	if (input.moveDirection.Length() < context.settings.moveThreshold) {
		return PlayerStateId::Idle;
	}

	}
	return PlayerStateId::Walk;

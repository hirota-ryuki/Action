# 三人称の溜め撃ちの手順

設計: [三人称の溜め撃ちの設計](三人称の溜め撃ちの設計.md)
経緯: [三人称の溜め撃ちの経緯](三人称の溜め撃ちの経緯.md)

作成日: 2026-11-19
対象: 三人称の溜め撃ち（#193）

三人称で右クリックを押している間、上半身だけ右手を前へ出して構え、離すと撃つ「三人称の溜め撃ち」を足すまでの手順です。上から順にやると、[三人称の溜め撃ちの設計](三人称の溜め撃ちの設計.md) の形になります。

**出来上がるもの:** 三人称で右クリックを押すと、上半身だけ Attack1（右手で撃つ）の途中で止めて構え、カメラはキャラクターを画面の左へ寄せた肩越しの視点になり、照準が出ます。構えたまま 0.6倍の速さで歩け、後ろ・横へは後ろ歩き・横歩きになります。離すと続きを流して、右手の前から画面の真ん中へ火の玉を撃ちます。

**前提:**

- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [アニメーションの上半身の層の手順](../../../エンジン/アニメーションの上半身の層/アニメーションの上半身の層の手順.md)（エンジン）を済ませておく。この手順の `InitAnimationLayer()` などは、そこで作る。
- 右クリックの炎魔法（溜めて撃つ）・3段攻撃・一人称の溜め撃ちは、もとからある（[炎魔法](../../魔法/炎魔法/炎魔法の設計.md)・[3段攻撃](../3段攻撃/3段攻撃の設計.md)）。この手順は、それに「三人称で構える」形を足す。
- 構えて歩くクリップ `Assets/modelData/player/Animation/WalkBack.fbx`・`StrafeL.fbx`・`StrafeR.fbx` は、リポジトリにもとからある。作り方は [三人称の溜め撃ちの設計](三人称の溜め撃ちの設計.md) の「構えて歩くクリップの作り方」。

アニメーションのコマは 30fps で、クリップの先頭を 0コマ目と数えます。ゲームの1回の更新は「フレーム」と書きます。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 溜め撃ちの数値（`PlayerChargeSettings`・player.json の `"charge"`） | ビルドが通る |

**もとからあって、変えないもの:**

- 右クリックを押している間に溜め、離したら撃つのは、炎魔法とスキルの部品（`SkillController`）にもとからある（変えない）。この手順では、`SkillController` の「溜めているか（`IsHolding()`）」「撃った回数（`GetUseCount()`）」を見て、上半身を動かす。
- 撃つ位置を入力の `aimOffsets` でずらすのは、`Character::ApplyAimOffset()` にもとからある（一人称で右手から撃つのに使っている）。三人称の溜め撃ちも、同じ仕組みで右手の前から撃つ。
- 1フレームの順番（入力 → 動く → スキル → モデルを更新 → `OnLateUpdate()`）は `Character::Update()` にもとからある（変えない）。

## 手順8: 上半身をカメラの向きへひねる

手順7では、構えている間は体がいつもカメラの向きを向くので、前へ斜めに進むときも横歩きになります。前・横へ進むときは、脚を進む向きへ向けて前歩きにし、上半身だけをカメラの向きへひねる方が自然です。後ろの方へ進むときは、今までどおり体はカメラの向きのまま、後ろ歩き・横歩きにします。

| 進む向き（カメラの向きから） | 脚 | 歩き方 |
|---|---|---|
| 前・横（約 100度まで） | 進む向きへ向ける | 前歩き。上半身をカメラの向きへひねる |
| 斜め後ろ（約 100〜135度） | カメラの向きのまま | 横歩き |
| 真後ろ寄り（約 135度より後ろ） | カメラの向きのまま | 後ろ歩き |

# 三人称の溜め撃ちの設計

経緯: [三人称の溜め撃ちの経緯](三人称の溜め撃ちの経緯.md)
手順: [三人称の溜め撃ちの手順](三人称の溜め撃ちの手順.md)（先に [アニメーションの上半身の層の手順](../../../エンジン/アニメーションの上半身の層/アニメーションの上半身の層の手順.md) を済ませる）

作成日: 2026-11-19
対象: 三人称で右クリック（炎魔法）を溜めて撃つときの、上半身の構え・肩越しの視点・構えて歩く動き（#193）

三人称で右クリックを押している間、上半身だけ Attack1（右手で撃つ）の途中で止めて構え、離すと続きを流して火の玉を撃ちます。溜めて撃つこと自体は炎魔法にもとからあり（[炎魔法の設計](../../魔法/炎魔法/炎魔法の設計.md)）、ここではその間の見た目と動き方を決めます。

- 下半身は今までどおりステートマシン（立ち止まる・歩く）が動かし、上半身だけをアニメーションの層で上書きする（[アニメーションの上半身の層](../../../エンジン/アニメーションの上半身の層/アニメーションの上半身の層の設計.md)）。
- 構えている間は肩越しの視点にし、右手の前から画面の真ん中（照準）へ撃つ。一人称で右手から撃つのと同じ仕組み（入力の `aimOffsets`）を使う。
- 構えたまま 0.6倍の速さで歩ける。走り・ジャンプ・氷魔法はできず、ダッシュすると溜めをやめる。ダッシュのあとの「走り続ける」も、構えたら終える。

**用語:**

| 用語 | 何のことか |
|---|---|
| 構える | 右クリックで溜め始めてから、撃って腕を下ろし始めるまで（上半身の段が `Charge` か `Cast`） |
| 溜める | 右クリックを押して、火の玉を溜めている間（段が `Charge`） |
| 肩越しの視点 | キャラクターを画面の左に寄せ、画面の真ん中がキャラクターの右前を指すカメラ |
| 層の重み | 上半身の層をどれだけ効かせるか（0〜1） |

アニメーションのコマは 30fps で、クリップの先頭を 0コマ目と数えます。ゲームの1回の更新は「フレーム」と書きます。

---

## 1. 全体像

| 部品 | 役割 |
|---|---|
| `PlayerUpperBody`（[PlayerUpperBody.h](../../../../Game/Source/Player/PlayerUpperBody.h)） | 上半身の段（`None`・`Charge`・`Cast`）を切り替え、層のクリップ・重み・再生の速さを `ModelRender` に渡す |
| `Player`（[Player.cpp](../../../../Game/Source/Player/Player.cpp)） | 層を作り、毎フレーム部品に「溜めているか」「撃った回数」を渡す。構えている間の入力の書き換え、火の玉の位置、上半身のひねり・右肩 |
| `PlayerInputSource`（[PlayerInputSource.cpp](../../../../Game/Source/Character/Input/PlayerInputSource.cpp)） | 構えている間は、カメラから画面の真ん中へ、火の玉の位置から撃つ入力にする。体をカメラの向きへ向ける |
| `PlayerWalkState`（[PlayerWalkState.h](../../../../Game/Source/Player/State/PlayerWalkState.h)） | 構えている間は、動く向きで前歩き・後ろ歩き・横歩きを選ぶ |
| `GameCamera`（[GameCamera.cpp](../../../../Game/Source/Objects/GameCamera.cpp)） | 溜めている間は肩越しの視点へ寄せる。Player に三人称かを渡す |
| `PlayerHud`（[PlayerHud.cpp](../../../../Game/Source/UI/Hud/PlayerHud.cpp)） | 構えている間は照準を出す |

1フレームの流れ（`Character::Update()` の順）:

1. 入力: 構えていれば、撃つ向き・位置と体の向きを入力に入れる（`PlayerInputSource`）。
2. 動く: `FilterAimingInput()` で入力の写しを書き換え（走らない・跳ばない・ゆっくり歩く）、ステートマシンへ渡す。歩きのステートがクリップを選ぶ。
3. スキル: 炎魔法が溜める・撃つ（もとからある）。三人称の空中では溜め始めない（`FilterSkillInput()`）。
4. モデルの更新: 下（歩きなど）→ 上半身の層の順に姿勢を作る。骨のワールド行列ができたら、骨の調整の層を順に重ねる: 体の連動 → 照準へのひねり（上半身のひねり・右肩）→ 揺れ物（[骨の調整の層の設計](../../キャラクター/骨の調整の層/骨の調整の層の設計.md)）。
5. `OnLateUpdate()`: 部品が段と重みを決め、火の玉の位置を右手の前に合わせる。

## 2. 詳細

### 上半身の段

| 段 | 層のクリップ | 次の段へ |
|---|---|---|
| `None` | 重みを 0.25秒で 0 へ（下の動きへ戻す） | 溜め始めたら `Charge` |
| `Charge` | Attack1 を 0コマ目から流し、9コマ目（右手を前へ突き出しきる手前）で止める。重みは 0.15秒で 1 へ | 離して撃ったら `Cast`、撃たずにやめたら（凍った・ダッシュなど）`None` |
| `Cast` | 止めた所から続きを流して撃つ | 17コマ目（下ろし始め）まで来たら `None`。また溜めたら `Charge` |

撃ったかは、炎魔法を撃った回数が増えたかで見ます。

### 脚と上半身の向き

構えている間、体はカメラの向きを向きます。進む向きによって、脚の向きと歩き方を変えます。

| 進む向き（カメラの向きから） | 脚 | 歩き方 |
|---|---|---|
| 前・横（約 100度まで） | 進む向きへ向ける | 前歩き。上半身をカメラの向きへひねる（100度まで。背骨 3割・胸 3割・上の胸 4割） |
| 斜め後ろ（約 100〜135度） | カメラの向きのまま | 横歩き（StrafeL・StrafeR） |
| 真後ろ寄り | カメラの向きのまま | 後ろ歩き（WalkBack）。さらに 0.6倍の速さ |

さらに、右肩を 25度後ろへ引き、右腕を 25度外（画面の右）へ開きます。首は引いた分だけ戻し、顔は狙う向きのままにします。肩越しの視点で、右腕と火の玉が体に隠れないようにするためです。

### 撃つ位置と肩越しの視点

- 火の玉は、構える前は胸の前（ふだん撃つ位置）、構えたら右手の 35cm 前（狙う向き）。層の重みで間を混ぜます。
- 肩越しの視点は、注視点とカメラを同じだけ右へずらし、キャラクターを画面の中心と左端の真ん中に映します。溜めている間は 0.2秒で寄せ、離したら撃つ動きを待たずに 0.15秒で戻します。

## 3. 実装方法

### 上半身は「溜めているか」と「撃った回数」だけで動かす

```cpp
m_upperBody.Update(
    m_skillController.IsHolding(ActionButton::Action2),    // 溜めているか
    m_skillController.GetUseCount(ActionButton::Action2),  // 撃った回数
    m_isThirdPersonCamera,
    deltaTime);
```

部品はスキルの部品を知らず、2つの値だけで段を決めます。止めるのは層の再生の速さを 0 にするだけ（`m_speed`）にしたので、離せば同じクリップの続きがそのまま流れます。層のクリップがどこまで進んだかは `ModelRender` から読めないので、同じ時間を部品でも数えています（`m_time += deltaTime * m_speed`）。

層は `{ { L"J_Bip_C_Spine", 0.5f }, { L"J_Bip_C_Chest", 1.0f } }` で作ります。胸から上を全部層にし、腰と胸の間の背骨を半分にして、下の動きとつなげます。構えている間は、体の連動に攻撃中と同じ度合い（`max(m_attackWeight, m_upperBody.GetWeight())`）を渡し、走りの腕の振りと顔の向きの調整を外します。

### 撃つ位置は、一人称と同じずらし方

`Character` は、`hasAim` のとき `aimOrigin` から `castForward` だけ前に出し、`aimOffsets` でずらして、照準の先の点へ向け直します（もとからある）。そこで入力元は、ずらした先がちょうど火の玉の位置になる量を入れます。

```cpp
input.AimOffset(ActionButton::Action2) = context.chargePosition - input.aimOrigin - input.aimDirection * context.castForward;
```

### 入力は写しを書き換える

構えている間は `m_input` の写しを書き換えてからステートマシンへ渡します（`FilterAimingInput()`）。走るボタン（`isRun`）はここで外し、ダッシュのあとの走り続ける（`keepRunAfterDash`）は、ステートマシンが構えているときに毎フレーム消します（`PlayerStateMachine::OnBeforeUpdate()`）。`m_input` そのものを変えると、スキルの部品と次のフレームの「押した瞬間」の判定に響くためです。歩く速さは移動の入力を 0.6倍にするだけなので、歩きのステートを変えずに済みます。

### 上半身のひねりは、骨のワールド行列にあとから掛ける

`Character` の骨の調整の層を「体の連動 → 派生クラスの層（`OnAddPoseLayers()` で足す照準へのひねり）→ 揺れ物」の順にしました。ひねったあとの体に、髪やスカートが付いてきます。照準の向きはカメラで変わるので、焼き込まない層にしてあります。骨とその子孫を回すのは `PoseLayers::RotateBoneTree()` を使います。回す向きの符号は、決まり（右手系・左手系）から決めず、実際に行列で回して近づくかで確かめています（`TwistUpperBodyToAim()`）。

### 構えて歩くクリップ

`PlayerWalkState::UpdateAimClip()` は、動く向きを体の前と右に分け（内積）、大きい方で前・後ろ・左・右を選びます。足の速さは「実際に動く速さ ÷ クリップの足が地面を送る速さ」にして、足が滑らないようにします。構えていない歩きは、今までどおり `Enter` で流したままです。

## 4. 使い方

### F1 の窓

| 窓 | 変えられるもの |
|---|---|
| 溜め撃ちの構え（`Player`） | 止めるコマ・火の玉の前への距離・右肩を引く角度・右腕を外へ開く角度・構えて歩く速さ・後ろ歩きにさらに掛ける速さ |
| 肩越しの視点（`GameCamera`） | 構えた視点のままにする（確認用）・距離・注視点の高さ・横の位置・画角 |

決めた値は、player.json の `"charge"`（構え）、`GameCamera.cpp` の `AIM_` の定数（視点）に書きます。

### 構えて歩くクリップの作り方

KinemIQ の `Walk - backwards`・`Walk - side steps left` を、Blender で SK_Player の骨格へ移しています（3段攻撃のモーションと同じスクリプト）。

```bash
cd Action/tools/BlenderScripts
"C:/Program Files/Blender Foundation/Blender 5.1/blender.exe" -b --python retarget_black_knight.py -- player_charge_walk_anims.json
```

| クリップ | 作り方（[player_charge_walk_anims.json](../../../../tools/BlenderScripts/player_charge_walk_anims.json)） |
|---|---|
| WalkBack | Walk - backwards の 48〜109コマ目（2周期。最初と最後の足の位置がいちばん近いところ） |
| StrafeL | Walk - side steps left の 17〜64コマ目（立った姿勢から左へ1歩踏み、また立つまで） |
| StrafeR | StrafeL を左右反転したもの（`mirror`） |

元の FBX はリポジトリにありません（`source` のパスは、作ったPCのダウンロードのフォルダ）。書き出したあと、ゲームを1回起動して `.tka` を作り、`.fbx` と一緒にコミットします。

## 5. 調整用の数値

[player.json](../../../../Game/Assets/data/player.json) の `"charge"`:

| キー | 値 | 何か |
|---|---|---|
| `holdFrame` | 9 | 溜めている間に止める Attack1 のコマ |
| `castEndFrame` | 17 | 撃ったあと、上半身を戻し始める Attack1 のコマ |
| `fadeInSeconds`・`fadeOutSeconds` | 0.15・0.25 | 上半身を構える動きへ入れる時間・下の動きへ戻す時間 |
| `moveSpeedRate` | 0.6 | 構えて歩く速さ（ふだんの歩きの何倍か） |
| `backMoveSpeedRate` | 0.6 | 後ろの方へ歩くときに、さらに掛ける |
| `ballForward` | 35 | 火の玉を右手からどれだけ前に置くか（cm） |
| `shoulderBackDeg`・`armOutDeg` | 25・25 | 右肩を引く角度・右腕を外へ開く角度（度） |

`"animation"` の `walkBackMoveSpeed`（88）・`strafeMoveSpeed`（46）は、後ろ歩き・横歩きの足が地面を送る速さです。

[GameCamera.cpp](../../../../Game/Source/Objects/GameCamera.cpp) の肩越しの視点: 距離 `AIM_DISTANCE` 120・注視点の高さ `AIM_TARGET_HEIGHT` 160・横の位置 `AIM_SCREEN_X` 0.5・画角 `AIM_VIEW_ANGLE_DEG` 50度・寄せる時間 `AIM_ENTER_SECONDS` 0.2秒・戻す時間 `AIM_EXIT_SECONDS` 0.15秒。

[Player.cpp](../../../../Game/Source/Player/Player.cpp): 脚を進む向きへ向ける境目 `AIM_TURN_LEGS_MIN_DOT` -0.2（約 100度）・ひねる角度の上限 `AIM_TWIST_MAX_DEG` 100度・3本の骨に分ける割合 `AIM_TWIST_SHARES` 0.3・0.3・0.4。

## 6. 決めたこと

| 決めたこと | 理由 |
|---|---|
| 片手（右手、Attack1）で構える | 肩越しの視点では、キャラクターの右側の前が画面の真ん中になる。右手で構えれば、右手の前の火の玉が照準の近くに見える（最初は両手の Attack3 で作り、#193 の途中で替えた。[経緯](三人称の溜め撃ちの経緯.md)） |
| 新しいクリップを作らず、Attack1 を途中で止める | 9コマ目で止めれば「右手を前へ出して溜めている」形になり、離せばそのまま撃つ動きになる |
| 肩越しの視点は「溜めている間」だけ | 撃って腕を下ろすまで寄せたままだと、撃ったあとの見通しが悪い |
| 前・横へは脚を進む向きへ向け、上半身をひねる | 体をいつもカメラの向きにすると、前へ斜めに進むときも横歩き・後ろ歩きのクリップを選ぶことになる。脚を進む向きへ向ければ、前歩きのクリップで歩ける |
| 三人称では地上でだけ溜め始める | 構えて動くのは歩きのステートだけで、空中の動きには合わせていない。押したまま着地しても始めず、押し直させる |
| ダッシュで溜めをやめる（撃たない） | ダッシュは避けるための動きなので、構えより優先する |

## 7. 既知の課題

- 構えて歩くのは Walk のステートだけ。構えたまま足場から落ちると、空中のモーションの上に構えが乗る。
- F1 の窓で変えた値は保存されない。player.json・`GameCamera.cpp` に手で書く。
- 元の KinemIQ の FBX はリポジトリにない。作り直すときは、ダウンロードし直して `source` のパスを合わせる。

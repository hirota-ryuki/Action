# プレイヤーの調整値の設計

作成日: 2026-11-08
対象: [player.json](../../../Game/Assets/data/player.json)、[PlayerConfig.cpp](../../../Game/Source/Player/PlayerConfig.cpp)
手順: [プレイヤーの調整値の手順](プレイヤーの調整値の手順.md)
経緯: [JSON読み込みの経緯](../システム/JSON読み込みの経緯.md)

プレイヤーの調整値（移動・ダッシュ・止まる・モデル・アニメーションなど）を、JSON ファイルに出したページです。JSON を読む仕組みそのものは [JSON読み込みの設計](../システム/JSON読み込みの設計.md) を見てください。

- **数値とパスは `Assets/data/player.json` に書く。** 数値の意味や決めた理由のコメントも JSON の方に書く。
- **JSON を読むのは `PlayerConfig.cpp` だけ。** Player は今までどおり `PlayerConfig::Make〇〇()` で構造体を受け取り、JSON を知らない。
- **JSON にキーがなくても今と同じに動く。** コードに既定値（JSON を作ったときと同じ値）を残し、ないキーは出力ウィンドウに出す。

---

## 1. 全体像

```
Player ──MakeCharacterConfig()など──▶ PlayerConfig.cpp ──JsonFile::Load("player.json")（最初の1回だけ）──▶ JsonFile
       ◀──── CharacterConfig など ─────                  ◀──────────────── Json ────────────────
```

| `player.json` の段 | 入れる先 | 中身 |
|---|---|---|
| `maxHp` | `CharacterConfig::maxHp` | HP の最大 |
| `hit` | `CharacterConfig::hitRadius` など | 弾に当たる球の半径・高さ |
| `caster` | `CharacterCastSettings` | 魔法を撃つ高さ・前へのずれ |
| `move` | `CharacterMoveSettings`、`PlayerStateSettings::moveThreshold` | 歩く・走る・ジャンプの速さ、重力、カプセル |
| `dash` | `PlayerStateSettings` の `dash〇〇` | ダッシュの距離・長さ・補間・つなぎ方 |
| `stop` | `PlayerStateSettings` の `stop〇〇`・`runAnimSeconds` | 走りから止まる長さ・補間、どちらの足で踏ん張るか |
| `model` | `CharacterModelDesc` | モデルのパス・上の向き（`"Y"`・`"Z"`）・大きさ |
| `animation` | `CharacterModelDesc::clips`、`PlayerStateSettings` | 切り替えの補間、歩きの足の速さ、クリップのパスとループ |

## 2. 実装方法

### 1回だけ読んで取っておく

`Make〇〇()` は2つあるが、`GetJson()` の中の `static const Json` に最初の1回だけ読んで、あとは同じものを使う。

### 1つずつ読む関数

```cpp
template <class T>
T Read(const Json& section, const char* sectionName, const char* key, T defaultValue);
```

- キーがないときと型が違うとき（数値のところに文字列など）は `defaultValue` を返し、`[PlayerConfig] player.json に dash.distance がないので、既定値を使います。` のように出力ウィンドウに出す。書き間違いに気づけるようにするため。
- 型が違うと nlohmann/json は例外を投げるので、`Read` の中だけで受け止める（落とさない）。
- 段（`"dash"` など）の取り出しは `GetSection()` で行い、段がないときは空の `{}` を返す。

### コマ数で書いて秒にする

アニメーションに合わせた長さは、JSON にはコマ数（`crouchFrames: 4` など、30fps・先頭が 0コマ目）で書き、`ReadFramesAsSeconds()` で 30 で割って秒にする。`PlayerStateSettings` は秒で持つため。

### 計算で作る値は元の値を書く

ほかの値から決まるものは、JSON に元の値を書き、計算はコードで行う。結果を直接書くと、元の値を変えたときに直し忘れるため。

| 構造体の値 | JSON に書く値 | 計算 |
|---|---|---|
| `dashSpeed` | `dash.distance`・`dash.kickFrames` | 距離 ÷（コマ数 ÷ 30） |
| `runSpeedMultiplier` | `move.walkSpeed`・`move.runSpeed` | 走る速さ ÷ 歩く速さ |

### クリップは名前で書く

`animation.clips` は `"Run": { "path": …, "loop": true }` のように名前をキーにする。名前と番号（`enPlayerAnimClip_Run`）と既定値の対応表 `CLIP_TABLE` を `PlayerConfig.cpp` に1つだけ置き、この表の順にクリップを詰める。

- JSON の並び順は関係ない。
- JSON にないクリップは既定のパスを使い、出力ウィンドウに出す。
- 表にない名前（書き間違いなど）が JSON にあれば、出力ウィンドウに出す。
- `static_assert` で、`EnPlayerAnimClip` の数と表の行数が違うとビルドが止まる。

### パスは std::string で持つ

JSON から読んだ文字列を持てるように、`AnimClipDesc::path`・`CharacterModelDesc::modelPath` を `const char*` から `std::string` にした。`const char*` のままだと、読んだ値が消えたときに指す先が壊れるため。

## 3. 使い方

### 数値を変える

`Assets/data/player.json` を書き換えてゲームを起動し直す。ビルドはいらない。

### クリップを足す

1. `PlayerAnimator.h` の `EnPlayerAnimClip` に番号を足す。
2. `PlayerConfig.cpp` の `CLIP_TABLE` に、名前・番号・既定のパスを1行足す（足さないと `static_assert` で止まる）。
3. `player.json` の `animation.clips` に、同じ名前でパスとループを書く。

### 値を足す

1. 構造体（`PlayerStateSettings` など）に値を足す。
2. `PlayerConfig.cpp` で `Read(section, "段", "キー", 既定値)` を1行足す。
3. `player.json` の同じ段にキーを足す。

## 4. 決めたこと

| 決めたこと | 理由 |
|---|---|
| Player ではなく PlayerConfig が JSON を読む | 数値の用意は PlayerConfig の役割。JSON の形を変えても直すのはここだけ |
| 既定値をコードに残す | JSON がなくても・キーが足りなくても、今と同じに動く |
| `from_json`（構造体ごとの読み方）を使わず、段ごとの関数で読む | JSON の段と構造体が1対1でない（`PlayerStateSettings` は `dash`・`stop`・`move`・`animation` にまたがる）、コマ数から秒への計算がある |

## 5. 既知の課題

- 起動中に JSON を読み直す仕組みはない。数値を変えたら起動し直す。
- 敵・魔法はまだコードに数値がある。同じ形（〇〇Config が JSON を読む）にそろえるかは、これから決める。
- `Read` などの読む関数は `PlayerConfig.cpp` にある。ほかでも使うなら `JsonFile` に移す。

# プレイヤーのステートの経緯

設計: [プレイヤーのステートの設計](プレイヤーのステートの設計.md)

何をして、なぜ今の形になったかの記録です。日付ごとに書き足します。ダッシュのことは [ダッシュの経緯](ダッシュの経緯.md) にあります。

---

## 2026-11-05 ステートパターンにした

以前は Player の中の if で切り替えていた。

| 以前 | 今 |
|---|---|
| `Player::UpdateAnimation()` が if を並べて、毎フレームアニメーションを決めていた | ステートが、入ったときに自分のアニメーションを流す |
| 速さは `CharacterMover`、アニメーションは `Player` と、判断が分かれていた | 「歩く」なら速さもアニメーションも `PlayerWalkState` にある |
| ダッシュの残り距離は `CharacterMover`、ポーズのフラグは `Player` にあった | ダッシュのことは `PlayerDashState` だけにある |

関数テーブルとの比較:

| | クラス（採用） | 関数テーブル |
|---|---|---|
| 流れの追いやすさ | ファイルをまたぐ | Player の中だけで上から読める |
| ステートだけが使うデータ | そのクラスに閉じ込められる | Player のメンバーになり、Player が膨らむ |
| Enemy などへの流用 | しやすい | しにくい |

当時の6ステートなら関数テーブルでも足りたが、剣の連続攻撃・回避・のけぞりなど、データを持つ動きを足す予定なのでクラスにした。

動きが変わったところ:

| 内容 | 以前 | 今 |
|---|---|---|
| ダッシュ中のジャンプ | できた | できない（終わってから） |
| ごく小さい移動入力（0.1 未満） | 待機アニメーションのまま、ゆっくり動いた | 動かない（Idle） |

## 2026-11-06 ダッシュと走るを1つのボタンにした

| 以前 | 今 |
|---|---|
| 走る（左Shift を押している間）とダッシュ（L）が別のボタン | 左Shift 1つ。押した瞬間にダッシュ、押しっぱなしで走る |
| ダッシュ中に押しても何も起きない | ダッシュ中に押すと、続けてダッシュが出る（のちに 2026-11-07 にやめた） |

「押しっぱなしで走る」は、入力元が `isRun` にダッシュボタンの押下を入れるだけで実現した（[入力の設計](../キャラクター/入力の設計.md)）。

## 2026-11-06 ラッシュをダッシュと呼ぶことにした

以前は「ラッシュ（Rush）」と呼んでいた。走りの一部として素早く前へ出る動きなので「ダッシュ（Dash）」にした。名前を変えただけで、動きは変えていない。

## 2026-11-07 走りから止まる Stop を足した

[走りから止まる設計](走りから止まる設計.md) を参照。Run から `Idle` になるときと、Run から来て `stopAfterRunSeconds`（0.2秒）以内の Walk から `Idle` になるときは、代わりに `Stop` へ移るようにした。

## 2026-11-07 設計と経緯を分けた

A4 1枚に収まるよう、ダッシュを [ダッシュの設計](ダッシュの設計.md) に、経緯をこのページに分けた。

# アニメーションの確認の設計

作成日: 2026-11-20
対象: ブランチ `PowerUpTry`、[Player.cpp](../../../../Game/Source/Player/Player.cpp) の `DrawAnimDebugUI`

ImGui に「アニメーションの確認」の窓を出し、プレイヤーのクリップをボタンで流せるようにします。ステートで使っていないクリップ（PowerUp など）も、ゲームの中で見られます。

- **ボタンを押すと、そのクリップを 0.3秒で補間して最初から流す。** ステートは変えない。
- **流したクリップは、次にステートが変わるまで続く。** 動いたり跳んだりすると、そのステートのアニメーションに戻る。

---

## 1. 実装方法

`Player::OnLateUpdate` で、デバッグUI（F1）が出ているときに `DrawAnimDebugUI` を呼びます。クリップの名前は `EnPlayerAnimClip` と同じ並びの配列に持ち、数がずれたらビルドで止まるようにしています。

```cpp
static const char* const CLIP_NAMES[] = {
	"Idle", "Walk", "Run", "JumpStart", "JumpLoop", "JumpLand", "Dash", "StopL", "StopR",
	"Attack1", "Attack2", "Attack3", "WalkBack", "StrafeL", "StrafeR", "PowerUp",
};
static_assert(sizeof(CLIP_NAMES) / sizeof(CLIP_NAMES[0]) == enPlayerAnimClip_Num,
	"EnPlayerAnimClip を足したら、CLIP_NAMES にも足してください。");
```

ボタンを押したら、`PlayerAnimator::PlayFrom` で流します。`Play` と違って、ステートが入れておいた予約（次の補間時間・始める位置）を使わず、消しもしません。ボタンは3つずつ横に並べます。

| 名前 | 何をするものか | どこから来たもの |
|---|---|---|
| `ImGui::Button` | ボタンを出し、押されたフレームだけ true を返す | 外部ライブラリ（Dear ImGui） |
| `ImGui::SameLine` | 次の部品を同じ行に並べる | 外部ライブラリ（Dear ImGui） |
| `PlayerAnimator::PlayFrom` | 補間時間・始める位置・速さを指定してクリップを流す | このゲームの [PlayerAnimator.h](../../../../Game/Source/Player/PlayerAnimator.h) |

## 2. 使い方

1. ゲームで F1 を押して、デバッグUIを出す。
2. 「アニメーションの確認」の窓で、流したいクリップのボタンを押す。

クリップを足したら、`EnPlayerAnimClip`・`PlayerConfig.cpp` の `CLIP_TABLE`・`player.json` の `clips` に加えて、`CLIP_NAMES` にも足します。

## 3. 決めたこと

| 決めたこと | 理由 |
|---|---|
| ステートを作らず、アニメーションだけを流す | 試しに作ったクリップを見るためのもので、動きや遷移は要らない |

# 3段攻撃の手順

設計: [3段攻撃の設計](3段攻撃の設計.md)
経緯: [3段攻撃の経緯](3段攻撃の経緯.md)

左クリックで、立ち止まって右手 → 左手 → 両手の順に氷魔法を撃つ3段攻撃を足すまでの手順です。

**出来上がるもの:** 地面で左クリックすると、撃つ瞬間にカメラの方を向き、右手を正面へ突き出して、手が出きったところで氷の弾を撃ちます。突き出している間にもう一度クリックしておくと、撃ち終わりで左手、その次は両手で撃ちます。撃ち終わりからは、ダッシュ・ジャンプ・移動で打ち切れます。

**前提:**

- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [プレイヤーのステートの手順](../プレイヤーのステート/プレイヤーのステートの手順.md)・[ダッシュの手順](../ダッシュ/ダッシュの手順.md)・[走りから止まる手順](../走りから止まる/走りから止まる手順.md) と、氷魔法（[氷魔法の手順](../../魔法/氷魔法/氷魔法の手順.md)）を済ませておく（順番は [README の「ゲームを作る順番」](../../../README.md#ゲームを作る順番)）。
- 攻撃のクリップ `Assets/modelData/player/Animation/Attack1.fbx`〜`Attack3.fbx` は、リポジトリにもとからある。作り方は [3段攻撃の設計](3段攻撃の設計.md) の「モーションの作り方」。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 攻撃のクリップ・ステートの種類・数値 | ビルドが通る |
| 2 | 攻撃するときに向く方向の入力 | ビルドが通る |
| 3 | 攻撃のステート `PlayerAttackState` | ビルドが通る |
| 4 | 登録して、地面にいるときの左クリックで入る | 左クリックで3段の攻撃のモーションが出る |
| 5 | 手を突き出したコマで弾を撃つ | 弾が、手が出きったところで出る |
| 6 | 攻撃中は体の連動の走り用の調整を外し、顔を前へ向ける | 撃つ手が正面へ出て、顔が前を向く |

**読み方:**

- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- 書き換えるところは、「前」と「後」の枠を並べています。
- コードの下に、3つを置きます。
  - 「行・何をしているか」の表: 1行ずつの動き。
  - 「なぜ」「効果」: その小手順でそう書く理由と、書くと何ができるようになるか。
  - 「初めて出てくる名前」の表: このページで初めて出てくる変数・引数・関数・型・マクロ・C++ の書き方を、コードに出てくる順に並べます。2回目からは載せないので、わからない名前はページ内検索（`Ctrl+F`）で最初に出てきた所を探してください。「どこから来たもの」で、このゲームで作ったもの（どの手順で作ったか）・エンジン（k2Engine）の機能・C++ の標準ライブラリ・C++ の書き方のどれかがわかります。
- [前提知識](../../../前提知識.md) で「よく知っている」にあるもの（クラス・継承・`virtual`・`override`・ポインター・`static`・`constexpr`・`Vector3` など）は、表に載せません。「まあまあ」「怪しい」「微妙」にあるものは載せます。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

PlayerStateId PlayerAttackState::CheckTransition(const PlayerStateContext& context, const CharacterInput& input) const
{
	const PlayerStateSettings& s = context.settings;
	if (!context.mover->IsOnGround()) {
		return PlayerStateId::Air;
	}
	if (!IsCancelable(context)) {
		return PlayerStateId::Attack;
	}
	// 撃ち終わりからは、ほかの動きで打ち切れる。
	if (input.dash.isTrigger && s.dashDistance > 0.0f) {
		return PlayerStateId::Dash;
	}

		return PlayerStateId::Air;

	if (WillChain(context)) {

	const PlayerStateId next = PlayerGroundState::SelectByInput(context, input);
	if (next != PlayerStateId::Idle) {

	}
	return m_clipTime < s.attackEndTime ? PlayerStateId::Attack : PlayerStateId::Idle;
}

void PlayerAttackState::Update(PlayerStateContext& context, const CharacterInput& input, float deltaTime)
{
	if (WillChain(context)) {
		StartStage(context, input, m_stage + 1);
	}
	// この段を始めたクリックは数えない。それより後のクリックで、次の段を予約する。
	if (!m_isFirstFrame && input.fire.isTrigger) {
		m_isNextQueued = true;
	}
	m_isFirstFrame = false;

	m_clipTime += deltaTime * context.settings.attackAnimSpeed;
	// 手を突き出したコマで撃つ。Player がこれを見て、このフレームだけ魔法の発射ボタンを押したことにする。

# 走りから止まる経緯

設計: [走りから止まる設計](走りから止まる設計.md)、[止まるモーションの設計](../アニメーション制作/止まるモーションの設計.md)

何をして、なぜ今の形になったかの記録です。日付ごとに書き足します。コマは 30fps で、クリップの先頭を 0コマ目と数えます。

## 2026-11-07 原神の動画から止まる動きを作った

「走ったあと慣性でザザっと止まるモーションを入れて」とのことで作った。動画の中で走りから止まる場面は 30秒・41秒・53秒・60秒あたりにあり、いちばん勢いよく滑って止まる 30秒の場面を使った（41秒などは、数歩で歩くように止まる）。

| 候補 | 選ばなかった理由 |
|---|---|
| Idle へ長めに補間するだけ | 走りのポーズのまま滑って見え、踏ん張る感じが出ない |
| Run の骨の角度を足して作る | 前のダッシュで、途中の形とつなぎ目が作り込めなかった |

読み取りから手で直したこと:

| 直したこと | 理由 |
|---|---|
| 30.14秒からあとの脚の A・B を入れ替えた | MediaPipe が左右の脚を取り違えていた |
| 29.91・29.94秒の前の足を、前後のコマから補間した | 前の足が後ろへ跳ね上がったように読み取られていた |
| 30.15〜30.25秒の後ろの足を、前後のコマから補間した | たたんだ足が体に隠れて、向きが乱れていた |
| コマごとに、低い方のつま先を地面（0）に合わせた | カメラが動いて、立ったときにつま先が浮いていた |

## 2026-11-07 走るボタンを先に離しても止まるようにした

左Shift と移動キーをほぼ同時に離すと、左Shift が先に外れて一瞬 Walk になり、滑らずに止まっていた。Run から来て 0.2秒以内の Walk も Stop へ移すようにした（`stopAfterRunSeconds`）。

## 2026-11-07 起き上がりで足がバタバタしないようにした

読み取りの揺れで、起き上がるところ（StopL / StopR の 15〜22コマ目）で前の足の甲が一度 50° ほど下を向いて戻り、太ももも1コマに 10〜20° ずつ振れていた。「慣性着地のあと足を戻すときにバタバタする」とのことで、StopL / StopR の 14〜30コマ目の脚（太もも・すね・足）を smoothstep でまっすぐ移るようにし、30〜33コマ目は 30コマ目のまま止めた。胴体・腕・首は揺れが小さいので元のまま。

## 2026-11-07 ダッシュのあとも止まる動きを挟むようにした

はじめは、ダッシュの終わりは着地して走り出すポーズなので、すぐ Idle へ移していた。「ダッシュからも慣性着地に移行してほしい」とのことで、移動の入力がなければ Stop へ移すようにした（`dashEndWithStop`）。

## 2026-11-07 設計と経緯を分けた

モーションの作り方を [止まるモーションの設計](../アニメーション制作/止まるモーションの設計.md) に、経緯をこのページに分けた。

## 2026-11-08 止まるときにスカートの中が見えないよう、太ももを上げすぎないようにした

「走りから止まるときにスカートの中身が見えないように、かつ自然に見えるように」とのことだった。UE で脚の角度を測ると、踏ん張るところ（StopL / StopR の 3〜13コマ目）で両方の太ももがほぼ水平（-2〜-15°）まで上がり、腰が 48cm まで沈んでいた。ゲームの録画（11-07）でも、前の太ももがスカートの前を持ち上げ、スカートの下から太ももが出ていた。原神の動画でも太ももは水平近くまで上がっているが、前が開いた長いドレスなので見えない。

`adjust_bone_rotation.py` の `rotoscope` に `thigh_max_deg`・`thigh_soft_deg` を足し、太ももを -30° より上へ上げないようにした（-40° からなだらかに寄せる）。すねはデータのままなので、前の脚は伸ばして突っ張る形になり、腰は 64〜70cm までしか沈まなくなった。

| 候補 | 選ばなかった理由 |
|---|---|
| 腰を沈めたまま、膝を閉じる・内へ向ける | 左右の軸まわりにしか回さない作り方なので、ひねりを入れると脚の向きがずれる。前の太ももが水平なままでは、スカートの前は持ち上がる |
| スカートのボーン（`J_Sec_*`）を動かす | モーションに含まれず、揺れものの物理もまだない |

## 2026-11-08 太ももの上限を -45° に下げた

-30° にしたあとも「正面から見たらまだスカートの中が見える。多少足に被ってもいいので見えないように」「止まったときの勢いでスカートがめくれすぎている」とのことだった。スカートのボーン（`J_Sec_L/R_SkirtSide`）は横にしかなく、どのモーションでも動いていなかったので、めくれるのも太ももがスカートを引っぱるためと考え、上限を -45° に下げた。両方の太ももが同じ角度で前へ出るので、正面から見て脚の間も開きにくい。踏ん張るところの腰は 71〜78cm、前の脚の膝は 7〜35° で、ほぼ伸ばして突っ張る形になった。

## 2026-11-08 太ももの上限をやめ、スカートのボーンを動かすようにした

「足はなるべく前の角度のほうが良い。そうするとどうしてもスカートがめくれるか」とのことで、モデルを調べた。FBX を読むスクリプトでスカートの布（`N00_002_03_Tops_01_CLOTH_01〜03`）がどのボーンについて動くかを数えると、太もものボーンにはほとんど付いておらず（合計 0.1）、腰とスカートのボーン（`J_Sec_*_Skirt*`）に付いていた。さらに親子関係を見ると、前と後ろのスカートのボーンは太ももの子、横は腰の子だった。モーションではスカートのボーンを動かしていないので、太ももを水平まで上げると前の布が水平に突き出て（-4〜+5°）、後ろの布も前へ持ち上がっていた（-28〜-32°）。

太ももの上限（-30°、-45°）は外して脚を原神のデータの角度に戻し、`adjust_bone_rotation.py` に `skirt_follow` を足した。スカートの根元を、親が回った分の一部だけついていくように戻す（前 0.5、後ろ 0.25、横は腰の傾きの 0.5）。踏ん張るところで、前の布は -39〜-41°、後ろの布は -93〜-94° になった。脚に少しかぶるのは許容とのことなので、前は太ももが布を突き抜けても、布が下に垂れて視線をさえぎる方を選んだ。`thigh_max_deg` はスクリプトに残してある。

## 2026-11-08 後ろへ来る腕を急に振らないようにした

スカートの直しは「完璧」とのことだった。続けて「止まったときに後ろに来る腕が急にブンと後ろに振るのが違和感。滑らかに」とのことだった。読み取りの角度を見ると、後ろへ来る腕（データの `a`）の肘が 8コマ目で 109° 曲がってから 10〜11コマ目で 10° まで伸び、前腕が3コマで約100°（-17 → -35 → -89 → -119°）振られていた。16〜18コマ目では肘が逆へ反っていた（-5〜-10°）。上腕はなめらかだった。

`rotoscope` に `arm_smooth` を足し、この腕の肘の曲がりだけを幅 2.5コマのガウスでならし、5° より伸ばさないようにした。前腕は 1コマ最大約14° で -35° から -124° へ振るようになった。上腕もならすと、始めと終わりの角度が 3〜5° ずれて走り・Idle とのつながりが変わるので、ならさなかった。
「もうちょっとゆっくりにして」とのことで、ならす幅を 2.5コマから 4コマに広げた。前腕は 5〜15コマ目（約0.33秒）かけて、1コマ最大約9°で振るようになった。

# 体の傾きの設計

作成日: 2026-11-15
対象: [BodyLean.h](../../../Game/Source/Character/Components/BodyLean.h)、[BodyLean.cpp](../../../Game/Source/Character/Components/BodyLean.cpp)
経緯: [移動の経緯](移動の経緯.md)

走り出すときに前へ、止まるときに後ろへ体を傾けて、重心が動いているように見せる部品です。Character が持ち、Player だけが使います（Enemy は使わない）。

- **見た目だけを傾ける。** 移動・当たり判定・魔法を撃つ向きは変えない。足元を中心に、モデルの回転だけを傾ける。
- **傾きは、移動の速さの変わり方（加速）から求める。** アニメーションやステートは知らない。

---

## 1. 全体像

```mermaid

    M["CharacterMover<br/>位置・見た目の向き"] --> L["BodyLean::Update"]
    L -->|傾けた回転| R[モデルの回転]

```

`Character::Update` の ⑥ で、移動したあとの位置と見た目の向き（[移動の設計](移動の設計.md)）を渡し、傾けた回転をモデルに渡す。

---

## 2. 実装方法

1. **速さを求める。** 前のフレームの位置との差から水平の速さを出す。動きすぎ（5000 cm/秒より速い）ならワープ（リスポーンなど）とみなし、傾きを 0 に戻す。
2. **速さをならす。** 移動の速さは一瞬で変わるので、`velocitySmoothSeconds` でならしてから、ならした速さの変わり方（加速）を求める。
3. **前向きの加速から傾きを決める。** 体の前向きの加速と重力の釣り合いの角度に `accelLeanScale` を掛け、`maxAccelLeanDeg` で抑える。
4. **傾きを少しずつ寄せる。** `leanSmoothSeconds` で目標の傾きに近づける。
5. **体の向きで見た前後に傾ける。** X 軸まわりに傾けてから、体の向きに回す。

```cpp
// BodyLean::Update
float targetPitch = atanf(forwardAcceleration / GRAVITY) * m_settings.accelLeanScale;
targetPitch = max(-maxPitch, min(maxPitch, targetPitch));
m_pitch += (targetPitch - m_pitch) * SmoothRate(deltaTime, m_settings.leanSmoothSeconds);
...
return rotation * pitchRotation;  // 体の向き × 前後の傾き
```

`SmoothRate(deltaTime, time)` は `1 - exp(-deltaTime / time)`。FPS が変わっても、同じ時間で同じだけ近づく。

---

## 3. 使い方

| やりたいこと | 書き方 |
|---|---|
| 傾きの量を変える | player.json の `lean` |
| ほかのキャラクターにも傾けさせる | そのキャラクターの `MakeConfig` で `config.lean.isEnabled = true` にする |

---

## 4. 調整用の数値（player.json の `lean`）

| 名前 | 値 | 意味 |
|---|---|---|
| `enabled` | true | 使うか |
| `accelLeanScale` | 0.12 | 物理の傾き（加速と重力の釣り合い）の何倍にするか |
| `maxAccelLeanDeg` | 8° | 傾きの上限 |
| `velocitySmoothSeconds` | 0.15秒 | 速さをならす時間 |
| `leanSmoothSeconds` | 0.1秒 | 傾きが目標に追いつく時間 |

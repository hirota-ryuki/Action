# 方向転換の手順

作成日: 2026-11-09
設計: [方向転換の設計](方向転換の設計.md)
経緯: [方向転換の経緯](方向転換の経緯.md)

入力の向きを変えたとき、キャラクターが一瞬で向かずに、決まった速さで回って向くようにする手順です。上から順にやると、[方向転換の設計](方向転換の設計.md) の形になります。

**出来上がるもの:** 走っていて反対へ入力すると、体がぱっと向かずに、1秒に 720°（180° の切り返しで約0.25秒）の速さで、近い方へぐるっと回ります。ダッシュも同じ速さで回ります。敵は今までどおり一瞬で向きます。

**前提:**

- [ゲームを作る順番](../../README.md#ゲームを作る順番) の 0〜22 を済ませている（`CharacterMover`・プレイヤーのステート・ダッシュがあり、プレイヤーの数値を `Assets/data/player.json` から読んでいる）。
- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64**（Release でもよい）でビルドする。
- 作業を始める前に、main からブランチを切る。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 回る速さの設定 `turnSpeedDeg` | ビルドが通る |
| 2 | 決まった速さで回る `TurnTo()` | ビルドが通る |
| 3 | 歩く・走る・空中で、`FaceTo()` の代わりに `TurnTo()` で回る | ビルドが通る（まだ速さが 0 なので一瞬で向く） |
| 4 | ダッシュも `TurnTo()` で回る | ビルドが通る（同上） |
| 5 | プレイヤーの回る速さを `player.json` から読む | 反対へ入力すると、ぐるっと回る |

## 手順1: 回る速さの設定を足す

1秒に何度まで回るかを、移動の設定に持たせます。0 のときは今までどおり一瞬で向くことにするので、最初の値は 0 にします（敵はこの値のまま）。

**この手順で触るファイル:**

```diff
+	float turnSpeedDeg = 0.0f;        // 向きを変える速さ（1秒に何度まで回るか）。0なら一瞬で向く。

```

## 手順2: 決まった速さで回る `TurnTo()` を作る

今の向きから目標の向きへ、1フレームで「速さ × 経過時間」までだけ回します。角度の差を −180〜180° にしてから回すので、近い方へ回ります。回り切れる差なら、目標の向きにぴったり合わせます。速さが 0 なら、もとからある `FaceTo()` で一瞬で向きます。

**この手順で触るファイル:**

| ファイル | 何をするか |
|---|---|
| [CharacterMover.h](../../../Game/Source/Character/Components/CharacterMover.h) | 追加（`TurnTo()` の宣言）・書き換え（クラスの説明と `FaceTo()` のコメント） |
| [CharacterMover.cpp](../../../Game/Source/Character/Components/CharacterMover.cpp) | 追加（`TurnTo()`） |

[CharacterMover.h](../../../Game/Source/Character/Components/CharacterMover.h) のクラスの説明に `TurnTo()` を**書き換え**で足し、`FaceTo()` の上に `TurnTo()` の宣言を**追加**します。`FaceTo()` のコメントは、一瞬で向くことがわかるように**書き換え**ます。

<!-- file: ../../../Game/Source/Character/Components/CharacterMover.h -->

```diff
 // 使い方は2通りある。
 // ・Update(input): 入力どおりに歩く・走る・跳ぶ。状態を持たないキャラクター（Enemy）向け。

+// ・Move() / MoveByInput() / Jump() / TurnTo() / FaceTo(): 1つずつの操作。ステートで動きを変えるキャラクター（Player）向け。
```

```diff
+	// 水平方向の向きを、direction へ turnSpeedDeg の速さで1フレーム分だけ回す（近い方へ回る）。
```

```diff
+void CharacterMover::TurnTo(const Vector3& direction, float deltaTime)
+{
+	if (m_settings.turnSpeedDeg <= 0.0f) {
+		FaceTo(direction);
+		return;
+	}
+	Vector3 horizontal = direction;
+	horizontal.y = 0.0f;
+	if (horizontal.LengthSq() <= FLT_EPSILON) {
+		return;
+	}
+	// 今の向きと目標の向きを、Y軸まわりの角度にする（SetRotationYFromDirectionXZ と同じ測り方）。
+	const Vector3 forward = GetForward();
+	const float currentYaw = atan2f(forward.x, forward.z);
+	const float targetYaw = atan2f(horizontal.x, horizontal.z);
+	// 差を -180〜180° にして、近い方へ回る。
+	float diff = targetYaw - currentYaw;
+	while (diff > Math::PI) {
+		diff -= Math::PI2;
+	}
+	while (diff < -Math::PI) {
+		diff += Math::PI2;
+	}
+	// 1フレームで回れる角度を超えたら、そこで止める（次のフレームで続きを回る）。
+	const float maxStep = Math::DegToRad(m_settings.turnSpeedDeg) * deltaTime;
+	if (fabsf(diff) <= maxStep) {
+		m_rotation.SetRotationY(targetYaw);
+		return;
+	}
+	m_rotation.SetRotationY(currentYaw + (diff > 0.0f ? maxStep : -maxStep));
+}
+

 {
```

## 手順3: 歩く・走る・空中で、`TurnTo()` で回る

## 手順5: プレイヤーの回る速さを `player.json` から読む

プレイヤーだけ、回る速さを `player.json` の `move.turnSpeedDeg` から読みます。720°/秒にします（180° の切り返しで約0.25秒）。

**この手順で触るファイル:**

| ファイル | 何をするか |
|---|---|
| [PlayerConfig.cpp](../../../Game/Source/Player/PlayerConfig.cpp) | 追加（`MakeMoveSettings()` で `turnSpeedDeg` を読む1行） |
| [player.json](../../../Game/Assets/data/player.json) | 追加（`move` に `turnSpeedDeg`） |

[PlayerConfig.cpp](../../../Game/Source/Player/PlayerConfig.cpp) の `MakeMoveSettings()` の `capsuleHeight` を読む行の下に**追加**します。キーがないときは 720 にします。

<!-- file: ../../../Game/Source/Player/PlayerConfig.cpp -->

```diff
 		settings.capsuleHeight = Read(section, "move", "capsuleHeight", 100.0f);
+		settings.turnSpeedDeg = Read(section, "move", "turnSpeedDeg", 720.0f);
 		return settings;
```

[player.json](../../../Game/Assets/data/player.json) の `move` の `capsuleHeight` の下に**追加**します。

<!-- file: ../../../Game/Assets/data/player.json -->

```diff
 		"capsuleHeight": 100.0,
+		"turnSpeedDeg": 720.0, // 向きを変える速さ（1秒に何度まで回るか）。180° の切り返しで約0.25秒。0 なら一瞬で向く。
 		"moveThreshold": 0.1 // 移動入力がこれより小さければ立ち止まる。
```

**確かめ方（これで出来上がり）:** ソリューションのビルドが通る。ゲームを起動して走り、反対へ入力すると、体がぱっと向かずに約0.25秒でぐるっと回る。ダッシュを横や後ろへ出したときも同じように回る。敵は今までどおり一瞬で向く。

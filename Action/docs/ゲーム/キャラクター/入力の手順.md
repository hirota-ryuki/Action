# 入力の手順

作成日: 2026-11-08
設計: [入力の設計](入力の設計.md)
経緯: [入力の経緯](入力の経緯.md)
確かめた記録: [ゲームの手順書の経緯](../土台/ゲームの手順書の経緯.md)

キャラクターが1フレームに受け取る入力（`CharacterInput`）と、入力元（`IInputSource`）の仕組み、Player 用の入力元（パッド・キーボード・マウス）を作るまでの手順です。NPC 用の入力元（AI）は [NPCのAIの手順](NPCのAIの手順.md) で作ります。

**出来上がるもの:** `Character` が毎フレームの ① で入力元から入力を受け取り、`m_input` に入れます。Player の入力元は、スティックの向きをカメラ基準からワールドの向きに直して渡します。キャラクターはパッドやカメラのことを知らずに、`m_input` だけを見て動けるようになります（動かすのは [移動の手順](移動の手順.md)）。

**前提:**

- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [陣営と当たり判定の手順](陣営と当たり判定の手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../README.md#ゲームを作る順番)）。
- 作業を始める前に、main からブランチを切る。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 入力の形 `CharacterInput` と、入力元のインターフェース | ビルドが通る |
| 2 | Player 用の入力元 `PlayerInputSource` | ビルドが通る |
| 3 | キャラクターに入力元を持たせる | 起動して落ちない |

```cpp
#pragma once

#include "Faction.h"

// ボタン1つ分の状態。押しているかどうかを毎フレーム渡すと、押した瞬間・離した瞬間を判定する。
struct ButtonState
{
	bool isTrigger = false;  // このフレームで押された。
	bool isPress = false;    // 押されている。
	bool isRelease = false;  // このフレームで離された。

	void Update(bool isPressNow)
	{
		isTrigger = isPressNow && !isPress;
		isRelease = !isPressNow && isPress;
		isPress = isPressNow;
	}
};

// キャラクターが1フレームに受け取る入力。
// キャラクターはこれを受け取って動くだけで、パッドやカメラ、AIのことは知らない。
// 値だけの構造体なので、画面に表示したり記録・再生したりしやすい。
struct CharacterInput
{
	Vector3 moveDirection = Vector3::Zero;  // 移動したい方向（ワールドのXZ）。長さ0〜1で速さの割合を表す。
	Vector3 lookDirection = Vector3::Zero;  // 向きたい方向。ゼロなら移動方向を向く。
	bool isRun = false;
	ButtonState jump;
	ButtonState dash;
	ButtonState fire;                       // 選んでいる魔法を撃つ。
	ButtonState subFire;                    // サブの魔法（MagicCaster::SetSubMagic）を撃つ。
	int magicSwitch = 0;                    // -1: 前の魔法へ、+1: 次の魔法へ、0: 切り替えない。
	bool hasAim = false;                    // true なら aimOrigin/aimDirection の方向へ撃つ。false ならキャラクターの正面へ撃つ。
	Vector3 aimOrigin = Vector3::Zero;
	Vector3 aimDirection = Vector3::AxisZ;
};

// 入力元が操作対象について知ってよい情報。
struct InputSourceContext
{
	const IGameObject* self = nullptr;  // 操作対象。AIが自分を狙わないように使う。
	Faction faction = Faction::Neutral;
	Vector3 position = Vector3::Zero;   // 足元の位置。
	Vector3 forward = Vector3::AxisZ;   // 正面の向き。
	float deltaTime = 0.0f;
	bool isFirstPerson = false;         // 一人称視点か。プレイヤーの照準をカメラに合わせるのに使う。
};

// 入力元のインターフェース。プレイヤーの操作もNPCのAIもこれを実装する。
// キャラクターが持つ入力元を差し替えるだけで、操作する人（またはAI）を入れ替えられる。
class IInputSource
{
public:
	virtual ~IInputSource() = default;
	// 毎フレーム呼ばれる。input には前フレームの値が入っているので、上書きして返す。
	// ButtonState は Update() に「押しているか」を渡すこと（押した瞬間の判定に前フレームの値を使うため）。
	virtual void Update(const InputSourceContext& context, CharacterInput& input) = 0;
};
```

- **`CharacterInput` は値だけの構造体にする。** 画面に出したり、記録して再生したりしやすくなります。
- **ボタンは「押しているか」を毎フレーム `ButtonState::Update()` に渡す。** 前のフレームの値と比べて、押した瞬間・離した瞬間を決めます。そのため入力元には、前のフレームの入力が入ったまま渡します。

**確かめ方:** ソリューションのビルドが通る。

```cpp
#pragma once

#include "CharacterInput.h"

// パッド・キーボード・マウスの入力を CharacterInput に変換する入力元。
// スティックの向きはカメラ基準からワールドの向きに変換して渡す。
//
// 割り当て:
//   移動        左スティック / WASD
//   走る        左Shift
//   ジャンプ    Aボタン / J
//   ダッシュ    Xボタン / L
//   発射        マウス左ボタン / Yボタン / I
//   魔法切替    LB・RB / Q・E
class PlayerInputSource : public IInputSource
{
public:
	explicit PlayerInputSource(int padNo = 0);
	void Update(const InputSourceContext& context, CharacterInput& input) override;

private:
	// ゲームのウィンドウが前面にあるか。マウスは他のウィンドウを操作中に反応させない。
	static bool IsGameWindowActive();
	static bool IsKeyPressed(int virtualKey);

	int m_padNo = 0;
	ButtonState m_prevMagicKey;  // Qキー。
	ButtonState m_nextMagicKey;  // Eキー。
};
```

<!-- new: ../../../Game/Source/Character/Input/PlayerInputSource.cpp -->

```cpp
#include "stdafx.h"
#include "PlayerInputSource.h"
#include "system.h"

PlayerInputSource::PlayerInputSource(int padNo)
	: m_padNo(padNo)
{
}

void PlayerInputSource::Update(const InputSourceContext& context, CharacterInput& input)
{
	const GamePad& pad = *g_pad[m_padNo];

	// スティックはカメラから見た向きなので、カメラの水平な前・右を使ってワールドの向きにする。
	Vector3 cameraForward = g_camera3D->GetForward();
	Vector3 cameraRight = g_camera3D->GetRight();
	cameraForward.y = 0.0f;
	cameraRight.y = 0.0f;
	cameraForward.Normalize();
	cameraRight.Normalize();
	input.moveDirection = cameraForward * pad.GetLStickYF() + cameraRight * pad.GetLStickXF();
	input.lookDirection = Vector3::Zero;

	// ジャンプはスペース（パッドは A）。パッド未接続時は A ボタンが J キーに割り当てられているので、J でも跳べる。
	input.jump.Update(IsKeyPressed(VK_SPACE) || pad.IsPress(enButtonA));
	// 左Shift（パッドは X）: 押した瞬間にダッシュ、押しっぱなしで走る。
	// 走るのはダッシュが終わったあとなので、単押しを繰り返すとダッシュが続けて出る。
	// パッド未接続時は X ボタンが L キーに割り当てられているので、L でも同じ動きになる。
	const bool isDashPress = IsKeyPressed(VK_LSHIFT) || pad.IsPress(enButtonX);
	input.dash.Update(isDashPress);
	input.isRun = isDashPress;
	input.fire.Update((IsGameWindowActive() && IsKeyPressed(VK_LBUTTON)) || pad.IsPress(enButtonY));
	// パッド未接続時は右トリガー(RB2)が8キーに割り当てられている。
	input.subFire.Update((IsGameWindowActive() && IsKeyPressed(VK_RBUTTON)) || pad.IsPress(enButtonRB2));

	m_prevMagicKey.Update(IsKeyPressed('Q'));
	m_nextMagicKey.Update(IsKeyPressed('E'));
	input.magicSwitch = 0;
	if (m_prevMagicKey.isTrigger || pad.IsTrigger(enButtonLB1)) {
		input.magicSwitch -= 1;
	}
	if (m_nextMagicKey.isTrigger || pad.IsTrigger(enButtonRB1)) {
		input.magicSwitch += 1;
	}

	// 一人称では視線の方向へ目の位置から撃つ。三人称ではキャラクターの正面へ撃つ（hasAim = false）。
	input.hasAim = context.isFirstPerson;
	if (input.hasAim) {
		input.aimOrigin = g_camera3D->GetPosition();
		input.aimDirection = g_camera3D->GetForward();
	}
}

bool PlayerInputSource::IsGameWindowActive()
{
	return g_hWnd != nullptr && GetForegroundWindow() == g_hWnd;
}

bool PlayerInputSource::IsKeyPressed(int virtualKey)
{
	// 最上位ビットが「今押されている」を表す。
	return (GetAsyncKeyState(virtualKey) & 0x8000) != 0;
}
```

- **スティックの向きは、カメラの水平な前・右でワールドの向きにする。**
- **マウスのボタンは、ゲームのウィンドウが前にあるときだけ使う。** ほかのウィンドウを操作中のクリックで魔法が出ないようにするためです。
- **左Shift は1つのキーで2つの意味を持つ。** 押した瞬間にダッシュ（`dash`）、押している間は走る（`isRun`）。

**確かめ方:** ソリューションのビルドが通る。

## 1. StatusEffects

コード: [StatusEffects.h](../../../../Game/Source/Character/Components/StatusEffects.h)、[StatusEffects.cpp](../../../../Game/Source/Character/Components/StatusEffects.cpp)

キャラクターがメンバーとして持つ部品です。Player も Enemy も持っているので、**どちらも凍るし、燃える**。

| 関数 | 内容 |
|---|---|
| `Init(modelRender)` | 見た目を変えるモデル。nullptr なら見た目は変えない |
| `Update(deltaTime)` | 残り時間を進め、色を変える |
| `Freeze(seconds)` | 凍らせる。凍結中にもう一度呼ぶと、残り時間の長い方で上書きする |
| `Burn(seconds)` | 燃やす。燃焼中にもう一度呼ぶと、残り時間の長い方で上書きする |
| `IsFrozen()` / `IsBurning()` | 今その状態か |
| `CanAct()` | 移動・攻撃などの行動ができるか（今は「凍っていない」こと） |

外には `CanAct()` だけを伝え、移動を止めるのは持ち主の側で行います。
- Player: 行動できなくなると `PlayerFrozenState` になる（[プレイヤーのステートの設計](../../プレイヤー/プレイヤーのステート/プレイヤーのステートの設計.md)）
- Enemy: 空の入力を `CharacterMover` に渡す
- 魔法: `CanAct()` が false の間、Character はスキルを使わず、`SkillController::CancelAll()` で溜めているスキルを消す

## 2. 凍結

| タイミング | 見た目 |
|---|---|
| 凍った瞬間 | モデルを水色にし、アニメーションを止める（その瞬間のポーズで固まる） |
| 解ける直前（0.4秒） | 元の色へなめらかに戻す |
| 解けた | アニメーションを動かす |

凍結時間は、かけた側（[氷魔法](../../魔法/氷魔法/氷魔法の設計.md)では2.5秒）が決めます。

## 3. 燃焼

| タイミング | 見た目 |
|---|---|
| 燃えている間 | モデルを赤〜橙にし、色の強さを揺らして炎が当たっているように見せる |
| 消える直前（0.4秒） | 元の色へなめらかに戻す |

燃焼は行動を止めません。体力ができたら、継続ダメージにつなげる想定です。
燃焼をかけるのは、[炎魔法](../../魔法/炎魔法/炎魔法の設計.md)の炎魔法発射後の燃える床（`BurningGround`）です。

## 4. 凍結と燃焼は打ち消し合う

- 凍っているときに燃やすと、**解凍される**（そのあと燃える）
- 燃えているときに凍らせると、**火が消える**（そのあと凍る）

## 5. 実装方法

### 状態は「残り秒数」1つで表す

```cpp
float m_freezeTimer = 0.0f;  // 0より大きい間は凍結中
float m_burnTimer = 0.0f;    // 0より大きい間は燃焼中
float m_burnElapsed = 0.0f;  // 燃え始めてからの秒数（揺らめき用）

bool IsFrozen() const { return m_freezeTimer > 0.0f; }
bool CanAct() const { return !IsFrozen(); }
```

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| メンバー変数 | `m_freezeTimer` | 凍結の残り時間を持つため | 凍結の残り秒数。0 より大きい間は凍結中 | ゲームの [StatusEffects.h](../../../../Game/Source/Character/Components/StatusEffects.h) の `StatusEffects` クラス |
| メンバー変数 | `m_burnTimer` | 燃焼の残り時間を持つため | 燃焼の残り秒数。0 より大きい間は燃焼中 | ゲームの StatusEffects.h の `StatusEffects` クラス |
| メンバー変数 | `m_burnElapsed` | 炎の揺らめきの時刻を持つため | 燃え始めてからの秒数。揺らめきの計算の `sin` に入れる | ゲームの StatusEffects.h の `StatusEffects` クラス |

状態のフラグや enum は持ちません。`Update()` で秒数を減らし、0 以下になったら解けます。
かけ直したときは、残りの長い方を残します（`if (seconds <= m_freezeTimer) return;`）。

### 見た目は「乗算色」と「加算色」を、通常の色から補間する

**用語:**

| 用語 | 何のことか |
|---|---|
| 乗算色 | モデルの色にかける色。`(1, 1, 1, 1)` なら元の色のまま。赤を 0.3 にすると、赤が 3割に弱まる |
| 加算色 | モデルの色に足す色。`(0, 0, 0, 0)` なら元の色のまま。青を足すと、青っぽく明るくなる |

```cpp
void StatusEffects::SetLook(float rate, const Vector4& mulColor, const Vector4& addColor)
{
    // rate = 0 で通常の色、1 で状態異常の色
    m_modelRender->SetMulColor(LerpColor(rate, NORMAL_MUL_COLOR, mulColor));
    m_modelRender->SetAddColor(LerpColor(rate, NORMAL_ADD_COLOR, addColor));
}
```

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 関数 | `SetLook()` | 状態異常の見た目を、1か所で決めるため | 割合 `rate` で、通常の色と状態異常の色を混ぜて、モデルに設定する | ゲームの [StatusEffects.cpp](../../../../Game/Source/Character/Components/StatusEffects.cpp) の `StatusEffects` クラス（private） |
| 引数 | `rate` | 通常の色から状態異常の色への、混ぜる割合を渡すため | 0 で通常の色、1 で状態異常の色 | ゲームの StatusEffects.cpp の `StatusEffects::SetLook()` |
| 引数 | `mulColor`・`addColor` | 状態異常のときの乗算色・加算色を渡すため | `rate` が 1 のときに使う色（凍結なら `FROZEN_MUL_COLOR`・`FROZEN_ADD_COLOR`） | ゲームの StatusEffects.cpp の `StatusEffects::SetLook()` |
| メンバー変数 | `m_modelRender` | 見た目を変えるモデルを覚えるため | `Init()` で渡された `ModelRender` へのポインター。`nullptr` なら見た目は変えない | ゲームの StatusEffects.h の `StatusEffects` クラス |
| 関数 | `SetMulColor()` | モデルの色に、乗算する色を設定するため | アルベドカラー（もとの色）にかける色を設定する。`(1, 1, 1, 1)` で元の色 | k2Engine（エンジン）の [ModelRender.h](../../../../k2Engine/graphics/ModelRender.h) の `ModelRender` クラス |
| 関数 | `SetAddColor()` | モデルの色に、加算する色を設定するため | 色に足す色を設定する | k2Engine（エンジン）の ModelRender.h の `ModelRender` クラス |
| 関数 | `LerpColor()` | 通常の色と状態異常の色を混ぜるため | `t` が 0 で `a`、1 で `b` になるように、4つの成分ずつ混ぜた色を返す | ゲームの StatusEffects.cpp（名前のない `namespace` の中） |
| 値 | `NORMAL_MUL_COLOR`・`NORMAL_ADD_COLOR` | 通常の色を決めておくため | 乗算色は `(1, 1, 1, 1)`、加算色は `(0, 0, 0, 0)`（どちらも元の色のまま） | ゲームの StatusEffects.cpp（名前のない `namespace` の中） |

| 状態 | rate の決め方 |
|---|---|
| 凍結 | ふだんは 1。残りが 0.4 秒を切ったら `残り / 0.4`（1→0）で元の色へ戻す |
| 燃焼 | `揺らめき × 消え際`。揺らめきは `1 - 0.3 × (0.5 + 0.5 × sin(経過秒 × 14))`、消え際は凍結と同じ |

凍結は、乗算で赤を落として青を上げ、さらに水色を足しています。暗い部分（髪・服）も水色に見えるようにするためです。

### アニメーションは凍った瞬間に止め、解けたときに戻す

```cpp
void StatusEffects::Freeze(float seconds)
{
    if (seconds <= m_freezeTimer) { return; }
    m_burnTimer = 0.0f;                               // 凍らせると火が消える
    if (!IsFrozen()) { m_modelRender->SetAnimationSpeed(0.0f); }  // 凍った瞬間のポーズで固める
    SetLook(1.0f, FROZEN_MUL_COLOR, FROZEN_ADD_COLOR);
    m_freezeTimer = seconds;
}

void StatusEffects::Burn(float seconds)
{
    if (IsFrozen()) { Unfreeze(); }                   // 燃やすと解凍される（速さを1に戻す）
    ...
}
```

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 関数 | `SetAnimationSpeed()` | アニメーションを止める・戻すため | 再生の速さを倍率で設定する。0 で止まり、1 で通常の速さ | k2Engine（エンジン）の ModelRender.h の `ModelRender` クラス |
| 値 | `FROZEN_MUL_COLOR`・`FROZEN_ADD_COLOR` | 凍結の見た目の色を決めておくため | 乗算色は `(0.30, 0.78, 1.45, 1.0)`（赤を落とし青を上げる）、加算色は `(0.06, 0.22, 0.34, 0.0)`（水色を足す） | ゲームの StatusEffects.cpp（名前のない `namespace` の中） |
| 関数 | `Unfreeze()` | 凍結を解くため | 凍結の残り時間を 0 にし、アニメーションの速さを 1 に戻し、見た目を通常の色に戻す | ゲームの StatusEffects.cpp の `StatusEffects` クラス（private） |

打ち消し合いは、かける関数の中で相手の秒数を 0 にするだけで書いています。

## 6. 使い方

### 新しい状態異常を作る（例: 毒）

`StatusEffects` に、凍結・燃焼と同じ形で足します。

1. 残り時間のメンバーを足す（例: `m_poisonTimer`）。
2. かける関数（`Poison(seconds)`）と、今その状態かを返す関数（`IsPoisoned()`）を足す。
3. `Update()` で残り時間を進め、見た目（色）を変える。
4. 行動を止めるものなら `CanAct()` の条件に含める。Player はそれだけで `PlayerFrozenState` に入る。
5. 弾などからかけるときは、`HitTarget::GetStatusEffects()` で受け取った先に対して呼ぶ。

# キャラクターの構成の手順

作成日: 2026-11-08
設計: [キャラクターの構成](キャラクターの構成.md)
経緯: [キャラクターの構成の経緯](キャラクターの構成の経緯.md)
確かめた記録: [ゲームの手順書の経緯](../土台/ゲームの手順書の経緯.md)

キャラクターの基底クラス（`Actor` → `Character`）と、まだ何もできない `Player`・`Enemy` を作り、`Game` から置くまでの手順です。`Character` が持つ部品（入力・移動・モデル・状態異常・当たり判定・魔法）は、このあとの手順書で1つずつ足していきます。

**出来上がるもの:** `Character` が「初期化の順番」と「1フレームの順番」を決め、派生クラスは「動く」部分（`UpdateAction()`）だけを書く形ができます。`Game` が Player と Enemy を作りますが、まだモデルがないので、画面には何も増えません。

**前提:**

- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [ゲームの土台の手順](../土台/ゲームの土台の手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../README.md#ゲームを作る順番)）。
- 作業を始める前に、main からブランチを切る。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 位置だけを持つ基底クラス `Actor` | ビルドが通る |
| 2 | キャラクターの基底クラス `Character` と、変わる値 `Status` | ビルドが通る |
| 3 | `Player`（と、調整値の `PlayerConfig`） | ビルドが通る |
| 4 | `Enemy` | ビルドが通る |

```cpp
#pragma once

// ワールドに置くものの位置・回転・大きさ。
struct Transform
{
	Vector3 position = Vector3::Zero;
	Quaternion rotation = Quaternion::Identity;
	Vector3 scale = Vector3::One;
};

// ワールドに置くものの基底クラス。位置（Transform）だけを持つ。
// モデルを持つかどうかは派生クラスが決める（範囲・トリガー・音など、モデルのない Actor もあるため）。
// Transform が位置の正。動かす部品（キャラコンなど）を持つ派生クラスは、動いた結果を毎フレーム Transform に書く。
class Actor : public IGameObject
{
public:
	const Transform& GetTransform() const
	{
		return m_transform;
	}
	const Vector3& GetPosition() const
	{
		return m_transform.position;
	}
	// 派生クラスで、動かす部品の位置も合わせて変える。
	virtual void SetPosition(const Vector3& position)
	{
		m_transform.position = position;
	}
	const Quaternion& GetRotation() const
	{
		return m_transform.rotation;
	}
	// 正面の向き（回転を Z 軸にかけたもの）。
	Vector3 GetForward() const
	{
		Vector3 forward = Vector3::AxisZ;
		m_transform.rotation.Apply(forward);
		return forward;
	}

protected:
	Transform m_transform;
};
```

`SetPosition()` は `virtual` にします。動かす部品（キャラコンなど）を持つ派生クラスが、部品の位置も一緒に変えられるようにするためです。

**確かめ方:** ソリューションのビルドが通る。

```cpp
#pragma once

// キャラクターの、遊んでいる間に変わる値（HP など）。
// 速さ・時間などの調整用の定数はここに入れない（各キャラクターの Config に書く）。
// 凍結・燃焼のような一時的な状態は StatusEffects にある。
// キャラクターごとの値は、これを継承して足す（例: PlayerStatus）。
class Status
{
public:
	virtual ~Status() = default;

	// HP を最大にして始める。
	void Init(float maxHp)
	{
		m_maxHp = maxHp;
		m_hp = maxHp;
	}

	float GetHp() const
	{
		return m_hp;
	}
	float GetMaxHp() const
	{
		return m_maxHp;
	}
	// 最大HPに対する今のHPの割合（0〜1）。HPゲージに使う。最大HPが 0 以下なら 0。
	float GetHpRate() const
	{
		if (m_maxHp <= 0.0f) {
			return 0.0f;
		}
		return min(1.0f, max(0.0f, m_hp / m_maxHp));
	}
	// HP を減らす。0 より下にはならない。
	void Damage(float amount)
	{
		m_hp = max(0.0f, m_hp - amount);
	}
	// HP を増やす。最大より上にはならない。
	void Heal(float amount)
	{
		m_hp = min(m_maxHp, m_hp + amount);
	}
	bool IsHpEmpty() const
	{
		return m_hp <= 0.0f;
	}

private:
	float m_hp = 100.0f;
	float m_maxHp = 100.0f;
};
```

<!-- new: ../../../Game/Source/Character/Character.h -->

```cpp
#pragma once

#include "Actor.h"
#include "Status.h"

// キャラクターごとの調整値。派生クラスが MakeConfig() で返す。
struct CharacterConfig
{
	float maxHp = 100.0f;
};

// Player・Enemy など、キャラクターの基底クラス。
// 全キャラクターに共通の部品（入力・移動・モデル・状態異常・当たり判定・魔法）を持ち、
// 初期化の順番と1フレームの順番をここで決める。派生クラスは「動く」部分（UpdateAction）と、自分だけの部品を書く。
// 位置は Actor の Transform が正。キャラコン（CharacterMover）が動いた結果を、毎フレーム Transform に書く。
class Character : public Actor
{
public:
	bool Start() final;
	void Update() final;
	void Render(RenderContext& rc) final;

	// 遊んでいる間に変わる値。派生クラスが自分の Status（PlayerStatus など）を返す。
	virtual Status& GetStatus() = 0;
	// 読むだけの側（UI など）に渡す const 版。
	virtual const Status& GetStatus() const = 0;

	// 体を描くか。一人称カメラのときは false にする。
	void SetRenderBody(bool isRenderBody)
	{
		m_isRenderBody = isRenderBody;
	}
	bool IsRenderBody() const
	{
		return m_isRenderBody;
	}

protected:

	// 調整値。Start() で1回だけ呼ぶ。
	virtual CharacterConfig MakeConfig() const = 0;
	// 共通の部品を Init したあとに呼ぶ。自分だけの部品の Init を書く。
	virtual void OnStart()
	{
	}
	// ③ 動く。CharacterMover の Move 系を1回だけ呼ぶ（凍結中も重力のために呼ぶ）。
	virtual void UpdateAction(float deltaTime) = 0;
	// モデルを更新したあと（ボーンに付けたものを動かす、など）。
	virtual void OnLateUpdate(float deltaTime)
	{
	}
	// 体を描いたあと、自分だけのものを描く。
	virtual void OnRender(RenderContext& rc)
	{
	}

private:
	bool m_isRenderBody = true;
};
```

<!-- new: ../../../Game/Source/Character/Character.cpp -->

```cpp
#include "stdafx.h"
#include "Character.h"

bool Character::Start()
{
	const CharacterConfig config = MakeConfig();

	GetStatus().Init(config.maxHp);

	OnStart();
	return true;
}

void Character::Update()
{
	const float deltaTime = g_gameTime->GetFrameDeltaTime();

	// ③ 動く（派生クラス）
	UpdateAction(deltaTime);
	// ⑦ モデルを更新したあとの処理（派生クラス）
	OnLateUpdate(deltaTime);
}

void Character::Render(RenderContext& rc)
{
	if (!m_isRenderBody) {
		return;
	}
	OnRender(rc);
}
```

- **調整値は `CharacterConfig` にまとめ、派生クラスが `MakeConfig()` で返す。** 今は HP だけです。部品を足すたびに、その部品の設定をここに足します。
- **1フレームの順番に番号を付けておく。** 今あるのは ③ 動く と ⑦ モデルのあと だけで、①②④⑤⑥ はこのあとの手順で足します。
- **`GetStatus()` の実体は派生クラスが持つ。** 派生クラスごとに値を足せるようにするためです（次の手順の `PlayerStatus`）。

**確かめ方:** ソリューションのビルドが通る。

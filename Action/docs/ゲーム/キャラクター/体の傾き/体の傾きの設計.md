# 体の傾きの設計

作成日: 2026-11-15
対象: [BodyLean.h](../../../../Game/Source/Character/Components/BodyLean.h)、[BodyLean.cpp](../../../../Game/Source/Character/Components/BodyLean.cpp)
経緯: [移動の経緯](../移動/移動の経緯.md)

走り出すときに前へ、止まるときに後ろへ体を傾けて、重心が動いているように見せる部品です。Character が持ち、Player だけが使います（Enemy は使わない）。

- **見た目だけを傾ける。** 移動・当たり判定・魔法を撃つ向きは変えない。足元を中心に、モデルの回転だけを傾ける。
- **傾きは、移動の速さの変わり方（加速）から求める。** アニメーションやステートは知らない。

---

## 1. 全体像

```mermaid
flowchart LR
    M["CharacterMover<br/>位置・見た目の向き"] --> L["BodyLean::Update"]
    L -->|傾けた回転| R[モデルの回転]
    R --> BL["BodyLink・SpringBones<br/>（骨の段）"]
```

`Character::Update` の ⑥ で、移動したあとの位置と見た目の向き（[移動の設計](../移動/移動の設計.md)）を渡し、傾けた回転をモデルに渡す。

---

## 2. 実装方法

1. **速さを求める。** 前のフレームの位置との差から水平の速さを出す。動きすぎ（5000 cm/秒より速い）ならワープ（リスポーンなど）とみなし、傾きを 0 に戻す。
2. **速さをならす。** 移動の速さは一瞬で変わるので、`velocitySmoothSeconds` でならしてから、ならした速さの変わり方（加速）を求める。
3. **前向きの加速から傾きを決める。** 体の前向きの加速と重力の釣り合いの角度に `accelLeanScale` を掛け、`maxAccelLeanDeg` で抑える。
4. **傾きを少しずつ寄せる。** `leanSmoothSeconds` で目標の傾きに近づける。
5. **体の向きで見た前後に傾ける。** X 軸まわりに傾けてから、体の向きに回す。

```cpp
// BodyLean::Update
float targetPitch = atanf(forwardAcceleration / GRAVITY) * m_settings.accelLeanScale;
targetPitch = max(-maxPitch, min(maxPitch, targetPitch));
m_pitch += (targetPitch - m_pitch) * SmoothRate(deltaTime, m_settings.leanSmoothSeconds);
...
return rotation * pitchRotation;  // 体の向き × 前後の傾き
```

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 変数 | `targetPitch` | 目標の傾きを持つため | 前後の傾きの目標（ラジアン）。前向きの加速から求め、上限で抑える | ゲームの [BodyLean.cpp](../../../../Game/Source/Character/Components/BodyLean.cpp) の `Update()` の中 |
| 関数 | `atanf()` | 加速と重力の釣り合いから、傾きの角度を求めるため | `atan`（逆正接）をラジアンで返す。加速 ÷ 重力 を渡すと、釣り合う傾きの角度になる | C++ の標準ライブラリ（`<math.h>`。[k2EngineLowPreCompile.h](../../../../k2EngineLow/k2EngineLowPreCompile.h) で読み込み済み） |
| 変数 | `forwardAcceleration` | 前向きの加速だけを取り出すため | 加速度を、体の前向きの向きに映した値（cm/秒²）。この抜き出しの前で求めている | ゲームの [BodyLean.cpp](../../../../Game/Source/Character/Components/BodyLean.cpp) の `Update()` の中 |
| 値 | `GRAVITY` | 傾きを、重力との釣り合いで求めるため | 重力加速度（`980.0f`、cm/秒²） | ゲームの [BodyLean.cpp](../../../../Game/Source/Character/Components/BodyLean.cpp)（名前のない `namespace` の中） |
| メンバー変数 | `m_settings` | 調整用の数値を持つため | `BodyLeanSettings`。傾きの倍率・上限・ならす時間が入っている | ゲームの [BodyLean.h](../../../../Game/Source/Character/Components/BodyLean.h) の `BodyLean` クラス |
| メンバー変数 | `accelLeanScale` | 傾きの大きさを調整するため | 物理の傾きに掛ける倍率（`0.12`） | ゲームの [BodyLean.h](../../../../Game/Source/Character/Components/BodyLean.h) の `BodyLeanSettings` |
| 変数 | `maxPitch` | 傾きの上限を持つため | 傾きの上限（ラジアン）。`maxAccelLeanDeg`（8°）を直したもの。この抜き出しの前で求めている | ゲームの [BodyLean.cpp](../../../../Game/Source/Character/Components/BodyLean.cpp) の `Update()` の中 |
| マクロ | `max`・`min` | 値を、上限と下限の間に収めるため | 大きい方・小さい方を返す。`std::max` ではなく、`windows.h` のマクロ | Windows の API（`<windows.h>`） |
| メンバー変数 | `m_pitch` | 今の前後の傾きを持つため | 今の前後の傾き（ラジアン）。毎フレーム目標へ近づける | ゲームの [BodyLean.h](../../../../Game/Source/Character/Components/BodyLean.h) の `BodyLean` クラス |
| 関数 | `SmoothRate()` | 目標への近づき方を、FPS によらず同じにするため | `time` 秒くらいで近づく割合（0〜1）を返す。`time` が 0 以下なら 1（すぐ近づく） | ゲームの [BodyLean.cpp](../../../../Game/Source/Character/Components/BodyLean.cpp)（名前のない `namespace` の中） |
| メンバー変数 | `leanSmoothSeconds` | 傾きが追いつく時間を調整するため | 傾きが目標に追いつく時間（秒、`0.1`） | ゲームの [BodyLean.h](../../../../Game/Source/Character/Components/BodyLean.h) の `BodyLeanSettings` |
| 変数 | `pitchRotation` | 前後の傾きを、回転にするため | X 軸まわりに `m_pitch` だけ回した `Quaternion` | ゲームの [BodyLean.cpp](../../../../Game/Source/Character/Components/BodyLean.cpp) の `Update()` の中 |

**用語:**

| 用語 | 何のことか |
|---|---|
| ピッチ | 体が前後にうなずくように傾く回転（X 軸まわり）。ここでは、前へ傾くと正 |

`SmoothRate(deltaTime, time)` は `1 - exp(-deltaTime / time)`。FPS が変わっても、同じ時間で同じだけ近づく。

## 3. 使い方

| やりたいこと | 書き方 |
|---|---|
| 傾きの量を変える | player.json の `lean` |
| ほかのキャラクターにも傾けさせる | そのキャラクターの `MakeConfig` で `config.lean.isEnabled = true` にする |

---

## 4. 調整用の数値（player.json の `lean`）

| 名前 | 値 | 意味 |
|---|---|---|
| `enabled` | true | 使うか |
| `accelLeanScale` | 0.12 | 物理の傾き（加速と重力の釣り合い）の何倍にするか |
| `maxAccelLeanDeg` | 8° | 傾きの上限 |
| `velocitySmoothSeconds` | 0.15秒 | 速さをならす時間 |
| `leanSmoothSeconds` | 0.1秒 | 傾きが目標に追いつく時間 |

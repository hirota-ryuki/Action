Player と Enemy で共通に使う、ステートの基底クラス `State` とステートマシン `StateMachine` を、テンプレートで作るまでの手順です。それぞれのステートは [敵のステートの手順](../敵/敵のステートの手順.md)・[プレイヤーのステートの手順](../プレイヤー/プレイヤーのステートの手順.md) で作ります。

**出来上がるもの:** ステートの種類（`Id`）と、ステートが触ってよいもの（`Context`）を決めれば、どのキャラクターでも同じ手順でステートを切り替えられる仕組みができます。行動できない（凍結中など）ときは、今のステートによらず `Frozen` へ移します。

**前提:**

- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [状態異常の手順](状態異常の手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../README.md#ゲームを作る順番)）。
- 作業を始める前に、main からブランチを切る。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | ステートの基底クラス `State` | ビルドが通る |
| 2 | ステートマシン `StateMachine` | ビルドが通る |

```cpp
#pragma once

struct CharacterInput;

// ステートの基底クラス（Player・Enemy で共通）。Id と Context はキャラクターごとに決める。
//   Id: ステートの種類の enum class
//   Context: ステートが触ってよいもの（移動・モデルなど）。ステートは持ち主のクラスを直接は知らない。
// StateMachine が毎フレーム次の順に呼ぶ。
//   1. CheckTransition: 次にどのステートへ移るかを決める
//   2. 移るなら、今のステートの Exit → 次のステートの Enter
//   3. Update: そのステートの動き
// ステートは自分の中だけで動き方と遷移を決める。ほかのステートの中身は知らない。
// ステートは最初に1つずつ作って使い回すので、中のデータは Enter で必ず初期化する。
template <class Id, class Context>
class State
{
public:
	virtual ~State() = default;

	virtual Id GetId() const = 0;
	// デバッグ表示用の名前。
	virtual const char* GetName() const = 0;

	// このステートに入ったとき。アニメーションの切り替えなど。
	virtual void Enter(Context& context, const CharacterInput& input)
	{
	}
	// 次のステートを返す。移らないなら GetId() を返す。
	// 凍結（行動できない）への遷移は、どのステートからでも StateMachine が行うので、ここでは見なくてよい。
	virtual Id CheckTransition(const Context& context, const CharacterInput& input) const = 0;
	// 1フレームの動き。CharacterMover の Move 系（Update を含む）の関数を1回だけ呼ぶこと（重力はそこでかかる）。
	virtual void Update(Context& context, const CharacterInput& input, float deltaTime) = 0;
	// このステートから出るとき。
	virtual void Exit(Context& context)
	{
	}
};
```

- **毎フレーム、遷移を決めてから動く。** `CheckTransition()` で次のステートを決め、移るなら今のステートの `Exit()` → 次の `Enter()`、そのあと `Update()` です。
- **ステートは最初に1つずつ作って使い回す。** 中のデータは `Enter()` で必ず初期化します。

**確かめ方:** ソリューションのビルドが通る。

```cpp
#pragma once

#include "State.h"
#include "CharacterInput.h"
#include "StatusEffects.h"

// ステートを持ち、毎フレーム遷移と更新を行う（Player・Enemy で共通）。
// 行動できない（凍結中など）ときは、今のステートによらず Frozen へ移す。
//   Id: ステートの種類の enum class。Frozen（行動できないとき）と Num（種類の数）を持つこと。
//   Context: ステートが触ってよいもの。statusEffects（const StatusEffects*）と previousId（Id）を持つこと。
// 派生クラスはコンストラクタで、Id の全部のステートを Register<ステートのクラス>() で登録する。
template <class Id, class Context>
class StateMachine
{
public:
	using StateType = State<Id, Context>;

	virtual ~StateMachine() = default;

	// context の部品は初期化済みのものを渡す。firstId から始める（行動できないときは Frozen）。
	void Init(const Context& context, Id firstId)
	{
		for (const auto& state : m_states) {
			K2_ASSERT(state != nullptr, "登録していないステートがあります。派生クラスのコンストラクタで Register してください。");
		}
		m_context = context;
		m_firstId = firstId;
		m_current = nullptr;
		Reset();
	}

	// 遷移を決めてから動く。押したフレームに動き始め、1フレームに移るのは1回だけ。
	void Update(const CharacterInput& input, float deltaTime)
	{
		if (m_current == nullptr) {
			return;
		}
		OnBeforeUpdate(m_context, input);
		const Id next = CanAct() ? m_current->CheckTransition(m_context, input) : Id::Frozen;
		if (next != m_current->GetId()) {
			ChangeState(next, input);
		}
		m_current->Update(m_context, input, deltaTime);
	}

	// 最初のステートに戻す（リスポーン時など）。行動できないときは Frozen にする。
	void Reset()
	{
		ChangeState(CanAct() ? m_firstId : Id::Frozen, CharacterInput());
	}

	Id GetCurrentId() const
	{
		return m_current != nullptr ? m_current->GetId() : m_firstId;
	}
	// デバッグ表示用。
	const char* GetCurrentName() const
	{
		return m_current != nullptr ? m_current->GetName() : "None";
	}

protected:
	// ステートを登録する。番号はステート自身の GetId() から取る（番号と中身を取り違えないように）。
	template <class T>
	void Register()
	{
		auto state = std::make_unique<T>();
		const int index = static_cast<int>(state->GetId());
		K2_ASSERT(m_states[index] == nullptr, "同じ番号のステートを2回登録しています。");
		m_states[index] = std::move(state);
	}

	// 遷移を決める前に毎フレーム呼ばれる。キャラクターだけの前処理を書く。
	virtual void OnBeforeUpdate(Context& context, const CharacterInput& input)
	{
	}

private:
	void ChangeState(Id next, const CharacterInput& input)
	{
		if (m_current != nullptr) {
			m_current->Exit(m_context);
			m_context.previousId = m_current->GetId();
		}
		m_current = m_states[static_cast<int>(next)].get();
		m_current->Enter(m_context, input);
	}

	bool CanAct() const
	{
		return m_context.statusEffects == nullptr || m_context.statusEffects->CanAct();
	}

	Context m_context;
	// ステートは最初に全部作り、番号で引く。切り替えのたびに new しない。
	std::unique_ptr<StateType> m_states[static_cast<int>(Id::Num)];
	StateType* m_current = nullptr;
	Id m_firstId = Id::Frozen;
};
```

- **`Id` は `Frozen` と `Num` を持つ決まり。** `Num` でステートの数を知り、配列で全部のステートを持ちます。切り替えのたびに `new` しません。
- **`Context` は `statusEffects` と `previousId` を持つ決まり。** 行動できるかを `statusEffects` で見て、移る前のステートを `previousId` に入れます。
- **登録はステート自身の `GetId()` の番号に入れる（`Register<T>()`）。** 番号と中身を取り違えないためです。全部登録していなければ、`Init()` で止まります（`K2_ASSERT`）。

**確かめ方（これで出来上がり）:** ソリューションのビルドが通る（テンプレートなので、使う手順で初めて中身がコンパイルされる）。

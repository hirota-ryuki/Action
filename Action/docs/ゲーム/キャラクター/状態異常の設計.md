キャラクターにかかる状態異常（凍結・燃焼）をまとめたページです。

---

## 1. StatusEffects

コード: [StatusEffects.h](../../../Game/Source/Character/Components/StatusEffects.h)、[StatusEffects.cpp](../../../Game/Source/Character/Components/StatusEffects.cpp)

キャラクターがメンバーとして持つ部品です。Player も Enemy も持っているので、**どちらも凍るし、燃える**。

| 関数 | 内容 |
|---|---|
| `Init(modelRender)` | 見た目を変えるモデル。nullptr なら見た目は変えない |
| `Update(deltaTime)` | 残り時間を進め、色を変える |
| `Freeze(seconds)` | 凍らせる。凍結中にもう一度呼ぶと、残り時間の長い方で上書きする |
| `Burn(seconds)` | 燃やす。燃焼中にもう一度呼ぶと、残り時間の長い方で上書きする |
| `IsFrozen()` / `IsBurning()` | 今その状態か |
| `CanAct()` | 移動・攻撃などの行動ができるか（今は「凍っていない」こと） |

外には `CanAct()` だけを伝え、移動を止めるのは持ち主の側で行います。
- Player: 行動できなくなると `PlayerFrozenState` になる（[プレイヤーのステートの設計](../プレイヤー/プレイヤーのステートの設計.md)）
- Enemy: 空の入力を `CharacterMover` に渡す
- 魔法: `CanAct()` が false の間、Character は魔法を撃たず、`MagicCaster::CancelAll()` で溜めている魔法を消す

## 2. 凍結

| タイミング | 見た目 |
|---|---|
| 凍った瞬間 | モデルを水色にし、アニメーションを止める（その瞬間のポーズで固まる） |
| 解ける直前（0.4秒） | 元の色へなめらかに戻す |
| 解けた | アニメーションを動かす |

凍結時間は、かけた側（[氷魔法](../魔法/氷魔法の設計.md)では2.5秒）が決めます。

## 3. 燃焼

| タイミング | 見た目 |
|---|---|
| 燃えている間 | モデルを赤〜橙にし、色の強さを揺らして炎が当たっているように見せる |
| 消える直前（0.4秒） | 元の色へなめらかに戻す |

燃焼は行動を止めません。体力ができたら、継続ダメージにつなげる想定です。
燃焼をかけるのは、[炎魔法](../魔法/炎魔法の設計.md)の炎魔法発射後の燃える床（`BurningGround`）です。

## 4. 凍結と燃焼は打ち消し合う

- 凍っているときに燃やすと、**解凍される**（そのあと燃える）
- 燃えているときに凍らせると、**火が消える**（そのあと凍る）

## 5. 実装方法

### 状態は「残り秒数」1つで表す

```cpp
float m_freezeTimer = 0.0f;  // 0より大きい間は凍結中
float m_burnTimer = 0.0f;    // 0より大きい間は燃焼中
float m_burnElapsed = 0.0f;  // 燃え始めてからの秒数（揺らめき用）

bool IsFrozen() const { return m_freezeTimer > 0.0f; }
bool CanAct() const { return !IsFrozen(); }
```

状態のフラグや enum は持ちません。`Update()` で秒数を減らし、0 以下になったら解けます。
かけ直したときは、残りの長い方を残します（`if (seconds <= m_freezeTimer) return;`）。

### 見た目は「乗算色」と「加算色」を、通常の色から補間する

```cpp
void StatusEffects::SetLook(float rate, const Vector4& mulColor, const Vector4& addColor)
{
    // rate = 0 で通常の色、1 で状態異常の色
    m_modelRender->SetMulColor(LerpColor(rate, NORMAL_MUL_COLOR, mulColor));
    m_modelRender->SetAddColor(LerpColor(rate, NORMAL_ADD_COLOR, addColor));
}
```

| 状態 | rate の決め方 |
|---|---|
| 凍結 | ふだんは 1。残りが 0.4 秒を切ったら `残り / 0.4`（1→0）で元の色へ戻す |
| 燃焼 | `揺らめき × 消え際`。揺らめきは `1 - 0.3 × (0.5 + 0.5 × sin(経過秒 × 14))`、消え際は凍結と同じ |

凍結は、乗算で赤を落として青を上げ、さらに水色を足しています。暗い部分（髪・服）も水色に見えるようにするためです。

### アニメーションは凍った瞬間に止め、解けたときに戻す

```cpp
void StatusEffects::Freeze(float seconds)
{
    if (seconds <= m_freezeTimer) { return; }
    m_burnTimer = 0.0f;                               // 凍らせると火が消える
    if (!IsFrozen()) { m_modelRender->SetAnimationSpeed(0.0f); }  // 凍った瞬間のポーズで固める
    SetLook(1.0f, FROZEN_MUL_COLOR, FROZEN_ADD_COLOR);
    m_freezeTimer = seconds;
}

void StatusEffects::Burn(float seconds)
{
    if (IsFrozen()) { Unfreeze(); }                   // 燃やすと解凍される（速さを1に戻す）
    ...
}
```

打ち消し合いは、かける関数の中で相手の秒数を 0 にするだけで書いています。

## 6. 使い方

### 新しい状態異常を作る（例: 毒）

`StatusEffects` に、凍結・燃焼と同じ形で足します。

1. 残り時間のメンバーを足す（例: `m_poisonTimer`）。
2. かける関数（`Poison(seconds)`）と、今その状態かを返す関数（`IsPoisoned()`）を足す。
3. `Update()` で残り時間を進め、見た目（色）を変える。
4. 行動を止めるものなら `CanAct()` の条件に含める。Player はそれだけで `PlayerFrozenState` に入る。
5. 弾などからかけるときは、`HitTarget::GetStatusEffects()` で受け取った先に対して呼ぶ。

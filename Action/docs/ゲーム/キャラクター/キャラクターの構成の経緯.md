# キャラクターの構成の経緯

設計: [キャラクターの構成](キャラクターの構成.md)

何をして、なぜ今の形になったかの記録です。日付ごとに書き足します。

---

## 2026-11-05 部品の組み合わせにした

共通の処理を部品にして、Player と Enemy の両方に持たせる形にした。基底クラスは作らなかった（基底に処理を集めると、種類が増えるたびに大きくなりやすいため）。

## 2026-11-06 モデルの読み込みを部品にした

`CharacterModel` を作り、Player・Enemy の違いをデータ（`CharacterModelDesc`）だけにした（[キャラクターモデルの設計](キャラクターモデルの設計.md)）。

## 2026-11-07 基底クラスを作る方針にした

Player に処理を極力書かず、Actor → Character → Player の継承と部品で組み立てる方針にした（[プレイヤーの構成の設計](../プレイヤー/プレイヤーの構成の設計.md)）。まだ実装していない。

## 2026-11-07 移動を別のページにした

A4 1枚に収めるため、`CharacterMover` を [移動の設計](移動の設計.md) に分けた。

## 2026-11-07 Actor・Character を作り、Player を組み立てだけにした

[プレイヤーの構成の設計](../プレイヤー/プレイヤーの構成の設計.md) の方針どおりに実装した。

- `Actor`（Transform）→ `Character`（共通の部品と順番）→ `Player` / `Enemy` にした。`Player.cpp` は 244行 → 約60行。
- 調整値を `PlayerConfig.cpp` に、剣を `WeaponAttachment`、落下を `FallRespawn`、アニメーションの受け渡しを `PlayerAnimator` に分けた。
- `MagicCaster` は、はじめ Player の部品にする案だったが、Enemy も持つので Character に置いた。
- Player の1フレームで、落下の判定を魔法より前に動かした（前は魔法のあと）。落ちたフレームに撃つ位置が変わるだけで、見た目は変わらない。
- `Status`（HP）を足した。まだダメージで減らしてはいない。

## 2026-11-14 プレイヤーの剣を消した

プレイヤーの右手に小さい剣（`Assets/modelData/weapon/sowrd/sowrd.tkm`）を付けていたが、使っていないので、表示とコードを消した。

- `WeaponAttachment.h`・`WeaponAttachment.cpp` を消した（剣のほかに使っているところはなかった）。
- `Player` から `m_sword` と、剣を動かす・描くだけだった `OnLateUpdate`・`OnRender` を消した（Character の空の既定に戻る）。
- `PlayerConfig::MakeSwordDesc()` と、剣でしか使っていなかった `ReadVector3()`、`player.json` の `"sword"` の段を消した。
- 作業用フォルダ（git worktree）で `Game.sln` を Debug / x64 でビルドし、通ることを確かめた。

あとから、剣のモデル（`Assets/modelData/weapon/sowrd/` の `sowrd.tkm` とテクスチャ）も消した。ほかに読んでいるところはなかった。

## 2026-11-14 一人称の銃を消した

B ボタンで一人称にしたときに手元に出していた青い銃も、使っていないので消した。
- `GameCamera` から、銃のモデル（`m_firstPersonGunRender`）・`InitFirstPersonGun()`・`UpdateFirstPersonGun()`・銃を描くだけだった `Render()`・銃の位置と向きの定数を消した。一人称の切り替えとカメラの動きは変えていない。
- 銃のモデル（`Assets/modelData/weapon/gun/`）を消した。
- 作業用フォルダ（git worktree）で `Game.sln` を Debug / x64 でビルドし、通ることを確かめた。

あわせて、どこからも読んでいなかった弾のモデル（`Assets/modelData/weapon/bullet/`）も消した。これで `weapon/` のフォルダは空になった。

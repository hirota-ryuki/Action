# 陣営と当たり判定の設計

作成日: 2026-11-05（`キャラクター入力・魔法・弾の設計.md` から分割）
対象: `Game/Source/Character/Faction.h`、`Game/Source/Character/Components/HitTarget.*`
手順: [陣営と当たり判定の手順](陣営と当たり判定の手順.md)（何もない状態から、どのファイルに何を足すか）

誰と誰が敵対しているか（陣営）と、魔法などが当たる判定をまとめたページです。

- **当たるかどうかは陣営で決まる**: 魔法・炎魔法発射後の燃える床・AI の狙いは、すべて `IsHostile(a, b)` で判断する。
- **当たり判定は登録制**: キャラクターが `HitTarget` を持つと一覧に載り、魔法は一覧から相手を探す。

---

## 1. Faction：陣営

コード: [Faction.h](../../../Game/Source/Character/Faction.h)

```
Player ─┐                ┌─ Enemy
        ├─ 敵対している ─┤
Ally ───┘                └─

Neutral … 誰とも敵対しない（魔法も当たらない）
```

`IsHostile(a, b)` は、次のすべての判断に使います。
- 魔法が当たるか
- 炎魔法発射後の燃える床（`BurningGround`）が燃やすか
- AIが狙うか

---

## 2. HitTarget / HitTargetRegistry：当たり判定と、その一覧

コード: [HitTarget.h](../../../Game/Source/Character/Components/HitTarget.h)、[HitTarget.cpp](../../../Game/Source/Character/Components/HitTarget.cpp)

```
HitTarget（キャラクターがメンバーとして持つ）
  Init() したとき     → 一覧に登録
  デストラクタ        → 一覧から登録を解除
  持ち主が削除待ち    → 当たらない

HitTargetRegistry（一覧）
  FindHitOnSegment()   魔法の通り道に、敵対する相手がいるか（撃った本人は除く）
  FindNearestHostile() 一番近い敵対する相手（AIの索敵）
  GetTargets()         全件（炎魔法発射後の燃える床の範囲判定、デバッグ表示用）
```

当たったときの効果を受ける窓口は2つあります。

| 窓口 | 用途 |
|---|---|
| `SetStatusEffects()` | 魔法などが状態異常（凍結・燃焼）をかける先（[状態異常の設計](状態異常の設計.md)） |
| `SetOnHit()` | 当たったことを持ち主に知らせる処理（ひるみ・反撃など、今後用） |

---

## 3. 実装方法

### 敵対の判定：「プレイヤー側かどうか」が違えば敵対

```cpp
inline bool IsHostile(Faction a, Faction b)
{
    if (a == Faction::Neutral || b == Faction::Neutral) {
        return false;
    }
    const bool isAFriendly = a == Faction::Player || a == Faction::Ally;
    const bool isBFriendly = b == Faction::Player || b == Faction::Ally;
    return isAFriendly != isBFriendly;
}
```

陣営どうしの表は持たず、「プレイヤー側（Player・Ally）か」の1ビットを比べるだけです。

### 一覧：関数の中の static な配列

```cpp
std::vector<HitTarget*>& HitTargetRegistry::Targets()
{
    static std::vector<HitTarget*> s_targets;   // 最初に呼ばれたときに作られる
    return s_targets;
}
```

ほかの static 変数との初期化の順番に左右されないように、関数の中に置いています。
`HitTarget::Init()` で `push_back`、`HitTarget` のデストラクタで `erase` するので、持ち主が消えれば一覧からも自動で消えます。
持ち主が削除待ち（`IsDead()`）の間は `IsActive()` が false になり、どの検索にもかかりません。

### 魔法の当たり：1フレームの移動を線分にして、球との距離を見る

```cpp
for (HitTarget* target : Targets()) {
    if (!target->IsActive() || target->GetOwner() == ignoreOwner) { continue; }   // 撃った本人は除く
    if (!IsHostile(attackerFaction, target->GetFaction())) { continue; }

    const Vector3 center = target->GetCenter();                       // 足元 + 中心の高さ
    const Vector3 closest = ClosestPointOnSegment(from, to, center);  // 線分上で中心に一番近い点
    const float hitRadius = radius + target->GetRadius();
    if ((center - closest).LengthSq() > hitRadius * hitRadius) { continue; }

    // 複数に当たるときは、線分の始点に一番近い相手を選ぶ
}
```

- 点ではなく線分で調べるので、速い魔法でも相手をすり抜けない。
- `ClosestPointOnSegment` は、中心を線分に投影した位置を 0〜1 に収めて求める。
- 距離は2乗のまま比べて、平方根を使わない。

AI の索敵（`FindNearestHostile`）も同じループで、線分の代わりに自分の位置からの距離を比べています。

## 4. 使い方

### 味方・中立のNPCを作る

```cpp
Enemy* ally = NewGO<Enemy>(1, "ally");
ally->SetFaction(Faction::Ally);     // 敵を狙い、敵の魔法が当たる
```

### 魔法が当たる物を作る（キャラクター以外も同じ）

1. `HitTarget` をメンバーに持つ。
2. `Start()` で `m_hitTarget.Init(this, 陣営, 半径, 足元から中心までの高さ);`（一覧に登録される）。
3. 毎フレーム `m_hitTarget.SetPosition(足元の位置);`。
4. 必要なら、状態異常を受ける先を `SetStatusEffects()`、当たったときの処理を `SetOnHit()` で渡す。

登録の解除はデストラクタで自動に行われます。

### 陣営を足す

[Faction.h](../../../Game/Source/Character/Faction.h) の `Faction` に値を足し、`IsHostile()` に誰と敵対するかを書きます。魔法・炎魔法発射後の燃える床・AI はすべて `IsHostile()` を見ているので、ほかは変えなくて済みます。

## 5. 調整用の数値

当たり判定は「魔法の半径 + 相手の半径」の球で判定します。

| | 半径 | 足元からの中心の高さ | 場所 |
|---|---|---|---|
| Player | 45 | 70 | `Assets/data/player.json` の `hit` |
| Enemy | 45 | 60 | `Enemy.cpp` |
| 氷魔法 | 10 | - | `IceMagic.cpp` |
| 炎魔法 | 14〜45（溜め具合による） | - | `FireMagic.cpp` |

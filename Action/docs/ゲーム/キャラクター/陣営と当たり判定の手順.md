# 陣営と当たり判定の手順

設計: [陣営と当たり判定の設計](陣営と当たり判定の設計.md)
経緯: [キャラクターの構成の経緯](キャラクターの構成の経緯.md)

キャラクターの陣営（Player・味方・中立・敵）と、弾などに当ててもらうための当たり判定（`HitTarget`）を作り、キャラクターに持たせるまでの手順です。

**出来上がるもの:** Player は陣営 Player、Enemy は陣営 Enemy で作られ、それぞれの当たり判定が一覧（`HitTargetRegistry`）に登録されます。魔法や AI は、この一覧から相手を探せるようになります（[魔法の手順](../魔法/魔法の手順.md)・[NPCのAIの手順](NPCのAIの手順.md)）。

**前提:**

- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [キャラクターの構成の手順](キャラクターの構成の手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../README.md#ゲームを作る順番)）。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 陣営と、敵対しているかの判定 | ビルドが通る |
| 2 | 当たり判定 `HitTarget` と、その一覧 `HitTargetRegistry` | ビルドが通る |
| 3 | キャラクターに陣営と当たり判定を持たせる | 起動して落ちない |

**読み方:**

- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

	// 線分 from→to 上で point に最も近い点を返す。
	Vector3 ClosestPointOnSegment(const Vector3& from, const Vector3& to, const Vector3& point)
	{
		Vector3 segment = to - from;

HitTarget* HitTargetRegistry::FindHitOnSegment(
	const Vector3& from, const Vector3& to, float radius,
	Faction attackerFaction, const IGameObject* ignoreOwner,
	Vector3& hitPosition)
{
	HitTarget* hitTarget = nullptr;
	// 複数に当たる場合は、線分の始点に一番近い相手を選ぶ。
	float nearestFromDistanceSq = FLT_MAX;
	for (HitTarget* target : Targets()) {
		if (!target->IsActive() || target->GetOwner() == ignoreOwner) {
			continue;
		}
		if (!IsHostile(attackerFaction, target->GetFaction())) {
			continue;
		}
		const Vector3 center = target->GetCenter();
		const Vector3 closest = ClosestPointOnSegment(from, to, center);
		const float hitRadius = radius + target->GetRadius();
		if ((center - closest).LengthSq() > hitRadius * hitRadius) {
			continue;

		const float fromDistanceSq = (closest - from).LengthSq();
		if (fromDistanceSq < nearestFromDistanceSq) {
			nearestFromDistanceSq = fromDistanceSq;
			hitTarget = target;
			hitPosition = closest;
		}
	}
	return hitTarget;

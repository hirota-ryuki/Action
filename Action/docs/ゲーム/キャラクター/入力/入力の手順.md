# 入力の手順

設計: [入力の設計](入力の設計.md)
経緯: [入力の経緯](入力の経緯.md)

キャラクターが受け取る入力の形（`CharacterInput`）と、入力元（`IInputSource`）を作り、Player をパッド・キーボード・マウスで操作できる形にするまでの手順です。キャラクターは入力を受け取るだけで、パッドやカメラ、AI のことは知りません。

**出来上がるもの:** Player は毎フレーム、パッド・キーボード・マウスの入力を `CharacterInput` として受け取ります。Enemy は、まだ何も入力しない入力元を使います（[NPCのAIの手順](../NPCのAI/NPCのAIの手順.md) で AI に替えます）。まだ動く部分がないので、見た目は変わりません。

**前提:**

- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [陣営と当たり判定の手順](../陣営と当たり判定/陣営と当たり判定の手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../../README.md#ゲームを作る順番)）。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 入力の形と、入力元のインターフェース | ビルドが通る |
| 2 | Player 用の入力元 `PlayerInputSource` | ビルドが通る |
| 3 | キャラクターに入力元を持たせる | 起動して落ちない |

**読み方:**

- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- コードの下に、3つを置きます。
  - 「行・何をしているか」の表: 1行ずつの動き。
  - 「なぜ」「効果」: その小手順でそう書く理由と、書くと何ができるようになるか。
  - 「初めて出てくる名前」の表: このページで初めて出てくる変数・引数・関数・型・値・C++ の書き方を、コードに出てくる順に並べます。2回目からは載せないので、わからない名前はページ内検索（`Ctrl+F`）で最初に出てきた所を探してください。「どこから来たもの」で、このゲームで作ったもの・エンジン（k2Engine）の機能・Windows の API・C++ の書き方のどれかがわかります。
- [前提知識](../../../前提知識.md) で「よく知っている」にあるもの（クラス・継承・`virtual`・`override`・`= 0`・`= default`・`protected`・`Vector3`・`g_pad`・`IsPress`・`IsTrigger`・`enButtonA` など・`g_camera3D`・前方宣言・三項演算子・`nullptr` など）は、表に載せません。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

# 移動の手順

作成日: 2026-11-08
設計: [移動の設計](移動の設計.md)
確かめた記録: [ゲームの手順書の経緯](../土台/ゲームの手順書の経緯.md)

キャラコン（`CharacterController`）を包んで、移動・ジャンプ・重力・向きを受け持つ部品 `CharacterMover` を作り、キャラクターに持たせるまでの手順です。

**出来上がるもの:** Player がスティック（WASD）で歩き、左Shift で走り、スペースで跳びます。重力で落ち、ステージの上に立ちます。Enemy も入力どおりに動きます（AI の設定で、今は止まっています）。まだモデルがないので、動きは見えません（[キャラクターモデルの手順](キャラクターモデルの手順.md) で見えるようになる）。

**前提:**

- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [NPCのAIの手順](NPCのAIの手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../README.md#ゲームを作る順番)）。
- 作業を始める前に、main からブランチを切る。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 移動の部品 `CharacterMover` | ビルドが通る |
| 2 | キャラクターに持たせ、入力どおりに動かす | 起動して落ちない |

<!-- new: ../../../Game/Source/Character/Components/CharacterMover.h -->

```cpp
#pragma once

struct CharacterInput;

// キャラクターの移動の設定。
struct CharacterMoveSettings
{
	float walkSpeed = 300.0f;
	float runSpeedMultiplier = 1.0f;  // 走る入力中の速度倍率。1なら走れない。
	float jumpSpeed = 0.0f;           // 0ならジャンプできない。
	float gravity = 980.0f;
	float capsuleRadius = 20.0f;
	float capsuleHeight = 100.0f;
};

// CharacterController を包み、移動・ジャンプ・重力・向きを処理する。
// パッドやカメラは触らない。
// 使い方は2通りある。
// ・Update(input): 入力どおりに歩く・走る・跳ぶ。状態を持たないキャラクター（Enemy）向け。
// ・Move() / MoveByInput() / Jump() / FaceTo(): 1つずつの操作。ステートで動きを変えるキャラクター（Player）向け。
// どちらも、1フレームに1回だけ Move() 系を呼ぶこと（重力はそこでかかる）。
class CharacterMover
{
public:
	// SetPosition() で決めた位置にカプセルを作る。
	void Init(const CharacterMoveSettings& settings);
	// 入力どおりに動く。走る入力なら runSpeedMultiplier 倍、ジャンプボタンで跳ぶ。
	void Update(const CharacterInput& input, float deltaTime);

	// 水平方向の速度で1フレーム動かす。重力もかける。向きは変えない。
	void Move(const Vector3& horizontalVelocity, float deltaTime);
	// 入力の移動方向に speed の速さで1フレーム動かし、入力の向きたい方向（なければ移動方向）を向く。
	void MoveByInput(const CharacterInput& input, float speed, float deltaTime);
	// 地面にいれば、speed の初速で跳ぶ。跳べたら true。
	bool Jump(float speed);
	// 水平方向の向きを変える。ゼロに近い方向は無視する。
	void FaceTo(const Vector3& direction);
	// 速度を打ち消して止める（リスポーン時など）。
	void Stop();

	// Init() の前に呼んでもよい。
	void SetPosition(const Vector3& position);
	const Vector3& GetPosition() const
	{
		return m_position;
	}
	void SetRotation(const Quaternion& rotation)
	{
		m_rotation = rotation;
	}
	const Quaternion& GetRotation() const
	{
		return m_rotation;
	}
	Vector3 GetForward() const;
	const CharacterMoveSettings& GetSettings() const
	{
		return m_settings;
	}

	bool IsOnGround() const;
	// 水平方向に動いているか。アニメーションの切り替えに使う。
	bool IsMoving() const
	{
		return m_isMoving;
	}

private:
	CharacterMoveSettings m_settings;
	CharacterController m_charaCon;
	Vector3 m_position = Vector3::Zero;
	Vector3 m_moveSpeed = Vector3::Zero;
	Quaternion m_rotation = Quaternion::Identity;
	bool m_isMoving = false;
	bool m_isInitialized = false;
};
```

<!-- new: ../../../Game/Source/Character/Components/CharacterMover.cpp -->

```cpp
#include "stdafx.h"
#include "CharacterMover.h"
#include "CharacterInput.h"

namespace
{
	// 移動入力のデッドゾーン閾値（二乗値）。sqrt を避けるため平方根前の値で比較。
	constexpr float MOVE_DEAD_ZONE_SQ = 0.01f;
}

void CharacterMover::Init(const CharacterMoveSettings& settings)
{
	m_settings = settings;
	m_charaCon.Init(m_settings.capsuleRadius, m_settings.capsuleHeight, m_position);
	m_isInitialized = true;
}

void CharacterMover::SetPosition(const Vector3& position)
{
	m_position = position;
	if (m_isInitialized) {
		m_charaCon.SetPosition(position);
	}
}

Vector3 CharacterMover::GetForward() const
{
	Vector3 forward = Vector3::AxisZ;
	m_rotation.Apply(forward);
	return forward;
}

bool CharacterMover::IsOnGround() const
{
	return m_isInitialized && m_charaCon.IsOnGround();
}

void CharacterMover::Stop()
{
	m_moveSpeed = Vector3::Zero;
	m_isMoving = false;
}

void CharacterMover::Update(const CharacterInput& input, float deltaTime)
{
	const bool canRun = input.isRun && m_settings.runSpeedMultiplier != 1.0f;
	const float speed = canRun ? m_settings.walkSpeed * m_settings.runSpeedMultiplier : m_settings.walkSpeed;
	if (input.jump.isTrigger) {
		Jump(m_settings.jumpSpeed);
	}
	MoveByInput(input, speed, deltaTime);
}

void CharacterMover::MoveByInput(const CharacterInput& input, float speed, float deltaTime)
{
	Vector3 horizontalVelocity = input.moveDirection;
	horizontalVelocity.y = 0.0f;
	horizontalVelocity *= speed;

	// 向きたい方向の指定があればそちらを、なければ移動方向を向く。
	Vector3 lookDirection = input.lookDirection;
	lookDirection.y = 0.0f;
	if (lookDirection.LengthSq() > FLT_EPSILON) {
		FaceTo(lookDirection);
	}
	else if (horizontalVelocity.LengthSq() > MOVE_DEAD_ZONE_SQ) {
		FaceTo(horizontalVelocity);
	}

	Move(horizontalVelocity, deltaTime);
}

void CharacterMover::Move(const Vector3& horizontalVelocity, float deltaTime)
{
	if (!m_isInitialized) {
		return;
	}

	m_moveSpeed.x = horizontalVelocity.x;
	m_moveSpeed.z = horizontalVelocity.z;
	m_moveSpeed.y -= m_settings.gravity * deltaTime;
	m_isMoving = m_moveSpeed.x * m_moveSpeed.x + m_moveSpeed.z * m_moveSpeed.z > MOVE_DEAD_ZONE_SQ;

	m_position = m_charaCon.Execute(m_moveSpeed, deltaTime);

	if (m_charaCon.IsOnGround()) {
		m_moveSpeed.y = 0.0f;
	}
}

bool CharacterMover::Jump(float speed)
{
	if (speed <= 0.0f || !IsOnGround()) {
		return false;
	}
	m_moveSpeed.y = speed;
	return true;
}

void CharacterMover::FaceTo(const Vector3& direction)
{
	Vector3 horizontal = direction;
	horizontal.y = 0.0f;
	if (horizontal.LengthSq() <= FLT_EPSILON) {
		return;
	}
	m_rotation.SetRotationYFromDirectionXZ(horizontal);
}
```

- **使い方は2通り。** `Update(input)` は入力どおりに歩く・走る・跳ぶ（状態を持たないキャラクター向け）。`Move()`・`MoveByInput()`・`Jump()`・`FaceTo()` は1つずつの操作（ステートで動きを変えるキャラクター向け）。
- **1フレームに1回だけ `Move()` 系を呼ぶ。** 重力はそこでかかります。
- **`Init()` の前に `SetPosition()` を呼んでよい。** カプセルは `Init()` のときに、その位置に作ります。

**確かめ方:** ソリューションのビルドが通る。

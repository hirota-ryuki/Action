# 氷魔法の手順

作成日: 2026-11-08
設計: [氷魔法の設計](氷魔法の設計.md)
経緯: [魔法と弾の経緯](魔法と弾の経緯.md)
確かめた記録: [ゲームの手順書の経緯](../土台/ゲームの手順書の経緯.md)

押した瞬間に氷の弾を1発撃ち、当たった相手を凍らせる氷魔法を作るまでの手順です。上から順にやると、[氷魔法の設計](氷魔法の設計.md) の形になります。

**出来上がるもの:** 左クリック（パッドは Y）で氷の弾が飛び、当たった相手が 2.5秒凍ります。Enemy も同じ氷魔法を持ちます（AI が撃つかどうかは [NPCのAIの手順](../キャラクター/NPCのAIの手順.md) の設定による）。

**前提:**

- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [弾の手順](弾の手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../README.md#ゲームを作る順番)）。凍らせるのは [状態異常の手順](../キャラクター/状態異常の手順.md) で作った `StatusEffects::Freeze()`。
- エフェクト `Assets/effect/ice_bullet.efk`・`ice_hit.efk` は、リポジトリにもとからある（変えない）。
- 作業を始める前に、main からブランチを切る。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | エフェクトの番号をまとめる `EffectId` | ビルドが通る |
| 2 | 氷の弾 `IceBullet` | ビルドが通る |
| 3 | 押した瞬間に撃つ `IceMagic` | ビルドが通る |
| 4 | Player と Enemy に氷魔法を持たせる | 撃てて、当たると凍る |

## 手順1: エフェクトの番号をまとめる EffectId を作る

```cpp
#pragma once

// EffectEngine::ResistEffect に登録するエフェクト番号。
// EffectEngine は番号をゲーム全体で共有し、登録済みの番号への再登録を黙って無視するため、

enum class EffectId : int
{
	IceBullet,  // 氷魔法の弾（飛翔中）
	IceHit,     // 氷魔法の着弾
};
```

<!-- new: ../../../Game/Source/Magic/IceBullet.h -->

```cpp
#pragma once

#include "BulletBase.h"

// 氷魔法の弾。当たった相手を一定時間凍らせる。
// 着弾後も軌跡と着弾エフェクトが消え切るまで残る。
class IceBullet : public BulletBase
{
public:
	IceBullet();
	~IceBullet() override;

protected:
	bool OnStart() override;
	void OnMove() override;
	void OnHitTarget(HitTarget& target, const Vector3& hitPosition) override;
	void OnExplode(const Vector3& hitPosition) override;
	bool IsVanishFinished() const override;

private:
	Effect m_bulletEffect;
	Effect m_hitEffect;
	bool m_isEffectReady = false;  // エフェクトを読み込めたか。
};
```

`IceBullet.cpp` に次を書きます。

<!-- new: ../../../Game/Source/Magic/IceBullet.cpp -->

```cpp
#include "stdafx.h"
#include "IceBullet.h"
#include "EffectId.h"
#include "HitTarget.h"
#include "StatusEffects.h"

namespace
{
	// エフェクトは Effekseer 用に自作したもの(Assets/effect/ice_*.efkproj が編集元)。
	// テクスチャは Effekseer サンプル(01_NextSoft01, CC-0)のものを使用。
	constexpr int BULLET_EFFECT_ID = static_cast<int>(EffectId::IceBullet);
	constexpr int HIT_EFFECT_ID = static_cast<int>(EffectId::IceHit);
	constexpr const char16_t* BULLET_EFFECT_PATH = u"Assets/effect/ice_bullet.efk";
	constexpr const char16_t* HIT_EFFECT_PATH = u"Assets/effect/ice_hit.efk";

	const Vector3 EFFECT_SCALE = { 10.0f, 10.0f, 10.0f };  // Effekseerの1単位をワールド10単位に拡大。
	constexpr float FREEZE_SECONDS = 2.5f;                  // 命中した相手を凍らせる時間。

	BulletSettings MakeSettings()
	{
		BulletSettings settings;
		settings.speed = 1500.0f;
		settings.range = 2000.0f;
		settings.radius = 10.0f;
		return settings;
	}
}

IceBullet::IceBullet()
	: BulletBase(MakeSettings())
{
}

IceBullet::~IceBullet()
{
	// Effect のデストラクタは再生を止めないため、ここで明示的に止める。
	// 通常は両方とも再生が終わってから削除されるので何も起きない。
	if (!m_isEffectReady || EffectEngine::GetInstance() == nullptr) {
		return;
	}
	m_bulletEffect.Stop();
	m_hitEffect.Stop();
}

bool IceBullet::OnStart()
{
	EffectEngine* effectEngine = EffectEngine::GetInstance();
	if (effectEngine == nullptr) {
		K2_ASSERT(false, "EffectEngine が未生成のため氷魔法のエフェクトを再生できません。");
		return false;
	}

	// 登録済みの番号は内部で無視されるので、弾を何発撃っても読み込みは1回だけ。
	effectEngine->ResistEffect(BULLET_EFFECT_ID, BULLET_EFFECT_PATH);
	effectEngine->ResistEffect(HIT_EFFECT_ID, HIT_EFFECT_PATH);
	if (effectEngine->LoadEffect(BULLET_EFFECT_ID) == nullptr || effectEngine->LoadEffect(HIT_EFFECT_ID) == nullptr) {
		K2_ASSERT(false, "氷魔法のエフェクト(Assets/effect/ice_bullet.efk, ice_hit.efk)の読み込みに失敗しました。");
		return false;
	}

	m_bulletEffect.Init(BULLET_EFFECT_ID);
	m_hitEffect.Init(HIT_EFFECT_ID);
	m_isEffectReady = true;

	// 新しいハンドルには行列が設定されていないので、再生直後に OnMove() で必ず設定される。
	m_bulletEffect.Play();
	return true;
}

void IceBullet::OnMove()
{
	m_bulletEffect.SetPosition(GetPosition());
	m_bulletEffect.SetRotation(GetRotation());
	m_bulletEffect.SetScale(EFFECT_SCALE);
	// 全体ではなくルートだけを動かし、軌跡のパーティクルを発生した場所に残す。
	m_bulletEffect.UpdateRoot();
}

void IceBullet::OnHitTarget(HitTarget& target, const Vector3& hitPosition)
{
	(void)hitPosition;
	if (StatusEffects* statusEffects = target.GetStatusEffects()) {
		statusEffects->Freeze(FREEZE_SECONDS);
	}
}

void IceBullet::OnExplode(const Vector3& hitPosition)
{
	// 弾本体は即座に消し、軌跡のパーティクルは寿命まで残す。
	m_bulletEffect.StopRoot();

	m_hitEffect.Play();
	m_hitEffect.SetPosition(hitPosition);
	m_hitEffect.SetRotation(GetRotation());
	m_hitEffect.SetScale(EFFECT_SCALE);
	m_hitEffect.Update();
}

bool IceBullet::IsVanishFinished() const
{
	// 軌跡のパーティクルと着弾エフェクトが両方消え切ったら終わり。
	return !m_bulletEffect.IsPlay() && !m_hitEffect.IsPlay();
}
```

- **飛んでいる間はルートだけを動かす（`UpdateRoot()`）。** 軌跡のパーティクルが、発生した場所に残ります。
- **着弾したら、弾本体だけを止める（`StopRoot()`）。** 軌跡は寿命まで残り、`IsVanishFinished()` で両方消え切ったら、基底クラスが弾を消します。
- **Effect のデストラクターは再生を止めない**ので、デストラクターで `Stop()` します。

**確かめ方:** ソリューションのビルドが通る。

```cpp
// 氷魔法。発射ボタンを押した瞬間に、当たった相手を凍らせる氷の弾（IceBullet）を1発撃つ。
```

<!-- new: ../../../Game/Source/Magic/IceMagic.cpp -->

```cpp
#include "stdafx.h"
#include "IceMagic.h"
#include "IceBullet.h"

IceMagic::IceMagic(float cooldown)
	: m_cooldownSeconds(cooldown)
{
}

void IceMagic::OnPress(const MagicCastContext& context)
{
	if (!IsReady()) {
		return;
	}
	IceBullet* bullet = NewGO<IceBullet>(1, BulletBase::OBJECT_NAME);
	bullet->Init(context.origin, context.direction, context.caster, context.faction);
	StartCooldown(m_cooldownSeconds);
}
```

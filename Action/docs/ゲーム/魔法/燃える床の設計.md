# 燃える床の設計

作成日: 2026-11-07（[炎魔法の設計](炎魔法の設計.md) から分けた）
対象: [BurningGround.h](../../../Game/Source/Magic/BurningGround.h)、[BurningGround.cpp](../../../Game/Source/Magic/BurningGround.cpp)

炎魔法が着弾したところの床がしばらく燃え、そこに入った敵を燃焼状態にするしくみです。

- **弾とは別のゲームオブジェクト。** 弾が消えたあとも残る。
- **相手はクラスでなく陣営で選ぶ。** 撃った本人と陣営を受け取る。

---

## 1. 燃やす相手

次の相手を毎フレーム燃やす（`StatusEffects::Burn`）。
- 撃った本人ではない
- 敵対している（[陣営と当たり判定の設計](../キャラクター/陣営と当たり判定の設計.md)）
- 足元が範囲の円の中にある（相手の半径の半分まで含める）
- 足元の高さが、床から下50〜上150の間にある（ジャンプで飛び越えられる）

範囲から出ても、燃焼は1.5秒続く。燃焼の見た目は [状態異常の設計](../キャラクター/状態異常の設計.md)。

---

## 2. 実装方法

### 燃え広がり：最初に速く、だんだんゆっくり（ease-out）

```cpp
float BurningGround::GetCurrentRadius() const
{
    if (m_elapsed >= SPREAD_SECONDS) { return m_radius; }
    const float t = m_elapsed / SPREAD_SECONDS;
    const float easeOut = 1.0f - (1.0f - t) * (1.0f - t);
    return m_radius * (SPREAD_START_RATE + (1.0f - SPREAD_START_RATE) * easeOut);   // 10% → 100%
}
```

広がっている間は、エフェクトの大きさも毎フレーム合わせます（エフェクトは半径10の円なので `半径 / 10` 倍）。

### 範囲の判定：高さの帯と、水平な円

```cpp
for (HitTarget* target : HitTargetRegistry::GetTargets()) {
    // 撃った本人・敵対していない相手・状態異常を受けない相手は飛ばす
    const float height = foot.y - m_position.y;
    if (height < -BURN_DEPTH || height > BURN_HEIGHT) { continue; }   // 床の下50〜上150
    const float range = GetCurrentRadius() + target->GetRadius() * TARGET_RADIUS_RATE;
    if (dx * dx + dz * dz > range * range) { continue; }               // XZ の円
    statusEffects->Burn(BURN_SECONDS);
}
```

燃えている時間が過ぎたら、炎の発生だけを止め（`StopRoot`）、出ている炎が消えるのを待ってから自分を削除します（Burning → Vanishing の2状態）。

## 3. 使い方（着弾後に残る効果を作る）

1. 弾とは別のゲームオブジェクトを作り、弾の `OnExplode` で `NewGO` する。撃った本人と陣営を渡す。
2. 相手を探すときは `HitTargetRegistry::GetTargets()` を使い、`IsHostile()` で敵対しているかを見る。
3. 名前を決めて（`BurningGround::OBJECT_NAME` のように）、[Game.cpp](../../../Game/Source/Core/Game.cpp) のデストラクタでその名前のものを削除する。
4. エフェクトを使うなら、[EffectId.h](../../../Game/Source/Core/EffectId.h) に番号を足す。

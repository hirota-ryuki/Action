# 炎魔法の手順

作成日: 2026-11-08
設計: [炎魔法の設計](炎魔法の設計.md)
経緯: [魔法と弾の経緯](魔法と弾の経緯.md)
確かめた記録: [ゲームの手順書の経緯](../土台/ゲームの手順書の経緯.md)

右クリックで溜めて撃つ炎魔法を作るまでの手順です。ステージに置いて燃やし続ける炎（`FireEffect`）も、ここで作ります。上から順にやると、[炎魔法の設計](炎魔法の設計.md) の形のうち、燃える床（[燃える床の手順](燃える床の手順.md)）を除いた部分ができます。

**出来上がるもの:** ステージの1か所で炎が燃え続けます。右クリック（パッドは右トリガー）を押している間に火の玉が溜まり、離すと炎の弾が飛びます。長く溜めるほど弾が大きくなります。

**前提:**

- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [氷魔法の手順](氷魔法の手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../README.md#ゲームを作る順番)）。そこで作った `EffectId` に番号を足す。
- エフェクト `Assets/effect/fire.efk`・`fire_bullet.efk`・`fire_charge.efk`・`fire_charged.efk`・`fire_hit.efk` は、リポジトリにもとからある（変えない）。
- 作業を始める前に、main からブランチを切る。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | ステージで燃え続ける炎 `FireEffect` | 炎が途切れずに燃える |
| 2 | 炎の弾 `FireBullet` | ビルドが通る |
| 3 | 溜めて撃つ `FireMagic` を、Player のサブの魔法にする | 右クリックで溜めて撃てる |

### 1-3. FireEffect.h・FireEffect.cpp を書く

<!-- new: ../../../Game/Source/Objects/FireEffect.h -->

```cpp
#pragma once

// 炎エフェクトを指定位置で燃やし続けるクラス。
// 元エフェクトはループしないため、2つの再生枠を交互に使い、
// 前の再生が消え切る前に次の再生を重ねて途切れないようにする。
class FireEffect : public IGameObject
{
public:
	FireEffect();
	~FireEffect();
	bool Start();
	void Update();

	void SetPosition(const Vector3& position)
	{
		m_position = position;
		m_isTransformDirty = true;
	}

	void SetScale(const Vector3& scale)
	{
		m_scale = scale;
		m_isTransformDirty = true;
	}

private:
	void PlayNext();
	void ApplyTransform(Effect& effect);

	static constexpr int SLOT_COUNT = 2;

	Vector3 m_position = Vector3::Zero;
	Vector3 m_scale = Vector3::One;
	Effect m_effects[SLOT_COUNT];
	int m_nextSlot = 0;
	int m_replayIntervalFrames = 0;   // 次の再生を重ねるまでのフレーム数。0以下なら重ねない（元エフェクトが無限ループ）。
	float m_framesSinceLastPlay = 0.0f;  // 前の再生からの経過時間（エフェクトのフレーム数）。
	bool m_isValid = false;           // エフェクトを読み込めたか。
	bool m_isTransformDirty = false;
};
```

<!-- new: ../../../Game/Source/Objects/FireEffect.cpp -->

```cpp
#include "stdafx.h"
#include "FireEffect.h"
#include "EffectId.h"

namespace
{
	constexpr int FIRE_EFFECT_ID = static_cast<int>(EffectId::Fire);
	constexpr const char16_t* FIRE_EFFECT_PATH = u"Assets/effect/fire.efk";  // Effekseer サンプル(01_Pierre01/Flame, CC-0)を書き出したもの。
	// エフェクトの長さがこれ以上なら無限ループとみなし、再生を重ねない（Effekseer は無限を INT_MAX 付近で表す）。
	constexpr int INFINITE_TERM_THRESHOLD = 60 * 60 * 60;
}

FireEffect::FireEffect()
{

}

FireEffect::~FireEffect()
{
	// Effect のデストラクタは再生を止めないため、ここで明示的に止める。
	if (!m_isValid || EffectEngine::GetInstance() == nullptr) {
		return;
	}
	for (Effect& effect : m_effects) {
		effect.Stop();
	}
}

bool FireEffect::Start()
{
	EffectEngine* effectEngine = EffectEngine::GetInstance();
	if (effectEngine == nullptr) {
		// ウィンドウ無しで起動した場合など、EffectEngine が作られていない。
		K2_ASSERT(false, "EffectEngine が未生成のため炎エフェクトを再生できません。");
		return true;
	}

	// 登録済みの番号は内部で無視されるので、複数生成しても読み込みは1回だけ。
	effectEngine->ResistEffect(FIRE_EFFECT_ID, FIRE_EFFECT_PATH);
	Effekseer::EffectRef effect = effectEngine->LoadEffect(FIRE_EFFECT_ID);
	if (effect == nullptr) {
		// ファイルが無い・壊れているなど。毎フレーム空再生しないよう無効のまま終える。
		K2_ASSERT(false, "炎エフェクト(Assets/effect/fire.efk)の読み込みに失敗しました。");
		return true;
	}

	// 1つの再生が最も長く残るフレーム数の半分ごとに次を重ねる。
	// 2枠を交互に使うので、枠を使い回す時点で前の再生は消え切っている。
	const Effekseer::EffectTerm term = effect->CalculateTerm();
	if (term.TermMax > 0 && term.TermMax < INFINITE_TERM_THRESHOLD) {
		m_replayIntervalFrames = (term.TermMax + 1) / 2;
	}

	for (Effect& slot : m_effects) {
		slot.Init(FIRE_EFFECT_ID);
	}
	m_isValid = true;
	PlayNext();

	return true;
}

void FireEffect::Update()
{
	if (!m_isValid) {
		return;
	}

	// エフェクトは経過時間をエフェクトのフレーム（1秒に EffectEngine::FRAMES_PER_SECOND）に直して進むので、こちらも同じ数え方にする。
	m_framesSinceLastPlay += g_gameTime->GetFrameDeltaTime() * EffectEngine::FRAMES_PER_SECOND;
	const bool isIntervalElapsed = m_replayIntervalFrames > 0 && m_framesSinceLastPlay >= m_replayIntervalFrames;
	const bool isAllStopped = !m_effects[0].IsPlay() && !m_effects[1].IsPlay();
	if (isIntervalElapsed || isAllStopped) {
		PlayNext();
	}

	// 位置・拡大率が変わった時だけ行列を更新する。
	if (m_isTransformDirty) {
		for (Effect& effect : m_effects) {
			ApplyTransform(effect);
		}
		m_isTransformDirty = false;
	}
}

void FireEffect::PlayNext()
{
	Effect& effect = m_effects[m_nextSlot];
	effect.Play();
	// 新しいハンドルには行列が設定されていないので、再生直後に必ず設定する。
	ApplyTransform(effect);

	m_nextSlot = (m_nextSlot + 1) % SLOT_COUNT;
	m_framesSinceLastPlay = 0;
}

void FireEffect::ApplyTransform(Effect& effect)
{
	effect.SetPosition(m_position);
	effect.SetScale(m_scale);
	effect.Update();
}
```

- **重ねる間隔は、エフェクトの長さの半分。** `CalculateTerm()` で1回の再生がいちばん長く残るフレーム数を調べ、その半分ごとに次を再生します。2枠を交互に使うので、枠を使い回すときには前の再生は消え切っています。
- **間隔は「エフェクトのフレーム」で数える。** エフェクトは経過時間 × `EffectEngine::FRAMES_PER_SECOND` で進むので、こちらも同じ数え方にします（[フレームレートの手順](../../エンジン/フレームレートの手順.md) の手順2で足した定数）。

`FireBullet.cpp` に次を書きます。

<!-- new: ../../../Game/Source/Magic/FireBullet.cpp -->

```cpp
#include "stdafx.h"
#include "FireBullet.h"
#include "EffectId.h"
#include "HitTarget.h"

namespace
{
	// エフェクトは Effekseer 用に自作したもの(Assets/effect/fire_*.efkproj が編集元)。
	// テクスチャは Effekseer サンプル(01_Pierre01, CC-0)のものを使用。
	constexpr int BULLET_EFFECT_ID = static_cast<int>(EffectId::FireBullet);
	constexpr int HIT_EFFECT_ID = static_cast<int>(EffectId::FireHit);

	struct EffectEntry
	{
		EffectId id;
		const char16_t* path;
	};
	// 炎魔法で使うエフェクトの一覧。FireMagic もこの登録を使う。
	constexpr EffectEntry EFFECTS[] = {
		{ EffectId::FireBullet, u"Assets/effect/fire_bullet.efk" },
		{ EffectId::FireCharge, u"Assets/effect/fire_charge.efk" },
		{ EffectId::FireCharged, u"Assets/effect/fire_charged.efk" },
		{ EffectId::FireHit, u"Assets/effect/fire_hit.efk" },
	};

	// 溜めなし(0)〜最大まで溜めた(1)ときの値。間は線形に補間する。
	constexpr float MIN_RADIUS = 14.0f;               // 弾の当たり判定の半径。
	constexpr float MAX_RADIUS = 45.0f;
	constexpr float MIN_BULLET_EFFECT_SCALE = 8.0f;     // 弾のエフェクトの拡大率。
	constexpr float MAX_BULLET_EFFECT_SCALE = 26.0f;
	constexpr float MIN_HIT_EFFECT_SCALE = 12.0f;       // 着弾エフェクトの拡大率。
	constexpr float MAX_HIT_EFFECT_SCALE = 26.0f;

	constexpr float SPEED = 1300.0f;
	constexpr float RANGE = 2000.0f;

	float Lerp(float rate, float a, float b)
	{
		return a + (b - a) * rate;
	}

	BulletSettings MakeSettings(float chargeRate)
	{
		BulletSettings settings;
		settings.speed = SPEED;
		settings.range = RANGE;
		settings.radius = Lerp(chargeRate, MIN_RADIUS, MAX_RADIUS);
		return settings;
	}
}

FireBullet::FireBullet()
	: BulletBase(MakeSettings(0.0f))
{
}

FireBullet::~FireBullet()
{
	// Effect のデストラクタは再生を止めないため、ここで明示的に止める。
	// 通常は両方とも再生が終わってから削除されるので何も起きない。
	if (!m_isEffectReady || EffectEngine::GetInstance() == nullptr) {
		return;
	}
	m_bulletEffect.Stop();
	m_hitEffect.Stop();
}

void FireBullet::SetCharge(float chargeRate)
{
	m_chargeRate = chargeRate < 0.0f ? 0.0f : (chargeRate > 1.0f ? 1.0f : chargeRate);
	SetSettings(MakeSettings(m_chargeRate));
}

bool FireBullet::RegisterEffects()
{
	EffectEngine* effectEngine = EffectEngine::GetInstance();
	if (effectEngine == nullptr) {
		K2_ASSERT(false, "EffectEngine が未生成のため炎魔法のエフェクトを再生できません。");
		return false;
	}

	// 登録済みの番号は内部で無視されるので、何度呼んでも読み込みは1回だけ。
	for (const EffectEntry& entry : EFFECTS) {
		const int id = static_cast<int>(entry.id);
		effectEngine->ResistEffect(id, entry.path);
		if (effectEngine->LoadEffect(id) == nullptr) {
			K2_ASSERT(false, "炎魔法のエフェクト(Assets/effect/fire_*.efk)の読み込みに失敗しました。");
			return false;
		}
	}
	return true;
}

Vector3 FireBullet::GetBulletEffectScale(float chargeRate)
{
	const float scale = Lerp(chargeRate, MIN_BULLET_EFFECT_SCALE, MAX_BULLET_EFFECT_SCALE);
	return Vector3(scale, scale, scale);
}

bool FireBullet::OnStart()
{
	if (!RegisterEffects()) {
		return false;
	}

	m_bulletEffect.Init(BULLET_EFFECT_ID);
	m_hitEffect.Init(HIT_EFFECT_ID);
	m_isEffectReady = true;

	// 新しいハンドルには行列が設定されていないので、再生直後に OnMove() で必ず設定される。
	m_bulletEffect.Play();
	return true;
}

void FireBullet::OnMove()
{
	m_bulletEffect.SetPosition(GetPosition());
	m_bulletEffect.SetRotation(GetRotation());
	m_bulletEffect.SetScale(GetBulletEffectScale(m_chargeRate));
	// 全体ではなくルートだけを動かし、炎と煙の尾を通った場所に残す。
	m_bulletEffect.UpdateRoot();
}

void FireBullet::OnExplode(const Vector3& hitPosition)
{
	// 弾本体は即座に消し、尾の炎と煙は寿命まで残す。
	m_bulletEffect.StopRoot();

	const float hitScale = Lerp(m_chargeRate, MIN_HIT_EFFECT_SCALE, MAX_HIT_EFFECT_SCALE);
	m_hitEffect.Play();
	m_hitEffect.SetPosition(hitPosition);
	m_hitEffect.SetScale(Vector3(hitScale, hitScale, hitScale));
	m_hitEffect.Update();
}

bool FireBullet::IsVanishFinished() const
{
	// 尾と着弾エフェクトが両方消え切ったら終わり。
	return !m_bulletEffect.IsPlay() && !m_hitEffect.IsPlay();
}
```

- **溜め具合は `SetCharge()` で受け取り、`SetSettings()` で弾の性能を作り直す。** `Start()` より前に呼びます。
- **溜めなし〜最大の間は、線形に補間する（`Lerp()`）。**

**確かめ方:** ソリューションのビルドが通る。

```cpp
#pragma once

#include "MagicBase.h"

// 炎魔法。発射ボタンを押している間に溜め、離すと炎の弾（FireBullet）を撃つ。
// 長く溜めるほど弾が大きくなる。
// 溜めている間は、撃つ位置に溜め具合に応じて大きくなる火の玉を出し、周りから炎を吸い込ませる。
// 最大まで溜まると閃光と衝撃波を出し、その後は火の玉が脈打つ。
class FireMagic : public MagicBase
{
public:
	// cooldown: 撃ってから次に溜め始められるまでの秒数。maxChargeSeconds: 最大まで溜まる秒数。
	explicit FireMagic(float cooldown = 0.6f, float maxChargeSeconds = 1.2f);
	~FireMagic() override;

	const char* GetName() const override
	{
		return "FireMagic";
	}
	void OnPress(const MagicCastContext& context) override;
	void OnHold(const MagicCastContext& context) override;
	void OnRelease(const MagicCastContext& context) override;
	void OnCancel() override;

private:
	float GetChargeRate() const;
	void UpdateChargeEffect(const MagicCastContext& context);
	void StopCharge();

	Effect m_chargeEffect;   // 溜め中の火の玉。
	Effect m_chargedEffect;  // 最大まで溜まった瞬間の閃光。
	float m_cooldownSeconds = 0.0f;
	float m_maxChargeSeconds = 0.0f;
	float m_chargeSeconds = 0.0f;  // ここまでに溜めた秒数。
	float m_fullElapsed = 0.0f;    // 最大まで溜まってからの秒数。脈打ちに使う。
	bool m_isCharging = false;
	bool m_isFullCharged = false;
	bool m_isEffectReady = false;  // 溜め中のエフェクトを読み込めたか。
};
```

`FireMagic.cpp` に次を書きます。

<!-- new: ../../../Game/Source/Magic/FireMagic.cpp -->

```cpp
#include "stdafx.h"
#include "FireMagic.h"
#include "FireBullet.h"
#include "EffectId.h"

namespace
{
	constexpr float FULL_PULSE_SPEED = 18.0f;  // 最大まで溜まった後に火の玉が脈打つ速さ（ラジアン/秒）。
	constexpr float FULL_PULSE_DEPTH = 0.12f;  // 脈打ちで大きさが変わる割合。
}

FireMagic::FireMagic(float cooldown, float maxChargeSeconds)
	: m_cooldownSeconds(cooldown)
	, m_maxChargeSeconds(maxChargeSeconds > 0.0f ? maxChargeSeconds : 1.0f)
{
}

FireMagic::~FireMagic()
{
	// Effect のデストラクタは再生を止めないため、ここで明示的に止める。
	if (!m_isEffectReady || EffectEngine::GetInstance() == nullptr) {
		return;
	}
	m_chargeEffect.Stop();
	m_chargedEffect.Stop();
}

void FireMagic::OnPress(const MagicCastContext& context)
{
	if (!IsReady()) {
		// クールダウン中に押した分は溜めない。離しても撃たない。
		return;
	}
	if (!m_isEffectReady && FireBullet::RegisterEffects()) {
		m_chargeEffect.Init(static_cast<int>(EffectId::FireCharge));
		m_chargedEffect.Init(static_cast<int>(EffectId::FireCharged));
		m_isEffectReady = true;
	}

	m_isCharging = true;
	m_isFullCharged = false;
	m_chargeSeconds = 0.0f;
	if (m_isEffectReady) {
		m_chargeEffect.Play();
		UpdateChargeEffect(context);
	}
}

void FireMagic::OnHold(const MagicCastContext& context)
{
	if (!m_isCharging) {
		return;
	}
	m_chargeSeconds += context.deltaTime;
	if (m_chargeSeconds >= m_maxChargeSeconds) {
		m_chargeSeconds = m_maxChargeSeconds;
		if (!m_isFullCharged) {
			// 溜まり切った瞬間に一度だけ閃光を出す。
			m_isFullCharged = true;
			m_fullElapsed = 0.0f;
			if (m_isEffectReady) {
				m_chargedEffect.Play();
			}
		}
		else {
			m_fullElapsed += context.deltaTime;
		}
	}
	UpdateChargeEffect(context);
}

void FireMagic::OnRelease(const MagicCastContext& context)
{
	if (!m_isCharging) {
		return;
	}
	FireBullet* bullet = NewGO<FireBullet>(1, BulletBase::OBJECT_NAME);
	bullet->SetCharge(GetChargeRate());
	bullet->Init(context.origin, context.direction, context.caster, context.faction);
	StartCooldown(m_cooldownSeconds);
	StopCharge();
}

void FireMagic::OnCancel()
{
	// 溜めは捨てる（撃たない）。
	StopCharge();
}

float FireMagic::GetChargeRate() const
{
	return m_chargeSeconds / m_maxChargeSeconds;
}

void FireMagic::UpdateChargeEffect(const MagicCastContext& context)
{
	if (!m_isEffectReady) {
		return;
	}
	Quaternion rotation;
	rotation.SetRotationYFromDirectionXZ(context.direction);
	m_chargeEffect.SetPosition(context.origin);
	m_chargeEffect.SetRotation(rotation);
	// 撃つ弾と同じ大きさにして、溜めた火の玉がそのまま飛んでいくように見せる。
	Vector3 scale = FireBullet::GetBulletEffectScale(GetChargeRate());
	if (m_isFullCharged) {
		// 溜まり切った後は脈打たせて、撃てる状態だと分かるようにする。
		scale *= 1.0f + FULL_PULSE_DEPTH * sinf(m_fullElapsed * FULL_PULSE_SPEED);
	}
	m_chargeEffect.SetScale(scale);
	m_chargeEffect.UpdateRoot();

	if (m_isFullCharged) {
		// 閃光は火の玉についていかせる。
		m_chargedEffect.SetPosition(context.origin);
		m_chargedEffect.SetRotation(rotation);
		m_chargedEffect.SetScale(FireBullet::GetBulletEffectScale(1.0f));
		m_chargedEffect.Update();
	}
}

void FireMagic::StopCharge()
{
	m_isCharging = false;
	m_isFullCharged = false;
	m_chargeSeconds = 0.0f;
	if (m_isEffectReady) {
		// 火の玉は即座に消し、立ち上る炎と煙は寿命まで残す。
		m_chargeEffect.StopRoot();
	}
}
```

- **溜めている間の火の玉は、撃つ弾と同じ大きさにする。** `FireBullet::GetBulletEffectScale()` を使うので、溜めた火の玉がそのまま飛んでいくように見えます。
- **最大まで溜まったら、閃光を1回だけ出して、その後は脈打たせる。** 撃てる状態だとわかるようにするためです。

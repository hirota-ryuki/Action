# 炎魔法の手順

設計: [炎魔法の設計](炎魔法の設計.md)
経緯: [魔法の経緯](../魔法の経緯.md)

右クリックで溜めて撃つ炎魔法を作るまでの手順です。炎魔法発射後の燃える床は [炎魔法発射後の燃える床の手順](../炎魔法発射後の燃える床/炎魔法発射後の燃える床の手順.md) で作ります。

**出来上がるもの:** 右クリック（パッドは右トリガー）を押している間に撃つ位置で火の玉が溜まり、離すとその火の玉が飛んでいきます。長く溜めるほど大きくなります。

**前提:**

- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [氷魔法の手順](../氷魔法/氷魔法の手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../../README.md#ゲームを作る順番)）。そこで作った `EffectId` に番号を足す。
- エフェクト `Assets/effect/fire_fly.efk`・`fire_charge.efk`・`fire_charged.efk`・`fire_hit.efk` は、リポジトリにもとからある。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 溜めて撃つ炎魔法 `FireMagic` | ビルドが通る |
| 2 | Player の Action2 のボタンに炎魔法を登録する | 右クリックで溜めて撃てる |

**読み方:**

- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- コードの下に、3つを置きます。
  - 「行・何をしているか」の表: 1行ずつの動き。
  - 「なぜ」「効果」: その小手順でそう書く理由と、書くと何ができるようになるか。
  - 「初めて出てくる名前」の表: このページで初めて出てくる変数・引数・関数・型・マクロ・C++ の書き方を、コードに出てくる順に並べます。2回目からは載せないので、わからない名前はページ内検索（`Ctrl+F`）で最初に出てきた所を探してください。「どこから来たもの」で、このゲームで作ったもの・エンジン（k2Engine）の機能・C++ の標準ライブラリ・C++ の書き方のどれかがわかります。
- [前提知識](../../../前提知識.md) で「よく知っている」にあるもの（クラス・継承・ポインター・テンプレート・`std::unique_ptr`・`K2_ASSERT`・`nullptr` など）は、表に載せません。「まあまあ」「怪しい」「微妙」にあるもの（`std::make_unique`・`std::move` など）は載せます。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

## 手順1: 溜めて撃つ炎魔法 FireMagic を作る

押している間は撃つ位置で火の玉を溜め、離すとその火の玉が飛んでいく魔法です。`IsChargeType()` で `true` を返すと、`SkillBase`（[魔法の手順](../魔法の手順.md)）が離されるまで撃つ位置で待たせ、その間 `OnCharge()` を呼びます。離されたら `OnRelease()` を呼んでから、`MagicBase` が飛ばします。

**この手順で触るファイル:**

| ファイル | 何をするか |

| [EffectId.h](../../../../Game/Source/Core/EffectId.h) | 追加（飛ぶ炎・溜め・着弾の番号） |
| [FireMagic.h](../../../../Game/Source/Magic/FireMagic.h) | 新しく作る（炎魔法） |
| [FireMagic.cpp](../../../../Game/Source/Magic/FireMagic.cpp) | 新しく作る（溜める、飛ぶ、エフェクト） |

`Source\Magic` フィルターに `FireMagic.h` と `FireMagic.cpp` を作ります。

namespace
{
	// エフェクトは Effekseer 用に自作したもの(Assets/effect/fire_*.efkproj が編集元)。
	// テクスチャは Effekseer サンプル(01_Pierre01, CC-0)のものを使用。

		EffectId id;
		const char16_t* path;

	// 炎魔法で使うエフェクトの一覧。

		{ EffectId::FireFly, u"Assets/effect/fire_fly.efk" },
		{ EffectId::FireCharge, u"Assets/effect/fire_charge.efk" },
		{ EffectId::FireCharged, u"Assets/effect/fire_charged.efk" },
		{ EffectId::FireHit, u"Assets/effect/fire_hit.efk" },
	};

	constexpr float MAX_CHARGE_SECONDS = 1.2f;  // 最大まで溜まる秒数。
	constexpr float FULL_PULSE_SPEED = 18.0f;   // 最大まで溜まった後に火の玉が脈打つ速さ（ラジアン/秒）。
	constexpr float FULL_PULSE_DEPTH = 0.12f;   // 脈打ちで大きさが変わる割合。

	constexpr float MIN_RADIUS = 14.0f;               // 当たり判定の半径。
	constexpr float MAX_RADIUS = 45.0f;
	constexpr float MIN_FLY_EFFECT_SCALE = 8.0f;      // 飛ぶ炎（と溜め中の火の玉）のエフェクトの拡大率。
	constexpr float MAX_FLY_EFFECT_SCALE = 26.0f;
	constexpr float MIN_HIT_EFFECT_SCALE = 12.0f;     // 着弾エフェクトの拡大率。
	constexpr float MAX_HIT_EFFECT_SCALE = 26.0f;

	constexpr float SPEED = 1300.0f;
	constexpr float RANGE = 2000.0f;

	float Lerp(float rate, float a, float b)
	{
		return a + (b - a) * rate;
	}

	MagicSettings MakeSettings(float chargeRate)
	{
		MagicSettings settings;
		settings.speed = SPEED;
		settings.range = RANGE;
		settings.radius = Lerp(chargeRate, MIN_RADIUS, MAX_RADIUS);
		return settings;
	}

	Vector3 GetFlyEffectScale(float chargeRate)
	{
		const float scale = Lerp(chargeRate, MIN_FLY_EFFECT_SCALE, MAX_FLY_EFFECT_SCALE);
		return Vector3(scale, scale, scale);
	}

bool FireMagic::RegisterEffects()
{
	EffectEngine* effectEngine = EffectEngine::GetInstance();
	if (effectEngine == nullptr) {
		K2_ASSERT(false, "EffectEngine が未生成のため炎魔法のエフェクトを再生できません。");
		return false;
	}

	// 登録済みの番号は内部で無視されるので、何度呼んでも読み込みは1回だけ。
	for (const EffectEntry& entry : EFFECTS) {
		const int id = static_cast<int>(entry.id);
		effectEngine->ResistEffect(id, entry.path);
		if (effectEngine->LoadEffect(id) == nullptr) {

	m_chargeEffect.Play();

{
	m_chargeRate = min(chargeSeconds / MAX_CHARGE_SECONDS, 1.0f);
	if (m_chargeRate >= 1.0f && !m_isFullCharged) {
		// 溜まり切った瞬間に一度だけ閃光を出す。
		m_isFullCharged = true;
		m_fullChargeSeconds = chargeSeconds;
		m_chargedEffect.Play();

	m_chargeEffect.SetRotation(GetRotation());
	// 飛ぶ炎と同じ大きさにして、溜めた火の玉がそのまま飛んでいくように見せる。

- 右クリック（パッドは右トリガー）を押している間、撃つ位置で火の玉が大きくなり、1.2秒で閃光が出て脈打ち始める。離すと火の玉が飛ぶ。長く溜めるほど大きい。
- 溜めている途中で凍らされると、火の玉が消えて何も飛ばない。

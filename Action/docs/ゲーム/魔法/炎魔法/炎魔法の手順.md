# 炎魔法の手順

設計: [炎魔法の設計](炎魔法の設計.md)
経緯: [魔法の経緯](../魔法の経緯.md)

右クリックで溜めて撃つ炎魔法を作るまでの手順です。ステージに置いて燃やし続ける炎（`FireEffect`）も、ここで作ります。炎魔法発射後の燃える床は [炎魔法発射後の燃える床の手順](../炎魔法発射後の燃える床/炎魔法発射後の燃える床の手順.md) で作ります。

**出来上がるもの:** ステージの1か所で炎が燃え続けます。右クリック（パッドは右トリガー）を押している間に撃つ位置で火の玉が溜まり、離すとその火の玉が飛んでいきます。長く溜めるほど大きくなります。

**前提:**

- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [氷魔法の手順](../氷魔法/氷魔法の手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../../README.md#ゲームを作る順番)）。そこで作った `EffectId` に番号を足す。
- エフェクト `Assets/effect/fire.efk`・`fire_fly.efk`・`fire_charge.efk`・`fire_charged.efk`・`fire_hit.efk` は、リポジトリにもとからある。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | ステージで燃え続ける炎 `FireEffect` | 炎が途切れずに燃える |
| 2 | 溜めて撃つ炎魔法 `FireMagic` | ビルドが通る |
| 3 | Player の枠1に炎魔法を登録する | 右クリックで溜めて撃てる |

**読み方:**

- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- コードの下に、3つを置きます。
  - 「行・何をしているか」の表: 1行ずつの動き。
  - 「なぜ」「効果」: その小手順でそう書く理由と、書くと何ができるようになるか。
  - 「初めて出てくる名前」の表: このページで初めて出てくる変数・引数・関数・型・マクロ・C++ の書き方を、コードに出てくる順に並べます。2回目からは載せないので、わからない名前はページ内検索（`Ctrl+F`）で最初に出てきた所を探してください。「どこから来たもの」で、このゲームで作ったもの・エンジン（k2Engine）の機能・C++ の標準ライブラリ・C++ の書き方のどれかがわかります。
- [前提知識](../../../前提知識.md) で「よく知っている」にあるもの（クラス・継承・ポインター・テンプレート・`std::unique_ptr`・`K2_ASSERT`・`nullptr` など）は、表に載せません。「まあまあ」「怪しい」「微妙」にあるもの（`std::make_unique`・`std::move` など）は載せます。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

namespace

	constexpr const char16_t* FIRE_EFFECT_PATH = u"Assets/effect/fire.efk";  // Effekseer サンプル(01_Pierre01/Flame, CC-0)を書き出したもの。
	// エフェクトの長さがこれ以上なら無限ループとみなし、再生を重ねない（Effekseer は無限を INT_MAX 付近で表す）。
	constexpr int INFINITE_TERM_THRESHOLD = 60 * 60 * 60;

{

FireEffect::~FireEffect()
{
	// Effect のデストラクタは再生を止めないため、ここで明示的に止める。
	if (!m_isValid || EffectEngine::GetInstance() == nullptr) {
		return;
	}

bool FireEffect::Start()
{
	EffectEngine* effectEngine = EffectEngine::GetInstance();
	if (effectEngine == nullptr) {
		// ウィンドウ無しで起動した場合など、EffectEngine が作られていない。
		K2_ASSERT(false, "EffectEngine が未生成のため炎エフェクトを再生できません。");
		return true;
	}

	// 登録済みの番号は内部で無視されるので、複数生成しても読み込みは1回だけ。
	effectEngine->ResistEffect(FIRE_EFFECT_ID, FIRE_EFFECT_PATH);
	Effekseer::EffectRef effect = effectEngine->LoadEffect(FIRE_EFFECT_ID);
	if (effect == nullptr) {
		// ファイルが無い・壊れているなど。毎フレーム空再生しないよう無効のまま終える。
		K2_ASSERT(false, "炎エフェクト(Assets/effect/fire.efk)の読み込みに失敗しました。");
		return true;
	}

	// 1つの再生が最も長く残るフレーム数の半分ごとに次を重ねる。
	// 2枠を交互に使うので、枠を使い回す時点で前の再生は消え切っている。
	const Effekseer::EffectTerm term = effect->CalculateTerm();
	if (term.TermMax > 0 && term.TermMax < INFINITE_TERM_THRESHOLD) {
		m_replayIntervalFrames = (term.TermMax + 1) / 2;
	}

	for (Effect& slot : m_effects) {
		slot.Init(FIRE_EFFECT_ID);
	}
	m_isValid = true;
	PlayNext();

	return true;
}

void FireEffect::Update()
{
	if (!m_isValid) {
		return;
	}

	// エフェクトは経過時間をエフェクトのフレーム（1秒に EffectEngine::FRAMES_PER_SECOND）に直して進むので、こちらも同じ数え方にする。
	m_framesSinceLastPlay += g_gameTime->GetFrameDeltaTime() * EffectEngine::FRAMES_PER_SECOND;
	const bool isIntervalElapsed = m_replayIntervalFrames > 0 && m_framesSinceLastPlay >= m_replayIntervalFrames;
	const bool isAllStopped = !m_effects[0].IsPlay() && !m_effects[1].IsPlay();
	if (isIntervalElapsed || isAllStopped) {
		PlayNext();
	}

	// 位置・拡大率が変わった時だけ行列を更新する。
	if (m_isTransformDirty) {
		for (Effect& effect : m_effects) {
			ApplyTransform(effect);
		}
		m_isTransformDirty = false;
	}
}

void FireEffect::PlayNext()
{
	Effect& effect = m_effects[m_nextSlot];
	effect.Play();
	// 新しいハンドルには行列が設定されていないので、再生直後に必ず設定する。
	ApplyTransform(effect);

	m_nextSlot = (m_nextSlot + 1) % SLOT_COUNT;
	m_framesSinceLastPlay = 0;
}

void FireEffect::ApplyTransform(Effect& effect)
{
	effect.SetPosition(m_position);
	effect.SetScale(m_scale);
	effect.Update();
}

{
}

FireMagic::~FireMagic()
{
	// Effect のデストラクタは再生を止めないため、ここで明示的に止める。
	// 通常はすべて再生が終わってから削除されるので何も起きない。
	if (!m_isEffectReady || EffectEngine::GetInstance() == nullptr) {
		return;
	}
	m_chargeEffect.Stop();
	m_chargedEffect.Stop();
	m_flyEffect.Stop();
	m_hitEffect.Stop();
}

bool FireMagic::RegisterEffects()
{
	EffectEngine* effectEngine = EffectEngine::GetInstance();
	if (effectEngine == nullptr) {
		K2_ASSERT(false, "EffectEngine が未生成のため炎魔法のエフェクトを再生できません。");
		return false;
	}

	// 登録済みの番号は内部で無視されるので、何度呼んでも読み込みは1回だけ。
	for (const EffectEntry& entry : EFFECTS) {
		const int id = static_cast<int>(entry.id);
		effectEngine->ResistEffect(id, entry.path);
		if (effectEngine->LoadEffect(id) == nullptr) {
			K2_ASSERT(false, "炎魔法のエフェクト(Assets/effect/fire_*.efk)の読み込みに失敗しました。");
			return false;
		}
	}
	return true;
}

bool FireMagic::OnStart()
{
	if (!RegisterEffects()) {
		return false;
	}

	m_chargeEffect.Init(static_cast<int>(EffectId::FireCharge));
	m_chargedEffect.Init(static_cast<int>(EffectId::FireCharged));
	m_flyEffect.Init(static_cast<int>(EffectId::FireFly));
	m_hitEffect.Init(static_cast<int>(EffectId::FireHit));
	m_isEffectReady = true;

	// 新しいハンドルには行列が設定されていないので、再生直後に OnCharge() で必ず設定される。
	m_chargeEffect.Play();
	return true;
}

void FireMagic::OnCharge(float chargeSeconds)
{
	m_chargeRate = min(chargeSeconds / MAX_CHARGE_SECONDS, 1.0f);
	if (m_chargeRate >= 1.0f && !m_isFullCharged) {
		// 溜まり切った瞬間に一度だけ閃光を出す。
		m_isFullCharged = true;
		m_fullChargeSeconds = chargeSeconds;
		m_chargedEffect.Play();
	}

	m_chargeEffect.SetPosition(GetPosition());
	m_chargeEffect.SetRotation(GetRotation());
	// 飛ぶ炎と同じ大きさにして、溜めた火の玉がそのまま飛んでいくように見せる。
	Vector3 scale = GetFlyEffectScale(m_chargeRate);
	if (m_isFullCharged) {
		// 溜まり切った後は脈打たせて、撃てる状態だと分かるようにする。
		scale *= 1.0f + FULL_PULSE_DEPTH * sinf((chargeSeconds - m_fullChargeSeconds) * FULL_PULSE_SPEED);
	}
	m_chargeEffect.SetScale(scale);
	m_chargeEffect.UpdateRoot();

	if (m_isFullCharged) {
		// 閃光は火の玉についていかせる。
		m_chargedEffect.SetPosition(GetPosition());
		m_chargedEffect.SetRotation(GetRotation());
		m_chargedEffect.SetScale(GetFlyEffectScale(1.0f));
		m_chargedEffect.Update();
	}
}

void FireMagic::OnLaunch()
{
	// 手元の火の玉は即座に消し（立ち上る炎と煙は寿命まで残す）、同じ大きさの炎を飛ばす。
	m_chargeEffect.StopRoot();
	SetSettings(MakeSettings(m_chargeRate));
	m_flyEffect.Play();
}

void FireMagic::OnCancel()
{
	// 溜めは捨てる（飛ばさない）。火の玉は即座に消し、立ち上る炎と煙は寿命まで残す。
	m_chargeEffect.StopRoot();
}

void FireMagic::OnMove()
{
	m_flyEffect.SetPosition(GetPosition());
	m_flyEffect.SetRotation(GetRotation());
	m_flyEffect.SetScale(GetFlyEffectScale(m_chargeRate));
	// 全体ではなくルートだけを動かし、炎と煙の尾を通った場所に残す。
	m_flyEffect.UpdateRoot();
}

void FireMagic::OnExplode(const Vector3& hitPosition)
{
	// 飛んでいる炎は即座に消し、尾の炎と煙は寿命まで残す。
	m_flyEffect.StopRoot();

	const float hitScale = Lerp(m_chargeRate, MIN_HIT_EFFECT_SCALE, MAX_HIT_EFFECT_SCALE);
	m_hitEffect.Play();
	m_hitEffect.SetPosition(hitPosition);
	m_hitEffect.SetScale(Vector3(hitScale, hitScale, hitScale));
	m_hitEffect.Update();
}

bool FireMagic::IsVanishFinished() const
{
	// 溜めの名残・閃光・尾・着弾エフェクトがすべて消え切ったら終わり。
	return !m_chargeEffect.IsPlay() && !m_chargedEffect.IsPlay()
		&& !m_flyEffect.IsPlay() && !m_hitEffect.IsPlay();
}

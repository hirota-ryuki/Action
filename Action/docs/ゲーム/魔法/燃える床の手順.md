# 燃える床の手順

作成日: 2026-11-08
設計: [燃える床の設計](燃える床の設計.md)
経緯: [魔法と弾の経緯](魔法と弾の経緯.md)
確かめた記録: [ゲームの手順書の経緯](../土台/ゲームの手順書の経緯.md)

炎魔法の着弾後に、しばらく燃え続ける床（`BurningGround`）を作るまでの手順です。上から順にやると、[燃える床の設計](燃える床の設計.md) の形になります。

**出来上がるもの:** 炎の弾が着弾すると、真下の床が中心から一気に燃え広がり、4秒間燃え続けます。燃えている範囲に入った敵対する相手は、燃焼状態になります。溜め具合が大きいほど、燃える範囲が広くなります。

**前提:**

- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [炎魔法の手順](炎魔法の手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../README.md#ゲームを作る順番)）。燃やすのは [状態異常の手順](../キャラクター/状態異常の手順.md) で作った `StatusEffects::Burn()`。
- エフェクト `Assets/effect/fire_ground.efk` は、リポジトリにもとからある（変えない）。
- 作業を始める前に、main からブランチを切る。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 燃える床 `BurningGround` | ビルドが通る |
| 2 | 炎の弾が着弾したら、真下の床を燃やす | 着弾したところの床が燃える |

### 1-3. BurningGround.h・BurningGround.cpp を書く

<!-- new: ../../../Game/Source/Magic/BurningGround.h -->

```cpp
#pragma once

#include "Faction.h"

// 炎魔法の着弾後に、しばらく燃え続ける床。
// 着弾の飛び散りに合わせて、中心から一気に燃え広がる。
// 燃えている間、範囲に入った敵対する相手を燃焼状態にする（StatusEffects::Burn）。
// 時間が来たら炎の発生を止め、残りの炎が消え切ってから自分を削除する。
class BurningGround : public IGameObject
{
public:
	// NewGO の名前。Game が終了時にまとめて削除するのに使う。
	static constexpr const char* OBJECT_NAME = "burningGround";

	~BurningGround();

	// NewGO 直後、Start() より前に呼ぶ。
	// position: 床の位置。radius: 燃える範囲の半径。seconds: 燃えている時間。
	// owner には効かない。owner は削除済みになることがあるので比較にだけ使う。
	void Init(const Vector3& position, float radius, float seconds, const IGameObject* owner, Faction faction);

	bool Start();
	void Update();

private:
	enum class EnState
	{
		Burning,    // 燃えている。範囲に入った相手を燃やす。
		Vanishing,  // 燃え終わった。残りの炎が消えるのを待つ。
	};

	void BurnTargetsInRange();
	// 今燃えている範囲の半径。燃え広がっている途中は radius より小さい。
	float GetCurrentRadius() const;
	void UpdateEffectScale();

	Effect m_effect;
	Vector3 m_position = Vector3::Zero;
	const IGameObject* m_owner = nullptr;
	float m_radius = 0.0f;
	float m_seconds = 0.0f;
	float m_elapsed = 0.0f;
	Faction m_faction = Faction::Neutral;
	EnState m_state = EnState::Burning;
	bool m_isValid = false;           // エフェクトを読み込めたか。
	bool m_isSpreadFinished = false;  // 最大の広さまで燃え広がったか。
};
```

<!-- new: ../../../Game/Source/Magic/BurningGround.cpp -->

```cpp
#include "stdafx.h"
#include "BurningGround.h"
#include "EffectId.h"
#include "FireBullet.h"
#include "HitTarget.h"
#include "StatusEffects.h"

namespace
{
	constexpr int GROUND_EFFECT_ID = static_cast<int>(EffectId::FireGround);
	// fire_ground.efk は半径10の円に炎を出す。Scale 10 倍でワールドの半径100になる。
	constexpr float EFFECT_RADIUS_AT_SCALE_ONE = 10.0f;

	constexpr float BURN_SECONDS = 1.5f;     // 範囲に入った相手を燃やす時間。範囲から出ても、この時間は燃え続ける。
	constexpr float BURN_HEIGHT = 150.0f;    // 床からこの高さまでに足元がある相手を燃やす（ジャンプで飛び越えられる）。
	constexpr float BURN_DEPTH = 50.0f;      // 床よりこれだけ下に足元がある相手も燃やす（坂の下側など）。
	constexpr float TARGET_RADIUS_RATE = 0.5f;  // 相手の当たり判定の半径のうち、範囲の判定に足す割合。
	constexpr float SPREAD_SECONDS = 0.4f;     // 中心から最大の広さまで燃え広がる秒数。着弾の飛び散りに合わせる。
	constexpr float SPREAD_START_RATE = 0.1f;   // 燃え始めの広さ（最大に対する割合）。
}

BurningGround::~BurningGround()
{
	// Effect のデストラクタは再生を止めないため、ここで明示的に止める。
	if (!m_isValid || EffectEngine::GetInstance() == nullptr) {
		return;
	}
	m_effect.Stop();
}

void BurningGround::Init(const Vector3& position, float radius, float seconds, const IGameObject* owner, Faction faction)
{
	m_position = position;
	m_radius = radius;
	m_seconds = seconds;
	m_owner = owner;
	m_faction = faction;
}

bool BurningGround::Start()
{
	m_isValid = FireBullet::RegisterEffects();
	if (!m_isValid) {
		return true;
	}

	m_effect.Init(GROUND_EFFECT_ID);
	m_effect.Play();
	m_effect.SetPosition(m_position);
	UpdateEffectScale();
	return true;
}

void BurningGround::Update()
{
	if (!m_isValid) {
		DeleteGO(this);
		return;
	}

	switch (m_state) {
	case EnState::Burning:
		if (!m_isSpreadFinished) {
			// 燃え広がっている間は、出ている炎ごと外へ広げる。最大の広さに達したフレームまで更新する。
			UpdateEffectScale();
			m_isSpreadFinished = m_elapsed >= SPREAD_SECONDS;
		}
		BurnTargetsInRange();
		m_elapsed += g_gameTime->GetFrameDeltaTime();
		if (m_elapsed >= m_seconds) {
			// 炎の発生だけを止め、出ている炎は寿命まで燃やして自然に消す。
			m_effect.StopRoot();
			m_state = EnState::Vanishing;
		}
		break;
	case EnState::Vanishing:
		if (!m_effect.IsPlay()) {
			DeleteGO(this);
		}
		break;
	}
}

void BurningGround::BurnTargetsInRange()
{
	for (HitTarget* target : HitTargetRegistry::GetTargets()) {
		if (!target->IsActive() || target->GetOwner() == m_owner) {
			continue;
		}
		if (!IsHostile(m_faction, target->GetFaction())) {
			continue;
		}
		StatusEffects* statusEffects = target->GetStatusEffects();
		if (statusEffects == nullptr) {
			continue;
		}

		const Vector3& foot = target->GetFootPosition();
		const float height = foot.y - m_position.y;
		if (height < -BURN_DEPTH || height > BURN_HEIGHT) {
			continue;
		}
		const float dx = foot.x - m_position.x;
		const float dz = foot.z - m_position.z;
		const float range = GetCurrentRadius() + target->GetRadius() * TARGET_RADIUS_RATE;
		if (dx * dx + dz * dz > range * range) {
			continue;
		}
		statusEffects->Burn(BURN_SECONDS);
	}
}

float BurningGround::GetCurrentRadius() const
{
	if (m_elapsed >= SPREAD_SECONDS) {
		return m_radius;
	}
	// 最初に勢いよく広がり、最大に近づくにつれてゆっくりになる。
	const float t = m_elapsed / SPREAD_SECONDS;
	const float easeOut = 1.0f - (1.0f - t) * (1.0f - t);
	return m_radius * (SPREAD_START_RATE + (1.0f - SPREAD_START_RATE) * easeOut);
}

void BurningGround::UpdateEffectScale()
{
	const float scale = GetCurrentRadius() / EFFECT_RADIUS_AT_SCALE_ONE;
	m_effect.SetScale(Vector3(scale, scale, scale));
	m_effect.Update();
}
```

- **燃え広がりは、出ている炎ごと大きくする。** `UpdateEffectScale()` で、燃え広がっている間だけ毎フレーム拡大率を変えます。最初に勢いよく広がり、最大に近づくにつれてゆっくりになります（ease-out）。
- **高さも見る。** 床から `BURN_HEIGHT`（150）より上に足元がある相手は燃やさないので、ジャンプで飛び越えられます。
- **相手は `HitTargetRegistry` から探す。** 燃やす先は `HitTarget::GetStatusEffects()` で受け取るので、相手のクラスを知らなくて済みます。

**確かめ方:** ソリューションのビルドが通る（まだ置く処理はない）。

## 手順2: 炎の弾が着弾したら、真下の床を燃やす

```diff
+	// 地形のレイはキャラクターのカプセルにも当たるので、相手に当たったときは足元から調べる。
+	Vector3 rayStart = m_hasHitTarget ? m_hitFootPosition : hitPosition - GetDirection() * FLOOR_RAY_BACK_OFF;
+	rayStart.y += FLOOR_RAY_LIFT;
+	Vector3 rayEnd = rayStart;
+	rayEnd.y -= FLOOR_SEARCH_DEPTH;
+
+	Vector3 floorPosition;
+	if (!physicsWorld->RayTest(rayStart, rayEnd, floorPosition)) {
+		// 下に床がない（崖の外など）。床は燃やさない。
+		return;
+	}
+
+	BurningGround* ground = NewGO<BurningGround>(1, BurningGround::OBJECT_NAME);
+	ground->Init(
+		floorPosition,
+		Lerp(m_chargeRate, MIN_GROUND_RADIUS, MAX_GROUND_RADIUS),
+		GROUND_BURN_SECONDS,
+		GetOwner(),
+		GetFaction());
+}
```

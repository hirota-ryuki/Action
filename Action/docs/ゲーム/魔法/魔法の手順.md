# 魔法の手順

設計: [魔法の設計](魔法の設計.md)
経緯: [魔法の経緯](魔法の経緯.md)

魔法の基底クラス（`MagicBase`）と、魔法を登録して撃つ部品（`MagicCaster`）を作り、キャラクターに持たせるまでの手順です。魔法は撃つたびに1つ作り、その1つが飛んでいく1発になります。氷魔法・炎魔法そのものは [氷魔法の手順](氷魔法の手順.md)・[炎魔法の手順](炎魔法の手順.md) で作ります。

**出来上がるもの:** Player と Enemy が `MagicCaster` を持ち、発射ボタン（`fire`・`subFire`）に合わせて、枠0・枠1に登録した魔法を撃つようになります。まだ魔法を1つも登録していないので、撃っても何も出ません。[入力の手順](../キャラクター/入力の手順.md) で足した魔法の切り替え（Q・E キー）は、この手順で消します。

**前提:**

- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- ゲームの手順書は [README の「ゲームを作る順番」](../../README.md#ゲームを作る順番) の順に進める。この手順の前に、[走りから止まる手順](../プレイヤー/走りから止まる手順.md) まで済ませておく。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | ゲームの時計 `GameClock` | ビルドが通る |
| 2 | 魔法の基底クラス `MagicBase` の形 | ビルドが通る |
| 3 | `MagicBase` の流れ（待つ → 飛ぶ → 当たる → 消える） | ビルドが通る |
| 4 | 魔法を登録して撃つ部品 `MagicCaster` | ビルドが通る |
| 5 | キャラクターに `MagicCaster` を持たせ、撃つ位置と向きを作る | 起動して落ちない |
| 6 | ゲームを終えるときに、残っている魔法を消す | 起動して、閉じても落ちない |
| 7 | 魔法の切り替えの入力を消す | 起動して落ちない |

**読み方:**

- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

## 手順1: ゲームの時計 GameClock を作る

bool MagicBase::Start()
{
	m_isValid = OnStart();
	if (m_isValid) {
		// 見た目を最初の位置に合わせておく。
		if (m_state == EnState::Charging) {
			OnCharge(0.0f);
		}
		else {
			OnMove();
		}

	return true;

void MagicBase::Update()
{
	if (!m_isValid) {
		// 待っている間は MagicCaster がこの魔法を指しているので、離されるか中断されるまで消えない。
		if (m_state == EnState::Charging && !m_isReleased && !m_isCanceled) {
			return;
		}
		DeleteGO(this);
		return;
	}

	switch (m_state) {
	case EnState::Charging:
		UpdateCharging();
		break;
	case EnState::Flying:
		UpdateFlying();
		break;
	case EnState::Vanishing:
		if (IsVanishFinished()) {
			DeleteGO(this);
		}
		break;
	}
}

void MagicBase::SetPose(const Vector3& position, const Vector3& direction)
{
	m_position = position;
	m_direction = direction;
	if (m_direction.LengthSq() <= FLT_EPSILON) {
		m_direction = Vector3::AxisZ;
	}
	m_direction.Normalize();
	m_rotation.SetRotationYFromDirectionXZ(m_direction);
}

void MagicBase::UpdateCharging()
{
	if (m_isCanceled) {
		OnCancel();
		m_state = EnState::Vanishing;
		return;
	}
	if (m_isReleased) {
		OnLaunch();
		m_state = EnState::Flying;
		OnMove();
		return;
	}
	OnCharge(GameClock::Now() - m_chargeStartTime);
}

void MagicBase::UpdateFlying()
{
	const float moveDistance = m_settings.speed * g_gameTime->GetFrameDeltaTime();
	const Vector3 nextPosition = m_position + m_direction * moveDistance;

	// キャラクター → 地形の順に調べる。地形のレイはキャラクターのカプセルにも当たるが、
	// キャラクターの当たり判定の方が大きいので、狙って撃てば先にキャラクターとして命中する。
	Vector3 hitPosition;
	HitTarget* hitTarget = HitTargetRegistry::FindHitOnSegment(
		m_position, nextPosition, m_settings.radius, m_faction, m_owner, hitPosition);
	if (hitTarget != nullptr) {
		HitInfo hitInfo;
		hitInfo.attacker = m_owner;
		hitInfo.attackerFaction = m_faction;
		hitInfo.position = hitPosition;
		hitInfo.direction = m_direction;
		hitTarget->NotifyHit(hitInfo);
		OnHitTarget(*hitTarget, hitPosition);
		Explode(hitPosition);
		return;
	}

	PhysicsWorld* physicsWorld = PhysicsWorld::GetInstance();
	if (physicsWorld != nullptr && physicsWorld->RayTest(m_position, nextPosition, hitPosition)) {
		Explode(hitPosition);
		return;
	}

	m_position = nextPosition;
	m_flightDistance += moveDistance;
	if (m_flightDistance >= m_settings.range) {
		// 射程切れは空中で着弾した扱いにする。
		Explode(m_position);
		return;
	}

	OnMove();
}

{
	m_position = hitPosition;
	OnMove();
	OnExplode(hitPosition);
	m_state = EnState::Vanishing;

MagicCaster::Slot& MagicCaster::GetOrAddSlot(int slot)
{
	if (slot >= static_cast<int>(m_slots.size())) {
		m_slots.resize(slot + 1);

bool MagicCaster::IsReady(const Slot& slot) const

	return !slot.hasFired || GameClock::Now() - slot.lastFireTime >= slot.cooldown;
}

void MagicCaster::Fire(int slot, const ButtonState& button, const Vector3& origin, const Vector3& direction)
{
	if (slot < 0 || slot >= static_cast<int>(m_slots.size())) {
		return;
	}
	Slot& target = m_slots[slot];
	if (!target.create) {
		return;
	}

	// 押した瞬間: クールダウンが明けていれば、魔法を1つ作る。
	if (button.isTrigger && target.holding == nullptr && IsReady(target)) {
		MagicBase* magic = target.create();
		magic->Init(origin, direction, m_owner, m_faction);
		if (magic->IsChargeType()) {
			// 溜め撃ちは、離して飛ばしたときからクールダウンを数える。
			target.holding = magic;
		}
		else {
			target.lastFireTime = GameClock::Now();
			target.hasFired = true;
		}
	}

	if (target.holding == nullptr) {
		return;
	}
	if (button.isPress) {
		// 押している間: 待たせている魔法を手元に合わせる。
		target.holding->Hold(origin, direction);
	}
	else {
		// 離した: 飛ばして、手を放す。
		target.holding->Release();
		target.holding = nullptr;
		target.lastFireTime = GameClock::Now();
		target.hasFired = true;
	}
}

	for (Slot& slot : m_slots) {
		if (slot.holding != nullptr) {
			slot.holding->Cancel();

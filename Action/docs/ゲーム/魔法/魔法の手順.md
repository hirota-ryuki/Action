# 魔法の手順

設計: [魔法の設計](魔法の設計.md)
経緯: [魔法の経緯](魔法の経緯.md)

スキルの基底クラス（`SkillBase`）と、スキルを入力のボタンごとに登録して使う部品（`SkillController`）を作り、それを継承した魔法の基底クラス（`MagicBase`）を作って、キャラクターに持たせるまでの手順です。魔法は撃つたびに1つ作り、その1つが飛んでいく1発になります。氷魔法・炎魔法そのものは [氷魔法の手順](氷魔法/氷魔法の手順.md)・[炎魔法の手順](炎魔法/炎魔法の手順.md) で作ります。スキルの考え方は [スキルの設計](../スキル/スキルの設計.md) にあります。

**出来上がるもの:** Player と Enemy が `SkillController` を持ち、入力の `Action1`・`Action2` のボタンに登録したスキルを使うようになります。まだスキルを1つも登録していないので、押しても何も出ません。

**前提:**

- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- ゲームの手順書は [README の「ゲームを作る順番」](../../README.md#ゲームを作る順番) の順に進める。この手順の前に、[走りから止まる手順](../プレイヤー/走りから止まる/走りから止まる手順.md) まで済ませておく。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | ゲームの時計 `GameClock` | ビルドが通る |
| 2 | スキルの基底クラス `SkillBase` の形 | ビルドが通る |
| 3 | `SkillBase` の流れ（溜める → 使う → 使い終わる → 消える） | ビルドが通る |
| 4 | スキルを登録して使う部品 `SkillController` | ビルドが通る |
| 5 | 魔法の基底クラス `MagicBase`（飛ぶ → 当たる → 着弾する） | ビルドが通る |
| 6 | キャラクターに `SkillController` を持たせ、撃つ位置と向きを作る | 起動して落ちない |
| 7 | ゲームを終えるときに、残っているスキルを消す | 起動して、閉じても落ちない |

**読み方:**

- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- コードの下に、3つを置きます。
  - 「行・何をしているか」の表: 1行ずつの動き。
  - 「なぜ」「効果」: その小手順でそう書く理由と、書くと何ができるようになるか。
  - 「初めて出てくる名前」の表: このページで初めて出てくる変数・引数・関数・型・マクロ・C++ の書き方を、コードに出てくる順に並べます。2回目からは載せないので、わからない名前はページ内検索（`Ctrl+F`）で最初に出てきた所を探してください。「どこから来たもの」で、このゲームで作ったもの・エンジン（k2Engine）の機能・C++ の標準ライブラリ・C++ の書き方のどれかがわかります。
- [前提知識](../../前提知識.md) で「よく知っている」にあるもの（クラス・継承・ポインター・テンプレート・`std::unique_ptr`・`K2_ASSERT`・`nullptr` など）は、表に載せません。「まあまあ」「怪しい」「微妙」にあるもの（`std::make_unique`・`std::move` など）は載せます。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

## 手順1: ゲームの時計 GameClock を作る

## 手順2: スキルの基底クラス SkillBase の形を作る

魔法のように「ボタンを押すと1つ作られ、使い終わったら自分で消える」ものを、スキルと呼びます。押している間に溜めて離したら使う、溜めている途中で凍ったら中断する、といった入力のあとの判断は、どのスキルでも同じなので、基底クラス `SkillBase` にまとめます。派生クラス（このあと作る `MagicBase` など）は、見た目と効果だけを書きます。考え方は [スキルの設計](../スキル/スキルの設計.md) にあります。

	static constexpr float COOLDOWN = 0.0f;

- **効果:** `NewGO<派生クラス>(優先度, SkillBase::OBJECT_NAME)` で作れば、毎フレーム `Update()` が呼ばれ、Game が名前で探して消せる。

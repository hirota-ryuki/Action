# 魔法の調整値の手順

設計: [魔法の調整値の設計](魔法の調整値の設計.md)
経緯: [魔法の調整値の経緯](魔法の調整値の経緯.md)

氷魔法・炎魔法・黒騎士の斬撃の強さを、コードの定数から `Assets/data/magic.json` に出し、`MagicConfig` が読む形に変えるまでの手順です。

**出来上がるもの:** `magic.json` の数値を書き換えて起動し直すだけで、氷魔法の連射間隔・速さ・凍らせる秒数、炎魔法の溜め時間・燃える床の広さ、黒騎士の斬撃の速さが変わります。ビルドはいりません。キーがないときは、`MagicConfig.cpp` に書いた既定値で動き、出力ウィンドウに知らせます。Player も敵も同じ値を使います。

**前提:**

- ゲームの手順書（[README の「ゲームを作る順番」](../../../README.md#ゲームを作る順番)）の 23 まで済ませておく。とくに次を使う。
  - [JSON読み込みの手順](../../システム/JSON読み込み/JSON読み込みの手順.md)（`JsonFile::Load`）
  - [魔法の手順](../魔法の手順.md)（`MagicBase`・`MagicSettings`・`SkillController`）
  - [氷魔法の手順](../氷魔法/氷魔法の手順.md)・[炎魔法の手順](../炎魔法/炎魔法の手順.md)・[炎魔法発射後の燃える床の手順](../炎魔法発射後の燃える床/炎魔法発射後の燃える床の手順.md)
  - 読み方の手本は [プレイヤーの調整値の手順](../../プレイヤー/プレイヤーの調整値/プレイヤーの調整値の手順.md) の手順3（`PlayerConfig.cpp` の JSON を読む土台）。同じ形で作る。
- **氷魔法・炎魔法の手順書は変えない。** それらは、連射間隔を `IceMagic::COOLDOWN`・`FireMagic::COOLDOWN` に、速さや半径などを `IceMagic.cpp`・`FireMagic.cpp` の定数に書く形で正しい。この手順書で、それらを `magic.json` の値に置き換える。
- 黒騎士の斬撃（`SlashMagic.cpp`）は手順書がないので、今のコードにもとからあるものを使う。
- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | `magic.json` を作る | ファイルがある |
| 2 | `MagicConfig.h` に、魔法ごとの調整値の構造体を作る | ビルドが通る |
| 3 | `MagicConfig.cpp` に、JSON を読む土台と、魔法ごとの読み込みを書く | ビルドが通る |
| 4 | `SkillController::Register` に、クールダウンを渡す形を足す | ビルドが通り、動きが変わらない |
| 5 | 氷魔法を `MagicConfig` から読む | ビルドが通り、氷魔法が変わらない |
| 6 | 炎魔法を `MagicConfig` から読む | ビルドが通り、炎魔法が変わらない |
| 7 | 黒騎士の斬撃を `MagicConfig` から読む | ビルドが通り、斬撃が変わらない |
| 8 | Player がクールダウンを渡し、`COOLDOWN` の定数を消す | ビルドが通り、連射間隔が変わらない |

**読み方:**

- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- 消すところは、消す行を枠で示します（番号は消す前の番号）。書き換えるところは、「前」と「後」の枠を並べています（番号は、それぞれ書き換える前と後の番号）。
- コードの下に、3つを置きます。
  - 「行・何をしているか」の表: 1行ずつの動き。
  - 「なぜ」「効果」: その小手順でそう書く理由と、書くと何ができるようになるか。
  - 「初めて出てくる名前」の表: このページで初めて出てくる変数・引数・関数・型・マクロ・C++ の書き方を、コードに出てくる順に並べます。2回目からは載せないので、わからない名前はページ内検索（`Ctrl+F`）で最初に出てきた所を探してください。
- [前提知識](../../../前提知識.md) で「よく知っている」にあるもの（`constexpr`・`static` のメンバー・`namespace`・`template`・`const` など）は、表に載せません。「まあまあ」「怪しい」「微妙」にあるものは載せます。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

	// 入れ子の1段（"ice" など）を取り出す。ないときは空の {} を返すので、中のキーはどれも既定値になる。
	Json GetSection(const char* name)
	{
		const Json& json = GetJson();
		auto it = json.find(name);
		if (it == json.end() || !it->is_object()) {
			Log(std::string(JSON_PATH) + " に \"" + name + "\" がないので、既定値を使います。");
			return Json::object();
		}
		return *it;
	}

	// section の key を読む。ないとき・数でないときは defaultValue を返し、出力ウィンドウに出す（書き間違いに気づくため）。
	float Read(const Json& section, const char* sectionName, const char* key, float defaultValue)
	{
		auto it = section.find(key);
		if (it == section.end() || !it->is_number()) {
			Log(std::string(JSON_PATH) + " の " + sectionName + "." + key + " がない（または数でない）ので、既定値を使います。");
			return defaultValue;
		}
		return it->get<float>();
	}

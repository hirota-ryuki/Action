魔法が撃つ弾の基底クラス `BulletBase` を作るまでの手順です。上から順にやると、[弾の設計](弾の設計.md) の形になります。

**出来上がるもの:** まっすぐ飛び、敵対する相手か地形に当たるか、射程が尽きると着弾し、着弾の演出が終わってから自分を消す弾の基底クラスができます。派生クラスは見た目と、当たったときの効果だけを書けばよくなります（[氷魔法の手順](氷魔法の手順.md)・[炎魔法の手順](炎魔法の手順.md)）。

**前提:**

- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [魔法と弾の手順](魔法と弾の手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../README.md#ゲームを作る順番)）。当たり判定は [陣営と当たり判定の手順](../キャラクター/陣営と当たり判定の手順.md) で作った `HitTargetRegistry` を使う。
- 作業を始める前に、main からブランチを切る。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | 弾の基底クラス `BulletBase` | ビルドが通る |
| 2 | ゲームを終えるときに、残っている弾を消す | ビルドが通る |

## 手順1: 弾の基底クラス BulletBase を作る

弾の「飛ぶ → 当たる → 演出を待って消える」の流れは、どの弾も同じです。この流れを基底クラスに固定し、`Start()` と `Update()` を `final` にして派生クラスで変えられないようにします。派生クラスは、5つの関数（見た目・当たったときの効果）だけを書きます。

`BulletBase.h` に次を書きます。

<!-- new: ../../../Game/Source/Magic/BulletBase.h -->

```cpp
#pragma once

#include "Faction.h"

class HitTarget;

// 弾の設定。
struct BulletSettings
{
	float speed = 1500.0f;   // 毎秒の移動距離。
	float range = 2000.0f;   // これだけ飛ぶと消える。
	float radius = 10.0f;    // 弾の当たり判定の半径。相手の当たり判定の半径と足して判定する。
};

// 弾の基底クラス。まっすぐ飛び、敵対する相手か地形に当たるか射程が尽きると着弾する。
// 着弾後は演出が終わるのを待ってから自分を削除する。
//
// 派生クラスは見た目と命中時の効果だけを書く:
//   OnStart()          エフェクトやモデルの読み込み。失敗したら false を返すとすぐ削除される。
//   OnMove()           位置が変わったときに見た目を合わせる。
//   OnHitTarget()      敵対する相手に当たったときの効果（凍結など）。
//   OnExplode()        着弾したときの演出（相手・地形・射程切れのすべてで呼ばれる）。
//   IsVanishFinished() 着弾後の演出が終わったか。
class BulletBase : public IGameObject
{
public:
	// NewGO の名前。Game が終了時にまとめて削除するのに使う。
	static constexpr const char* OBJECT_NAME = "bullet";

	virtual ~BulletBase() = default;

	// NewGO 直後、Start() より前に呼ぶ。direction は正規化していなくてよい。
	// owner には当たらない。owner は削除済みになることがあるので比較にだけ使う。
	void Init(const Vector3& position, const Vector3& direction, const IGameObject* owner, Faction faction);

	bool Start() final;
	void Update() final;

protected:
	explicit BulletBase(const BulletSettings& settings);

	// 弾ごとに性能を変えたいとき（溜め具合など）に、Start() より前に呼ぶ。
	void SetSettings(const BulletSettings& settings)
	{
		m_settings = settings;
	}

	virtual bool OnStart() { return true; }
	virtual void OnMove() {}
	virtual void OnHitTarget(HitTarget& target, const Vector3& hitPosition) { (void)target; (void)hitPosition; }
	virtual void OnExplode(const Vector3& hitPosition) { (void)hitPosition; }
	virtual bool IsVanishFinished() const { return true; }

	const Vector3& GetPosition() const
	{
		return m_position;
	}
	const Vector3& GetDirection() const
	{
		return m_direction;
	}
	const Quaternion& GetRotation() const
	{
		return m_rotation;
	}
	const IGameObject* GetOwner() const
	{
		return m_owner;
	}
	Faction GetFaction() const
	{
		return m_faction;
	}

private:
	enum class EnState
	{
		Flying,      // 飛翔中。
		Vanishing,   // 着弾済み。演出が終わるのを待つ。
	};

	void UpdateFlying();
	void Explode(const Vector3& hitPosition);

	BulletSettings m_settings;
	const IGameObject* m_owner = nullptr;
	Vector3 m_position = Vector3::Zero;
	Vector3 m_direction = Vector3::AxisZ;     // 進行方向（正規化済み）。
	Quaternion m_rotation = Quaternion::Identity;
	float m_flightDistance = 0.0f;            // ここまでに飛んだ距離。射程判定に使う。
	Faction m_faction = Faction::Neutral;
	EnState m_state = EnState::Flying;
	bool m_isValid = false;                   // OnStart() に成功したか。
};
```

`BulletBase.cpp` に次を書きます。

<!-- new: ../../../Game/Source/Magic/BulletBase.cpp -->

```cpp
#include "stdafx.h"
#include "BulletBase.h"
#include "HitTarget.h"

BulletBase::BulletBase(const BulletSettings& settings)
	: m_settings(settings)
{
}

void BulletBase::Init(const Vector3& position, const Vector3& direction, const IGameObject* owner, Faction faction)
{
	m_position = position;
	m_direction = direction;
	if (m_direction.LengthSq() <= FLT_EPSILON) {
		m_direction = Vector3::AxisZ;
	}
	m_direction.Normalize();
	m_rotation.SetRotationYFromDirectionXZ(m_direction);
	m_owner = owner;
	m_faction = faction;
}

bool BulletBase::Start()
{
	m_isValid = OnStart();
	if (m_isValid) {
		// 見た目を最初の位置に合わせておく。
		OnMove();
	}
	return true;
}

void BulletBase::Update()
{
	if (!m_isValid) {
		DeleteGO(this);
		return;
	}

	switch (m_state) {
	case EnState::Flying:
		UpdateFlying();
		break;
	case EnState::Vanishing:
		if (IsVanishFinished()) {
			DeleteGO(this);
		}
		break;
	}
}

void BulletBase::UpdateFlying()
{
	const float moveDistance = m_settings.speed * g_gameTime->GetFrameDeltaTime();
	const Vector3 nextPosition = m_position + m_direction * moveDistance;

	// キャラクター → 地形の順に調べる。地形のレイはキャラクターのカプセルにも当たるが、
	// キャラクターの当たり判定の方が大きいので、狙って撃てば先にキャラクターとして命中する。
	Vector3 hitPosition;
	HitTarget* hitTarget = HitTargetRegistry::FindHitOnSegment(
		m_position, nextPosition, m_settings.radius, m_faction, m_owner, hitPosition);
	if (hitTarget != nullptr) {
		HitInfo hitInfo;
		hitInfo.attacker = m_owner;
		hitInfo.attackerFaction = m_faction;
		hitInfo.position = hitPosition;
		hitInfo.direction = m_direction;
		hitTarget->NotifyHit(hitInfo);
		OnHitTarget(*hitTarget, hitPosition);
		Explode(hitPosition);
		return;
	}

	PhysicsWorld* physicsWorld = PhysicsWorld::GetInstance();
	if (physicsWorld != nullptr && physicsWorld->RayTest(m_position, nextPosition, hitPosition)) {
		Explode(hitPosition);
		return;
	}

	m_position = nextPosition;
	m_flightDistance += moveDistance;
	if (m_flightDistance >= m_settings.range) {
		// 射程切れは空中で着弾した扱いにする。
		Explode(m_position);
		return;
	}

	OnMove();
}

void BulletBase::Explode(const Vector3& hitPosition)
{
	m_position = hitPosition;
	OnMove();
	OnExplode(hitPosition);
	m_state = EnState::Vanishing;
}
```

- **1フレームに進む分を線分で調べる。** 今の位置から次の位置までを `HitTargetRegistry::FindHitOnSegment()` で調べるので、速い弾でも相手をすり抜けません。
- **キャラクター → 地形の順に調べる。** 地形のレイはキャラクターのカプセルにも当たりますが、キャラクターの当たり判定の方が大きいので、狙って撃てば先にキャラクターとして当たります。
- **射程切れも「着弾」にする。** `OnExplode()` は、相手・地形・射程切れのどれでも呼ばれます。

**確かめ方:** ソリューションのビルドが通る（まだ弾を撃つ魔法はない）。

## 手順2: ゲームを終えるときに、残っている弾を消す

弾は撃ったキャラクターが `NewGO` するだけで、だれも持っていません。ゲームを終えるときに残らないよう、`Game` のデストラクターで名前（`BulletBase::OBJECT_NAME`）で探して消します。

+	});
 }

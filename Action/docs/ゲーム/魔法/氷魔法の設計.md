# 氷魔法の設計

作成日: 2026-11-05（`キャラクター入力・魔法・弾の設計.md` から分割）
対象: `Game/Source/Magic/IceMagic.*`、`Game/Source/Magic/IceBullet.*`

左クリック（パッドの Y）で撃つ、当たった相手を凍らせる魔法です。Player はメインの魔法として、Enemy も同じものを持っています。
魔法と弾の共通の仕組みは [魔法と弾の設計](魔法と弾の設計.md) を見てください。

---

## 1. IceMagic：撃ち方

コード: [IceMagic.cpp](../../../Game/Source/Magic/IceMagic.cpp)

単発の魔法です。`OnPress` で、使える状態なら `IceBullet` を1発生成し、クールダウンを始めます。それだけです。

## 2. IceBullet：氷の弾

コード: [IceBullet.cpp](../../../Game/Source/Magic/IceBullet.cpp)

| 関数 | やっていること |
|---|---|
| `OnStart` | `ice_bullet.efk` と `ice_hit.efk` を読み込み、弾のエフェクトを再生する |
| `OnMove` | エフェクトのルートだけを動かす（軌跡は発生した場所に残る） |
| `OnHitTarget` | 相手の `StatusEffects` を凍らせる（[状態異常の設計](../キャラクター/状態異常の設計.md)） |
| `OnExplode` | 弾本体を消し、着弾エフェクトを再生する |
| `IsVanishFinished` | 軌跡と着弾エフェクトが両方消えたか |

## 3. 実装方法

### 撃つ：OnPress だけ

```cpp
void IceMagic::OnPress(const MagicCastContext& context)
{
    if (!IsReady()) {
        return;
    }
    IceBullet* bullet = NewGO<IceBullet>(1, BulletBase::kObjectName);
    bullet->Init(context.origin, context.direction, context.caster, context.faction);
    StartCooldown(m_cooldownSeconds);
}
```

### エフェクト：番号で登録し、読み込みは1回だけ

```cpp
effectEngine->ResistEffect(kBulletEffectId, kBulletEffectPath);   // 登録済みの番号は無視される
effectEngine->ResistEffect(kHitEffectId, kHitEffectPath);
if (effectEngine->LoadEffect(kBulletEffectId) == nullptr || ...) {
    return false;                                                  // OnStart が false → 弾はすぐ削除
}
```

弾を撃つたびに `OnStart` で登録しますが、読み込まれるのは最初の1回だけです。番号は [EffectId.h](../../../Game/Source/Core/EffectId.h) にまとめています。

### 軌跡を残す：ルートだけを動かし、ルートだけを止める

```cpp
void IceBullet::OnMove()
{
    m_bulletEffect.SetPosition(GetPosition());
    m_bulletEffect.SetRotation(GetRotation());
    m_bulletEffect.SetScale(kEffectScale);
    m_bulletEffect.UpdateRoot();      // 全体ではなくルートだけ。出たパーティクルはその場に残る
}

void IceBullet::OnExplode(const Vector3& hitPosition)
{
    m_bulletEffect.StopRoot();        // 弾本体だけ消し、軌跡は寿命まで残す
    m_hitEffect.Play();
    m_hitEffect.SetPosition(hitPosition);
    ...
}

bool IceBullet::IsVanishFinished() const
{
    return !m_bulletEffect.IsPlay() && !m_hitEffect.IsPlay();   // 両方消えたら弾を削除
}
```

`Effect` のデストラクタは再生を止めないので、`IceBullet` のデストラクタで明示的に `Stop()` しています。

### 当てる：相手の状態異常を呼ぶだけ

```cpp
void IceBullet::OnHitTarget(HitTarget& target, const Vector3& hitPosition)
{
    if (StatusEffects* statusEffects = target.GetStatusEffects()) {
        statusEffects->Freeze(kFreezeSeconds);
    }
}
```

## 4. 使い方

### 氷魔法を手本に、単発の魔法を作る

1. 弾を作る（`BulletBase` を継承。[魔法と弾の設計](魔法と弾の設計.md) 6章）。
2. 魔法を作る（`MagicBase` を継承）。3章の `IceMagic::OnPress` と同じ形で、生成する弾だけを変える。
3. キャラクターの `Start()` で `m_magicCaster.AddMagic(std::make_unique<ThunderMagic>());`。

弾の名前を `BulletBase::kObjectName` にしておくと、ゲーム終了時にまとめて削除されます。

## 5. 調整用の数値

| 内容 | 値 | 場所 |
|---|---|---|
| 連射間隔 | 0.35秒 | `IceMagic` のコンストラクタ引数 |
| 弾の速さ / 射程 / 半径 | 1500 / 2000 / 10 | `IceBullet.cpp` の `MakeSettings` |
| 凍結時間 | 2.5秒 | `IceBullet.cpp` の `kFreezeSeconds` |

# 氷魔法の設計

作成日: 2026-11-05（`キャラクター入力・魔法・弾の設計.md` から分割。2026-11-14 に氷の弾を氷魔法にまとめた）
対象: `Game/Source/Magic/IceMagic.*`
経緯: [魔法の経緯](魔法の経緯.md)
手順: [氷魔法の手順](氷魔法の手順.md)（何もない状態から、どのファイルに何を足すか）

左クリック（パッドの Y）で撃つ、当たった相手を凍らせる魔法です。Player は枠0に登録しています。
魔法の共通の仕組みは [魔法の設計](魔法の設計.md) を見てください。

- **押した瞬間に飛び出す。** 溜めないので、溜め撃ちの関数は書かない。
- **見た目と効果だけを書く。** 飛ぶ・当たる・消えるは `MagicBase` に任せる。

---

## 1. 上書きする関数

コード: [IceMagic.h](../../../Game/Source/Magic/IceMagic.h)、[IceMagic.cpp](../../../Game/Source/Magic/IceMagic.cpp)

| 関数 | やっていること |
|---|---|
| `OnStart` | `ice_fly.efk` と `ice_hit.efk` を読み込み、飛んでいる氷のエフェクトを再生する |
| `OnMove` | エフェクトのルートだけを動かす（軌跡は発生した場所に残る） |
| `OnHitTarget` | 相手の `StatusEffects` を凍らせる（[状態異常の設計](../キャラクター/状態異常の設計.md)） |
| `OnExplode` | 飛んでいる氷を消し、着弾エフェクトを再生する |
| `IsVanishFinished` | 軌跡と着弾エフェクトが両方消えたか |

クールダウンは `IceMagic::COOLDOWN` に書き、`MagicCaster::Register<IceMagic>()` が読みます。

---

## 2. 実装方法

### エフェクト：番号で登録し、読み込みは1回だけ

```cpp
effectEngine->ResistEffect(FLY_EFFECT_ID, FLY_EFFECT_PATH);   // 登録済みの番号は無視される
effectEngine->ResistEffect(HIT_EFFECT_ID, HIT_EFFECT_PATH);
if (effectEngine->LoadEffect(FLY_EFFECT_ID) == nullptr || ...) {
    return false;                                            // OnStart が false → すぐ削除
}
```

撃つたびに `OnStart` で登録しますが、読み込まれるのは最初の1回だけです。番号は [EffectId.h](../../../Game/Source/Core/EffectId.h) にまとめています。

### 軌跡を残す：ルートだけを動かし、ルートだけを止める

```cpp
void IceMagic::OnMove()
{
    m_flyEffect.SetPosition(GetPosition());
    m_flyEffect.SetRotation(GetRotation());
    m_flyEffect.SetScale(EFFECT_SCALE);
    m_flyEffect.UpdateRoot();      // 全体ではなくルートだけ。出たパーティクルはその場に残る
}

void IceMagic::OnExplode(const Vector3& hitPosition)
{
    m_flyEffect.StopRoot();        // 飛んでいる氷だけ消し、軌跡は寿命まで残す
    m_hitEffect.Play();
    m_hitEffect.SetPosition(hitPosition);
    ...
}

bool IceMagic::IsVanishFinished() const
{
    return !m_flyEffect.IsPlay() && !m_hitEffect.IsPlay();   // 両方消えたら削除
}
```

`Effect` のデストラクタは再生を止めないので、`IceMagic` のデストラクタで明示的に `Stop()` しています。

### 当てる：相手の状態異常を呼ぶだけ

```cpp
void IceMagic::OnHitTarget(HitTarget& target, const Vector3& hitPosition)
{
    if (StatusEffects* statusEffects = target.GetStatusEffects()) {
        statusEffects->Freeze(FREEZE_SECONDS);
    }
}
```

## 3. 使い方（氷魔法を手本に、押してすぐ撃つ魔法を作る）

1. `MagicBase` を継承し、`COOLDOWN` と性能（`MakeSettings`）を書く。
2. 1章の表の関数を、新しい見た目と効果で書く。
3. キャラクターの `OnStart()` で `m_magicCaster.Register<ThunderMagic>(0);`。

---

## 4. 調整用の数値

| 内容 | 値 | 場所 |
|---|---|---|
| 連射間隔 | 0.35秒 | `IceMagic.h` の `COOLDOWN` |
| 速さ / 射程 / 半径 | 1500 / 2000 / 10 | `IceMagic.cpp` の `MakeSettings` |
| 凍結時間 | 2.5秒 | `IceMagic.cpp` の `FREEZE_SECONDS` |

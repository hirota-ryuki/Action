# 氷魔法の手順

設計: [氷魔法の設計](氷魔法の設計.md)
経緯: [魔法の経緯](../魔法の経緯.md)

押した瞬間に氷が飛び出し、当たった相手を凍らせる氷魔法を作るまでの手順です。

**出来上がるもの:** 左クリック（パッドは Y）で氷が飛び、当たった相手が 2.5秒凍ります。Enemy も同じ氷魔法を持ちます（AI が撃つかどうかは [NPCのAIの手順](../../キャラクター/NPCのAI/NPCのAIの手順.md) の設定による）。

**前提:**

- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [魔法の手順](../魔法の手順.md) を済ませておく（順番は [README の「ゲームを作る順番」](../../../README.md#ゲームを作る順番)）。凍らせるのは [状態異常の手順](../../キャラクター/状態異常/状態異常の手順.md) で作った `StatusEffects::Freeze()`。
- エフェクト `Assets/effect/ice_fly.efk`・`ice_hit.efk` は、リポジトリにもとからある。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | エフェクトの番号をまとめる `EffectId` | ビルドが通る |
| 2 | 氷魔法 `IceMagic` | ビルドが通る |
| 3 | Player と Enemy に氷魔法を登録する | 撃てて、当たると凍る |

**読み方:**

- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- コードの下に、3つを置きます。
  - 「行・何をしているか」の表: 1行ずつの動き。
  - 「なぜ」「効果」: その小手順でそう書く理由と、書くと何ができるようになるか。
  - 「初めて出てくる名前」の表: このページで初めて出てくる変数・引数・関数・型・マクロ・C++ の書き方を、コードに出てくる順に並べます。2回目からは載せないので、わからない名前はページ内検索（`Ctrl+F`）で最初に出てきた所を探してください。「どこから来たもの」で、このゲームで作ったもの・エンジン（k2Engine）の機能・C++ の標準ライブラリ・C++ の書き方のどれかがわかります。
- [前提知識](../../../前提知識.md) で「よく知っている」にあるもの（クラス・継承・ポインター・テンプレート・`std::unique_ptr`・`K2_ASSERT`・`nullptr` など）は、表に載せません。「まあまあ」「怪しい」「微妙」にあるもの（`std::make_unique`・`std::move` など）は載せます。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

## 手順1: エフェクトの番号をまとめる EffectId を作る

エンジンの `EffectEngine` は、エフェクトを番号で登録します。番号はゲーム全体で共有され、登録済みの番号にもう一度登録しても黙って無視されるので、番号が重ならないように1か所にまとめます。

|---|---|
| [EffectId.h](../../../../Game/Source/Core/EffectId.h) | 新しく作る（エフェクトの番号） |

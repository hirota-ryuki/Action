# 氷魔法の設計

作成日: 2026-11-05（`キャラクター入力・魔法・弾の設計.md` から分割。2026-11-14 に氷の弾を氷魔法にまとめた）
対象: `Game/Source/Magic/IceMagic.*`
経緯: [魔法の経緯](../魔法の経緯.md)
手順: [氷魔法の手順](氷魔法の手順.md)（何もない状態から、どのファイルに何を足すか）

左クリック（パッドの Y）で撃つ、当たった相手を凍らせる魔法です。Player は `ActionButton::Action1` に登録しています。
魔法の共通の仕組みは [魔法の設計](../魔法の設計.md) を見てください。

- **押した瞬間に飛び出す。** 溜めないので、溜め撃ちの関数は書かない。
- **見た目と効果だけを書く。** 飛ぶ・当たる・消えるは `MagicBase` に任せる。

| 用語 | 何のことか |
|---|---|
| `.efk` | Effekseer のエフェクトのファイル。Effekseer のエディターで作る |
| パーティクル | エフェクトを作る、たくさんの小さな粒（板や光）。1つずつ、出てから消えるまでの寿命がある |
| エフェクトのルート | エフェクトの発生源。ルートが動くと、そこから新しく出るパーティクルの位置が動くが、すでに出たパーティクルはその場に残る |
| 軌跡 | 飛んでいった通り道に残る、氷の粒の跡 |

炎魔法・燃える床のページは、この表の用語を使います。

---

## 1. 上書きする関数

コード: [IceMagic.h](../../../../Game/Source/Magic/IceMagic.h)、[IceMagic.cpp](../../../../Game/Source/Magic/IceMagic.cpp)

| 関数 | やっていること |
|---|---|
| `OnStart` | `ice_fly.efk` と `ice_hit.efk` を読み込み、飛んでいる氷のエフェクトを再生する |
| `OnMove` | エフェクトのルートだけを動かす（軌跡は発生した場所に残る） |
| `OnHitTarget` | 相手の `StatusEffects` を凍らせる（[状態異常の設計](../../キャラクター/状態異常/状態異常の設計.md)） |
| `OnExplode` | 飛んでいる氷を消し、着弾エフェクトを再生する |
| `IsVanishFinished` | 軌跡と着弾エフェクトが両方消えたか |

連射間隔（クールダウン）は `magic.json` の `ice.cooldown` にあり、`Player.cpp` が `SkillController::Register<IceMagic>(ボタン, 間隔)` に渡します（[スキルの設計](../../スキル/スキルの設計.md)、[魔法の調整値の設計](../魔法の調整値/魔法の調整値の設計.md)）。

## 2. 実装方法

### エフェクト：番号で登録し、読み込みは1回だけ

```cpp
effectEngine->ResistEffect(FLY_EFFECT_ID, FLY_EFFECT_PATH);   // 登録済みの番号は無視される
effectEngine->ResistEffect(HIT_EFFECT_ID, HIT_EFFECT_PATH);
if (effectEngine->LoadEffect(FLY_EFFECT_ID) == nullptr || ...) {
    return false;                                            // OnStart が false → すぐ削除
}
```

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 型 | `EffectEngine` | エフェクトの登録・読み込み・再生をまとめて受け持つため | `GetInstance()` で1つだけ取り出して使う | k2EngineLow（エンジン）の [EffectEngine.h](../../../../k2EngineLow/graphics/effect/EffectEngine.h) |
| 変数 | `effectEngine` | `EffectEngine` を呼ぶために持つため | `EffectEngine::GetInstance()` で取り出したポインター | ゲームの [IceMagic.cpp](../../../../Game/Source/Magic/IceMagic.cpp) の `OnStart()` |
| 関数 | `ResistEffect()` | 番号とエフェクトのファイルを結びつけて、読み込むため | 名前はエンジン側の綴りで、Register（登録）の意味。番号とファイルのパスを受け取り、その番号が登録されていなければ読み込む。登録済みなら何もしない | k2EngineLow（エンジン）の [EffectEngine.h](../../../../k2EngineLow/graphics/effect/EffectEngine.h) の `EffectEngine` |
| 値 | `FLY_EFFECT_ID`・`HIT_EFFECT_ID` | 飛んでいる氷・着弾のエフェクトを番号で指すため | `EffectId::IceFly`・`IceHit` を `int` にした番号 | ゲームの `IceMagic.cpp`（`EffectId` は [EffectId.h](../../../../Game/Source/Core/EffectId.h)） |
| 値 | `FLY_EFFECT_PATH`・`HIT_EFFECT_PATH` | 読み込むエフェクトのファイルを指すため | `Assets/effect/ice_fly.efk`・`ice_hit.efk` のパス（`char16_t` の文字列） | ゲームの `IceMagic.cpp` |
| 関数 | `LoadEffect()` | 登録した番号のエフェクトを取り出すため | 登録済みの番号のエフェクトを返す。読み込めていなければ空（`nullptr`）が返る。登録していない番号なら、プログラムを止める | k2EngineLow（エンジン）の [EffectEngine.h](../../../../k2EngineLow/graphics/effect/EffectEngine.h) の `EffectEngine` |

撃つたびに `OnStart` で登録しますが、読み込まれるのは最初の1回だけです。番号は [EffectId.h](../../../../Game/Source/Core/EffectId.h) にまとめています。

### 軌跡を残す：ルートだけを動かし、ルートだけを止める

```cpp
void IceMagic::OnMove()
{
    m_flyEffect.SetPosition(GetPosition());
    m_flyEffect.SetRotation(GetRotation());
    m_flyEffect.SetScale(EFFECT_SCALE);
    m_flyEffect.UpdateRoot();      // 全体ではなくルートだけ。出たパーティクルはその場に残る
}

void IceMagic::OnExplode(const Vector3& hitPosition)
{
    m_flyEffect.StopRoot();        // 飛んでいる氷だけ消し、軌跡は寿命まで残す
    m_hitEffect.Play();
    m_hitEffect.SetPosition(hitPosition);
    ...
}

bool IceMagic::IsVanishFinished() const
{
    return !m_flyEffect.IsPlay() && !m_hitEffect.IsPlay();   // 両方消えたら削除
}
```

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 型 | `Effect` | 1つのエフェクトを、位置・回転・大きさつきで再生するため | `Init()` で番号を渡し、`Play()` で再生を始め、位置などを設定して `Update()`（または `UpdateRoot()`）で反映する | k2EngineLow（エンジン）の [Effect.h](../../../../k2EngineLow/graphics/effect/Effect.h) |
| メンバー変数 | `m_flyEffect`・`m_hitEffect` | 飛んでいる氷・着弾のエフェクトを持つため | どちらも `Effect` | ゲームの [IceMagic.h](../../../../Game/Source/Magic/IceMagic.h) の `IceMagic` |
| 関数 | `SetPosition()`・`SetRotation()`・`SetScale()` | エフェクトの位置・回転・大きさを決めるため | 値を覚えるだけ。再生中のエフェクトへは、`Update()` か `UpdateRoot()` で反映される | k2EngineLow（エンジン）の [Effect.h](../../../../k2EngineLow/graphics/effect/Effect.h) の `Effect` |
| 関数 | `GetPosition()`・`GetRotation()` | 魔法の今の位置と回転を、エフェクトに合わせるため | `SkillBase` が持つ位置と、向きから作った回転を返す | ゲームの [SkillBase.h](../../../../Game/Source/Skill/SkillBase.h) の `SkillBase` |
| 値 | `EFFECT_SCALE` | エフェクトを大きくするため | `{ 10, 10, 10 }`。Effekseer の 1 単位を、ワールドの 10 単位にする | ゲームの `IceMagic.cpp` |
| 関数 | `UpdateRoot()` | 軌跡を残しながら、エフェクトを動かすため | ルートの位置・回転・大きさだけを反映する。出たパーティクルは動かない | k2EngineLow（エンジン）の [Effect.h](../../../../k2EngineLow/graphics/effect/Effect.h) の `Effect` |
| 関数 | `StopRoot()` | 飛んでいる氷だけを消すため | ルートだけを止める。新しい発生は止まり、出たパーティクルは寿命まで残る | k2EngineLow（エンジン）の [Effect.h](../../../../k2EngineLow/graphics/effect/Effect.h) の `Effect` |
| 関数 | `Play()` | エフェクトを再生するため | エフェクトの再生を始める | k2EngineLow（エンジン）の [Effect.h](../../../../k2EngineLow/graphics/effect/Effect.h) の `Effect` |
| 関数 | `IsPlay()` | エフェクトがまだ残っているかを調べるため | 再生中なら true を返す。ルートを止めたあとも、パーティクルが残っていれば true | k2EngineLow（エンジン）の [Effect.h](../../../../k2EngineLow/graphics/effect/Effect.h) の `Effect` |

`Effect` のデストラクタは何もしません（[Effect.cpp](../../../../k2EngineLow/graphics/effect/Effect.cpp)）。止めないと、魔法が消えたあともエフェクトの再生が `EffectEngine` に残るので、`IceMagic` のデストラクタで `Stop()` します。普通は両方の再生が終わってから消えるので、何も起きません。

### 当てる：相手の状態異常を呼ぶだけ

```cpp
void IceMagic::OnHitTarget(HitTarget& target, const Vector3& hitPosition)
{
    if (StatusEffects* statusEffects = target.GetStatusEffects()) {
        statusEffects->Freeze(MagicConfig::GetIce().freezeSeconds);
    }
}
```

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 型 | `HitTarget` | 当てられる側の当たり判定を表すため | 引数 `target` は、当たった相手の `HitTarget` | ゲームの [HitTarget.h](../../../../Game/Source/Character/Components/HitTarget.h) |
| 型 | `StatusEffects` | 凍結・燃焼の状態異常を持つため | 凍らせる `Freeze()`、燃やす `Burn()` などを持つ | ゲームの [StatusEffects.h](../../../../Game/Source/Character/Components/StatusEffects.h) |
| 関数 | `GetStatusEffects()` | 当たった相手の状態異常の部品を取り出すため | `StatusEffects` へのポインターを返す。状態異常を受けない相手なら `nullptr` | ゲームの `HitTarget.h` の `HitTarget` |
| 関数 | `Freeze()` | 相手を凍らせるため | 秒数を受け取り、その間凍らせる。凍結中に再度呼ぶと、残り時間の長い方になる | ゲームの `StatusEffects.h` の `StatusEffects` |
| 関数 | `MagicConfig::GetIce()` | 凍らせる時間などの調整値を取り出すため | `IceMagicConfig` を返す。凍らせる時間（`freezeSeconds`）は 2.5 秒（`magic.json` の `ice.freezeSeconds`） | ゲームの [MagicConfig.h](../../../../Game/Source/Magic/MagicConfig.h)（[魔法の調整値の設計](../魔法の調整値/魔法の調整値の設計.md)） |

## 3. 使い方（氷魔法を手本に、押してすぐ撃つ魔法を作る）

1. `MagicBase` を継承する。連射間隔と性能（速さ・射程・半径）は `magic.json` に足し、コンストラクターは `MagicBase(MagicConfig::GetXxx().settings)` を呼ぶ（[魔法の調整値の設計](../魔法の調整値/魔法の調整値の設計.md) の「新しい魔法の値を足す」）。
2. 1章の表の関数を、新しい見た目と効果で書く。
3. キャラクターの `OnStart()` で、使うボタンに登録する（[魔法の設計](../魔法の設計.md) の「4. 使い方」）。

## 4. 調整用の数値

値は [magic.json](../../../../Game/Assets/data/magic.json) の `ice` の段にあります（[魔法の調整値の設計](../魔法の調整値/魔法の調整値の設計.md)）。

| 内容 | 値 | 場所（`magic.json`） |
|---|---|---|
| 連射間隔 | 0.35秒 | `ice.cooldown` |
| 速さ / 射程 / 半径 | 1500 / 2000 / 10 | `ice.speed` / `ice.range` / `ice.radius` |
| 凍結時間 | 2.5秒 | `ice.freezeSeconds` |

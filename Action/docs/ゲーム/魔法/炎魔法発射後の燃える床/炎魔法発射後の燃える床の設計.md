# 炎魔法発射後の燃える床の設計

手順: [炎魔法発射後の燃える床の手順](炎魔法発射後の燃える床の手順.md)（何もない状態から、どのファイルに何を足すか）

炎魔法が着弾したところの床がしばらく燃え、そこに入った敵を燃焼状態にするしくみです。以下、炎魔法発射後の燃える床を「燃える床」と書きます。

- **炎魔法とは別のゲームオブジェクト。** 炎魔法が消えたあとも残る。
- **相手はクラスでなく陣営で選ぶ。** 撃った本人と陣営を受け取る。
- **同時に燃えるのは3枚まで。** 連射で床が重なって描くのが重くならないようにする。

| 用語 | 何のことか |
|---|---|
| ease-out | [用語集の「動きを近づける」](../../../用語集.md#動きを近づける) |
| `StopRoot`・Vanishing | [氷魔法の設計](../氷魔法/氷魔法の設計.md)（ルートだけを止める）・[魔法の設計](../魔法の設計.md)（消える演出中の状態） |

## 全体像

```mermaid
flowchart LR
    A[炎魔法が着弾] --> B[床にできる]
    B --> C[半径が広がる<br/>0.4秒]
    C --> D[敵を燃やす<br/>床の上にいる間]
    D -->|4秒たつ、または<br/>新しい床で4枚目になる| E[炎を止めて消える]
```

横から見ると、床の位置を基準にした高さの帯と、その中の床の今の半径の円で相手を調べます。

```
        ↑ BURN_HEIGHT（上150）
 ───────┼──────────────────  帯の上端
  相手  │   ○ 足元がこの帯の中にあれば対象
 ───────●──────────────────  床（m_position）  ←→ 床の今の半径（+ 相手の半径の半分）
        │
 ───────┼──────────────────  帯の下端
        ↓ BURN_DEPTH（下50）
```

## 1. 燃やす相手

次の相手を毎フレーム燃やす（`StatusEffects::Burn`）。
- 撃った本人ではない
- 敵対している（[陣営と当たり判定の設計](../../キャラクター/陣営と当たり判定/陣営と当たり判定の設計.md)）
- 足元が、床の今の半径の円の中にある（判定は、相手の半径の半分を足した半径で行う）
- 足元の高さが、床から下50〜上150の間にある（ジャンプで飛び越えられる）

円から出ても、燃焼は1.5秒続く。燃焼の見た目は [状態異常の設計](../../キャラクター/状態異常/状態異常の設計.md)。

## 2. 実装方法

### 燃え広がり：最初に速く、だんだんゆっくり（ease-out）

```cpp
float BurningGround::GetCurrentRadius() const
{
    if (m_elapsed >= SPREAD_SECONDS) { return m_radius; }
    const float t = m_elapsed / SPREAD_SECONDS;
    const float easeOut = 1.0f - (1.0f - t) * (1.0f - t);
    return m_radius * (SPREAD_START_RATE + (1.0f - SPREAD_START_RATE) * easeOut);   // 10% → 100%
}
```

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 関数 | `BurningGround::GetCurrentRadius()` | 今燃えている範囲の半径を出すため | 燃え広がっている途中は `m_radius` より小さい値、広がり終わったら `m_radius` を返す | ゲームの [BurningGround.cpp](../../../../Game/Source/Magic/BurningGround.cpp)（[BurningGround.h](../../../../Game/Source/Magic/BurningGround.h)） |
| メンバー変数 | `m_elapsed` | 燃え始めてからの秒数を持つため | 毎フレーム、1フレームの経過時間を足していく | ゲームの `BurningGround.h` の `BurningGround` |
| 値 | `SPREAD_SECONDS` | 燃え広がる時間を決めるため | 中心から最大の広さまで広がる秒数（0.4 秒） | ゲームの `BurningGround.cpp` |
| メンバー変数 | `m_radius` | 最大の半径を持つため | `Init()` で受け取った、燃える範囲の半径 | ゲームの `BurningGround.h` の `BurningGround` |
| 変数 | `t` | 広がりの進み具合を持つため | 0（燃え始め）〜1（広がり終わり）の割合 | ゲームの `BurningGround.cpp` の `GetCurrentRadius()` |
| 変数 | `easeOut` | 最初に速く、だんだんゆっくりの割合にするため | `1 - (1 - t)²`。`t` が 0.5 のとき 0.75 になる | ゲームの `BurningGround.cpp` の `GetCurrentRadius()` |
| 値 | `SPREAD_START_RATE` | 燃え始めの広さを決めるため | 最大に対する割合（0.1）。燃え始めは最大の 10% から始まる | ゲームの `BurningGround.cpp` |

広がっている間は、エフェクトの大きさも毎フレーム合わせます（エフェクトは半径10の円なので `半径 / 10` 倍）。

### 相手を調べる：高さの帯と、水平な円

```cpp
for (HitTarget* target : HitTargetRegistry::GetTargets()) {
    // 撃った本人・敵対していない相手・状態異常を受けない相手は飛ばす
    const float height = foot.y - m_position.y;
    if (height < -BURN_DEPTH || height > BURN_HEIGHT) { continue; }   // 床の下50〜上150
    const float range = GetCurrentRadius() + target->GetRadius() * TARGET_RADIUS_RATE;
    if (dx * dx + dz * dz > range * range) { continue; }               // XZ の円
    statusEffects->Burn(BURN_SECONDS);
}
```

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 型 | `HitTargetRegistry` | 当てられる相手を、クラスを知らずに探すため | 登録されている `HitTarget` の一覧を持つ。`GetTargets()` で全部取り出せる | ゲームの [HitTarget.h](../../../../Game/Source/Character/Components/HitTarget.h) |
| 型 | `HitTarget` | 当てられる側の当たり判定を表すため | キャラクターが持つ。足元の位置・半径・陣営・状態異常（`StatusEffects`）を持つ。変数 `target` は、その1つへのポインター | ゲームの `HitTarget.h` |
| 変数 | `foot` | 相手の足元の位置を持つため | `target->GetFootPosition()` の値 | ゲームの `BurningGround.cpp` の `BurnTargetsInRange()` |
| 変数 | `height` | 床から見た、相手の足元の高さを持つため | `foot.y - m_position.y`。床より下なら負になる | ゲームの `BurningGround.cpp` の `BurnTargetsInRange()` |
| 値 | `BURN_DEPTH`・`BURN_HEIGHT` | 燃やす高さの範囲を決めるため | 床の下 50 まで、上 150 まで（ジャンプで飛び越えられる） | ゲームの `BurningGround.cpp` |
| メンバー変数 | `m_position` | 床の位置を持つため | `Init()` で受け取った位置 | ゲームの `BurningGround.h` の `BurningGround` |
| 変数 | `range` | 円の判定に使う、水平の半径を持つため | 床の今の半径（`GetCurrentRadius()`）に、相手の半径の半分を足した値 | ゲームの `BurningGround.cpp` の `BurnTargetsInRange()` |
| 関数 | `GetRadius()` | 相手の当たり判定の半径を読むため | 当たり判定の球の半径を返す | ゲームの `HitTarget.h` の `HitTarget` |
| 値 | `TARGET_RADIUS_RATE` | 相手の大きさを、どれだけ範囲に足すかを決めるため | 相手の半径のうち、足す割合（0.5） | ゲームの `BurningGround.cpp` |
| 変数 | `dx`・`dz` | 床と相手の足元の、水平の差を持つため | x と z の差。`dx² + dz²` と `range²` を比べて、円の中かを調べる | ゲームの `BurningGround.cpp` の `BurnTargetsInRange()` |
| 変数 | `statusEffects` | 相手の状態異常の部品を持つため | `StatusEffects` へのポインター | ゲームの `BurningGround.cpp` の `BurnTargetsInRange()`（型は [StatusEffects.h](../../../../Game/Source/Character/Components/StatusEffects.h)） |
| 関数 | `Burn()` | 相手を燃やすため | 秒数を受け取り、その間燃やす。燃焼中に再度呼ぶと、残り時間の長い方になる。凍っていれば解凍する | ゲームの `StatusEffects.h` の `StatusEffects` |
| 値 | `BURN_SECONDS` | 燃やす時間を決めるため | 1.5 秒。範囲から出ても、この時間は燃え続ける | ゲームの `BurningGround.cpp` |

燃えている時間が過ぎたら、炎の発生だけを止め（`StopRoot`）、出ている炎が消えるのを待ってから自分を削除します（Burning → Vanishing の2状態。2つとも上の用語の表を参照）。

### 同時に燃える床の数：燃え始めに、古い床から止める

床は4秒燃え、炎魔法は0.6秒ごとに撃てるので、連射すると7〜8枚が重なります。床1枚の炎の粒は約320あり、重なると描くのが重くなります。そこで、新しい床が `Start()` でエフェクトを再生したあとに、燃えている床を数えます。

```cpp
void BurningGround::LimitBurningCount()
{
    while (true) {
        int burningCount = 1;                 // 自分
        BurningGround* oldest = nullptr;
        QueryGOs<BurningGround>(OBJECT_NAME, [&](BurningGround* ground) {
            // 自分・Start() がまだの床・燃え終わった床は数えない
            if (ground == this || !ground->m_isValid || ground->m_state != EnState::Burning) { return true; }
            burningCount++;
            if (oldest == nullptr || ground->m_elapsed > oldest->m_elapsed) { oldest = ground; }
            return true;
        });
        if (burningCount <= MAX_BURNING_COUNT || oldest == nullptr) { return; }
        oldest->StopBurning();                // StopRoot して Vanishing にする
    }
}
```

**名前:**

| ジャンル | 名前 | 何のためのもの | 何をするためのもの | どこから来たもの |
|---|---|---|---|---|
| 関数 | `QueryGOs` | 燃える床を全部調べるため | 名前（`OBJECT_NAME`）が合うゲームオブジェクトごとに、渡した関数を呼ぶ | k2EngineLow（エンジン）の [GameObjectManager.h](../../../../k2EngineLow/gameObject/GameObjectManager.h) |
| 値 | `MAX_BURNING_COUNT` | 同時に燃える床の数を決めるため | 自分を入れて、この数（3）を超えないようにする | ゲームの `BurningGround.cpp` |
| 関数 | `StopBurning()` | 燃えている時間を待たずに炎を止めるため | `StopRoot` で炎の発生を止め、Vanishing にする。出ている炎は寿命まで残る | ゲームの `BurningGround.cpp` |
| メンバー変数 | `m_isValid` | エフェクトを再生したかを見るため | `Start()` でエフェクトを読み込めたら `true` | ゲームの `BurningGround.h` の `BurningGround` |

- **数えるのは燃え始めのときだけ。** 毎フレーム数えなくても、床が増えるのは燃え始めのときだけなので足りる。
- **`Start()` がまだの床は数えない。** エフェクトを再生する前に止めると、あとで再生された炎がいつまでも止まらない。その床は、自分の `Start()` で数を抑える。
- **止めるのは、いちばん長く燃えている床。** 今狙っている場所の床が残る。

## 3. 使い方（着弾後に残る効果を作る）

1. 魔法とは別のゲームオブジェクトを作り、魔法の `OnExplode` で `NewGO` する。撃った本人と陣営を渡す。
2. 相手を探すときは `HitTargetRegistry::GetTargets()` を使い、`IsHostile()` で敵対しているかを見る。
3. 名前を決めて（`BurningGround::OBJECT_NAME` のように）、[Game.cpp](../../../../Game/Source/Core/Game.cpp) のデストラクタでその名前のものを削除する。
4. エフェクトを使うなら、[EffectId.h](../../../../Game/Source/Core/EffectId.h) に番号を足す。

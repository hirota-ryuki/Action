# 魔法の調整値の手順

設計: [魔法の調整値の設計](魔法の調整値の設計.md)
経緯: [魔法と弾の経緯](魔法と弾の経緯.md)

氷魔法・炎魔法の強さ（間隔・弾の速さ・射程・半径・凍らせる秒数・燃える床の広さ）を `Assets/data/magic.json` から読み、Player も敵も同じ値で魔法を作れるようにする手順です。

**出来上がるもの:** `magic.json` の値を書き換えて起動し直すだけで、魔法の強さが変わる。魔法を持たせるときは `std::make_unique<IceMagic>(MagicSettings::GetIce())` のように値を渡して作るので、Player と敵で同じ強さになる。

**前提:**

- Visual Studio 2022 で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に [JSON読み込みの手順](../システム/JSON読み込みの手順.md)・[氷魔法の手順](氷魔法の手順.md)・[炎魔法の手順](炎魔法の手順.md)・[燃える床の手順](燃える床の手順.md) を済ませておく。この手順は、それらで作った定数を `magic.json` に移す。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | `magic.json` | （まだ読まない） |
| 2 | 値の入れ物 `MagicSettings.h` | ビルドが通る |
| 3 | `magic.json` を読む `MagicSettings.cpp` | ビルドが通る |
| 4 | 氷魔法が値を使う | 氷魔法が前と同じに動く |
| 5 | 炎魔法が値を使う | 炎魔法が前と同じに動く |

**読み方:**

- 新しいファイルは、少しずつ書き足していきます。
- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあと（書き換えたあと）の行番号です。右の枠のコードを、そのまま書きます。
- 書き換え・削除は、変える前の番号で示します。書き換えは「前」と「後」を並べます。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

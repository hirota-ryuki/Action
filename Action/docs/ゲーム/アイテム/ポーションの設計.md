# ポーションの設計

作成日: 2026-11-11
対象: [Potion.h](../../../Game/Source/Item/Potion.h)、[PlayerStatus.h](../../../Game/Source/Player/PlayerStatus.h)、[PlayerDrinkState.cpp](../../../Game/Source/Player/State/PlayerDrinkState.cpp)、[PlayerHud.cpp](../../../Game/Source/UI/Hud/PlayerHud.cpp)、[item.json](../../../Game/Assets/data/item.json)
手順: [ポーションの手順](ポーションの手順.md)（[アイテムの手順](アイテムの手順.md) のあと）
経緯: [アイテムの経緯](アイテムの経緯.md)

落ちているポーションを拾うと画面右下のストックが増え、R で1つ飲むと HP が回復するしくみです。ダークソウルのエスト瓶のように、飲むと少しの間すきができます。

- **ポーションの数は `PlayerStatus` が持つ。** 上限はなく、落ちて戻ったときもそのまま残る。
- **飲むのは `Drink` ステート。** 入った瞬間にまとめて回復し、そのあと硬直する。
- **右下の表示は `PlayerHud` が数を読むだけ。**

---

## 1. 全体像

```
Potion::OnPickUp ──→ PlayerStatus::AddPotion(1)
                         │ GetPotionCount()
                         ▼
                     PlayerHud（右下: 瓶の絵と「x3」）

R → CharacterInput.useItem
      ▼
PlayerGroundState::CheckTransition
  useItem を押した瞬間 ＆ 地面の上 ＆ CanDrink（1つ以上持っていて、HP が満タンでない）→ Drink

PlayerDrinkState
  Enter  : UsePotion() で1つ減らし、Heal(healAmount)
  Update : 歩く速さ × 0.5 で動ける。止まっていれば Idle、動いていれば Walk のクリップ
  0.6秒たったら → 入力に合わせて Idle / Walk / Run（足場がなければいつでも Air）
```

## 2. 硬直の間にできないこと

| 操作 | どう止めているか |
|---|---|
| ダッシュ・ジャンプ | `PlayerDrinkState::CheckTransition` が見ない |
| 魔法 | `Character::CanUseMagic()` を `Player` が上書きし、Drink の間は false を返す |
| アイテムを拾う | 拾うのは地上のステートだけ（[アイテムの設計](アイテムの設計.md)） |
| もう一度飲む | Drink の間は `useItem` を見ない |

凍結すると、どのステートからでも Frozen に移ります（[ステートマシンの設計](../キャラクター/ステートマシンの設計.md)）。回復は入った瞬間に済んでいるので、硬直の途中で凍っても回復は消えません。

## 3. 実装方法

### 数の持ち方

`PlayerStatus` に `int m_potionCount` を足しました。`UsePotion()` は持っていなければ false を返し、数を減らしません。始めの数は `Player::OnStart` で `item.json` の `potion.startCount` を入れます（`Character::Start` が HP を入れたあと）。`Player::Respawn` は `PlayerStatus` を触らないので、落ちて戻っても数はそのままです。

### 魔法を止める口

魔法は `Character::Update` の④で、ステートとは別に撃ちます。そこで、もとからある凍結の判定に `CanUseMagic()` を足しました。

```cpp
m_magicCaster.Update(m_input, m_mover.GetPosition(), m_mover.GetForward(), deltaTime,
	m_statusEffects.CanAct() && CanUseMagic());
```

`CanUseMagic()` の既定は true なので、Enemy は変わりません。

### 右下の表示

`PlayerHud::UpdatePotion` が、前のフレームの数より増えたら絵を 1.3倍にし、0.2秒で戻します（拾ったのがわかるように）。0個のときは絵と数を灰色にします。フォントに「×」がないので、数は `x3` と書きます。`Icon` に `SetScale` を足しました。

## 4. 使い方

| やりたいこと | 書き方 |
|---|---|
| 回復量・硬直を変える | `item.json` の `potion` の値を変える |
| 飲むアニメーションを当てる | `PlayerAnimClip` にクリップを足し、`PlayerDrinkState::Update` で Idle・Walk の代わりに流す |
| 別の回復アイテムを足す | `Item` を継承し、`OnPickUp` で `PlayerStatus` の別の数を増やす。飲むステートは種類ごとに足す |

## 5. 調整用の数値（item.json の potion）

| 値 | 今の値 | 意味 |
|---|---|---|
| `startCount` | 2 | ゲームを始めたときに持っている数 |
| `healAmount` | 30 | 1つで回復する HP（最大 HP は 100） |
| `drinkSeconds` | 0.6 | 飲んだあとの硬直の長さ（秒） |
| `drinkMoveSpeedRate` | 0.5 | 硬直の間に歩ける速さ（歩く速さに掛ける） |
| `modelPath` | `Assets/modelData/item/Potion/Potion.fbx` | Meshy で作った瓶 |
| `modelScale` | 0.5 | モデルの大きさ（もとの高さ 95） |
| `floatHeight` | 30 | 地面から瓶の真ん中までの高さ |

右下の位置・大きさは [PlayerHud.cpp](../../../Game/Source/UI/Hud/PlayerHud.cpp) の `POTION_*` の定数です。

## 6. 決めたこと

| 決めたこと | 理由 |
|---|---|
| 飲んだ瞬間にまとめて回復する | 数秒かけて回復する形より、わかりやすい |
| 上限なし、落ちて戻っても残す | ユーザーと決めた |
| 始めに2つ持つ | すぐ試せるように |
| R で飲む（パッドはまだ） | パッドの A・B・X・Y・LB・RB・RB2 はもう使っている |
| HP が満タンなら飲まない | 押し間違いで1つ減らさない |
| 飲むアニメーションは後回し | まず仕組みを作った。今は Idle・Walk のクリップを流している |

## 7. 既知の課題

- 飲むアニメーションがない。
- 太陽が奥から当たるので、カメラから見える瓶の面は影の側になり、トゥーンの影の色で暗い紫に見える（[アイテムの経緯](アイテムの経緯.md)）。
- 敵はポーションを持たない。

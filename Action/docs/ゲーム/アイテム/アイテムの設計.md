# アイテムの設計

作成日: 2026-11-11
対象: [Item.h](../../../Game/Source/Item/Item.h)、[ItemManager.h](../../../Game/Source/Item/ItemManager.h)、[ItemConfig.cpp](../../../Game/Source/Item/ItemConfig.cpp)、[ItemPicker.h](../../../Game/Source/Player/ItemPicker.h)、[PlayerGroundState.cpp](../../../Game/Source/Player/State/PlayerGroundState.cpp)、[PickupHud.cpp](../../../Game/Source/UI/Hud/PickupHud.cpp)、[item.json](../../../Game/Assets/data/item.json)
手順: [アイテムの手順](アイテムの手順.md)（何もない状態から、どのファイルに何を足すか）
経緯: [アイテムの経緯](アイテムの経緯.md)

ステージに落ちているアイテムに近づくと、画面の右に「拾えるもの」の一覧が出て、F で拾うしくみです。今あるアイテムは [ポーション](ポーションの設計.md) だけです。

- **アイテムは Actor → Item → Potion の継承。** 派生クラスは名前・絵・見た目・拾ったときの効き目だけを書く。
- **アイテムを置くのも消すのも `ItemManager` だけ。** 一覧を持つのもここだけにする。
- **拾うかどうかはプレイヤーのステートが決める。** アイテムも ItemManager も、いつ拾われるかを知らない。

---

## 1. 全体像

★はこの機能で足したクラス、無印はもとからあるクラスです。

```
Game
 ├─ Player
 │   ├─ PlayerStatus …………… ポーションの数（ポーションの設計）
 │   ├─ ★ ItemPicker ………… 拾える半径の中のアイテムを、近い順に並べた一覧
 │   └─ PlayerStateMachine
 │         PlayerGroundState（Idle / Walk / Run）… F で拾う（UpdatePickUp）
 ├─ ★ ItemManager（IGameObject）… Spawn<T> / FindInRange / PickUp
 │      └─ ★ Item（Actor）………… 回る・ゆれる・地面に合わせる
 │             └─ ★ Potion ……… 拾ったら数を1増やす
 └─ UIManager
     └─ ★ PickupHud ……………… 拾える一覧（ItemPicker を読むだけ）
```

| クラス | すること | しないこと |
|---|---|---|
| `ItemManager` | 置く・半径の中を探す・拾われたら効き目を呼んで消す | 拾うかどうか決める |
| `Item` | 見た目（回る・上下にゆれる）。名前・絵・効き目の入口 | 自分を消す |
| `ItemPicker` | 今どれが拾えるかを持つ。先頭を拾う口（`PickUpFirst`） | ボタンを見る |
| 地上のステート | F を見て、拾うかどうかを決める | アイテムを消す |
| `PickupHud` | `ItemPicker` の一覧を描く | 何かを変える |

## 2. 1フレームの流れ

```
Player::UpdateAction
  ① m_itemPicker.Update(足元)       … ItemManager::FindInRange で近い順に並べ直す
  ② m_stateMachine.Update
       PlayerGroundState::Update → UpdatePickUp
         F を押した瞬間       → picker->PickUpFirst(status)
         押し続けて 0.3秒たったら → 0.05秒ごとに PickUpFirst（まとめて拾う）
           └ ItemManager::PickUp(item, status)
               ├ item->OnPickUp(status)   … Potion なら AddPotion(1)
               └ 一覧から外して DeleteGO(item)
UIManager（優先度 3、キャラクターの後）
  PickupHud::Update … player->GetItemPicker().GetCandidates() を読んで描く
```

- 拾えるのは地上のステート（Idle・Walk・Run）だけです。Dash・Air・Stop・Frozen・Drink の間は F を見ません。一覧はそのまま出ます。
- 拾ったアイテムは、`PickUpFirst` が `ItemPicker` の一覧からもすぐ外します。同じフレームの UI が、消したアイテムを読むことはありません。

## 3. 実装方法

### アイテムの持ち方

`ItemManager` が `std::vector<Item*>` を持ちます。`Spawn<T>` は `NewGO<T>` してから一覧に入れるので、一覧の外にアイテムができることはありません。`~ItemManager` で残りを全部 `DeleteGO` するので、Game は ItemManager を消すだけで済みます。

```cpp
template <class T>
T* Spawn(const Vector3& position)
{
	T* item = NewGO<T>(ITEM_PRIORITY, ITEM_OBJECT_NAME);
	item->SetPosition(position);
	m_items.push_back(item);
	return item;
}
```

`Item` は `Start` で、置いた位置の上下2000の線を地面に当てて、地面の高さに合わせます（`SnapToGround`）。`item.json` に書く置き場所は `[x, z]` だけで済みます。

### 拾う判断をステートに置いた

押し続けた時間は、ステートではなく `PlayerStateContext` に持ちます（`pickupHoldSeconds`・`nextPickupSeconds`）。押しながら歩き出すと Idle → Walk とステートが入れ替わりますが、数え直さずに済みます。

拾えるものがない間は、次に拾う時間を今の時間まで進めておきます。押したまま遠くから近づいたときに、たまった分を一度に拾わないためです。

### 一覧の UI

`PickupHud` は5行分の部品（帯・絵・名前）を先に作っておき、候補の数だけ描きます。絵は、前と違う絵になったときだけ `Icon::Init` し直します。1行目の左に F の印（白い四角と「F」の文字）を付け、帯を明るくします。

## 4. 使い方

| やりたいこと | 書き方 |
|---|---|
| 新しいアイテムを作る | `Item` を継承し、`GetName`・`GetIconPath`・`OnPickUp`・`MakeLook` を書く（見本: `Potion`） |
| アイテムを置く | `itemManager->Spawn<Potion>(位置)`。敵が落とすなら敵の位置を渡す |
| 置き場所を変える | `item.json` の `potionSpawns` に `[x, z]` を足す |
| アイコンを作る | `blender -b --factory-startup --python tools/BlenderScripts/make_item_icon.py -- <fbx> <png>` で撮り、texconv で `Assets/sprite/item/` に DDS にする |

## 5. 調整用の数値（item.json）

| 値 | 今の値 | 意味 |
|---|---|---|
| `pickup.radius` | 150 | 足元からこの距離以内のアイテムを一覧に出す |
| `pickup.holdDelaySeconds` | 0.3 | F を押し続けて、まとめて拾い始めるまでの秒数 |
| `pickup.holdIntervalSeconds` | 0.05 | まとめて拾うときの間隔（秒）。0 以下ならまとめて拾わない |
| `look.floatAmplitude` | 5 | 上下にゆれる幅（片側） |
| `look.floatSeconds` | 2.0 | 上下にゆれる1往復の秒数 |
| `look.spinDegPerSecond` | 90 | 1秒に回る角度 |

一覧の位置・大きさ・行の数（5）は [PickupHud.cpp](../../../Game/Source/UI/Hud/PickupHud.cpp) の定数です。

## 6. 決めたこと

| 決めたこと | 理由 |
|---|---|
| 一覧は ItemManager だけが持つ（static の登録簿にしない） | 置くのも消すのも1か所にすると、消し忘れが起きない。敵が落とす形も `Spawn` を呼ぶだけで足せる |
| ItemManager は Game が作って `Player::SetItemManager` で渡す | `UIManager::SetPlayer` と同じ渡し方。`FindGO` で探さない |
| 候補の一覧を `ItemPicker` に分けた | ステート（拾う）と UI（描く）が同じ一覧を見る。ステートに持たせると UI がステートを知ることになる |
| 拾うのはいつも1行目（いちばん近いもの） | ホイールで選ぶ形も考えたが、F だけで済む方にした |
| 拾うときのアニメーションはない | ボタンを押すだけで拾う |

## 7. 既知の課題

- パッドの割り当てがまだない（F だけ）。
- キーは `GetAsyncKeyState` で読んでいるので、ほかのウィンドウを使っているときの F でも拾う（ほかのキーと同じ）。
- 拾える半径は足元からの距離（高さも含む）。段差の上のアイテムは近くても拾えないことがある。

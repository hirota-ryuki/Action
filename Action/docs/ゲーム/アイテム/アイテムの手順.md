# アイテムの手順

設計: [アイテムの設計](アイテムの設計.md)
経緯: [アイテムの経緯](アイテムの経緯.md)

落ちているアイテム（基底クラス `Item` と、その1つ目の `Potion`）を `ItemManager` が置き、プレイヤーが近づくと拾える一覧が出て、F で拾えるまでの手順です。拾ったポーションを飲むのは [ポーションの手順](ポーションの手順.md) で作ります。

**出来上がるもの:** 起動すると、プレイヤーの前にポーションが回りながら浮いています。近づくと画面の真ん中の右に「ポーション」の一覧が近い順に出て、F で1つ、F を押し続けると続けて拾えます。拾ったポーションの数は `PlayerStatus` に入りますが、まだ画面には出ません。

**前提:**

- Visual Studio で `Action/Game/Game.sln` を開き、構成は **Debug / x64** でビルドする。
- 先に、ゲームの手順書（[README の「ゲームを作る順番」](../../README.md#ゲームを作る順番) の 0〜23）を済ませておく。
- モデルは Meshy で作った瓶（zip）を使う。アイコンを作るのに Blender 5.1 を使う。

| 手順 | 足すもの | 確かめ方 |
|---|---|---|
| 1 | ポーションのモデルとアイコンを置く | `Action/Game/Assets/modelData/item/Potion/Potion.fbx` と、同じフォルダに PNG が4枚、`Action/Game/Assets/sprite/item/potion.dds` がある |
| 2 | 落ちているアイテムの基底クラス Item を作る | ソリューションのビルドが通る（`Item` はまだどこからも使わない） |
| 3 | アイテムの調整値 ItemConfig と item.json を作る | ソリューションのビルドが通る |
| 4 | ポーションの数と、Potion を作る | ソリューションのビルドが通る |
| 5 | アイテムをまとめて持つ ItemManager を作る | ソリューションのビルドが通る |
| 6 | Game で ItemManager を作り、ポーションを置く | 起動すると、プレイヤーの右前にポーションが3つ、左前に1つ、地面の少し上で回りながら上下にゆれている |
| 7 | 拾うボタン（F）を足す | ソリューションのビルドが通る（まだ誰も `interact` を見ない） |
| 8 | 拾う数値を item.json から読む | ソリューションのビルドが通る |
| 9 | 拾える候補の一覧 ItemPicker を作り、Player に持たせる | ソリューションのビルドが通る |
| 10 | 地上のステートで、F で拾う | 起動してポーションに近づき F を押すと、いちばん近いものが1つ消える |
| 11 | 拾える一覧を画面に出す PickupHud を作る | 起動してポーションに近づくと、画面の真ん中の右に「ポーション」の行が近い順に出て、1行目の左に F の印が付く |

**読み方:**

- 新しいファイルは、空のクラスから始めて少しずつ足します。
- 足す場所は「〇行目 `その行に書いてあること` の下」で示します。行番号は、それより前の小手順を済ませたときの番号です。
- 枠の左の数字は、足したあとの行番号です。右の枠のコードを、そのまま書きます。
- 書き換えるところは、「前」と「後」の枠を並べています。
- VSCode で `Ctrl+Shift+V` を押してプレビューで読みます。

## 手順1: ポーションのモデルとアイコンを置く

落ちているアイテムの見た目と、拾える一覧に出す絵を先に置きます。コードはまだ書きません。

**この手順で触るファイル:**

| ファイル | 何をするか |
|---|---|
| モデルとアイコン | モデル（`Assets/modelData/item/Potion/`）とアイコン（`Assets/sprite/item/potion.dds`）を置く |

### 1-1. モデルを置く

Meshy で作った瓶のモデル（FBX と PNG 4枚の zip）を使います。

<!-- copy: ../../../Game/Assets/modelData/item/Potion/Potion.fbx -->

1. `Action/Game/Assets/modelData/item/Potion/` フォルダーを作る。
2. Meshy から書き出した zip（`Meshy_AI_fantasy_potion_bottle_20261111_texture_fbx.zip`）の中身を、フォルダーを作らずにそこへ全部出す。
3. FBX だけ名前を `Potion.fbx` に変える。PNG（色・`_metallic`・`_normal`・`_roughness`）の名前は変えない（FBX の中に、元の名前で書いてあるため）。

`.tkm` と、色の画像の `.DDS` は、ゲームを初めて起動したときにエンジンが同じフォルダーに作ります（[モデル読み込みの設計](../../エンジン/モデル読み込みの設計.md)）。

### 1-2. アイコンを作る

拾える一覧と右下のストックに出す絵を、モデルを Blender で撮って作ります。撮るスクリプト [make_item_icon.py](../../../tools/BlenderScripts/make_item_icon.py) はリポジトリにあります。

<!-- copy: ../../../tools/BlenderScripts/make_item_icon.py -->

1. `Action/` で次を実行し、背景が透明な 256×256 の PNG を作る（Blender 5.1 で確かめた）。

   ```
   "C:/Program Files/Blender Foundation/Blender 5.1/blender.exe" -b --factory-startup --python tools/BlenderScripts/make_item_icon.py -- Game/Assets/modelData/item/Potion/Potion.fbx <作業用のフォルダー>/potion.png 256
   ```

2. 作業用のフォルダーで texconv を使い、DDS にする（ミップマップなし、sRGB にしない）。

   ```
   <Action>/tools/3dsMaxScripts/texconv.exe -nologo -f R8G8B8A8_UNORM -m 1 -y -o . potion.png
   ```

3. できた `potion.DDS` を `Action/Game/Assets/sprite/item/potion.dds`（小文字）に置く。

**確かめ方:** `Action/Game/Assets/modelData/item/Potion/Potion.fbx` と、同じフォルダに PNG が4枚、`Action/Game/Assets/sprite/item/potion.dds` がある。

void Item::SnapToGround()
{
	PhysicsWorld* physicsWorld = PhysicsWorld::GetInstance();
	if (physicsWorld == nullptr) {
		return;
	}
	const Vector3 up = { 0.0f, GROUND_RAY_LENGTH, 0.0f };
	Vector3 hitPosition;

void Item::Update()
{
	m_time += g_gameTime->GetFrameDeltaTime();

	float wave = 0.0f;
	if (m_look.floatSeconds > 0.0f) {
		wave = sinf(m_time / m_look.floatSeconds * 2.0f * PI);
	}
	Vector3 modelPosition = m_transform.position;
	modelPosition.y += m_look.floatHeight + m_look.floatAmplitude * wave;

	m_model.SetPosition(modelPosition);
	m_model.Update();

{
	PhysicsWorld* physicsWorld = PhysicsWorld::GetInstance();
	if (physicsWorld == nullptr) {
		return;
	}
	const Vector3 up = { 0.0f, GROUND_RAY_LENGTH, 0.0f };
	Vector3 hitPosition;
	if (physicsWorld->RayTest(m_transform.position + up, m_transform.position - up, hitPosition)) {
		m_transform.position = hitPosition;
	}
}

void Item::Update()
{
	m_time += g_gameTime->GetFrameDeltaTime();

	float wave = 0.0f;
	if (m_look.floatSeconds > 0.0f) {
		wave = sinf(m_time / m_look.floatSeconds * 2.0f * PI);

	Vector3 modelPosition = m_transform.position;
	modelPosition.y += m_look.floatHeight + m_look.floatAmplitude * wave;

	rotation.SetRotationDegY(fmodf(m_time * m_look.spinDegPerSecond, 360.0f));

	m_model.SetRotation(rotation);

// アイテムの調整値を Assets/data/item.json から読む。数値の意味は item.json の方に書いてある。
// ここに書いてある値は、JSON にキーがないときの既定値（item.json を作ったときと同じ値）。

namespace
{
	using Json = JsonFile::Json;

	constexpr const char* JSON_PATH = "item.json";

	const Json& GetJson()
	{
		static const Json json = JsonFile::Load(JSON_PATH);
		return json;
	}

	void Log(const std::string& message)
	{
		const std::string line = "[ItemConfig] " + message + "\n";
		OutputDebugStringA(line.c_str());
	}

	// 入れ子の1段（"pickup" など）を取り出す。ないときは空の {} を返すので、中のキーはどれも既定値になる。
	Json GetSection(const char* name)
	{
		const Json& json = GetJson();
		auto it = json.find(name);
		if (it == json.end() || !it->is_object()) {
			Log(std::string(JSON_PATH) + " に \"" + name + "\" がないので、既定値を使います。");
			return Json::object();
		}
		return *it;
	}

	// section の key を読む。ないとき・型が違うときは defaultValue を返し、出力ウィンドウに出す。
	template <class T>
	T Read(const Json& section, const char* sectionName, const char* key, T defaultValue)
	{
		auto it = section.find(key);
		if (it == section.end()) {
			Log(std::string(JSON_PATH) + " に " + sectionName + "." + key + " がないので、既定値を使います。");
			return defaultValue;
		}
		try {
			return it->get<T>();
		}
		catch (const nlohmann::json::exception&) {
			Log(std::string(JSON_PATH) + " の " + sectionName + "." + key + " の型が違うので、既定値を使います。");
			return defaultValue;
		}
	}
}

ItemLook ItemConfig::MakePotionLook()
{
	const Json look = GetSection("look");
	const Json potion = GetSection("potion");
	ItemLook result;
	result.modelPath = Read<std::string>(potion, "potion", "modelPath", "Assets/modelData/item/Potion/Potion.fbx");
	result.upAxis = enModelUpAxisY;  // Meshy の FBX は Y が上。
	result.modelScale = Read(potion, "potion", "modelScale", 0.5f);
	result.floatHeight = Read(potion, "potion", "floatHeight", 30.0f);
	result.floatAmplitude = Read(look, "look", "floatAmplitude", 5.0f);
	result.floatSeconds = Read(look, "look", "floatSeconds", 2.0f);

void ItemManager::FindInRange(const Vector3& position, float radius, std::vector<Item*>& out) const
{
	out.clear();
	const float radiusSq = radius * radius;
	for (Item* item : m_items) {
		const Vector3 diff = item->GetPosition() - position;
		if (diff.LengthSq() <= radiusSq) {
			out.push_back(item);
		}
	}
	std::sort(out.begin(), out.end(), [&position](const Item* a, const Item* b) {
		return (a->GetPosition() - position).LengthSq() < (b->GetPosition() - position).LengthSq();
	});
}

		return ROW_TOP - (ROW_HEIGHT + ROW_GAP) * static_cast<float>(index);
	}
}

void PickupHud::Init()
{
	for (int i = 0; i < MAX_ROWS; ++i) {
		Row& row = m_rows[i];
		const float y = RowCenterY(i);
		row.back.Init(UISprite::WHITE_PATH, ROW_WIDTH, ROW_HEIGHT);
		row.back.SetPosition({ ROW_LEFT + ROW_WIDTH * 0.5f, y });
		row.back.SetColor(i == 0 ? ROW_SELECTED_COLOR : ROW_COLOR);
		row.icon.SetPosition({ ROW_LEFT + ICON_LEFT + ICON_SIZE * 0.5f, y });
		row.name.SetPosition({ ROW_LEFT + NAME_LEFT, y });
		row.name.SetAlign(Text::Align::Left);
		row.name.SetScale(NAME_SCALE);
		row.name.SetColor(NAME_COLOR);
		row.name.SetShadow(NAME_SHADOW_OFFSET, NAME_SHADOW_COLOR);
	}

	const Vector2 keyPosition = { ROW_LEFT - KEY_GAP - KEY_SIZE * 0.5f, RowCenterY(0) };
	m_keyBack.Init(UISprite::WHITE_PATH, KEY_SIZE, KEY_SIZE);
	m_keyBack.SetPosition(keyPosition);
	m_keyBack.SetColor(KEY_BACK_COLOR);
	m_keyText.SetPosition(keyPosition);
	m_keyText.SetScale(KEY_TEXT_SCALE);
	m_keyText.SetColor(KEY_TEXT_COLOR);
	m_keyText.SetText(L"F");
}

void PickupHud::Update(float deltaTime)
{
	m_rowCount = 0;
	if (m_player != nullptr) {
		const std::vector<Item*>& candidates = m_player->GetItemPicker().GetCandidates();
		m_rowCount = min(static_cast<int>(candidates.size()), MAX_ROWS);
		for (int i = 0; i < m_rowCount; ++i) {
			Row& row = m_rows[i];
			const Item* item = candidates[i];
			if (row.iconPath != item->GetIconPath()) {
				row.iconPath = item->GetIconPath();
				row.icon.Init(row.iconPath.c_str(), ICON_SIZE, ICON_SIZE);
			}
			row.name.SetText(item->GetName());
		}
	}

	for (int i = 0; i < MAX_ROWS; ++i) {
		Row& row = m_rows[i];
		row.back.Update(deltaTime);
		row.name.Update(deltaTime);
		if (!row.iconPath.empty()) {
			row.icon.Update(deltaTime);
		}
	}
	m_keyBack.Update(deltaTime);
	m_keyText.Update(deltaTime);
}

void PickupHud::Draw(RenderContext& rc)
{
	if (m_rowCount <= 0) {
		return;
	}
	for (int i = 0; i < m_rowCount; ++i) {
		Row& row = m_rows[i];
		row.back.Draw(rc);
		row.icon.Draw(rc);
		row.name.Draw(rc);
	}
	m_keyBack.Draw(rc);
	m_keyText.Draw(rc);
}

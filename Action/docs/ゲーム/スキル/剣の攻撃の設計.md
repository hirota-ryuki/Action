# 剣の攻撃の設計

作成日: 2026-11-15
対象: `Game/Source/Attack/`（`AttackBase` と黒騎士の攻撃1〜3）、`SkillBase`・`SkillController` の攻撃のための変更、`EnemyAttackState`、`BlackKnightInputSource`（まだ実装していない。この設計のとおりに作る）
経緯: [剣の攻撃の経緯](剣の攻撃の経緯.md)

剣で斬る攻撃を、スキル（[スキルの設計](スキルの設計.md)）の派生 `AttackBase` にする設計です。黒騎士の攻撃1〜3を、`EnemyAttackState` から `AttackBase` の派生へ移します。

- **攻撃1回 = `AttackBase` の派生1つ。** 魔法と同じく、使うたびに `NewGO` し、振り終えたら消える。
- **体の動きは攻撃が全部受け持つ。** アニメーション・踏み込み・溜め・斬撃を出すのは攻撃で、`EnemyAttackState` は「攻撃が終わるまで待つ」だけにする。
- **攻撃の種類はボタンで分ける。** 攻撃1〜3 を `Action1`〜`Action3` に登録し、`attackIndex` はなくす。

---

## 1. 全体像

```
SkillBase
├─ MagicBase   … 飛んでいく1発（撃ったら持ち主から離れる）
└─ AttackBase  … 剣の1振り（振り終わるまで持ち主の体を使う）
    ├─ DashSlashAttack   攻撃1  溜めてから踏み込んで横に斬り抜ける
    ├─ HeavyComboAttack  攻撃2  その場で重い連続斬り
    └─ SlashWaveAttack   攻撃3  連続斬りで、斬撃（SlashMagic）を5つ飛ばす
```

| | MagicBase | AttackBase |
|---|---|---|
| 動くもの | 魔法が持ち主を離れて飛ぶ | 持ち主の体（アニメーション・踏み込み） |
| 作るもの | 魔法のモデルやエフェクト | 作らない（持ち主のモデルと移動の部品を借りる） |
| 当たり判定 | 魔法が自分で持つ | 剣の当たりはまだない。斬撃は `SlashMagic`（MagicBase）を作る |
| 終わるとき | 当たった・射程を飛び終えた | アニメーションを流し終えた |
| 持ち主との関係 | 撃ったら離れる | 振り終わるまで手が離せない |
| 中断されたとき | 溜めの途中だけ止まる | 振っている途中でも止まる |

| ボタン | 黒騎士が登録する攻撃 | AI が押すとき |
|---|---|---|
| `Action1` | `DashSlashAttack`（攻撃1） | 中くらいの距離 |
| `Action2` | `HeavyComboAttack`（攻撃2） | 近い |
| `Action3` | `SlashWaveAttack`（攻撃3） | 遠い |

`Action3` は `ActionButton` に新しく足します。Player は `Action3` を読まないので、押されることはありません。

## 2. 1回の攻撃の流れ

| フレーム | どこで | 何をする |
|---|---|---|
| N | `BlackKnightInputSource` | 距離に合わせて `Action1`〜`Action3` のどれかを1フレーム押す |
| N | `EnemyGroundState` | どれかのボタンが押された瞬間に `Attack` へ移る |
| N | `SkillController` | そのボタンの攻撃を `NewGO`（優先度0）し、`SetBody()` で体を渡す |
| N+1 | 攻撃（優先度0、キャラクターより先） | `OnStart` → `OnActivate`: 相手の方を向き、アニメーションを流す |
| N+1〜 | 攻撃の `OnSkillUpdate` | 溜め・踏み込み・斬撃。アニメーションが終わったら `End()` |
| 終わり | `SkillController` | `IsOwnerBusy()` が false になったので手を離す |
| 終わり | `EnemyAttackState` | `SkillController` が空いたので、入力に合わせて Idle / Move / Run へ |

- 黒騎士が死んだら、`EnemyAttackState` の `Exit` で `SkillController::CancelAll()` を呼び、振っている途中の攻撃を止める。
- 凍ったら、今までどおり `Character::UpdateSkill()` が `CancelAll()` を呼ぶ。
- 攻撃中に当たっても、今までどおりひるまない（`EnemyAttackState` が Hit へ移らない）。

## 3. 実装方法

### 体を渡す: SkillBody

攻撃は持ち主のモデルと移動の部品を動かすので、`SkillController` が作った直後に渡します。魔法は使いません。

```cpp
// SkillBase.h
struct SkillBody
{
    CharacterModel* model = nullptr;
    CharacterMover* mover = nullptr;
    float timeScale = 1.0f;       // 動き全体の速さ（黒騎士の PLAY_SPEED）。
    float rootMoveScale = 100.0f; // アニメーションの中で進む距離（モデルの m）をゲームの距離にする倍率。
    float blendSeconds = 0.2f;    // アニメーションを切り替えるときの補間時間。
};
```

`Enemy::OnStart()` が `m_skillController.SetBody(...)` で渡し、`SkillController` は作った攻撃に毎回 `SetBody()` します。体を渡していないキャラクター（Player）が攻撃を登録しても、`AttackBase::OnStart()` が false を返して何もしません。

### 振り終わるまで手を離さない（SkillBase の変更）

「手を離せないか」の判断は `SkillBase` に残し、派生は「体を使うスキルか」だけを答えます。

```cpp
// SkillBase
virtual bool UsesOwnerBody() const { return false; }   // AttackBase が true を返す

bool SkillBase::IsOwnerBusy() const
{
    if (m_isCanceled) { return false; }
    if (m_state == EnState::Charging) { return !m_isReleased; }
    return m_state == EnState::Active && UsesOwnerBody();   // 体を使うスキルは、使っている間ずっと
}
```

あわせて次の2つを直します。

- `ReceiveInput()`: 使っている間（Active）は、ボタンを見ずに撃つ位置と向きだけを合わせる。攻撃3の斬撃が、そのときの相手の方へ飛ぶように。
- `Update()`: 使っている間（Active）も `m_isCanceled` を見て、`OnCancel()` → `End()` する。

### 攻撃をキャラクターより先に動かす

`SkillBase` に `static constexpr int PRIORITY = 1;` を置き、`AttackBase` は 0 にします。`SkillController::Register<T>()` は `NewGO<T>(T::PRIORITY, ...)` で作ります。攻撃が先に体を動かし、そのあとキャラクターがモデルの位置を合わせるので、1フレーム遅れて見えることがありません。

### AttackBase が書くこと

派生は、攻撃ごとの数値（`AttackData`）を返し、要るなら `OnSwing` を書きます。

```cpp
struct AttackData
{
    int clip;                    // 流すアニメーション。
    float chargeAt = -1.0f;      // この秒数のコマで止めて溜める。負なら溜めない。
    float chargeSeconds = 0.0f;  // 溜める秒数。
    const float* root = nullptr; // コマごとに前へ進んだ距離（モデルの m）。
    int rootNum = 0;
};

class AttackBase : public SkillBase
{
protected:
    virtual const AttackData& GetData() const = 0;
    virtual void OnSwing(float time) { (void)time; }   // 毎フレーム。斬撃を出すコマなどを見る。
private:
    bool UsesOwnerBody() const final { return true; }
    bool OnStart() final;          // 体がなければ false
    void OnActivate() final;       // 相手を向き、アニメーションを流す
    void OnSkillUpdate() final;    // 溜め → 踏み込み → OnSwing → 終わったら End()
    void OnCancel() final;         // 溜めで止めたアニメーションの速さを戻す
};
```

`OnSkillUpdate()` の中身は、今の `EnemyAttackState::Update()` の溜め・踏み込みをそのまま移したものです。時間は `g_gameTime->GetFrameDeltaTime() * body.timeScale` で進めます。

### EnemyAttackState は待つだけ

```cpp
EnemyStateId EnemyAttackState::CheckTransition(...) const
{
    if (EnemyGroundState::CheckDamage(context, false) == EnemyStateId::Dead) { return EnemyStateId::Dead; }
    if (context.skills->IsBusy()) { return EnemyStateId::Attack; }   // 攻撃が終わるまで
    return EnemyGroundState::SelectByInput(context, input);
}
void EnemyAttackState::Exit(EnemyStateContext& context)
{
    context.skills->CancelAll();   // 死んだときなど、途中で出るなら止める
}
```

`Update()` では何もしません（体を動かすのは攻撃）。`EnemyStateContext` に `SkillController* skills` を足します。

## 4. 使い方

### 攻撃を足す

1. `AttackBase` を継承し、`GetData()` で clip・溜め・進む距離の表を返す。
2. 斬撃などを出すなら `OnSwing(time)` を書く。
3. 持ち主の `OnStart()` で `m_skillController.Register<新しい攻撃>(ActionButton::...)`。

### AI に使わせる

入力元で、その攻撃のボタンを1フレーム押す（`input.Action(ActionButton::Action2).Update(true);`）。

## 5. 調整用の数値

| 数値 | 場所 | 今の値 |
|---|---|---|
| 攻撃1で溜める秒数 | `DashSlashAttack` の `CHARGE_SECONDS` | 0.6秒（今の `EnemyTuning::attack1ChargeSeconds`） |
| 攻撃1の溜めのコマ | `DashSlashAttack` の `AttackData::chargeAt` | Attack1 の 5.5コマ目（左腰に剣を構えてかがむ） |
| 攻撃3の斬撃を出すコマ・傾き | `SlashWaveAttack` | 今の `EnemyAttackState.cpp` の `ATTACKS[2]` と同じ |
| 斬撃を出す高さ・前へ出す距離 | `SlashWaveAttack` | 110・80 |

コマは 30fps で、クリップの先頭を 0コマ目と数えます。

## 6. 決めたこと

| 決めたこと | 理由 |
|---|---|
| 体の動きは攻撃が全部受け持つ | 1つの攻撃の中身が1クラスにまとまる。ほかのキャラクターにも同じ攻撃を登録できる |
| 攻撃の種類はボタンで分け、`attackIndex` をなくす | `SkillController` の「1つのボタンに1つのスキル」のままで済む |
| `IsOwnerBusy()` を派生で上書きせず、`UsesOwnerBody()` を答えさせる | 入力を受け取ったあとの判断を `SkillBase` の1か所に残すため |
| 攻撃は優先度0で作る | キャラクターより先に体を動かし、モデルが1フレーム遅れないようにする |
| 斬撃は今のまま、振るコマで1つずつ作る | 先に5つ作ると、待たせる仕組み・飛べと言う口・途中で止まったときの片付けが要り、重さも変わらない |
| 攻撃1の溜めの秒数を `EnemyTuning` から攻撃の定数へ移す | `EnemyTuning` を読んでいるのは攻撃1だけで、変える画面もないため |

## 7. 既知の課題

- 剣が当たったときのダメージはまだない（今と同じ）。
- 攻撃を作ったフレーム（N）は、攻撃もステートも体を動かさないので、1フレームだけ重力がかからない。
- 一人称の腕のように「攻撃した」を見る仕組みは、`SkillController::GetUseCount()` で足りる（今は使っていない）。

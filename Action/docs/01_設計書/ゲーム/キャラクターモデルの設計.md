# キャラクターモデルの設計

作成日: 2026-11-06
対象: `Game/Source/Character/CharacterModel.*`（ブランチ `feature/character-model`）

Player と Enemy のモデル・アニメーションの読み込みを、汎用の部品 `CharacterModel` にまとめたページです。

---

## 1. 方針

- **キャラクターが持つのはデータだけ**: どのモデル・アニメーションを使うかを `CharacterModelDesc` に書いて渡す。プレイヤー専用のクラスは作らない。
- **読み込みの決まりは部品に閉じ込める**: FBX の変換、リターゲット、「クリップを先に読む」決まりは `CharacterModel` だけが知っている。
- **Init は持ち主が呼ぶ**: ほかの部品（`CharacterMover` など）と同じく、Player・Enemy が自分の `Start()` で呼ぶ。

---

## 2. 全体の関係

```
 Player / Enemy（組み立て役）
   │  Start(): m_model.Init(MakeModelDesc())   ← Desc はそれぞれの .cpp に書いたデータ
   ▼
 CharacterModel ──持つ──▶ ModelRender ◀──参照── StatusEffects（凍結・燃焼の色）
   │                          ▲          ◀──参照── PlayerStateMachine（アニメーションの切り替え）
   │                          └──────────────参照── Player の剣（右手ボーン）
   └─ 読み込み時だけ使う ─▶ FbxRuntimeImporter（FBX→tkm、FBXアニメ→tka）
```

### 部品の一覧（誰が持ち、誰が Init を呼び、何を渡すか）

| 部品 | 持ち主 | Init を呼ぶ | 渡すもの | 何をするか |
|---|---|---|---|---|
| `CharacterModel` | Player・Enemy | 持ち主の `Start()` | `CharacterModelDesc`（モデル・向き・大きさ・クリップ） | モデルとアニメーションの読み込み・描画 |
| `CharacterMover` | Player・Enemy | 持ち主の `Start()` | `CharacterMoveSettings` | 移動・ジャンプ・重力 |
| `StatusEffects` | Player・Enemy | 持ち主の `Start()` | `CharacterModel` の `ModelRender` | 凍結・燃焼 |
| `HitTarget` | Player・Enemy | 持ち主の `Start()` | 自分・陣営・半径 | 弾に当たる判定 |
| `MagicCaster` | Player・Enemy | 持ち主の `Start()` | 自分・陣営・撃つ位置 | 魔法を撃つ |
| `PlayerStateMachine` | Player | Player の `Start()` | `CharacterMover` と `ModelRender` | 歩く・走るなどの切り替え |

### 初期化の順番

`StatusEffects`・ステート・剣は `ModelRender` を使うので、**`CharacterModel` を先に Init** します。

```cpp
m_mover.Init(MakeMoveSettings());
m_model.Init(MakeModelDesc());                    // ① モデル
InitSword();                                      // ② 右手ボーンを探す
m_statusEffects.Init(&m_model.GetModelRender());  // ③ 以降はモデルを使う部品
```

## 3. CharacterModel

コード: [CharacterModel.h](../../../Game/Source/Character/CharacterModel.h)、[CharacterModel.cpp](../../../Game/Source/Character/CharacterModel.cpp)

| 関数 | 呼ぶとき | 内容 |
|---|---|---|
| `Init(desc)` | `Start()` で1回 | クリップを読み込み、モデルを初期化する |
| `SetTransform(位置, 回転)` | 毎フレーム | 大きさは Desc で指定したもの |
| `Update()` / `Draw(rc)` | 毎フレーム | `ModelRender` にそのまま渡す |
| `PlayAnimation(番号, 補間秒)` | アニメーションを変えるとき | 番号は `clips` の添字 |
| `GetModelRender()` | ほかの部品に渡すとき | アニメーション速度・ボーン・状態異常の色など |

### CharacterModelDesc

| 項目 | 内容 | Player | Enemy |
|---|---|---|---|
| `modelPath` | `.tkm` か `.fbx` | `SK_Player.FBX` | `unityChan.tkm` |
| `upAxis` | モデルの上方向 | Z（3ds Max） | Y |
| `scale` | 大きさ | 1.128 | 1.08 |
| `clips` | クリップの一覧。添字が番号 | 4つ（全部 run の FBX、暫定） | idle・run の tka |

### Init の中でしていること

1. `clips` のパスが `.fbx` なら、モデルを tkm に変換して `.tks`（スケルトン）を作り、アニメーションをボーン名でリターゲットして `.tka` に変換する。変換結果は更新日時でキャッシュされる。
2. クリップをすべて読み込む。`ModelRender::Init` が中で 0 番を再生するので、**必ずモデルより先**に読む。
3. `ModelRender::Init` を呼び、影を落とす設定にする。

---

## 4. 新しいキャラクター・アニメーションを足す

| やりたいこと | すること |
|---|---|
| 新しいキャラクターにモデルを持たせる | `CharacterModel` をメンバーにし、`.cpp` に `MakeModelDesc()` を書いて `Start()` で `Init` する |
| アニメーションを足す | クリップ番号の enum に足し、`MakeModelDesc()` の `clips` に1行足す。FBX ならパスを書くだけでリターゲットされる |
| Player の暫定対応（全部 run）をやめる | Player の `MakeModelDesc()` で、各番号に正しいアニメーションのパスを入れる |

---

## 5. 既知の課題

- **Player のアニメーションは run だけ**: 旧 Sapphiart 用の idle/walk/jump はスケルトンが違って使えないため、全クリップに run を入れています。
- **Desc を外から渡す仕組みはない**: 見た目を差し替える必要（キャラクター選択など）が出たら、`MakeModelDesc()` の中身を外から渡す形にします。`NewGO` は引数を取れないので、`Start()` より前に Setter で渡す形になります。

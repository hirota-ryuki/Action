# 陣営と当たり判定の設計

作成日: 2026-11-05（`キャラクター入力・魔法・弾の設計.md` から分割）
対象: `Game/Source/Character/Faction.h`、`Game/Source/Character/HitTarget.*`

誰と誰が敵対しているか（陣営）と、弾などが当たる判定をまとめたページです。

- **当たるかどうかは陣営で決まる**: 弾・燃える床・AI の狙いは、すべて `IsHostile(a, b)` で判断する。
- **当たり判定は登録制**: キャラクターが `HitTarget` を持つと一覧に載り、弾は一覧から相手を探す。

---

## 1. Faction：陣営

コード: [Faction.h](../../../Game/Source/Character/Faction.h)

```
Player ─┐                ┌─ Enemy
        ├─ 敵対している ─┤
Ally ───┘                └─

Neutral … 誰とも敵対しない（弾も当たらない）
```

`IsHostile(a, b)` は、次のすべての判断に使います。
- 弾が当たるか
- 燃える床（`BurningGround`）が燃やすか
- AIが狙うか

---

## 2. HitTarget / HitTargetRegistry：当たり判定と、その一覧

コード: [HitTarget.h](../../../Game/Source/Character/HitTarget.h)、[HitTarget.cpp](../../../Game/Source/Character/HitTarget.cpp)

```
HitTarget（キャラクターがメンバーとして持つ）
  Init() したとき     → 一覧に登録
  デストラクタ        → 一覧から登録を解除
  持ち主が削除待ち    → 当たらない

HitTargetRegistry（一覧）
  FindHitOnSegment()   弾の通り道に、敵対する相手がいるか（撃った本人は除く）
  FindNearestHostile() 一番近い敵対する相手（AIの索敵）
  GetTargets()         全件（燃える床の範囲判定、デバッグ表示用）
```

当たったときの効果を受ける窓口は2つあります。

| 窓口 | 用途 |
|---|---|
| `SetStatusEffects()` | 弾などが状態異常（凍結・燃焼）をかける先（[状態異常の設計](状態異常の設計.md)） |
| `SetOnHit()` | 当たったことを持ち主に知らせる処理（ひるみ・反撃など、今後用） |

当たり判定は「弾の半径 + 相手の半径」の球で判定します。

| | 半径 | 足元からの中心の高さ |
|---|---|---|
| Player | 45 | 70 |
| Enemy | 45 | 60 |
| 氷の弾 | 10 | - |
| 炎の弾 | 14〜45（溜め具合による） | - |

---

## 3. 実装方法

### 味方・中立のNPCを作る

```cpp
Enemy* ally = NewGO<Enemy>(1, "ally");
ally->SetFaction(Faction::Ally);     // 敵を狙い、敵の弾が当たる
```

### 弾が当たる物を作る（キャラクター以外も同じ）

1. `HitTarget` をメンバーに持つ。
2. `Start()` で `m_hitTarget.Init(this, 陣営, 半径, 足元から中心までの高さ);`（一覧に登録される）。
3. 毎フレーム `m_hitTarget.SetPosition(足元の位置);`。
4. 必要なら、状態異常を受ける先を `SetStatusEffects()`、当たったときの処理を `SetOnHit()` で渡す。

登録の解除はデストラクタで自動に行われます。

### 陣営を足す

[Faction.h](../../../Game/Source/Character/Faction.h) の `Faction` に値を足し、`IsHostile()` に誰と敵対するかを書きます。弾・燃える床・AI はすべて `IsHostile()` を見ているので、ほかは変えなくて済みます。

---

## 4. 決めたこと

| 以前 | 今 |
|---|---|
| 弾の当たり判定が `QueryGOs<Enemy>` の決め打ちで、敵にしか当たらなかった | 陣営と登録制にして、味方・中立・敵を同じように扱える |
| 敵は弾を撃てなかった | 敵も同じ仕組みで氷魔法を撃つ |

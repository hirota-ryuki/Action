# 走りから止まる設計

作成日: 2026-11-07
対象: `Game/Source/PlayerState/PlayerStopState.*`、`PlayerRunState.h`、`Game/Assets/modelData/player/Animation/StopL.fbx`・`StopR.fbx`、`tools/UnrealScripts/stop_roto.json`

走っているときに移動の入力を離すと、すぐには止まらず、走っていた勢いで前へ滑りながら踏ん張って止まる（ザザっと止まる）しくみのページです。
ステート全体は [プレイヤーのステートの設計](プレイヤーのステートの設計.md)、モーションの作り方は [動画からアニメーションを作る設計](動画からアニメーションを作る設計.md) を見てください。

- **走り（Run）から入力を離したときだけ止まる動きを挟む**: 歩き（Walk）から離したときや、ダッシュの終わりは、今までどおりすぐ Idle へ移る。
- **モーションは原神の動画から作った通しの1本**: 「前の足を突っ張り、腰を落として滑る → 起き上がって立つ」。踏ん張る足ごとに StopL / StopR の2本がある。
- **踏ん張る足は、止まった瞬間の走りの足に合わせる**: 走りの中で、ちょうど前に着こうとしている足で踏ん張る。足が入れ替わって見えないようにするため。

---

## 1. 全体像

```
 Run ── 移動の入力を離した（足場あり）──▶ Stop ── stopSeconds たった ──▶ Idle
  ▲                                    │
  └──── 移動の入力がある（Walk / Run）────┤
                                       ├── ダッシュボタン ──▶ Dash
                                       └── ジャンプボタン・足場がない ──▶ Air
```

| 時間（秒） | クリップのコマ | 動き | 進む速さ |
|---|---|---|---|
| 0 〜 0.13 | f00〜f04 | 前の足を着き、上半身を起こしながら腰を落とす | 480 から まっすぐ下がる |
| 0.13 〜 0.47 | f04〜f14 | 前の足を突っ張り、後ろの膝をたたんだ低い姿勢のまま滑る | 同上。0.47秒で 0 になる（約112 進む） |
| 0.47 〜 1.0 | f14〜f30 | 後ろの足を引き寄せながら起き上がり、まっすぐ立つ | 0 |
| 1.0 〜 | — | Idle へ 0.3秒の補間で移る | 0 |

## 2. 実装方法

### Run から Stop へ

[PlayerRunState.h](../../../Game/Source/PlayerState/PlayerRunState.h) は、地面の共通ルールで `Idle` になるときだけ `Stop` を返します。

```cpp
PlayerStateId CheckTransition(const PlayerStateContext& context, const CharacterInput& input) const override
{
    const PlayerStateId next = PlayerGroundState::CheckTransition(context, input);
    if (next == PlayerStateId::Idle && context.settings.stopSeconds > 0.0f) {
        return PlayerStateId::Stop;
    }
    return next;
}
```

- ダッシュボタンを離して歩きに戻るとき（`Walk`）や、足場がないとき（`Air`）は、止まる動きを挟みません。
- `stopSeconds` を 0 にすると、前と同じくすぐ立ち止まります。

### どちらの足で踏ん張るか

Run は毎フレーム、走りのアニメーションの位置を `context.runAnimTime` に足していきます（入ったときは、ダッシュのあとの開始位置 `nextStartTimes[Run]` から）。
Stop に入ったら、走りの1周期（`runAnimSeconds` = 14コマ）の中で、`stopLRunTime`（左足が前に着く f09）と `stopRRunTime`（右足が前に着く f02）のどちらに近いかで、StopL か StopR を選びます。

| クリップ | 前へ突っ張る足 | 走りで近いところ | クリップの最初のコマ |
|---|---|---|---|
| StopL | 左 | f09（左足が前に着く） | 左足を前に着き、右足が後ろで浮いている |
| StopR | 右 | f02（右足が前に着く） | 右足を前に着き、左足が後ろで浮いている |

走りの最初のコマとクリップの最初のコマの形が近いので、補間は 0.1秒（`stopBlendSeconds`）と短くしています。

### 滑る速さ

[PlayerStopState.cpp](../../../Game/Source/PlayerState/PlayerStopState.cpp) は、入った瞬間の正面へ、走る速さ（`walkSpeed × runSpeedMultiplier`）から `stopSlideSeconds` かけて 0 までまっすぐ下げます。向きは変えません。

```cpp
const float mid = min(m_elapsed + deltaTime * 0.5f, slide);
speed = m_startSpeed * (1.0f - mid / slide);
```

フレームの真ん中の時間で速さを測るので、フレームレートが変わっても滑る距離（走る速さ × 時間 ÷ 2 ≒ 112）はほぼ同じです。

### Stop から出るとき

- 移動の入力が入ったら、`SelectByInput()` で Walk / Run にすぐ戻ります（止まるのをやめて走り出せる）。
- ダッシュ・ジャンプは、止まっている途中でもすぐ出せます。
- 出るときは `stopExitBlendSeconds`（0.3秒）で次のアニメーションへつなぎます。

## 3. モーション（StopL / StopR）

原神の動画（個人用 OneDrive の `02_Action参考資料/原神/`）の 29.78〜30.89秒（34コマ）を、[動画からアニメーションを作る設計](動画からアニメーションを作る設計.md) の手順で読み取って作りました。動画ではキャラクターが画面の左へ走っているので、`pose_to_angles.py` に `flip` を付けて左右を反転して読んでいます。

| ファイル | 内容 |
|---|---|
| [genshin_stop_pose.json](../../../tools/UnrealScripts/genshin_stop_pose.json) | 29.57〜30.95秒の角度（直したあと、ならしたもの）。使うのは 6コマ目から 34コマ |
| [stop_roto.json](../../../tools/UnrealScripts/stop_roto.json) | StopL / StopR を作る設定。2本は脚・腕の左右（`map`）を入れ替えただけ |

読み取りから手で直したこと:

| 直したこと | 理由 |
|---|---|
| 30.14秒からあとの脚の A・B を入れ替えた | MediaPipe が左右の脚を取り違えていた（前へ突っ張る足が途中で入れ替わっていた） |
| 29.91・29.94秒の前の足を、前後のコマから補間した | 前の足が後ろへ跳ね上がったように読み取られていた |
| 30.15〜30.25秒の後ろの足を、前後のコマから補間した | たたんだ足が体に隠れて、向きが乱れていた |
| コマごとに、低い方のつま先を地面（0）に合わせた | カメラが動いて、立ったときにつま先が脚の長さの 0.2〜0.3 浮いていた |

UE での設定は走りと同じく、胴体と首を 10° 前へ（`lean_deg`）、顔を 30° 起こし（`head_pitch_deg`）、高さはコマごとに一番低いつま先を 0.5cm に合わせます（`height: "toe"`）。走りの最初のコマとつながるよう、走りと同じ値にしています。

## 4. 使い方

### 滑る距離・止まるまでの時間を変える

`Player.cpp` の `MakeStateSettings()` の `stopSlideSeconds` を変えます。滑る距離は「走る速さ × stopSlideSeconds ÷ 2」です。
クリップは 0.47秒（f14）で低い姿勢から起き上がり始めるので、大きく変えるとクリップの動きと進み方がずれます。

### モーションを作り直す

```bash
T=$(cd Action/tools/UnrealScripts && pwd -W)
MSYS_NO_PATHCONV=1 "<UE_5.8>/Engine/Binaries/Win64/UnrealEditor-Cmd.exe" "<空の>.uproject" -run=pythonscript \
  "-script=$T/adjust_bone_rotation.py $T/stop_roto.json" -unattended -nop4 -nosplash -NullRHI
```

そのあとゲームを1回起動して `.tka` を作り直し、`.fbx` と `.tka` をコミットします。

## 5. 調整用の数値

| 内容 | 値 | 場所 |
|---|---|---|
| 止まるクリップを流す長さ | 1.0秒（f30、立ち上がったところ） | `Player.cpp` の `MakeStateSettings`（`stopSeconds`） |
| 滑る長さ | 0.47秒（f14）。約112 進む | 同上（`stopSlideSeconds`） |
| 走りから入る / 出るときの補間時間 | 0.1秒 / 0.3秒 | 同上（`stopBlendSeconds` / `stopExitBlendSeconds`） |
| 走りの1周期 / 左足・右足が前に着くところ | 14コマ / f09 / f02 | 同上（`runAnimSeconds` / `stopLRunTime` / `stopRRunTime`） |
| 使う動画の範囲 | 29.78〜30.89秒（34コマ） | `stop_roto.json`（`start: 6, count: 34`） |

## 6. 決めたこと

### 原神の動画から作った（2026-11-07）

「走ったあと慣性でザザっと止まるモーションを入れて」とのことでした。今の走り・ダッシュと同じく、原神の動画から作っています。動画の中で走りから止まる場面は 30秒・41秒・53秒・60秒あたりにあり、いちばん勢いよく滑って止まる 30秒の場面を使いました（41秒などは、数歩で歩くように止まる）。

| 候補 | 選ばなかった理由 |
|---|---|
| Idle へ長めに補間するだけ | 走りのポーズのまま滑って見え、踏ん張る感じが出ない |
| Run の骨の角度を足して作る | 前のダッシュで、途中の形とつなぎ目が作り込めなかった（[動画からアニメーションを作る設計](動画からアニメーションを作る設計.md) の「決めたこと」） |

### 歩きとダッシュのあとは止まる動きを挟まない

歩きは速さ 170 と遅く、滑って止まるほどの勢いがないためです。ダッシュの終わりは着地して走り出すポーズなので、ここから止まる動きを足すかは、遊んでみて決めます。

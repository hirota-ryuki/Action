# 魔法と弾の設計

作成日: 2026-11-05（`キャラクター入力・魔法・弾の設計.md` から分割し、サブの魔法を追記）
対象: `Game/Source/Magic/MagicBase.h`、`MagicCaster.*`、`BulletBase.*`

魔法と弾の共通の仕組み（基底クラスと、魔法を持って撃つ部品）をまとめたページです。
それぞれの魔法は [氷魔法の設計](氷魔法の設計.md)、[炎魔法の設計](炎魔法の設計.md) を見てください。

---

## 1. 役割の分け方

**魔法 =「どう撃つか」**、**弾 =「飛んで当たる物」** と役割を分けています。
こうすると、長押しの魔法を追加しても弾の側は変わりません。

```
MagicCaster ──ボタンの状態に応じて呼ぶ──▶ MagicBase（IceMagic・FireMagic など）
                                              │ 生成する
                                              ▼
                                         BulletBase（IceBullet・FireBullet など）
```

| クラス | 役割 | 足すときに継承する？ |
|---|---|---|
| `MagicCaster` | 魔法を持ち、ボタンに合わせて呼ぶ | しない（キャラクターが持つ部品） |
| `MagicBase` | どう撃つか（単発・溜め撃ちなど） | する |
| `BulletBase` | 飛ぶ・当たる・消える、の共通の流れ | する |

## 2. MagicBase：魔法の基底クラス

コード: [MagicBase.h](../../../../Game/Source/Magic/MagicBase.h)

| 関数 | 呼ばれるとき |
|---|---|
| `OnPress` | 発射ボタンを押した瞬間 |
| `OnHold` | 押している間、毎フレーム（押した瞬間のフレームも含む） |
| `OnRelease` | 離した瞬間 |
| `OnCancel` | 押している途中で中断されたとき（凍結した、魔法を切り替えた） |

撃ち方の違いは、どの関数を上書きするかで表します。

| 撃ち方 | 上書きする関数 | 例 |
|---|---|---|
| 単発 | `OnPress` で撃つ | [氷魔法](氷魔法の設計.md) |
| 溜め撃ち | `OnHold` で溜めて、`OnRelease` で撃つ。`OnCancel` で溜めを捨てる | [炎魔法](炎魔法の設計.md) |
| 出し続ける | `OnHold` の間ずっと出す | （まだない） |

クールダウンは `StartCooldown()` / `IsReady()` で管理します。

## 3. MagicCaster：魔法の所持・切り替え・発射

コード: [MagicCaster.h](../../../../Game/Source/Magic/MagicCaster.h)、[MagicCaster.cpp](../../../../Game/Source/Magic/MagicCaster.cpp)

魔法の持たせ方は2つあります。

| 持たせ方 | 撃つボタン | 切り替え | Player が持っているもの |
|---|---|---|---|
| `AddMagic()`（メイン） | `fire` | `magicSwitch` で順に切り替える | 氷魔法 |
| `SetSubMagic()`（サブ） | `subFire` | 切り替えの対象にならず、いつでも撃てる | 炎魔法 |

```
毎フレーム:
  全部の魔法（メイン・サブとも）のクールダウンを進める
  行動できない（凍結中など）→ 押している途中なら OnCancel して終わり
  magicSwitch があればメインの魔法を切り替える（押している途中なら OnCancel）
  メインの魔法に fire を、サブの魔法に subFire を、それぞれ次のように渡す
    押された瞬間   → OnPress
    押している間   → OnHold
    離された瞬間   → OnRelease
```

撃つ位置と向きの決め方:
- `hasAim` が true なら、入力の `aimOrigin` / `aimDirection`
- false なら、足元から `castHeight` の高さ、キャラクターの正面（水平）
- どちらの場合も、自分のカプセルに当たらないよう `castForward` だけ前に出す

## 4. BulletBase：弾の基底クラス

コード: [BulletBase.h](../../../../Game/Source/Magic/BulletBase.h)、[BulletBase.cpp](../../../../Game/Source/Magic/BulletBase.cpp)

共通の流れは基底クラスにあり、派生クラスから変えられないように `final` にしています。

```
Flying（飛翔中）
  毎フレーム、今の位置 → 次の位置 の線分で調べる
    ① 敵対する相手に当たった → NotifyHit → OnHitTarget → 着弾
    ② 地形に当たった（レイ判定） → 着弾
    ③ 射程を超えた               → 空中で着弾
    ④ どれでもない               → 進んで OnMove
        │
        ▼ 着弾（OnExplode）
Vanishing（演出待ち）
  IsVanishFinished() が true になったら自分を削除
```

派生クラスが書くのは次の5つの関数だけです。

| 関数 | 書くこと |
|---|---|
| `OnStart()` | エフェクトやモデルの読み込み。失敗したら false を返すとすぐ削除される |
| `OnMove()` | 位置が変わったとき、見た目を合わせる |
| `OnHitTarget()` | 敵対する相手に当たったときの効果 |
| `OnExplode()` | 着弾の演出（相手・地形・射程切れのすべてで呼ばれる） |
| `IsVanishFinished()` | 着弾後の演出が終わったか |

弾の性能は `BulletSettings`（速さ、射程、半径）で決めます。生成した直後なら `SetSettings()` で変えられます（炎の弾は溜め具合で半径を変えています）。
`owner`（撃った本人）は削除済みになっていることがあるので、**比較にだけ使い、中身には触れません**。

### 後片付け

弾は `BulletBase::kObjectName`（`"bullet"`）という名前で生成されます。
[Game.cpp](../../../../Game/Source/Core/Game.cpp) のデストラクタで、この名前の弾を種類を問わずまとめて削除します（燃える床 `BurningGround` も同じように削除します）。

## 5. 実装方法

### ボタンの状態を OnPress / OnHold / OnRelease に変える

```cpp
void MagicCaster::UpdateButton(MagicBase& magic, const ButtonState& button,
                               const MagicCastContext& context, bool& isHolding)
{
    if (button.isTrigger) {
        isHolding = true;
        magic.OnPress(context);
    }
    if (isHolding && button.isPress) {
        magic.OnHold(context);          // 押した瞬間のフレームも呼ばれる
    }
    if (isHolding && !button.isPress) {
        isHolding = false;
        magic.OnRelease(context);
    }
}
```

メインとサブで同じ関数を使い、それぞれ `m_isHolding` / `m_isSubHolding` を渡します。
「押している途中か」を自分で持っているので、凍結や切り替えのときに `isHolding` なら `OnCancel()` を呼べます。押していないときは `OnCancel()` を呼びません。

### 切り替えは剰余で端から端へ回り込む

```cpp
const int newIndex = ((index % count) + count) % count;   // -1 → 最後、count → 0
```

`%` は負の数で負を返すので、`count` を足してからもう一度 `%` をとっています。

### クールダウンは基底クラスの残り秒数

```cpp
virtual void Update(float deltaTime) { if (m_cooldown > 0.0f) { m_cooldown -= deltaTime; } }
bool IsReady() const { return m_cooldown <= 0.0f; }
void StartCooldown(float seconds) { m_cooldown = seconds; }   // protected
```

`MagicCaster` は選んでいない魔法も含めて毎フレーム `Update` を呼ぶので、切り替えている間もクールダウンは進みます。

### 弾：Start と Update を final にして、流れを基底クラスに固定する

```cpp
class BulletBase : public IGameObject {
public:
    bool Start() final;    // OnStart() を呼び、失敗なら次の Update で削除
    void Update() final;   // Flying / Vanishing の2状態
protected:
    virtual bool OnStart() { return true; }
    virtual void OnMove() {}
    virtual void OnHitTarget(HitTarget& target, const Vector3& hitPosition) {}
    virtual void OnExplode(const Vector3& hitPosition) {}
    virtual bool IsVanishFinished() const { return true; }
};
```

派生クラスは見た目と効果だけを書き、飛ぶ・当たる・消える順番は変えられません。

### 弾が1フレームに進む分を線分で調べる

```cpp
void BulletBase::UpdateFlying()
{
    const Vector3 nextPosition = m_position + m_direction * (m_settings.speed * deltaTime);

    // ① キャラクター（陣営で敵対している相手だけ。撃った本人は除く）
    if (HitTarget* hitTarget = HitTargetRegistry::FindHitOnSegment(
            m_position, nextPosition, m_settings.radius, m_faction, m_owner, hitPosition)) {
        hitTarget->NotifyHit(hitInfo);
        OnHitTarget(*hitTarget, hitPosition);
        Explode(hitPosition);
        return;
    }
    // ② 地形（物理ワールドへのレイ）
    if (physicsWorld->RayTest(m_position, nextPosition, hitPosition)) { Explode(hitPosition); return; }
    // ③ 進む。射程を超えたら空中で着弾
    m_position = nextPosition;
    m_flightDistance += moveDistance;
    if (m_flightDistance >= m_settings.range) { Explode(m_position); return; }
    OnMove();
}
```

キャラクターを地形より先に調べます。地形のレイはキャラクターのカプセルにも当たりますが、当たり判定の球の方が大きいので、狙って撃てば先にキャラクターとして当たります。

## 6. 使い方

### 新しい弾を作る

```cpp
class ThunderBullet : public BulletBase {
public:
    ThunderBullet() : BulletBase(MakeSettings()) {}   // 速さ・射程・半径を決める
protected:
    bool OnStart() override;                           // エフェクト読み込み
    void OnMove() override;                            // 見た目を位置に合わせる
    void OnHitTarget(HitTarget& target, const Vector3& pos) override;  // 命中時の効果
    void OnExplode(const Vector3& pos) override;       // 着弾演出
    bool IsVanishFinished() const override;            // 演出が終わったか
};
```

新しいエフェクトを使うときは、[EffectId.h](../../../../Game/Source/Core/EffectId.h) に番号を追加します。

### 新しい撃ち方の魔法を作る

`MagicBase` を継承し、上の表のとおりに関数を上書きします。キャラクターの `Start()` で持たせます。

```cpp
m_magicCaster.AddMagic(std::make_unique<ThunderMagic>());     // メイン（Q/E で切り替え）
// または
m_magicCaster.SetSubMagic(std::make_unique<ThunderMagic>());  // サブ（右クリック）
```

メインの魔法が2つ以上になれば、Q/E キーやパッドの LB/RB で切り替えられます。

## 7. 調整用の数値

撃つ位置（`MagicCaster::Settings`、各キャラクターの `MakeCasterSettings`）です。

| 設定 | Player | Enemy |
|---|---|---|
| `castHeight` | 70 | 60 |
| `castForward` | 60 | 60 |

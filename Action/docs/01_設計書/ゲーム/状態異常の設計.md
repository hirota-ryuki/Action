# 状態異常の設計

作成日: 2026-11-05（`キャラクター入力・魔法・弾の設計.md` から分割し、燃焼を追記）
対象: `Game/Source/Character/StatusEffects.*`

キャラクターにかかる状態異常（凍結・燃焼）をまとめたページです。

---

## 1. StatusEffects

コード: [StatusEffects.h](../../../Game/Source/Character/StatusEffects.h)、[StatusEffects.cpp](../../../Game/Source/Character/StatusEffects.cpp)

キャラクターがメンバーとして持つ部品です。Player も Enemy も持っているので、**どちらも凍るし、燃える**。

| 関数 | 内容 |
|---|---|
| `Init(modelRender)` | 見た目を変えるモデル。nullptr なら見た目は変えない |
| `Update(deltaTime)` | 残り時間を進め、色を変える |
| `Freeze(seconds)` | 凍らせる。凍結中にもう一度呼ぶと、残り時間の長い方で上書きする |
| `Burn(seconds)` | 燃やす。燃焼中にもう一度呼ぶと、残り時間の長い方で上書きする |
| `IsFrozen()` / `IsBurning()` | 今その状態か |
| `CanAct()` | 移動・攻撃などの行動ができるか（今は「凍っていない」こと） |

外には `CanAct()` だけを伝え、移動を止めるのは持ち主の側で行います。
- Player: 行動できなくなると `PlayerFrozenState` になる（[プレイヤーのステートの設計](プレイヤーのステートの設計.md)）
- Enemy: 空の入力を `CharacterMover` に渡す
- 魔法: `MagicCaster::Update` に `canAct` を渡すと、溜めている途中なら取り消す

## 2. 凍結

| タイミング | 見た目 |
|---|---|
| 凍った瞬間 | モデルを水色にし、アニメーションを止める（その瞬間のポーズで固まる） |
| 解ける直前（0.4秒） | 元の色へなめらかに戻す |
| 解けた | アニメーションを動かす |

凍結時間は、かけた側（[氷魔法](氷魔法の設計.md)では2.5秒）が決めます。

## 3. 燃焼

| タイミング | 見た目 |
|---|---|
| 燃えている間 | モデルを赤〜橙にし、色の強さを揺らして炎が当たっているように見せる |
| 消える直前（0.4秒） | 元の色へなめらかに戻す |

燃焼は行動を止めません。体力ができたら、継続ダメージにつなげる想定です。
燃焼をかけるのは、[炎魔法](炎魔法の設計.md)の燃える床（`BurningGround`）です。

## 4. 凍結と燃焼は打ち消し合う

- 凍っているときに燃やすと、**解凍される**（そのあと燃える）
- 燃えているときに凍らせると、**火が消える**（そのあと凍る）

---

## 5. 実装方法

### 新しい状態異常を作る（例: 毒）

`StatusEffects` に、凍結・燃焼と同じ形で足します。

1. 残り時間のメンバーを足す（例: `m_poisonTimer`）。
2. かける関数（`Poison(seconds)`）と、今その状態かを返す関数（`IsPoisoned()`）を足す。
3. `Update()` で残り時間を進め、見た目（色）を変える。
4. 行動を止めるものなら `CanAct()` の条件に含める。Player はそれだけで `PlayerFrozenState` に入る。
5. 弾などからかけるときは、`HitTarget::GetStatusEffects()` で受け取った先に対して呼ぶ。

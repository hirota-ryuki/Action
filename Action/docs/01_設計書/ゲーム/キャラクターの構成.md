# キャラクターの構成

作成日: 2026-11-05（2026-11-06 に構成を見直し）
対象: `Game/Source/Objects/Player.*`、`Game/Source/Objects/Enemy.*`、`Game/Source/Character/`

Player と Enemy が**どの部品を持ち、誰が初期化し、1フレームにどの順で呼ぶか**をまとめた入口のページです。
部品ごとの詳しいことは、表の「ページ」から各ページへ進んでください。

- **キャラクターは入力を受け取って動くだけ**: パッド・マウス・AI のことは知らない。
- **継承より部品の組み合わせ**: Player と Enemy に基底クラスはない。共通の処理は部品にして両方に持たせる。
- **キャラクターに残すのはデータと組み立てだけ**: 調整値やモデルのパスは `Make〇〇()` に書き、処理は部品が持つ。

---

## 1. 全体像

```
 入力元（IInputSource）  PlayerInputSource（パッド・キーボード・マウス） / NpcInputSource（AI）
            │ CharacterInput（そのフレームの入力の値）
            ▼
   Player ／ Enemy  ← 組み立て役。部品を持ち、Init して、毎フレーム順に呼ぶ
            │
            ├─ PlayerStateMachine   （Player だけ）歩く・走る・跳ぶなどの切り替え
            ├─ CharacterModel       見た目（モデル・アニメーション）
            ├─ CharacterMover       移動・ジャンプ・重力
            ├─ StatusEffects        凍結・燃焼
            ├─ HitTarget            弾に当たる判定と陣営
            └─ MagicCaster          魔法を撃つ
```

### 部品の一覧

| 部品 | 役割 | 持ち主 | Init で渡すもの | ページ |
|---|---|---|---|---|
| `IInputSource` | そのフレームの入力を作る | 両方（差し替えできる） | -（Init なし） | [入力の設計](入力の設計.md) |
| `PlayerStateMachine` | 立ち止まる・歩く・走る・空中・ダッシュ・凍結の切り替え | Player | `CharacterMover`・`ModelRender`・`StatusEffects`・数値 | [プレイヤーのステートの設計](プレイヤーのステートの設計.md) |
| `CharacterModel` | モデルとアニメーションの読み込み・描画 | 両方 | `CharacterModelDesc`（モデル・向き・大きさ・クリップ） | [キャラクターモデルの設計](キャラクターモデルの設計.md) |
| `CharacterMover` | 移動・ジャンプ・重力・向き | 両方 | `CharacterMoveSettings` | このページの 4章 |
| `StatusEffects` | 凍結・燃焼 | 両方 | `ModelRender`（色を変える先） | [状態異常の設計](状態異常の設計.md) |
| `HitTarget` | 弾に当たる判定と陣営 | 両方 | 自分・陣営・半径・高さ | [陣営と当たり判定の設計](陣営と当たり判定の設計.md) |
| `MagicCaster` | 魔法を持ち、切り替えて撃つ | 両方 | 自分・陣営・撃つ位置 | [魔法と弾の設計](魔法と弾の設計.md) |

### ファイル構成

```
Game/Source/
├── Character/      キャラクターの部品（入力・見た目・移動・状態異常・陣営・当たり判定）
├── PlayerState/    プレイヤーのステート
├── Magic/          魔法と弾
└── Objects/
    ├── Player.*    プレイヤー（組み立て役）
    └── Enemy.*     敵・NPC（組み立て役）
```

## 2. 初期化（Start）

Init はすべて**持ち主が自分の `Start()` で呼びます**。順番の決まりは1つだけです。

> **`CharacterModel` を、`ModelRender` を使う部品（剣・`StatusEffects`・ステート）より先に Init する。**

```cpp
// Player::Start()
m_mover.Init(MakeMoveSettings());
m_model.Init(MakeModelDesc());                    // ① モデル
InitSword();                                      // ② 以降はモデルを使う
m_statusEffects.Init(&m_model.GetModelRender());
m_stateMachine.Init(stateContext);
m_hitTarget.Init(this, Faction::Player, ...);
m_magicCaster.Init(this, Faction::Player, MakeCasterSettings());
```

## 3. 1フレームの流れ（Update）

コード: [Player.cpp](../../../Game/Source/Objects/Player.cpp)、[Enemy.cpp](../../../Game/Source/Objects/Enemy.cpp)

| 順 | Player | Enemy |
|---|---|---|
| ① 入力 | `m_inputSource->Update()` | 同じ |
| ② 状態異常 | `m_statusEffects.Update()` | 同じ |
| ③ 移動・アニメーション | `m_stateMachine.Update()`（凍結中は Frozen ステート） | 行動できれば `m_mover.Update(input)` とアニメーションの切り替え。凍結中は空の入力で重力だけ |
| ④ 魔法 | `m_magicCaster.Update()` | 同じ |
| ⑤ 落下 | 落ちたらリスポーン | - |
| ⑥ 位置を合わせる | 当たり判定・モデル・剣 | 当たり判定・モデル |

Enemy は立ち止まるか歩くだけなので、ステートを持たずに入力どおり動かします。

## 4. CharacterMover：移動

コード: [CharacterMover.h](../../../Game/Source/Character/CharacterMover.h)、[CharacterMover.cpp](../../../Game/Source/Character/CharacterMover.cpp)

`CharacterController` を包み、移動・ジャンプ・重力・向きを処理します。使い方が2通りあります。

| 使い方 | 関数 | 使っているところ |
|---|---|---|
| 入力どおりに動かす | `Update(input)` | Enemy |
| 1つずつ操作する | `Move`・`MoveByInput`・`Jump`・`FaceTo` | Player のステート |

- どちらでも、1フレームに `Move` 系を**1回だけ**呼ぶ（重力はそこでかかる）。
- 向き（`MoveByInput`）: `lookDirection` があればそちら、なければ移動方向を向く。

| 設定（`CharacterMoveSettings`） | Player | Enemy |
|---|---|---|
| `walkSpeed` | 170 | 140 |
| `runSpeedMultiplier` | 480 / 170（走る速さが 480 になる） | 1.0（走れない） |
| `jumpSpeed` | 400 | 0（跳べない） |
| `gravity` | 980 | 980 |
| カプセルの半径 / 高さ | 20 / 100 | 20 / 100 |

## 5. Player・Enemy に残っている処理

| クラス | 固有の処理 |
|---|---|
| [Player](../../../Game/Source/Objects/Player.h) | 剣を右手のボーンに追従させる、落下時のリスポーン（Y < -1000）、一人称で体を消す |
| [Enemy](../../../Game/Source/Objects/Enemy.h) | 移動に合わせたアニメーションの切り替え、陣営の設定（`SetFaction`） |

どちらも、そのほかは `Make〇〇()` に書いた調整値・モデルのデータだけです。

## 6. 実装方法

### 部品はメンバー変数として値で持つ

```cpp
// Player.h
PlayerInputSource m_playerInputSource;
IInputSource* m_inputSource = &m_playerInputSource;  // 差し替えられるものだけポインタ
CharacterInput m_input;
CharacterMover m_mover;
CharacterModel m_model;
StatusEffects m_statusEffects;
HitTarget m_hitTarget;
MagicCaster m_magicCaster;
PlayerStateMachine m_stateMachine;
```

- `new` しないので、部品の寿命は持ち主と同じ。後片付けを書かなくてよい。
- 入力元だけはポインタにして、既定の入力元を指しておく。`SetInputSource(nullptr)` は既定に戻す。

### 調整値は .cpp の無名名前空間の関数に書く

```cpp
namespace
{
    CharacterMoveSettings MakeMoveSettings()
    {
        CharacterMoveSettings settings;
        settings.walkSpeed = 170.0f;
        settings.runSpeedMultiplier = 480.0f / 170.0f;
        ...
        return settings;
    }
}
m_mover.Init(MakeMoveSettings());  // Start() で渡す
```

部品の側は既定値つきの構造体だけを持ち、キャラクターごとの数値は持ち主の .cpp にまとめています。

### CharacterMover：横の速さは毎フレーム上書きし、縦の速さだけ持ち越す

```cpp
void CharacterMover::Move(const Vector3& horizontalVelocity, float deltaTime)
{
    m_moveSpeed.x = horizontalVelocity.x;          // 横はそのフレームの値で上書き
    m_moveSpeed.z = horizontalVelocity.z;
    m_moveSpeed.y -= m_settings.gravity * deltaTime; // 縦は前のフレームから重力で減らす
    m_position = m_charaCon.Execute(m_moveSpeed, deltaTime);
    if (m_charaCon.IsOnGround()) {
        m_moveSpeed.y = 0.0f;                      // 着地したら縦の速さを捨てる
    }
}
```

- `Jump()` は `m_moveSpeed.y` に初速を入れるだけ。次の `Move()` から重力で減っていく。
- 重力をかけるのは `Move()` の中だけなので、「1フレームに `Move` 系を1回だけ」が決まりになる。

### 剣：右手のボーンから毎フレーム位置を計算する

```cpp
rightHandBone->CalcWorldTRS(swordPosition, swordRotation, handScale);
Vector3 offset = kSwordOffset;
swordRotation.Apply(offset);          // 手の向きに合わせてずらす
swordPosition += offset;
swordRotation = offsetRotationX * offsetRotationY * offsetRotationZ * swordRotation;  // 剣のモデルの向きを補正
m_swordModelRender.SetTRS(swordPosition, swordRotation, kSwordScale);
```

右手のボーンは名前で探し、見つからなければ別名で探し直します（モデルによって名前が違うため）。

### リスポーン：高さだけを見る

`Y < -1000` になったら、`Start()` のときに覚えた位置に戻し、速さを消し（`m_mover.Stop()`）、ステートを最初に戻します（`m_stateMachine.Reset()`）。

何かを足すときに触る場所です。手順は各ページの「使い方」にあります。

| やりたいこと | 触る場所 | ページ |

| 新しい種類のキャラクター | Player・Enemy を手本に、1章の部品から必要なものを選んでメンバーにする。Init は2章の順番で | このページ |
| プレイヤーの新しい動き | `PlayerState` を継承する | [プレイヤーのステートの設計](プレイヤーのステートの設計.md) |

## 8. 決めたこと

### 基底クラスを作らなかった

- 基底クラスに処理を集めると、キャラクターの種類が増えるたびに大きくなりやすい。
- 部品ごとなら、単独で読める・直せる・確かめられる。
- 味方NPCは `Enemy` の陣営を変えるだけで作れる。別のキャラクターも、必要な部品を選んで持たせるだけで作れる。

### ダッシュは CharacterMover に入れない

Player だけの動きなので、Player のステート（`PlayerDashState`）に置いています。

---

## 9. 既知の課題

- **ダメージ・HP はまだない**: `HitTarget::SetOnHit` を使うか、`StatusEffects` の隣に体力の部品を足す想定。
- **デバッグ表示はまだない**: `GetInput()`（入力）、`GetStateName()`（Player のステート）、`HitTargetRegistry::GetTargets()`（当たり判定の一覧）で値は取れる。

# 前提知識

作成日: 2026-11-16
対象: 手順書・設計・経緯を読む人

手順書などを読む人が、もう知っていることの一覧です。手順書の「初めて出てくる名前」の表は、ここに書いた知っている度合いに合わせて書きます。

| 度合い | 手順書の表 |
|---|---|
| よく知っている（1・2 のサイトと、3 の「よく知っている」） | 載せない |
| まあまあ | 載せる。1行で短く |
| 怪しい | 載せる。何をするかをはっきり書く |
| 微妙 | 載せる。何をするかに、そのコードでの具体的な値や例を添える |
| 導入方法を知らない | 使い方は載せない。導入（プロジェクトへの組み込み・設定）を書く手順では、省かずに書く |
| ここにない | 知らない前提で載せる |

- 知っていることが増えたら、下の「3. その他に知っている技術」に書き足す。度合いが上がったら、その段に移す。
- サイトの概要は、そのサイトに出てくる技術名だけを並べる（2026-11-16 に読んだ内容）。

## 1. プログラミング言語(C++)

https://hogehoge0125.wixsite.com/my-site

- 0〜1: C++ とは、Visual Studio・コンソールアプリ・F5・Ctrl+F5
- 2. 文字の出力: `#include <iostream>`・`using namespace std`・`int main()`・`cout`・`<<`・`endl`・`\n`・コメント（`//`・`/* */`）
- 3. 変数: `int`・`float`・`double`・代入（`=`）・四則計算・`12.34f`
- 4. 文字の入力: `cin`・`>>`・`string`
- 5. if 文: `if`・`else`・関係演算子（`>`・`==`・`<=`・`!=`）・論理演算子（`&&`・`||`）・`true`・`false`
- 6. switch 文: `switch`・`case`・`default`・`break`・`char`・列挙型
- 7. for 文と while 文: `for`・`while`・`while(true)`・`i++`・`else if`
- 8. 配列: 配列・`sizeof`・2次元配列
- 9. 関数: `void`・`return`・引数・戻り値・早期リターン
- 10. ローカル変数とグローバル変数
- 11. クラスとインスタンス: クラス・メンバ変数・メンバ関数・インスタンス・`new`
- 12. 乱数: `rand()`・`srand(time(nullptr))`・`%`
- 13. ポリモーフィズム: 継承（`: public`）・基底クラス・派生クラス・オーバーロード・オーバーライド・`virtual`・`override`・カプセル化・抽象化・`NewGO` の仕組み
- 14. メモリとポインタ: アドレス・ポインタ（`int*`・`&`・`*`）・値渡し・参照渡し・16進数
- 挑戦状など: `namespace`・バブルソート・`swap` 関数

### よく知っている用語

設計・経緯の「用語」の表には載せない言葉です。

| 用語 | 何のことか |
|---|---|
| コンストラクタ・デストラクタ | クラスのインスタンスを作るとき・消すときに、自動で呼ばれる関数 |
| ラジアン | 角度の単位。180度が π（約 3.14）ラジアン |
| FBX・tkm・tks | モデルのファイル。FBX は多くの道具で使える形、tkm は k2Engine のモデル、tks は k2Engine の骨格（スケルトン） |
| Blender・UE・Mixamo・VRoid・Meshy | モデルやアニメーションを作る道具。Blender は 3D のモデル作り、UE（Unreal Engine）はゲームエンジン、Mixamo はアニメーションの配布サイト、VRoid は人型のモデル作り、Meshy は AI でモデルを作るサービス |
| 法線 | 面や頂点が向いている方向（長さ 1 のベクトル）。光の当たり方の計算に使う |
| 正規化 | ベクトルの向きはそのままで、長さを 1 にすること |
| シェーダー・HLSL | GPU で動く、頂点の位置やピクセルの色を計算するプログラム（頂点シェーダー・ピクセルシェーダー）。HLSL はそれを書く言語 |
| 頂点・テクスチャ・マテリアル・メッシュ・UV | モデルを作っているもの。頂点は点、メッシュは頂点と三角形の集まり、テクスチャは貼る画像、マテリアルは色や画像などの見た目の設定、UV は画像のどこを貼るかの座標 |
| ボーン（骨）・スケルトン（骨格）・ワールド行列 | ボーンはモデルを動かす関節、スケルトンはボーンのつながり全体。ワールド行列は、位置・向き・大きさを、ゲーム全体で共通の座標で表した行列 |
| 補間 | 2つの値の間の、途中の値を計算してつなぐこと。アニメーションの切り替えでは、2つのポーズをなめらかに混ぜる（ブレンド） |
| 深度・シャドウマップ | 深度は、ピクセルがカメラからどれだけ奥にあるかの値。シャドウマップは、光から見た深度を描いた画像で、影になるかを調べるのに使う |
| JSON | 値の名前と中身を `{ }` の中に並べて書く、人にも読めるデータの書き方 |
| GPU・Debug・Release | GPU は絵を描く計算をする部品。Debug・Release はビルドの種類で、Debug は調べやすく遅い、Release は速い |
| リターゲット・IK | リターゲットは、ほかのモデル用のアニメーションを、骨格の違うモデルに移すこと。IK は、手や足の先の位置を決めて、そこに届くように関節の角度を計算すること |
| git worktree | 1つのリポジトリから、別のブランチを開いた作業用のフォルダを作る git の機能 |
